#정보관리기술사 #프로젝트관리 #QC7 #품질통제 #통계적품질관리 #NEW
## 정의
품질통제도구 QC7
- 품질 개발·개선·관리 활동에 유용하며 데이터 정리의 기본이 되는 도구
- 품질관리에 가장 필수적인 통계적 방법 집합
## 키워드
* 체크시트, 파레토, 히스토그램, 관리도, 특성요인도, 산점도, 층별
## 암기법
* 현원자·체파히·특산층·관: 현상(체·파·히)·원인(특·산·층)·자료(관)
## 특징
- 현상파악: 체크시트·파레토·히스토그램으로 누락방지·우선순위·분포 파악
- 자료관리: 관리도(UCL·CL·LCL)로 공정 통계적 안정 상태 판정
- 원인분석: 특성요인도·산점도·층별로 인과·상관·요인 분리
- 기본 통계도구: 현장·프로젝트 품질문제의 가시화·우선순위화에 적합
## 목적
- 품질 데이터의 수집·정리·분석으로 문제의 현상·원인 규명
- 공정 안정성 유지 및 개선 우선순위 결정
## 구성요소
- 체크시트: 점검·수집 시 누락·오류 방지용 기록표
- 파레토 차트: 발생빈도 순 정렬로 문제 집중·우선순위 파악
- 히스토그램: 구간별 도수로 데이터 분포 형태 파악
- 관리도: UCL/CL/LCL로 공정이 통계적 관리상태인지 판정
- 특성요인도(어골도): 결과(특성)와 원인(Man·Machine·Material·Method·Environment) 관계
- 산점도: 두 변수(원인·결과) 상관(정·부·무) 시각화
- 층별: 데이터를 관련 부분집단으로 나눠 품질 영향 요인 규명
## 구성도
```
[QC7]
 ├─ 현상파악: Check Sheet / Pareto / Histogram
 ├─ 자료관리: Control Chart (UCL─CL─LCL)
 └─ 원인분석: Fishbone / Scatter / Stratification
```
