## 정의
DHP(Direct Hashing & Pruning)
- 많은 후보 항목 생성으로 인한 계산 비용 증가를 막기 위해 해싱과 가지치기로 빠르게 빈발 항목집합을 탐색하는 연관 분석 기법
## 키워드
* 가지치기(Pruning), 해시 테이블(Hash Table), 후보 축소
## 암기법
* 해가지: 해싱·가지치기
## 특징
- Apriori 개선: 해시 카운트로 비빈발 후보 사전 제거
- 후보 집합 크기 감소 → Apriori보다 빠른 계산
## 목적
- 후보 폭증을 억제하며 빈발 항목집합을 효율적으로 탐색
## 구성요소
- ① Frequent 1-itemset 생성(최소 지지도)
- ② (k+1) 후보 생성
- ③ 해시 함수로 버킷 매핑·카운트 누적
- ④ 저카운트 버킷 가지치기
- ⑤ 필터된 후보로 DB 재스캔 → Frequent (k+1) 결정
- ⑥ 최대 빈발 항목집합 추출
## 구성도
```
dataset → Frequent(k=1)
  → (k+1)후보 → Hash Bucket 매핑·카운트
  → 저빈도 가지치기 → Frequent(k+1)
```
