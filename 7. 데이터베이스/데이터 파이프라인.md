#정보관리기술사 #데이터베이스 #데이터파이프라인 #DataPipeline
## 정의
데이터 파이프라인(Data Pipeline)
- 다양한 데이터 소스의 Raw Data를 수집·변환·적재(ETL/ELT)하여 분석 가능한 형태로 전달하는 자동화 워크플로우 체계
- 기업용 AI·분석을 위한 데이터 활용 핵심 인프라
## 키워드
* ETL/ELT, Workflow, Airflow, Data Lake/Warehouse, Lineage, MLOps
## 암기법
* 수인품라마: 수집·인프라·품질·라벨링·마켓플레이스
## 특징
- 자동화성: 수집~적재~분석 자동 워크플로우
- 다양성: 정형·반정형·비정형 통합 처리
- 신뢰성: 검증·정제로 품질 보장
- 확장성: 배치·스트리밍 모두 지원
## 목적
- 데이터 활용을 위한 신뢰성 있는 정제 데이터 제공
- AI·분석·BI 활용을 위한 단일 데이터 흐름 구축
## 구성요소
- 등장 배경: 기업용 AI 발전, 데이터 활용 핵심 인프라
- 데이터 수집: 데이터 추출, 데이터 파싱, 다중 소스 통합, 데이터 적재
- 데이터 인프라: 처리 엔진, 데이터 저장소, 컴퓨팅 인프라, 플랫폼 환경
- 데이터 품질 관리: 검증, 정제, 표준화, 품질 모니터링
- 데이터 라벨링: 스키마 정의, 피처 생성, 데이터 변환, 자동 라벨링
- 마켓플레이스: 워크플로우 관리, 시스템 모니터링, 접근 제어, 인터페이스 제공
- 사례: 팔란티어(빅데이터 통합), AWS(클라우드 데이터 인프라), 오라클(자율 운영 DB), 크라우드웍스(국내 크라우드소싱), NIA AI 허브(국가 AI 데이터 플랫폼)
## 구성도
```
[Source] DB·API·IoT·Log
   ↓ 수집
[Staging] 검증·정제·표준화·라벨링
   ↓ 변환
[Data Warehouse / Lake / Lakehouse]
   ↓ 서빙
[BI · AI/ML · Marketplace] (모니터링·접근제어·리니지 환류)
```
