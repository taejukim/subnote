#데이터베이스 #함수적종속성 #정규화 #필수 #데이터베이스/정규화
## 정의
속성 간 결정 관계, FD
- 릴레이션에서 속성 X의 값이 속성 Y의 값을 유일하게 결정하는 제약 관계(X→Y)
- X를 결정자(Determinant), Y를 종속자(Dependent)라 하며 정규화의 이론적 기반
## 키워드
* 결정자(Determinant): 다른 속성을 결정하는 속성
* 종속자(Dependent): 결정자에 의해 결정되는 속성
* 완전함수종속(Full FD): 기본키 전체에 종속
* 부분함수종속(Partial FD): 기본키 일부에 종속
* 이행함수종속(Transitive FD): X→Y, Y→Z ⇒ X→Z
## 암기법
* "완부이" - 완전/부분/이행 함수종속
* "결종" - 결정자가 종속자를 결정
* "2부3이" - 2NF는 부분종속 제거, 3NF는 이행종속 제거
## 구성요소/특징/유형
### 함수적 종속성 유형

| 종속성구분                | 주요개념                                                                                                                                                                        |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **완**전 함수 종속         | – Full Functional Dependency<br>– 기본 키에만 종속되는 모두 구성되는 FD 관계<br>– X'⊂X 이고 X'→Y 를 만족하는 애트리뷰트 X'이 존재하지 않음                                                                      |
| **부**분 함수 종속 (2NF)   | – partial functional dependency<br>– X'⊂X 이고 X'→Y 를 만족하는 애트리뷰트 X'이 존재<br>– 부분 키가 종속성을 가지고 있음                                                                                |
| **이**행함수 종속 (3NF)    | – Transitive Dependency<br>– 릴레이션 R에서 속성 A→X이고 X→Y이면 A→Y임<br>– 키가 아닌 기본속성에서 종속성이 존재                                                                                         |
| **결**정자함수 종속성 (BCNF) | – Boyce-Code Normalization<br>– 함수적 종속이 되는 결정자가 후보키가 아닌 경우<br>– 즉, X→Y에서 X가 후보키가 아님<br>– 키에서 종속성이 존재                                                                        |
| **다**중값 종속성 (4NF)    | – MVD: Multi-Valued Dependency<br>– 한 관계에 둘 이상의 독립적 다중값 속성이 존재하는 경우<br>– X, Y, Z 세개의 속성을 가진 릴레이션 R에서 속성쌍 [X, Z] 값에 대응하는 Y값의 집합이 X값에만 종속되고 Z값에는 독립이면 Y는 X에 다중값 종속. X->>Y로 표기 |
| **조**인종속성 (5NF)      | – Adjoin Dependency<br>– 관계 중에서 둘로 나눌 때는 원래의 관계로 회복할 수 없으나, 셋 또는 그 이상으로 분리시킬 때 원래의 관계 복원 가능한 특수한 경우임                                                                        |

### Armstrong 공리
| 공리 | 설명 |
|------|------|
| 반사성(Reflexivity) | Y⊆X이면 X→Y |
| 첨가성(Augmentation) | X→Y이면 XZ→YZ |
| 이행성(Transitivity) | X→Y, Y→Z이면 X→Z |
### 추가 규칙
- 분해(Decomposition): X→YZ이면 X→Y, X→Z
- 합집합(Union): X→Y, X→Z이면 X→YZ
- 의사이행(Pseudotransitivity): X→Y, WY→Z이면 WX→Z
## 구성도
```
┌─────────────────────────────────────────────────────────────┐
│                    함수적 종속성 유형                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 완전함수종속 (Full FD)                                  │
│     ┌─────────────┐                                         │
│     │ 학번 + 과목 │ ──────→ 성적                            │ 
│     └─────────────┘   (전체 키에 종속)                      │
│                                                             │
│  2. 부분함수종속 (Partial FD) - 2NF에서 제거                │
│     ┌─────────────┐                                         │
│     │ 학번 + 과목 │                                         │
│     └──────┬──────┘                                         │
│            │                                                │
│         학번 ──────→ 학과 (일부 키에 종속)                  │
│                                                             │
│  3. 이행함수종속 (Transitive FD) - 3NF에서 제거             │
│     학번 ──→ 학과 ──→ 학과장                                │
│       └────────────────→ (이행적 종속)                      │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                  Armstrong 공리 체계                        │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐                 │
│  │ 반사성   │   │ 첨가성   │   │ 이행성   │                 │
│  │ Y⊆X→X→Y  │   │ X→Y      │   │ X→Y,Y→Z  │                 │
│  │          │   │ ⇒XZ→YZ   │   │ ⇒X→Z     │                 │
│  └──────────┘   └──────────┘   └──────────┘                 │
└─────────────────────────────────────────────────────────────┘
```
