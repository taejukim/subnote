#정보관리기술사 #데이터베이스 #상호운용성 #데이터이동권 #MyData #NEW
## 정의
데이터 상호운용성(Data Interoperability)
- 서로 다른 시스템 간 데이터 의미·구조를 동일하게 해석하여 교환·공유·활용 가능하게 하는 능력
데이터 이동권(Right to Data Portability)
- 정보주체가 자신의 데이터를 다른 서비스 제공자에게 직접 전송·이전 요구할 수 있는 권리
## 키워드
* MDR, Metadata, API, JSON, XML, MyData, ISO 11179, ISO 19941
## 암기법
* 기구의: Technical·Syntactic·Semantic·Organizational
## 특징
- 상호운용성: 시스템 간 공유, 표준화 중심
- 이동권: 개인정보 이전, 개인 권리 중심
- 4유형: Technical(API), Syntactic(JSON/XML), Semantic(MDR), Organizational(Governance)
## 목적
- AI 생태계 데이터 연계·활용 기반
- 데이터 주권·MyData 활성화
## 구성요소
- 절차: Data Source → 표준화 → 상호운용 → 이동권(MyData/API) → AI Service
- 이동권: 이전요청(본인확인) → 전송(표준·API) → 검증·완료
- 표준: ISO 11179(메타), 19941(클라우드), 23053(AI), 25000(품질)
## 구성도
```
수집 → XML/JSON/API 표준화 → 4유형 상호운용 → MyData 이동 → AI 학습·서비스
```
