#정보관리기술사 #데이터베이스 #데이터레이크하우스 #데이터베이스/빅데이터/분석
Data Lakehouse
## 정의 
- 정형, 비정형 데이터를 통합 관리하는 데이터 레이크 기능과 주제 지향, 시계열 단위 데이터를 관리 및 분석 하는 기능을 제공하는 데이터 웨어하우스를 결합한 하이브리드 데이터 관리 플랫폼

## 키워드
- 데이터 레이크, 데이터 웨어하우스, 배치, 스트리밍, 스키마 관리, 정형, 비정형, 서빙, BI, 도구, [[API]]
