#데이터베이스 #성능 #파티셔닝 #필수 #데이터베이스/NoSQL/분산
## 정의
대용량 테이블 분할 관리, 파티셔닝
- 대용량 테이블을 파티션 키를 기준으로 작은 물리적 세그먼트 단위로 분할하여 성능과 관리 효율성을 높이는 기법
- 논리적으로 하나의 테이블이지만 물리적으로 여러 파티션으로 저장
## 키워드
* Range, List, Hash, Composite, 파티션 키, 파티션 프루닝, 성능향상, 수직/수평 분할
## 암기법
* "레리해컴" - Range, List, Hash, Composite
## 파티셔닝 유형

| 유형                               | 개념도                                           | 설명                                                                            |
| -------------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------- |
| 레인지 파티셔닝 (Range Partitioning)    | ![[Pasted image 20260401222827.png\|300]]     | – 파티션 키 값의 범위로 분할<br>– 가장 일반적인 형태로 일정 범위를 주어 분할하는 기법                          |
| 리스트 파티셔닝 (List Partitioning)     | ![[Pasted image 20260401222841.png\|300]]<br> | – 불연속적인 값의 목록을 각 파티션에 지정<br>– 순서와 연관성이 없는 데이터의 그룹핑                            |
| 해시 파티셔닝 (Hash Partitioning)      | ![[Pasted image 20260401222858.png\|300]]     | – 파티션 키 값에 해시 함수 적용, 해쉬테이블로 파티션 매핑<br>– 데이터가 모든 파티션에 고르게 분산<br>– 병렬 처리시 성능 향상 |
| 결합 파티셔닝 (Composite Partitioning) | 레인지 파티셔닝 + 해시 or 리스트                          | – 레인지 파시셔닝 후 각 파티션내에서 해쉬, 혹은 리스트 기법으로 서브 파티션 구성<br>– 각 기법의 장점 결합 가능           |
| Reference 파티셔닝                   | ![[Pasted image 20260401222914.png\|300]]     | – 부모 테이블 파티션 키를 이용해 자식 테이블을 파티셔닝 하는기능                                         |
| Interval 파티셔닝                    | ![[Pasted image 20260401222926.png\|300]]     | – Range 파티션을 생성할 때 Interval 기준을 정의함으로써 정해진 간격으로 파티셔닝                          |

## 구성도
```
┌─────────────────────────────────────────┐
│           논리적 테이블 (SALES)         │
├─────────────────────────────────────────┤
│ ┌─────────┐ ┌─────────┐ ┌─────────┐     │
│ │ 2024_Q1 │ │ 2024_Q2 │ │ 2024_Q3 │     │
│ │ (Range) │ │ (Range) │ │ (Range) │     │
│ └─────────┘ └─────────┘ └─────────┘     │
└─────────────────────────────────────────┘
```
## 파티셔닝 장점
| 장점 | 설명 |
|------|------|
| 성능 향상 | 파티션 프루닝으로 스캔 범위 축소 |
| 관리 용이 | 파티션 단위 백업/삭제/이동 |
| 가용성 | 파티션 단위 장애 격리 |
| 병렬 처리 | 파티션별 병렬 쿼리 실행 |
## 파티션 프루닝
```
SELECT * FROM SALES WHERE sale_date = '2024-01-15'
→ 2024_Q1 파티션만 스캔 (나머지 파티션 제외)
```
