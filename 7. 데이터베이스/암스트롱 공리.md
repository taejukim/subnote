#정보관리기술사 #데이터베이스 #암스트롱공리 #데이터베이스/빅데이터/분석
Armstrong’s Axioms
## 정의
- 주어진 릴레이션 R에 대해 X, Y, Z라는 속성의 집합이 주어 졌을 경우 여러가지 함수종속의 성징을 유도해 폐포(F+)를 도출할 수 있는 추론 규칙
## 키워드
- 정당성, 완정성, 기본/부가 규칙, 폐포(F+), 정규화

## 암기법
- 특징 : 정완
	- 정당, 완전

# 특징
- 정규화에 이용 : 함수적 종속성을 제거하기 위한 정규화에 사용
- 정당(Sound) : 
	- 주어진 FD의 집합 F로 부터 F+에 속하는 FD만 생성할 수 있음
	- 이 규칙들은 잘못된 함수 종속을 생성하지 않음
- 완전(Complete)
	- 주어진 FD집합 F에 대해 모든 F+ 를 찾을 수 있음

## 속성 폐포 (Attribute Closure) 알고리즘
```
X^+ := X;
Repeat
    Old X^+ := X^+;
    For each functional dependency Y → Z in F do
        If Y⊆X^+ then X^+ := X^+∪Z;
Until (old X^+ := X^+);
```

- 함수적 종속 관계의 집합 F에서 **특정 속성 X가 함수적으로 결정하는 속성들의 집합**

---
### 예시

**R = {A, B, C, G, H, O}**  
**F = {A > B, A > C, CG > H, CG > I, B > H}**

> **AG는 후보키**, AG의 폐포는 **ABCGHI**


## 기본규칙 [기재부이]

| 규칙         | 개념도       | 설명                           |
| ---------- | --------- | ---------------------------- |
| **재**귀성 규칙 | X → Y     | – Y가 X의 부분 집합이면, X → Y이다     |
| **부**가성 규칙 | XZ → YZ   | – 만약 X → Y이면, XZ → YZ이다      |
| **이**행성 규칙 | X → Y → Z | – 만약 X → Y이고 Y → Z이면 X → Z이다 |

---

## 부가규칙 [부분합의]

| 규칙 | 개념도 | 설명 |
|------|--------|------|
| **분**해 규칙 | X → YZ ⟹ X → Y, X → Z | – X → YZ이면 X → Y이고 X → Z이다 |
| **합**집합 규칙 | X → Y, X → Z ⟹ X → YZ | – 만약 X → Y이고 만약 X → Z이면 X → YZ이다 |
| **의**사이행 규칙 | X → Y, YZ → W ⟹ XZ → W | – 만약 X → Y이고 YZ → W이면, XZ → W이다 |
