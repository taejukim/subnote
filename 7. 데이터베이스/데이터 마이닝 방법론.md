## 키워드
- KDD, CRISP-DM, SEMMA

##  KDD 정의 및 절차

– 1996년 Fayyad가 체계적으로 정리한 데이터 마이닝 프로세스로, 데이터베이스에서 인사이트 발굴을 위한 5개의 프로세스로 정의된 데이터 분석 방법론

| 구분 | 절차 | 설명 |
|-----|------|------|
| 데이터 처리 | 데이터셋 선택 (Selection) | 데이터를 선택하고 데이터셋을 생성 |
| | 데이터 전처리 (Preprocessing) | 분석 데이터셋에 포함되어 있는 잡음, 이상값, 결측값을 식별하고 필요시 제거 |
| | 데이터 변환 (Transformation) | 분석 목적에 맞는 변수를 선택하거나 데이터의 차원을 축소해, 효율적 적용위해 데이터셋 변환 |
| 데이터 마이닝 | 데이터 마이닝 (Data Mining) | 변환된 데이터셋을 이용해, 분석 목적에 맞는 데이터 마이닝 기법, 알고리즘으로 마이닝 수행 |
| | 마이닝 결과 평가 (Interpretation/Evaluation) | 분석 결과에 대한 해석과 평가 및 활용 |

##  SEMMA 정의 및 절차

– SAS 기업에서 개발한 데이터마이닝 표준 가이드로서 Sample, Explore, Modify, Modeling, Assessment의 단계의 각 프로세스를 순차적으로 실행하는 데이터마이닝 방법론

| 단계 | 주요 활동 | 기법 |
|-----|---------|------|
| Sampling | – 분석 데이터 생성<br>– 모델 평가를 위한 데이터 준비 | – 통계적 추출<br>– 조건 추출 |
| Explore | – 분석 데이터 탐색, 데이터 오류 검색<br>– 비즈니스 이해, 이상현상 및 변화 탐색 | – 그래프, 통계<br>– 클러스터링 |
| Modify | – 분석 데이터 수정, 변환<br>– 데이터 정보 표현 극대화 | – 수량화, 표준화<br>– 변환, 그룹화 |
| Modeling | – 모델 구축, 패턴 발견<br>– 모델링과 알고리즘의 적용 | – Neural Network<br>– Decision Tree |
| Assessment | – 모델 평가 및 검증, 피드백<br>– 모델 간 비교 및 Next Step 결정 | – Report<br>– Review |

## ■ CRISP-DM 정의 및 절차

– 비즈니스 목적에 맞는 결과를 도출하기 위한 계층적 프로세스 모델로서 4개 레벨과 6단계로 수행되는 마이닝 방법론

| 레벨 |
|-----|
| Phase (최상위 레벨) |
| Generic Tasks (단일 테스크 완전 수준) |
| Specialized Tasks (구체적 실행 수준) |
| Process Instances (프로세스 실행 수준) |

| 단계      | 주요 활동                                                        | 산출물                                        |
| ------- | ------------------------------------------------------------ | ------------------------------------------ |
| 비즈니스 이해 | – 비즈니스 관점 고객 이해, 영향평가 및 상황 조사<br>– 기술 관점 목표 수립, 프로젝트 세부계획 수립 | – Success Criteria<br>– Goals and Criteria |
| 데이터 이해  | – 초기 데이터 수집, 확보, 특성 확인<br>– 목표 부합 데이터 추출, 데이터 품질 검사/검증       | – Initial Data Report<br>– Quality Report  |
| 데이터 준비  | – 데이터 선택, 정제, 품질 확보, 구조화<br>– 데이터 통합, 형식 보완                  | –                                          |
