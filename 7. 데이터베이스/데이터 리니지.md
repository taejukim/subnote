#정보관리기술사 #데이터베이스 #데이터리니지 #DataLineage
## 정의
데이터 리니지(Data Lineage)
- 데이터 생명주기의 흐름과 변환 과정을 추적하는 작업, 또는 전 과정을 기록한 계보
- 데이터 출처·변환·경로·종착지·메타데이터를 시각화·관리하는 데이터 추적 체계
## 키워드
* ETL/ELT 추적, Metadata, 데이터 흐름 시각화, 영향도 분석, 거버넌스
## 암기법
* 출변경종메: 출처·변환·경로·종착·메타
## 특징
- 추적성: 데이터 출처~사용까지 추적
- 가시화성: 데이터 흐름 시각적 표현
- 영향도 분석성: 변경·장애 영향 파악
- 거버넌스 기반성: 표준·정책 준수 보장
## 목적
- 데이터 변환·이동의 투명성 확보
- 변경 영향 분석과 데이터 신뢰성 강화
## 구성요소
- 기본 구성: 데이터 출처, 변환, 경로, 종착지, 메타데이터
- 기술요소: ETL/ELT 프로세스 추적, 메타데이터 관리, 데이터 카탈로그, 자동화 도구, 시각화 도구
- 활용: 영향도 분석, 컴플라이언스, 데이터 품질 개선
- 데이터 표준화 + 데이터 리니지 = 데이터 카탈로그(정합성·신뢰성·가시화·통합성)
## 구성도
```
[Source] → [ETL/ELT] → [Staging] → [DW/Lake] → [BI/AI]
   ↓           ↓           ↓          ↓           ↓
            메타데이터 자동 수집·시각화·영향도 분석
```
