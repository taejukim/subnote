#데이터베이스 #AI #벡터 #필수 #데이터베이스/AI/신기술
## 정의
고차원 벡터 저장 및 검색, Vector DB
- 텍스트, 이미지 등을 임베딩 벡터로 변환하여 저장하고 유사도 검색을 수행하는 데이터베이스
- AI/ML 애플리케이션에서 의미 기반 검색(Semantic Search)을 지원
## 키워드
* 임베딩, 유사도 검색, ANN, HNSW, 코사인 유사도, RAG
## 암기법
* "임유인코" - 임베딩, 유사도, 인덱싱, 코사인
## 핵심 개념
| 개념     | 설명                   |
| ------ | -------------------- |
| 임베딩    | 데이터를 고차원 벡터로 변환      |
| 유사도 검색 | 벡터 간 거리/유사도 계산       |
| ANN    | 근사 최근접 이웃 검색         |
| HNSW   | 계층적 탐색 가능 소규모 세계 그래프 |
## 구성도
```
┌─────────────────────────────────────────┐
│              Vector DB                  │
├─────────────────────────────────────────┤
│  [텍스트] → [임베딩모델] → [벡터저장]   │
│  "고양이"   [0.2,0.8,...]  Vector Index │
├─────────────────────────────────────────┤
│  [쿼리벡터] → [ANN검색] → [유사문서]    │
└─────────────────────────────────────────┘
```
## 유사도 측정
| 방법      | 공식               | 특징    |
| ------- | ---------------- | ----- |
| 코사인 유사도 | cos(θ) = A·B / ( | A     |
| 유클리드 거리 | √Σ(ai-bi)²       | 절대 거리 |
| 내적      | A·B = Σaibi      | 크기 고려 |
![[Pasted image 20260401222423.png|500]]

| 구분     | 알고리즘/유사도                                      | 설명                                                |
| ------ | --------------------------------------------- | ------------------------------------------------- |
| 알고리즘   | **랜**덤 투영 (Random Projection)                 | – 고차원 데이터를 저차원 투영하여 차원을 축소하는 기법                   |
|        | **제**품 양자화 (Product Quantization)             | – 고차원 벡터데이터를 저차원 공간으로 나누고 개별 양자화로 전체 벡터 압축        |
|        | **L**SH (Locality Sensitive Hashing)          | – 고차원 데이터에서 유사한 데이터끼리 동일한 해시값으로 매핑될 확률을 높이는 해싱 기법 |
|        | **H**SNW (Hierarchical Navigable Small World) | – 그래프 기반 ANN 알고리즘<br>– 벡터들을 계층적 그래프로 구성하여 탐색      |
|        | **I**VF (Inverted File Index)                 | – 여러 그룹으로 나누고 필요한 그룹에서만 검색                        |
| 유사도 측정 | 코사인 유사도                                       | – 두 벡터의 각도로 유사도를 측정                               |
|        | 유클리드 거리                                       | – 두 점의 직선거리로 유사도를 측정                              |
|        | 맨하튼 거리                                        | – 두 점의 거리를 격자 기준으로 유사도 측정                         |
|        | 내적                                            | – 두 벡터가 얼마나 같은 방향을 향하는지 측정                        |

## 동작 과정
![[Pasted image 20260401222518.png|700]]

| 구분             | 핵심 작동 원리 | 설명                                                    |
| -------------- | -------- | ----------------------------------------------------- |
| ① 벡터 임베딩       | 벡터로 변환   | 텍스트, 이미지, 오디오 등 다양한 형태의 원본데이터를 고차원의 숫자 벡터로 변환         |
| ② 데이터 저장 및 인덱싱 | 해싱 기반    | 유사한 벡터들이 동일한 해시 버킷에 할당                                |
|                | 양자화 기반   | 고차원 벡터를 여러 개의 저차원 하위 벡터로 분할, 각 하위 벡터 공간을 양자화하여 벡터를 압축 |
|                | 그래프 기반   | 벡터들 노드로, 벡터 간 유사도를 엣지로 표현                             |
|                | 트리 기반    | 벡터 공간을 계층적으로 분할하여 검색범위 축소                             |
| ③ 쿼리 처리        | 벡터로 변환   | 사용자가 검색하고자 하는 데이터 또한 원본 데이터임. 동일한 벡터화 모델을 통해 벡터로 변환   |
| ④ 유사성 측정       | 코사인 유사도  | 두 벡터 사이의 각도로 코사인을 계산해 유사성측정                           |
|                | 유클리드 거리  | 두 벡터의 끝점을 잇는 가장 짧은 직선 거리를 측정                          |
|                | 내적       | 두 벡터의 각 성분끼리의 곱의 합으로 계산                               |
|                | 맨해튼 거리   | 두 벡터의 직각 거리의 절댓값을 모두 합산                               |
|                | 자카드 유사도  | 교집합의 크기를 합집합의 크기로 나눈 값                                |
| ⑤ 후처리          | 후처리 단계   | 초기 결과에 대해 추가적인 필터링이나 순위 재조정과 같은 후처리 단계 적용             |
