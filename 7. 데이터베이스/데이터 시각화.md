#데이터베이스 #데이터분석 #시각화 #필수 #데이터베이스/AI/신기술
## 정의
데이터의 시각적 표현, 데이터 시각화
- 데이터를 그래프, 차트, 대시보드 등 시각적 형태로 표현하여 인사이트를 도출하는 기법
- 복잡한 데이터 패턴과 관계를 직관적으로 이해할 수 있도록 지원
## 키워드
* 대시보드, 차트, 그래프, BI, Tableau, Power BI
## 암기법
* "비교분포관추" - 비교, 분포, 관계, 추세 시각화
## 시각화 유형
| 목적 | 차트 유형 | 적용 사례 |
|------|-----------|-----------|
| 비교 | 막대, 레이더 | 매출 비교 |
| 분포 | 히스토그램, 박스플롯 | 점수 분포 |
| 관계 | 산점도, 버블 | 상관관계 |
| 추세 | 라인, 영역 | 시계열 변화 |
| 구성 | 파이, 트리맵 | 비율 표현 |

## 시각화 프로세스 [구시표]

| 프로세스 | 설명 | |
|---------|------|--|
| ① 정보 **구**조화 | 주어진 정보를 탐색, 분류, 배열을 통해 구조적으로 그룹핑 하는 활동 | |
| | – 데이터 수집 및 탐색 | – 데이터 자료 또는 논거를 수집<br>– 빅데이터 고유의 특성이 훼손되지 않으면서 수집 및 탐색 필요 |
| | – 데이터 분류 | – 유사한 것들끼리 그룹핑하는 과정<br>– JSON, XML, CSV, TSV, 구분텍스트 |
| | – 데이터 배열 | – 값의 의미에 따라 배치하는 과정<br>– 래치 방법(위치, 알파벳, 시간, 카테고리, 위계) |
| | – 관계 탐색(재배열) | – 분류된 데이터를 인식하기 쉽게 패턴 만드는 과정<br>– 이상값 처리, 차원, 측정값 유형별 관계파악 |
| ② 정보 **시**각화 | 방대한 양의 정보를 한번에 사용자가 보고 이해하도록 시각적 표현방법과 인터렉션 기술을 이용해 추상적 정보를 직관적으로 표현하는 활동 | |
| | – 시간, 분포, 관계 시각화 | – 시간과 데이터의 분포 및 관계를 표현하는 기법<br>– 막대, 누적그래프, 파이차트, 스캐터, 버블, 히스토그램 등 |
| | – 비교, 변수, 공간 | – 구분, 순서, 비율, 색채 사용과 인지 등의 기본 원리를 사용하여 시각화 |
| ③ 정보 시각 **표**현 | 정보시각화한 결과물을 그래픽적으로 디자인을 완성시키는 단계 | |
| | – 디자인 기본 원리 사용 | – 타이포그래피 (서체, 무게, 크기, 스타일, 색채, 간격)<br>– 색상(구분, 순서표현, 비율, 색채사용인지)<br>– 그리드(화면 읽는 방식, 정보의 역피라미드) |
| | – 인터렉션 디자인 | – 다양한 유형의 시각 자료를 적용 및 테스트하여 확인<br>– 강조 및 디테일 표시, 사용자 컨텐츠 선택방식, 사용자 지정시각 매핑변화 |

##  인사이트 프로세스 [탐분활]

| 절차 | | 설명 |
|-----|--|------|
| ① **탐**색 | | 사용할 수 있는 자료를 확인하고, 그 자료가 어떤 의미를 가지는 지 살펴보며, 자료들 간 어떤 관계들이 있고, 어떤 관계들이 가능한지 살펴보는 단계 |
| | – 데이터 확인 | – 데이터 명세화, 데이터구성원리 정의 |
| | – 연결포인트 확인 | – 공통요소 탐색, 공통요소 변환, 탐색 범위 설정 |
| | – 관계 탐색 | – 이상값 처리, 차원, 측정값 유형별 관계파악 |
| ② **분**석 | | 탐색을 통해 찾아낸 관계를 명확하게 규명하고, 그 형태가 지닌 의미를 찾아내는 단계 |
| | – 분석대상 정의 | – 2차 탐색 및 목표 확인<br>– 분석 시각디자인 표현 |
| | – 분석과 시각화 도구 | – 분석의 시각적 표현<br>– 추세선 그래프, 회귀선 그래프 |
| | – 지표설정 분석 | – 지표의 기본구조<br>– 관계 축약 표현, 기준관리, 지표 설정 고려<br>– 인과 관계 데이터 및 지표 검토 |
| ③ **활**용 | | 발견한 인사이트를 내, 외부로 활용하여 가치를 검증하는 단계 |
| | – 내부적용 | – 구체적 탐색과 발전<br>– 발견한 모델을 서비스나 제품에 적용 |
| | – 외부적용 | – 외부 설명, 설득을 위한 시각화 도구 활용<br>– 커뮤니케이션 시각화. 디자인 |
| | – 인사이트 발전과 확장 | – 종합적 오류 검토 및 보완<br>– 실시간, 상하 관점 지표 검토 |
