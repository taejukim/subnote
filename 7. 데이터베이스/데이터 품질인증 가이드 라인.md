DQ인증 2025.02.26
## 정의
- 데이터 산업진흥 및 이용촉진에 관한 기본법 제 20조 5항(데이터 품질인증 대상 및 품질기준)에 의거 데이터 내용, 데이터 관리체계를 진단하고 수준을 평가해 품질을 인증하는 제도

## 키워드
- 데이터 산업진흥 및 이용촉진에 관한 기본법 제 20조 5항, 데이터 내용, 데이터 관리 체계, 사후 관리

## 데이터 내용 인증
- 데이터 내용 개념
	- 데이터 레코드, 필드에 입력되어 있는 문자, 숫자 등 값과 집합 또는 텍스트, 이미지, 동영상, 음성 등 원천 데이터와 속성값 등

| 인증 항목      | 세부 항목                                                 |
| ---------- | ----------------------------------------------------- |
| 인증 유형      | Complex-Type, Normal-Type, Simple-Type                |
| 심사 지표      | A Class, B Class, C Class                             |
| 인증 대상      | - 데이터 구조: 정형 데이터, 비정형 데이터- 데이터 내용(데이터 값)              |
| 정형 데이터 심사  | - 필수: 완전성, 유효성, 일관성- 선택: 유효성, 일관성, 정확성, 접근성, 유일성      |
| 비정형 데이터 심사 | - 필수: 완전성, 유효성, 정확성, 유일성- 선택: 유효성, 일관성, 정확성, 접근성, 유일성 |

## 데이터 관리 체계 인증
- 데이터 관리의 개념
	- 데이터 관리의 원칙을 정의하고 데이터 표준, 데잋터 품질, 데이터 구조, 데이터 연계 등에 대한 업무 기능, 조직, 프로세스, 제도 등을 체계적으로 정립하여 실행

| 인증 항목 | 세부 항목                                               |
| ----- | --------------------------------------------------- |
| 인증 등급 | 인증하지 않음, Level 2 ~ Level 5                          |
| 인증 대상 | 데이터 기반 사업, 데이터 시스템, 데이터 관리 조직                       |
| 심사 대상 | 불완전(0, 적용 불가), 수행(1), 관리(2), 체계화(3), 예측화(4), 혁신화(5) |
| 심사 방법 | 성숙도 수준: 도입(1), 관리(2), 체계화(3), 예측화(4), 혁신화(5)        |
