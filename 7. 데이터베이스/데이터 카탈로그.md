#정보관리기술사 #데이터베이스 #데이터카탈로그 #DataCatalog
## 정의
데이터 카탈로그(Data Catalog)
- 데이터의 메타데이터를 수집·통합 관리하여 다양한 사용자가 데이터를 효과적으로 이용할 수 있도록 지원하는 서비스
- 데이터 검색·계보·분류·품질을 통합하는 데이터 셀프서비스 플랫폼
## 키워드
* 메타데이터, 데이터 계보, 셀프서비스, 자동 태깅, 자연어 검색, 거버넌스
## 암기법
* 메계검분: 메타데이터·계보·검색·분류
## 특징
- 통합 검색성: 다중 소스 데이터 단일 검색
- 메타 자동 수집성: 변경 사항 자동 감지·반영
- 계보 가시화성: 데이터 흐름·이력 추적
- 거버넌스 강화성: 분류·태깅·품질 관리
## 목적
- 데이터 발견성·이해성·신뢰성 향상
- 데이터 셀프서비스 활성화와 활용성 극대화
## 구성요소
- 메타데이터 자동 수집: 스크래핑 도구, 데이터 인터페이스, 변경 사항 감지
- 데이터 계보 확인: 데이터 흐름 시각화, 스키마 변경 이력 저장, 데이터 소스 간 연결
- 통합 검색: 다중 소스 검색 엔진, 자연어 처리 기능, 검색 결과 필터링
- 데이터 분류: 자동 태깅 메커니즘, 사용자 정의 분류 기준, 계층적 체계
- 데이터 표준화 + 데이터 리니지 = 데이터 카탈로그(정합성·신뢰성·가시화·통합성)
## 구성도
```
[Source] DB·DW·Lake·SaaS
   ↓ 메타데이터 자동 수집
[Data Catalog]
   ├── 통합 검색 (자연어·필터)
   ├── 데이터 계보 시각화
   ├── 분류·태깅·품질 관리
   └── 셀프서비스 포털
```
