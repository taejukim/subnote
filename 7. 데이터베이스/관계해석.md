## 정의
관계해석(Relational Calculus)
- 관계형 데이터베이스에서 수학적 논리를 사용하여 데이터를 질의하는 선언적(비절차적) 언어
## 키워드
* 비절차적 언어, 수학적 논리, 원하는 데이터만 명시, 프레디킷 해석, TRC, DRC
## 암기법
* 튜도: 튜플 관계해석(TRC)·도메인 관계해석(DRC)
## 특징
- 선언성: what만 명시, how는 명시하지 않음
- 논리 기반: 술어논리(프레디킷) 사용
- 관계대수와 동등한 표현력(Codd)
## 목적
- 원하는 데이터만 논리식으로 명시하여 질의
## 구성요소
- 수식 예: {t.Ename, t.Salary | t ∈ EMPLOYEE ∧ t.Salary ≥ 3000}
- 연산자: ∨(OR), ∧(AND), ¬(NOT)
- 정량자: ∀(전칭), ∃(존재)
- TRC: 튜플 단위 질의, { t | t ∈ Employees ∧ t.age > 30 }
- DRC: 도메인(속성) 단위 질의, { <name, age> | ∃d (...) }
## 구성도
```
관계해석
 ├─ TRC: 튜플 변수 t로 조건 정의 → 행 단위 결과
 └─ DRC: 도메인 변수 x1,x2…로 조건 정의 → 속성값 결과
연산자: ∨ ∧ ¬ / 정량자: ∀ ∃
```
