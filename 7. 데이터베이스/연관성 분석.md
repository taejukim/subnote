## 빈발규칙과 비빈발규픽

| 구분  | 빈발규칙 (Frequent Rule)      | 비빈발규칙 (Infrequent Rule)       |
| --- | ------------------------- | ----------------------------- |
| 조건  | 최소 지지도 이상                 | 최소 지지도 미만                     |
| 해석  | 자주 발생 → 신뢰성 높음            | 드물게 발생 → 일반적 분석에서는 제외         |
| 활용  | 추천 시스템, 마케팅, 대규모 분석       | 이상 탐지, 희귀 이벤트 분석, 프리미엄 고객 분석  |
| 예시  | “맥주 → 땅콩” (많은 고객이 동시에 구매) | “캐비아 → 샴페인” (적은 고객이지만 고부가 가치) |

## 지표
| 구분               | 설명                               | 수식                                                                                     |
| ---------------- | -------------------------------- | -------------------------------------------------------------------------------------- |
| 지지도 (Support)    | 전체 거래 중 A와 B가 함께 등장한 비율          | $$Support(A \Rightarrow B) = \frac{\|A \cap B\|} N$$                                   |
| 신뢰도 (Confidence) | A가 발생했을 때 B도 발생할 확률              | $Confidence(A \Rightarrow B) = \frac{Support(A \cap B)}{Support(A)}$                   |
| 향상도 (Lift)       | B의 일반적인 발생 빈도 대비 A가 있을 때 B 발생 비율 | $Lift(A \Rightarrow B) = \frac{Confidence(A \Rightarrow B)}{Support(B)}$               |
| 레버리지 (Leverage)  | 동시 발생 확률과 독립 발생 확률의 차이           | $Leverage(A \Rightarrow B) = Support(A \cap B) - Support(A) \times Support(B)$         |
| 컨빅션 (Conviction) | A 발생 시 B 미발생에 대한 예측력             | $Conviction(A \Rightarrow B) = \frac{1 - Support(B)}{1 - Confidence(A \Rightarrow B)}$ |
- **지지도**: 얼마나 자주 같이 일어나는가?
- **신뢰도**: A가 일어나면 B도 같이 일어날 확률은?
- **향상도**: 단순 우연이 아니라 정말 의미 있는 관계인가?
- **레버리지 & 컨빅션**: 보조적 지표로 관계의 강도를 더 정교하게 해석
