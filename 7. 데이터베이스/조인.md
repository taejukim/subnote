## 정의
조인(Join)
- 두 개의 테이블을 엮어서 원하는 데이터를 추출하는 방법
## 키워드
* Equi Join, Natural Join, Outer Join, Semi Join, Nested Loop, Sort Merge, Hash Join
## 암기법
* 네소해: Nested Loop·Sort Merge·Hash Join
## 특징
- 논리(관계대수): Equi/Natural/Outer/Semi
- 물리(메커니즘): NL / Sort Merge / Hash
- OLTP vs OLAP: NL(소량·인덱스) vs SM·Hash(대량)
## 목적
- 다중 테이블에서 연관 데이터를 결합·추출
## 구성요소
- Nested Loop: 선행 테이블을 하나씩 접근하며 후행 조인, 부분범위·소량·Index/Random, Buffer Cache, OLTP, `USE_NL`
- Sort Merge: 양측 정렬 후 병합, 전체범위·대량·Full Scan, PGA, 인덱스 없을 때, `USE_MERGE`
- Hash Join: 작은 집합으로 해시테이블 구성 후 큰 집합 탐색, 전체범위·대량, PGA, 대량 집계, `USE_HASH`
- 비교: 조인방향 영향(NL 큼 / SM 없음 / Hash 있음), Hint·Area Size 고려
## 구성도
```
논리: Inner / Left / Right / Full Outer
물리:
  NL: 선행 → 후행(인덱스) 반복
  SM: 정렬(R)·정렬(S) → Merge
  Hash: Build(소) → Probe(대)
```
