#정보관리기술사 #데이터베이스 #데이터표준화 #DataStandardization
## 정의
데이터 표준화(Data Standardization)
- 데이터 명칭·정의·형식·규칙을 통일된 기준으로 정의하고 표준 용어·단어·도메인·코드로 적용하는 활동
- 조직 전체의 데이터 정합성·신뢰성·재사용성을 확보하기 위한 데이터 거버넌스 핵심 기반
## 키워드
* 표준 용어, 표준 단어, 표준 도메인, 표준 코드, 데이터 사전, 거버넌스
## 암기법
* 명정형규: 명칭·정의·형식·규칙
## 특징
- 통일성: 명칭·정의·형식 일관성
- 재사용성: 표준 용어·도메인 재사용
- 정합성: 시스템 간 데이터 의미 일관 보장
- 거버넌스 기반성: 표준화 조직·프로세스 운영
## 목적
- 데이터 정합성·신뢰성·재사용성 확보
- 시스템 간 통합과 데이터 활용 효율화
## 구성요소
- 표준화 결과 항목: 표준 용어, 표준 단어, 표준 도메인, 표준 코드
- 표준화 요소: 데이터 명칭, 정의, 형식, 규칙
- 표준화 절차: 요구사항 수집 → 데이터 표준 정의 → 표준 확정 → 표준 관리
- 거버넌스: 데이터 표준화 조직·프로세스 구축
- 데이터 표준화 + 데이터 리니지 = 데이터 카탈로그(정합성·신뢰성·가시화·통합성)
## 구성도
```
요구사항 수집 → 데이터 표준 정의(용어·단어·도메인·코드)
   → 표준 확정(승인) → 표준 관리(현행화)
                ↓
   [표준 적용] DB 모델·인터페이스·메타데이터
```
