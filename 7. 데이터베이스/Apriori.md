#정보관리기술사 #데이터베이스 #Apriori #데이터베이스/빅데이터/분석 #NEW
## 정의
Apriori 알고리즘
- 데이터셋에서 후보 항목집합을 생성하고 발생 빈도가 낮은 집합을 제외하여 빠르게 데이터 간 연관관계를 밝히는 분석 방법
## 키워드
* 빈발 항목집합, 최소 지지도 비교, 가지치기, Anti-monotone
## 암기법
* 빈지가지: 빈도수집·지지도·가지치기
## 특징
- 반모노톤성: 빈발 집합의 부분집합도 빈발 → 가지치기 근거
- 단계적 후보 생성·검증
- DB 다중 스캔 비용 존재
## 목적
- 연관규칙 분석을 위한 빈발 항목집합 탐색
## 구성요소
- ① DB 스캔으로 항목별 빈도 수집
- ② 지지도(Support) 계산
- ③ 최소 지지도 이하 가지치기(Pruning)
- ④ Frequent 1-itemset 생성
- ⑤ k-빈발 → (k+1) 후보 생성·검증·가지치기 반복
- ⑥ 최대 빈발 항목집합 도출
## 구성도
```
null
 ├ A B C D
 ├ AB AC … (①빈발산출 ②최소지지도 ③가지치기)
 └ ABC … ABCD
반모노톤성 기반 후보 생성·검증
```
