## 정의
아파치 카프카(Apache Kafka)
- 실시간 데이터 피드 관리를 위해 분산 스트리밍·파이프라이닝·재생을 목적으로 설계된 Publish/Subscribe 구조의 메시징 플랫폼
## 키워드
* Partition, Availability, Consistency, Latency, Topic, Broker, Producer, Consumer
## 암기법
* 프브컨토: Producer·Broker·Consumer·Topic
## 특징
- Pub/Sub: 발행-구독 모델
- 분산·재생: 스트리밍·파이프라인·리플레이
- 비동기 결합: Producer와 Consumer 독립 동작
## 목적
- 실시간 데이터 피드의 분산 수집·전달·재생
## 구성요소
- Topic: 발행 메시지 카테고리·식별자
- Producer: Topic 메시지 생성 후 Broker 전달
- Consumer: 구독 Topic 메시지 가져와 처리
- Broker: Producer-Consumer 간 메시지 관리 클러스터 서버
- 동작: ① Producer 전송 → ② Topic 큐 저장 → ③ Consumer pull → ④ 상호 비의존 송수신 → ⑤ Topic 단위 대량 저장
## 구성도
```
[Producer×N] → [Kafka Cluster / Broker]
                      Topic(큐)
                 → [Consumer×N]
```
