#정보관리기술사 #데이터베이스 #릴레이션무결성 #데이터베이스/관계모델
## 정의
- 릴레이션을 조작하는 과정에서 수행하기 전과 후에 대한 상태에 대한 정확성 유지 규칙

## 암기법
- 릴레이션 무결성 : 상과집튜즉지
	- 상태제약, 과도제약, 집합제약, 튜플제약, 즉시제약, 지연제약

## 릴레이션 무결성
| 제약구분 | 유형                    | 설명                                                                  | 특징               |
| ---- | --------------------- | ------------------------------------------------------------------- | ---------------- |
| 상태   | **상**태제약 (State)      | – 데이터베이스가 일관성 있는 상태가 되기 위한 조건을 명세<br>– 특정시점에 만족되어야 하는 정적 제약의 성질을 가짐 | – 특정시점에 만족       |
|      | **과**도제약 (Transition) | – 한 상태에서 다른 상태로 변환과정에서 적용되는 규칙<br>– 변경 전, 후 모두 만족하는 동적 제약의 성질을 가짐   | – 상태변환 직전/후 비교   |
| 범위   | **집**합제약 (Set)        | – 튜플 집합 전체에 관련되어 적용되는 규칙                                            | – CHECK절 전체 명시   |
|      | **튜**플제약 (Tuple)      | – 처리되고 있는 튜플에만 적용되는 규칙                                              | – CHECK절 단일 명시   |
| 시점   | **즉**시제약 (Immediate)  | – 연산이 수행되는 즉시 적용되는 규칙                                               | – AFTER 사용       |
|      | **지**연제약 (Deferred)   | – 트랜잭션이 완전히 수행된 후 적용되는 규칙                                           | – WHEN COMMIT 사용 |
