#정보관리기술사 #데이터베이스 #데이터클렌징 #데이터베이스/빅데이터/분석
Data Cleansing
## 정의
- 레코드 세트, 테이블 또는 데이터베이스에서 손상되거나 부정확한 레코드를 감지하고 전처리 과정을 통해 이상치 제거 및 식별, 교체, 삭제 수정하는 프로세스

## 키워드
- 데이터 변환, 데이터 파싱, 데이터 보강

##  데이터 클렌징 절차 [대원우유제]

![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260401224525.png|500]]

| 순서 | 프로세스 | 특징 |
|-----|---------|------|
| ① | 데이터베이스 **대**상 정의 | – 데이터 클렌징 대상 데이터베이스 범위 정립 |
| ② | Dirty Data **원**인 파악 | – 데이터 결측치 및 이상치 식별 |
| ③ | 데이터 품질 문제 **우**선순위 | – 클렌징 우선 순위 결정 |
| ④ | Bad Data의 데이터베이스 **유**입 차단 | – 잘못된 데이터 입력되는 원인을 찾아 새로운 규칙 생성 |
| ⑤ | 데이터베이스에서 Bad Data **제**거 | – 데이터베이스 내부의 결측치 및 이상치 제거 |

##  데이터 클렌징 기법 [변파보 코형수]

| 기법         | 상세기법       | 상세설명                                                               |
| ---------- | ---------- | ------------------------------------------------------------------ |
| 데이터 **변**환 | **코**드체계변환 | – 다양한 형태의 코드 값을 단일 형태로 변환 (예: 성별)                                  |
|            | **형**식 재구성 | – 다양한 형식의 데이터 값을 단일 형식으로 전환 (예: 일자)                                |
|            | **수**학적 변환 | – 다양한 형식의 단위 값을 단일 단위 값으로 변환 (화폐단위)                                |
| 데이터 **파**싱 |            | 데이터 정제 규칙을 적용하기 위해 유의미한 최소 단위로 분할하는 작업<br>예: 주민등록번호, 생년월일등의 유효성 체크 |
| 데이터 **보**강 |            | – 변화, 파싱 등을 통해 추가 정보를 반영하는 작업                                      |
|            |            |                                                                    |
