## 정의
쿼리 오프로딩(Query Offloading)
- DB 트랜잭션 중 Update와 Read를 분리하여 DB 처리량을 높이는 DB 성능 향상 기법
## 키워드
* Update/Read 트랜잭션 분리, Master DB, Staging DB, Slave DB, CDC
## 암기법
* 마슬C로: Master·Slave·CDC·로드밸런싱
## 특징
- Read 비중 큼: Read 70~90%, Update 10~30%
- 쓰기/읽기 분리: Master=Update, Slave=Read
- Staging 중계: Master→다수 Slave 직접복제 부하 완화
## 목적
- DB 처리량·성능 향상 (트랜잭션 유형 분리)
## 구성요소
- Master DB: Update(C/U/D)만 수행
- Staging DB: Slave 복제 중계, Master 직접복제 부하 방지
- Slave DB: Read 전용 N대, 장애 시 HA
- CDC: Source Back Log 재생 (GoldenGate, SharePlex, Galera 등)
- Load Balancing: Slave 조회 부하 분산
- vs 샤딩: 유형분리 vs 데이터분할, 성능 vs 용량, CDC vs 파티셔닝, App 구현 vs DBMS/프레임워크
## 구성도
```
APP ─┬─ Update Pool → Master DB ─CDC→ Staging DB ─CDC→ Slave DB×N
     └─ Read Pool ──────────────────────────────→ (LB/HA)
```
