## 정의
탐색적 데이터 분석(EDA)
- 시각화 기법으로 데이터 구조를 이해하고 인사이트를 도출하는 분석 기법
확증적 데이터 분석(CDA)
- 가설을 설정한 후 수집 데이터로 가설을 평가·추정하는 전통적 분석 기법
## 키워드
* 인사이트 도출, 가설 검증, P-value, 저항성, 잔차, 중심극한정리
## 암기법
* 탐확: EDA(탐정)·CDA(판사)
## 특징
- EDA: Statistics as Detective, Data→Model
- CDA: Statistics as Judge, Model→Data, P-value로 수용/기각
## 목적
- EDA: X-Y 관계 가설 도출, 모형정립·마이닝
- CDA: 도출 가설 검정·유의성 검증
## 구성요소
- EDA 핵심: 저항성, 잔차 해석, 재표현, 현시성 / 기법: 히스토그램, 줄기잎, 상자수염, 산점도
- CDA 핵심: 중심극한정리, P-value / 기법: t·F·ANOVA, 상관·회귀, 카이제곱, 모비율·비모수
- EDA 절차: 수집 → 시각화 탐색 → 패턴 도출 → 인사이트 (순환)
- CDA 절차: 가설 설정 → 수집 → 통계분석 → 가설검증 (피드백)
## 구성도
```
[Data] ──Exploratory──→ [Model]
[Model] ──Confirmatory─→ [Data]
EDA: 수집→시각화→패턴→인사이트↻
CDA: 가설→수집→분석→검증↻
```
