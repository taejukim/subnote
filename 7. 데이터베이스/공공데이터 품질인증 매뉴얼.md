#정보관리기술사 #데이터베이스 #공공데이터품질인증매뉴얼 #데이터베이스/빅데이터/분석
2025.07
## 정의
- 공공 데이터법에 따라 기관 전체의 공공데이터 품질관리 체계 및 보유 DB 전반의 품질 인증 기준에 적합한지 심사해 우수 기관에 인증을 부여하는 제도
## 키워드
- 공공데이터법 제 22조 2항, 품질인증

## ■ 영역

| 영역 | 항목 | 세부항목 |
|-----|------|---------|
| 공공데이터 관리체계(40) | – 품질관리 계획 수립(4) | – 품질관리 계획 수립 및 이행 진단을 위한 전반적인 요소 포함 |
| | – 데이터 보안체계 구축(2) | – 기밀성, 무결성, 가용성 확보 위한 데이터 보안 체계 구축 |
| | – DB 관리 및 역량 강화 노력(10) | – 평가 대상 데이터베이스 관리 및 품질 관리 역량 확보 수준 |
| | – 예방적 품질관리 진단(4) | – 사전 데이터 품질 확보 위한 유효성, 완전성 확보 여부 점검 |
| | – 데이터 표준관리체계 수립 및 관리(3) | – 공공데이터 표준 관리 측면 데이터 관리 체계 수립 및 관리 |
| | – 데이터 표준 확산(9) | – 데이터베이스 표준 정의 및 용어, 단어, 도메인 지표 검수 |
| | – 데이터 구조 안정화(4) | – 데이터 모델 및 개념적, 논리적 데이터베이스 수준 검증 |
| | – 데이터 연계 관리(4) | – 외부 시스템 상호작용 및 유사, 중복 데이터 처리 프로세스 |
| 공공데이터 값 관리(40) | – 데이터 품질진단(15) | – 공공데이터 값 관리 측면 품질 진단 기준 정의 및 진단 수행 |
| | – 데이터 오류율(10) | – 업무 규칙에 따른 데이터베이스 오류율 진단 및 개선 조치 |
| | – 품질진단 결과 조치(15) | – 품질진단 개선계획을 수립하고 개선조치 이행률을 점검, 관리 |
| 공공데이터 개방 및 활용(20) | – 공공데이터 개방 활성화(12) | – 공공데이터 개방 및 활용 측면 외부, 내부 조직 연계 수준 |
| | – 공공데이터 활용 및 개선(8) | – 오류 신고 요구사항 분석 및 국민 친화적 실질적 문제 개선 |
