#데이터베이스 #데이터관리 #거버넌스 #필수 #데이터베이스/데이터관리
## 정의
데이터 자산의 관리 체계, 데이터 거버넌스
- 조직 내 데이터의 가용성, 유용성, 무결성, 보안을 관리하는 전사적 데이터 관리 체계
- 데이터 정책, 표준, 프로세스를 수립하고 데이터 품질을 보장하는 프레임워크
## 키워드
* 데이터 스튜어드, 메타데이터, 데이터 품질, 마스터 데이터, 데이터 카탈로그
## 암기법
* "정표품보" - 정책, 표준, 품질, 보안
## 구성요소
| 구성요소    | 설명               |
| ------- | ---------------- |
| 데이터 정책  | 데이터 관리 원칙 및 지침   |
| 데이터 표준  | 명명규칙, 도메인, 코드 표준 |
| 데이터 품질  | 정확성, 완전성, 일관성 관리 |
| 데이터 보안  | 접근권한, 암호화, 감사    |
| 메타데이터   | 데이터에 대한 데이터 관리   |
| 마스터 데이터 | 핵심 기준 데이터 관리     |
|         |                  |
## 구성도
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260401223933.png|500]]

| 주요 기능 | 설명 |
|---------|------|
| 데이터 **품**질 관리 (DQM) | – 데이터 프로파일링 및 데이터 정제와 같은 작업을 포함하여 데이터 사용방법에 따라 실행 |
| **메**타 데이터 관리 | – 데이터 검색 중 데이터를 찾고, 분석 도구가 빅데이터를 정확하게 해석하고 사용할 수 있도록 실행 |
| 데이터 **주**기 관리 | – 데이터 생성 및 초기 저장에서부터 데이터가 폐기될 때까지 시스템의 데이터 흐름을 관리하는 정책수립 필요 |
| 데이터 **보**안 및 프라이버시 | – 데이터 요구 사항 및 정책은 사용자 역할을 기반으로 필요한 데이터 보호 수준을 정의 |
```
┌─────────────────────────────────────────┐
│          데이터 거버넌스 위원회         │
├─────────────────────────────────────────┤
│  정책    │  표준    │  품질    │ 보안   │
├─────────────────────────────────────────┤
│         데이터 스튜어드 조직            │
├─────────────────────────────────────────┤
│  메타데이터 │마스터데이터│데이터카탈로그│
└─────────────────────────────────────────┘
```
## 역할 체계
| 역할 | 책임 |
|------|------|
| CDO(Chief Data Officer) | 전사 데이터 총괄 |
| 데이터 스튜어드 | 도메인별 데이터 관리 |
| 데이터 아키텍트 | 데이터 구조 설계 |
| 데이터 관리자 | 일상적 데이터 운영 |

##  성숙도 단계

| 단계  | 구분    | 수준        | 품질부문            | 통제부문              | 조직부문             |
| --- | ----- | --------- | --------------- | ----------------- | ---------------- |
| 1단계 | 도입    | 데이터 품질 관리 | 전사 거버넌스 연계 없음   | 통제되지 않음           | 독립적 부서 미존재       |
| 2단계 | 프로세스화 | 프로세스화     | 거버넌스 측면 프로세스 보유 | 의사결정 체계 구축        | 담당자 배치           |
| 3단계 | 통합경영  | 경영진 주도    | 품질관리 진행         | 거버넌스에 전사 전략 비전 반영 | 독립된 거버넌스 조직 존재   |
| 4단계 | 위험대응  | 정량화       | 정량화된 품질 관리      | 데이터 위험 평가, 개선     | 조직 및 위험 관리 수행    |
| 5단계 | 가치창출  | 성과, 문화    | 데이터를 통한 성과 창출   | 분석 결과 산사업 및 전략 반영 | 조직에 경영진 포함 성과 관리 |
