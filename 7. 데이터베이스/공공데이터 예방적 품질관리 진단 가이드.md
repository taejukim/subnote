#정보관리기술사 #데이터베이스 #공공데이터예방적품질관리진단가이드 #데이터베이스/빅데이터/분석 #NEW
## 정의
공공데이터 예방적 품질관리 진단 가이드
- 데이터 품질을 일정 수준 이상으로 보장하기 위해 데이터 표준·구조·값·관리체계 등 4개 영역을 관리하는 활동
## 키워드
* 데이터 표준, 데이터 구조, 데이터 값, 데이터 관리체계, 공공데이터법 제22조
## 암기법
* 표구값관: 표준·구조·값·관리체계
* 계발설개완: 계획·발주·설계·개발·완료(+운영)
## 특징
- 예방적: 구축 전·전 수명주기에 품질 저하 사전 차단
- 4영역·10항목·20기준 체계
- 법령 근거: 공공데이터법 제22조(품질관리)
## 목적
- 공공데이터 품질을 일정 수준 이상 보장
## 구성요소
- 표준: 표준화, 공통표준화, 표준관리도구
- 구조: 구조설계·검증·관리도구
- 값: 값 검증, 이행데이터 검증
- 관리체계: 표준/구조/연계/값 관리체계, 개방 관리체계
- 단계: 계획(ISP/ISMP·RFP) → 발주(RFP·기술협상) → 설계(표준·모델·현황분석) → 개발(매핑·진단규칙·목표모델) → 완료(이행·검증·관리체계) → 운영
## 구성도
```
진단영역(4) → 진단항목(10) → 진단기준(20)
표구값관
계발설개완(+운영): 계획→발주→설계→개발→완료→운영
```
