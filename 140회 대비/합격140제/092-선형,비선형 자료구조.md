#정보관리기술사 #자료구조 #선형자료구조 #비선형자료구조
## 정의
선형/비선형 자료구조
- 선형 자료구조는 원소 간 1:1 관계로 순차 나열되는 구조, 비선형 자료구조는 1:N 또는 N:M 관계로 계층·연결된 구조
- 데이터 배치·연결방식·접근방식의 차이에 따라 구분되는 자료구조의 2대 분류
## 키워드
* 리스트, 스택, 큐, 연결리스트, 트리, 그래프, 1:1 관계, 1:N/N:M 관계
## 암기법
* 배스큐연덱: 배열·스택·큐·연결리스트·덱 (선형 자료구조 5대 유형)
## 특징
- 관계 구조 차이: 선형은 1:1 관계로 순차 나열, 비선형은 1:N·N:M 관계로 계층·네트워크 표현
- 접근방식 차이: 선형은 순차/인덱스 접근, 비선형은 트리·그래프 형태의 비순차 접근
- 메모리 배치 차이: 선형은 연속 메모리 배치, 비선형은 트리·그래프 형태 동적 할당
- 복잡도 차이: 선형은 상대적으로 단순, 비선형은 복잡한 구조와 다양한 탐색방식 요구
## 목적
- 문제 특성에 맞는 최적의 자료구조 선택을 통한 효율적 데이터 처리
- 순차 처리(FIFO/LIFO)와 계층·관계 표현(트리/그래프) 요구사항 충족
## 구성요소
- 선형 자료구조: 배열(인덱스접근), 스택(LIFO), 큐(FIFO), 연결리스트(포인터연결), 덱(양방향)
- 비선형 자료구조: 트리(부모-자식 계층), 그래프(방향/무방향), 힙(우선순위), 트라이(문자열검색), 해시테이블(키-값매핑)
- 선형 구현사례: 스택(함수호출관리), 큐(프린터 대기열), 연결리스트(음악재생목록)
- 비선형 구현사례: 트리(파일시스템), 그래프(네비게이션 경로), 힙(응급실 우선순위)
## 구성도
```
[자료구조]
   ├─ 선형(1:1) : 배열-스택-큐-연결리스트-덱
   │              (순차접근, FIFO/LIFO)
   └─ 비선형(1:N,N:M) : 트리-그래프-힙-트라이-해시테이블
                        (계층/네트워크 접근)
```
