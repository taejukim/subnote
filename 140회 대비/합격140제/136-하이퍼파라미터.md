#정보관리기술사 #AI #하이퍼파라미터 #모델튜닝
## 정의
하이퍼파라미터(Hyperparameter)
- 모델의 구조와 학습 프로세스를 제어하기 위해 사람이 학습 전 수동으로 설정하는 매개변수
- 학습 중 자동 조정되는 파라미터와 달리 실험·경험 기반 튜닝으로 최적값을 도출
## 키워드
* Learning Rate, Epoch, Batch Size, Activation Function, Grid Search, Random Search, Bayesian Optimization
## 암기법
* 목주적영조: 목적·주체·적용시기·영향범위·조정방식(파라미터 vs 하이퍼파라미터 비교축)
## 특징
- 사전설정성: 학습 이전에 연구자가 수동으로 결정
- 구조결정성: 은닉층 수·노드 수 등 모델 전체 구조에 영향
- 성능좌우성: 학습률·배치크기 등이 학습 성능에 큰 영향
- 튜닝필요성: 그리드·랜덤·베이지안 탐색으로 최적조합 탐색 필요
## 목적
- 모델 구조와 학습 과정을 사람이 제어해 최적 성능 도출
- 과적합 방지와 학습 효율성 확보를 위한 최적 조합 결정
## 구성요소
- 아키텍처 관련: 은닉층 수, 노드 수, Activation Function, Dropout Rate
- 학습 관련: Learning Rate, Optimization Algorithm, Epochs, Batch Size, Early Stop
- 탐색기법(Black-box): Grid Search, Random Search, Bayesian Optimization
- 탐색기법(Multi-Fidelity): Hyper-Band, Successive Halving
## 구성도
```
[하이퍼파라미터 후보군 설정]
        ↓
[Grid/Random/Bayesian Search로 조합 탐색]
        ↓
[모델 학습·검증] → [성능평가] → 최적 하이퍼파라미터 도출
```
