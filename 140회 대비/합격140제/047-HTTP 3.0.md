#정보관리기술사 #디지털네트워크 #HTTP3 #QUIC
## 정의
HTTP 3.0(HTTP over QUIC)
- TCP+TLS 조합 대신 UDP+TLS 1.3 기반 QUIC을 사용해 연결·전송 지연을 최소화한 차세대 HTTP 프로토콜
- 2022년 IETF 국제표준 채택 이후 모바일·저지연 서비스에 확산 중인 전송 프로토콜
## 키워드
* UDP, TLS 1.3, QUIC, 0-RTT, 멀티플렉싱, TCP HOL Blocking, Connection ID, QPACK
## 암기법
* 멀홀큐제: 멀티플렉싱·HOLBlocking해결·QPACK·Connection ID의 4대 기능
## 특징
- 멀티플렉싱: 하나의 연결에서 다중 요청 동시 전송
- HOL해결성: TCP HOL Blocking까지 해결(HTTP/2는 미해결)
- 대역폭최적화: QPACK 무손실 헤더압축으로 오버헤드 감소
- 빠른재연결성: 0-RTT와 Connection ID로 IP변경에도 연결 유지
## 목적
- 연결·전송 지연 최소화를 통한 웹 응답 속도 개선
- 모바일·5G 환경에서 안정적이고 빠른 통신 지원
## 구성요소
- 프로토콜 스택: IP(3계층)-UDP-QUIC(4계층)-TLS1.3(5계층)
- 주요기능: 멀티플렉싱, TCP HOL Blocking 해결, QPACK, 0-RTT, Connection ID
- 연결과정: 1-RTT Handshake(최초 연결) → 0-RTT Handshake(재연결, 캐싱된 자격증명 활용)
- 5G 연계: 초저지연 실현, 엣지컴퓨팅 최적화, 보안성(TLS1.3), 이동성(Connection ID)
## 구성도
```
[Application: HTTP/3]
[TLS 1.3]   - 암호화/세션
[QUIC]      - 신뢰성 전송, 멀티플렉싱, 0-RTT
[UDP]       - 경량 전송
[IP]        - 주소/라우팅
최초연결: Client --1-RTT(Initial CHLO→Rejection→Complete CHLO)--> Server
재연결  : Client --0-RTT(캐싱된 자격증명, 즉시 요청)--> Server
```
