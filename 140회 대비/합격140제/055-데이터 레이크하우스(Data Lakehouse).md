#정보관리기술사 #데이터베이스 #데이터레이크하우스 #DataLakehouse
## 정의
데이터 레이크하우스(Data Lakehouse)
- 데이터 레이크 계층 위에 데이터 웨어하우스 역할 계층을 통합하여 저렴한 스토리지와 고품질 데이터 관리를 함께 구현한 아키텍처
- 데이터 사일로와 데이터 늪(Data Swamp) 문제를 해결하기 위해 등장한 통합 데이터 아키텍처
## 키워드
* 데이터 레이크, 데이터 웨어하우스, ACID 트랜잭션, 배치·스트리밍, 데이터 카탈로그, Open API
## 암기법
* 늪사통: 데이터 늪·데이터 사일로 해결을 위한 통합 아키텍처 (레이크하우스 등장 배경)
## 특징
- 통합성: 레이크의 유연성과 웨어하우스의 신뢰성을 동시 확보
- 트랜잭션성: ACID 트랜잭션으로 데이터 정확성 보장
- 직접연결성: 데이터 복제 없이 BI 도구와 직접 연동 가능
- 메타데이터 기반: 데이터 카탈로그로 검색·품질·계보 관리
## 목적
- 데이터 웨어하우스·레이크 분리로 인한 데이터 단절(사일로) 해소
- 저비용 저장과 고품질 관리를 동시에 실현하는 통합 분석 환경 제공
## 구성요소
- 데이터 수집·변환: Batch Processing, Streaming Processing(CDC·CEP)
- 데이터 저장 관리: ACID 트랜잭션, 데이터 파이프라인, 메타데이터, 스토리지 레이어(Object/HDFS)
- 데이터 서빙: Open API(REST/gRPC/JDBC), BI 도구·대시보드
- 데이터 카탈로그: 메타데이터 수집·검색·품질관리·분류(Apache Atlas, Collibra 등)
## 구성도
```
[정형/비정형 데이터 소스]
        │ Batch / Streaming(CDC,CEP)
        ▼
[데이터 레이크 스토리지: Object/HDFS]
        │  ACID 트랜잭션 + 메타데이터(스키마·버전)
        ▼
[레이크하우스 계층] ──데이터 카탈로그(검색/품질/분류)
        │
   ┌────┴────┐
[Open API]  [BI/대시보드]
```
