#정보관리기술사 #AI #프롬프트엔지니어링 #InContextLearning
## 정의
프롬프트 엔지니어링 & 인-컨텍스트 러닝(ICL)
- 사전학습된 LLM을 재학습 없이 입력 프롬프트 설계만으로 원하는 출력을 유도하는 기술과 그 학습 패러다임
- 프롬프트 내 예제 수에 따라 원샷·퓨샷·제로샷으로 구분되는 메타러닝의 한 방식
## 키워드
* Instruction, Context, Input Data, Output Indicator, One-shot, Few-shot, Zero-shot
## 암기법
* 원퓨제: 원샷·퓨샷·제로샷(ICL 3가지 방식)
## 특징
- 모델 미업데이트: 파인튜닝과 달리 모델 파라미터 변경 없이 동작
- 프롬프트 4대 구성: Instruction·Context·Input Data·Output Indicator로 구조화
- 예제 기반 유도: Demonstration Example로 New Query 응답 방향 결정
- 대형 모델 의존성: 파라미터 10억개 이상 모델에서 효과 극대화
## 목적
- 재학습 없이 LLM의 응답 정확성·유용성을 극대화
- 다양한 다운스트림 태스크에 신속하고 유연하게 적용
## 구성요소
- Instruction: 모델이 수행할 지시사항
- Context: 더 나은 답변을 위한 외부 정보
- Input Data: 질의 대상 데이터
- Output Indicator: 결과물 형식 지정
- ICL 방식: One-shot/Few-shot/Zero-shot Learning
## 구성도
```
[Instruction] + [Context] + [Input Data] + [Output Indicator]
                    ↓ Prompt
        [Demonstration Examples: 0개/1개/N개]
                    ↓
              [Pre-trained LLM] → Output
```
