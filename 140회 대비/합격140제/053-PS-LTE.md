#정보관리기술사 #디지털네트워크 #PSLTE #국가재난안전통신망
## 정의
PS-LTE(Public Safety-LTE)
- 화재·홍수·지진 등 재난 발생 시 신속·효율적 재난관리를 위해 LTE 기술을 무선 교신에 적용한 국가재난안전통신망
- 재난 관련 기관에 적합한 통합 지휘 통신망을 제공하는 4세대 이동통신 기반 공공안전망
## 키워드
* MCPTT, IOPS, GCSE, ProSe(D2D), eMBMS, RAN-Sharing, MORAN, MOCN, GWCN
## 암기법
* 골음재의비: 골든타임확보·음영지역제로화·재산보호·의사소통일원화·비용절감 (PS-LTE 5대 추진목적)
## 특징
- 통합성: 전국 단일망으로 기관간 동시 상황 전파
- 신속성: MCPTT로 0.3초 이내 즉시 그룹통화 제공
- 복원력: IOPS로 망 단절 시 이동기지국 기반 임시 커버리지 확보
- 자원공유성: RAN-Sharing으로 700MHz 대역 전파간섭 완화
## 목적
- 재난 현장 골든타임 확보 및 인명피해 최소화
- 단일망 통합 운영을 통한 중복투자 해소와 비용 절감
## 구성요소
- MCPTT: ProSe·GCSE 기반 즉시 그룹/개별 통화 서비스
- IOPS: 망 단절 시 이동기지국 활용한 단독기지국 운용모드
- GCSE: Unicast(1:1)/MBMS(1:N) 기반 그룹통신 핵심기술
- D2D/ProSe: 기지국 경유 없이 단말 간 직접 통신
- eMBMS: 방송서비스 기반 멀티유저 그룹통신
- RAN-Sharing: MORAN(RAN 공유), MOCN(코어+RAN 공유), GWCN(MME까지 공유)
## 구성도
```
[재난 현장 단말] --MCPTT/GCSE/D2D--> [단말 그룹]
        │
   [PS-LTE 기지국] --IOPS(단절시 이동기지국)--
        │
   [RAN-Sharing: MORAN/MOCN/GWCN]
        │
   [통합 재난관리 지휘센터] ← 실시간 상황 전파
```
