#정보관리기술사 #AI #VLM #멀티모달
## 정의
VLM(Vision-Language Models)
- 컴퓨터 비전과 자연어 처리 기능을 결합하여 이미지와 텍스트를 함께 처리하는 멀티모달 AI 모델
- 언어·비전 인코더 출력을 동일 벡터공간에 매핑해 이미지 이해·생성 태스크 수행
## 키워드
* 언어 인코더, 비전 인코더, 멀티모달 융합, 대조적 학습, ViT, CLIP
## 암기법
* 언비융출: 언어인코더·비전인코더·멀티모달융합·출력레이어(VLM 4대 요소)
## 특징
- 이미지 설명 생성: 이미지 내용을 자연어로 설명
- 이미지 질의응답: 이미지 속 객체·장면에 대한 질의 응답
- 멀티모달 추론: 이미지+텍스트 결합 추론 수행
- 공통 임베딩 공간: 언어·비전 인코더 결과를 동일 벡터공간으로 정렬
## 목적
- 이미지와 텍스트를 통합 처리하여 응용 범위 확장
- 캡셔닝·질의응답 등 실세계 멀티모달 서비스 품질 향상
## 구성요소
- 언어 인코더: 텍스트 의미·문맥을 임베딩으로 변환
- 비전 인코더: 이미지 속성을 벡터 임베딩으로 변환
- 멀티모달 융합: 이미지·텍스트 벡터 결합 및 상관관계 학습
- 출력 레이어: 최종 결과 생성
- 학습방법: 대조적 학습, 마스킹, 생성형 모델 학습
## 구성도
```
[Image] → 비전 인코더(ViT) ──┐
                              ├→ [멀티모달 융합(공통 임베딩공간)] → [출력레이어] → 결과
[Text]  → 언어 인코더 ────────┘
```
