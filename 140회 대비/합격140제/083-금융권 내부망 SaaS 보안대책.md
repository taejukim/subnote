#정보관리기술사 #보안 #SaaS보안 #망분리예외
## 정의
금융권 내부망 SaaS 보안대책
- 금융회사가 내부망에서 SaaS를 이용할 수 있도록 이용가능 데이터 범위와 보안대책을 정한 규제 샌드박스 지침
- 망분리 예외를 전제로 단말기·연계·관리·운영정책 4대 영역의 보안통제를 요구하는 체계
## 키워드
* SaaS이용불가 데이터(보안관리, IT개발운영, 고객관리), 보안대책(단말기·연계·관리·운영정책), 망분리 대체통제, MFA
## 암기법
* 단연관운: 단말기·연계·관리·운영정책 (SaaS 보안대책 4대 영역)
## 특징
- 데이터 범위 제한: 고객정보·전자금융거래정보 처리 업무는 SaaS 이용 불가, 비중요 협업업무만 허용
- 단말기 물리적 분리: SaaS 접속 단말은 고객정보 처리 시스템과 분리, 허용 SaaS 외 접속 차단
- 연계구간 암호화: TLS 1.2 이상·VPN 적용, 대고객 트래픽과 SaaS 트래픽 망 분리
- 관리 상시성: 최소권한 부여, 로그 1년 이상 보존, 이상징후 모니터링 및 취약점 패치 확인
## 목적
- 망분리 예외 허용에 따른 침해사고(정보유출·악성코드·비인가접근) 예방
- 규제 샌드박스를 통한 SaaS 활용 확대와 보안성 확보의 균형
## 구성요소
- 이용불가 데이터: 보안관리(인증·웹격리), IT개발운영(개발테스트·장애관리), 고객관리(대고객업무·CRM)
- 이용가능 데이터: 협업도구(메신저·화상회의·오피스SW), ERP(인사·계약·회계), 데이터분석·교육관리
- SaaS 단말기 보안대책: 등록·해지 절차, 망분리 대체통제, MFA, 중계서버(Proxy) 운영
- SaaS 연계 보안대책: 무관 웹사이트 차단, 트래픽 분리, 구간 암호화
- SaaS 관리·운영정책: 권한 최소화, 로그관리, 제3자 앱 승인, 사전 보안성 검토, 침해사고 대응절차
## 구성도
```
[내부 단말기] ──(SaaS전용 중계서버/MFA)──> [SaaS]
      │                                         │
   물리적 분리                          제3자 제공앱
      │                                         │
고객정보 시스템(연결금지)              (관리자 승인·모니터링)
      ↑
4대 보안대책: 단말기 / 연계(암호화) / 관리(로그·권한) / 운영정책(교육·사고대응)
```
