#정보관리기술사 #AI #GraphRAG #지식그래프
## 정의
Graph RAG(Retrieval-Augmented Generation)
- 지식 그래프에서 엔티티·관계를 추출해 그래프 구조 기반으로 문맥을 검색·요약, LLM 응답에 활용하는 고급 RAG 기법
- 벡터 유사도 기반 단순 검색의 한계를 극복한 다단계 관계 추론형 검색-생성 프레임워크
## 키워드
* 지식그래프, 엔티티-관계, 그래프 순회, Community Detection, Leiden Algorithm, Map-Reduce LLM
## 암기법
* 그커하응: 그래프인덱싱·커뮤니티탐지·하이브리드검색·응답생성(Graph RAG 4대 요소)
## 특징
- 구조적 관계 탐색: 엔티티 간 다단계 관계(홉) 순회로 복잡 질의 처리
- Community 요약: Leiden 알고리즘으로 커뮤니티 감지·계층적 요약
- 할루시네이션 감소: 그래프 근거 기반 응답으로 신뢰도 향상
- 하이브리드 검색: 그래프 순회(Local)와 벡터 검색을 결합
## 목적
- 다단계 추론이 필요한 복잡 질의에 대한 정확한 응답 생성
- 글로벌 맥락 포착을 통한 근거 기반 신뢰성 있는 답변 제공
## 구성요소
- 그래프 인덱싱: 문서에서 엔티티·관계 추출, 트리플 형태 저장
- 커뮤니티 탐지: Leiden Algorithm으로 계층적 커뮤니티 분할·요약
- 하이브리드 검색: 그래프 순회+벡터, 커뮤니티 요약 검색 결합
- 응답 생성: 서브그래프별 Map 답변 후 Reduce로 통합 응답
## 구성도
```
[문서] → [엔티티/관계 추출] → [지식그래프(트리플)] → [Leiden 커뮤니티 탐지]
                                        ↓
   [하이브리드 검색: Local 순회 + Global 커뮤니티요약]
                                        ↓
        [Map: 서브그래프별 답변] → [Reduce: 통합응답] → LLM 최종 응답
```
