#정보관리기술사 #AI #AgenticOps #에이전트운영
## 정의
에이전틱옵스(AgenticOps)
- 자율적 의사결정 능력을 가진 AI 에이전트의 전체 생애주기를 관리하고 도구·환경과의 상호작용을 안정적으로 운영하는 프레임워크
- Agentic 개발과 Ops 운영을 결합한 선순환 구조의 에이전트 운영체계
## 키워드
* 자율형 AI 에이전트, Human-in-the-loop, 재귀적 피드백 루프, Fine-Tuning
## 암기법
* 코빌테디오리: 코드·빌드·테스트·디플로이·오퍼레이트·리테인(AgenticOps 6단계)
## 특징
- 목표지향적 자율성: 상위 목표만 제시하면 에이전트가 세부계획 수립·수행
- 재귀적 피드백 루프: 실행결과를 재입력해 추론을 실시간 보정
- Agentic-Ops 결합: 설계·배포·재학습 단계를 결합한 선순환 구조
- LLMOps와 차별화: 정적 모델 품질이 아닌 동적 환경변화 관리
## 목적
- AI 에이전트의 안정적 배포·운영과 지속적 성능 고도화
- 다중 에이전트 협업 환경에서 역할 분담과 성과 측정 체계화
## 구성요소
- Code: IDE 환경에서 에이전트 기능 구현
- Build/Test: 프롬프트 결합 빌드, 샌드박스 안전성 검증
- Deploy/Operate: 운영환경 배포, 실시간 관제 모니터링
- Retain: 운영데이터로 Fine-tuning 후 다시 Code 단계로 환류
## 구성도
```
[Code] → [Build] → [Test(샌드박스)] → [Deploy] → [Operate(모니터링)]
   ↑                                                      ↓
   └──────────────── [Retain: Fine-tuning] ←──────────────┘
```
