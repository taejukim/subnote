#정보관리기술사 #프로젝트관리 #RACI매트릭스 #역할분담
## 정의
RACI 매트릭스
- 프로젝트 활동의 책임과 역할을 R/A/C/I 4단계로 구분하여 표현한 업무분장 매트릭스
- 프로젝트의 의사소통, 평가 및 수용을 지원하는 역할관리 도구
## 키워드
* Responsible, Accountable, Consulted, Informed, 업무분장표, 역할과 책임
## 암기법
* 책승고통: 책임·승인·고려대상·통보 (R,A,C,I 4가지 역할)
## 특징
- 역할 명확화: 작업별 4가지 역할·책임을 명확하게 정의
- 중복/누락 방지: 모든 작업에 R, A를 최소 1개씩 지정
- 단일 승인자 원칙: A는 한 작업당 반드시 한 명만 지정
- 유연한 겸직: R/A, C/I는 한 주체에 동시 할당 가능
## 목적
- 프로젝트 참여자 간 역할·책임의 모호성 제거
- 원활한 의사소통과 책임 소재 명확화로 프로젝트 통제력 강화
## 구성요소
- R(Responsible): 실무담당자, 실제 작업을 수행·완수하는 책임
- A(Accountable): 의사결정권자, 최종 승인·검토 수행(작업당 1인)
- C(Consult): 업무수행 조언자, 전문지식·경험 기반 자문 제공
- I(Inform): 결과보고 대상자, 진행상황·결과를 통보받는 역할
## 구성도
```
                Task
   ┌───────────┬───────────┬───────────┬───────────┐
   │  R(책임)  │  A(승인)  │  C(자문)  │  I(통보)  │
   │ 실무수행  │ 최종승인  │ 조언제공  │ 결과보고  │
   └───────────┴───────────┴───────────┴───────────┘
     People1     People2     People3     People4
```
