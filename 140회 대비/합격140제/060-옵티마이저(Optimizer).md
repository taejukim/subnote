#정보관리기술사 #데이터베이스 #옵티마이저 #CBO
## 정의
옵티마이저(Optimizer)
- 사용자 SQL의 실행계획을 탐색하고 각 계획의 비용을 추정하여 최적 실행계획을 수립하는 DBMS 핵심 엔진
- RBO(규칙 기반)와 CBO(비용 기반) 두 방식으로 구분되는 질의 최적화 기술
## 키워드
* 실행계획, Rule 기반, 비용산정, Query Rewrite, QEP, 선택도, 카디널리티, 히스토그램, 비용(Cost)
## 암기법
* 파질옵큐: Parse·Query Rewrite·Query Optimization·QEP생성·Query Execution (옵티마이저 5단계 질의처리)
## 특징
- 경로탐색성: 가능한 실행계획을 나열하고 비용을 비교해 최적안 선택
- 규칙vs비용: RBO는 고정규칙 기반 정적 최적화, CBO는 통계정보 기반 동적 최적화
- 통계의존성: CBO는 테이블·인덱스·컬럼 통계정보 정확성에 성능이 좌우됨
- 산정지표: 선택도·카디널리티·히스토그램으로 비용을 정밀 계산
## 목적
- 다양한 실행경로 중 최소 비용의 실행계획으로 SQL 성능 최적화
- 통계정보 기반 현실적 데이터 특성 반영한 정확한 실행계획 수립
## 구성요소
- Parse: 구문·보안·의미 검사 및 단순 변환 수행
- Query Rewrite: 서브질의·뷰 병합, OR Expansion 등 질의 변환
- Query Optimization: RBO/CBO 방식으로 접근경로 결정
- QEP Generation: 질의실행계획과 실행 상세정보 생성
- 참조 통계정보: 테이블 통계(행수·블록수), 인덱스 통계(리프블록·레벨), 컬럼 통계(NDV)
- 활용 통계정보: 선택도(1/DV), 카디널리티(행수×선택도), 히스토그램, 비용(I/O·CPU)
## 구성도
```
[SQL 질의] → [Parse] → [Query Rewrite] → [Query Optimization]
                                              │  RBO(규칙) / CBO(통계+비용)
                                              ▼
                          참조통계(테이블/인덱스/컬럼)
                                → 활용통계(선택도/카디널리티/히스토그램/비용)
                                              ▼
                          [QEP 생성] → [Query Execution] → 결과
```
