#정보관리기술사 #보안 #암호분석 #양자내성암호
## 정의
암호분석: 케르히호프 원리와 양자내성암호기술
- 케르히호프 원리는 암호 시스템의 보안이 비밀키의 비밀성에만 의존해야 한다는 설계 원칙
- 양자내성암호(PQC)는 양자컴퓨터의 계산능력으로도 해독이 어렵도록 설계된 암호기술
## 키워드
* 알고리즘 공개, 비밀키, 격자기반, 해시기반, 코드기반, 다변수, 아이소제니, Shor, Grover
## 암기법
* 격해코다아: 격자기반·해시기반·코드기반·다변수다항식·아이소제니 (PQC 5대 유형)
## 특징
- 알고리즘 공개성: 케르히호프 원리는 알고리즘 공개, 키만 비밀 유지 요구
- 표준화 지향성: 두 개념 모두 국제표준(AES/RSA, PQC 표준화)에 기반해 검증됨
- 수학적난제기반성: 소인수분해·이산로그(기존)와 격자·코드 문제(PQC) 활용
- 민첩성: 특정 알고리즘 종속 지양, 취약점 발견 시 교체 용이성 확보
## 목적
- 암호시스템의 투명성·검증가능성·신뢰성 확보 및 지속가능한 보안 유지
- Shor·Grover 알고리즘 기반 양자컴퓨팅 위협에 대한 선제적 암호체계 전환
## 구성요소
- 케르히호프 원리 3원칙: 알고리즘 공개(투명성), 수학적 난제 기반 설계, 키 비밀성·키관리 최우선
- 격자 기반(Lattice): 최단벡터문제(SVP) 기반, CRYSTALS-Kyber/Dilithium
- 해시 기반(Hash): 해시함수 충돌저항성 기반, SPHINCS+, XMSS
- 코드 기반(Code): 선형코드 디코딩 문제, McEliece, BIKE
- 다변수 다항식: 유한체 연립방정식 풀이 난제, Rainbow, MAYO
- 아이소제니 기반: 타원곡선 아이소제니 계산 난제, SIKE, SQIsign
## 구성도
```
[케르히호프 원리] 알고리즘공개 + 비밀키 의존
        │ 설계철학 계승
        ▼
[PQC 설계] Shor/Grover 대응 수학적 난제 선택
        │
  ┌─────┼─────┬─────┬─────┐
격자기반 해시기반 코드기반 다변수 아이소제니
(Kyber) (SPHINCS+) (McEliece) (Rainbow) (SIKE)
```
