#정보관리기술사 #운영체제 #부팅 #커널
## 정의
운영체제(Operating System)
- 컴퓨터의 HW·SW 자원을 효율적으로 관리해 사용자가 편리하게 컴퓨터를 사용하도록 지원하는 시스템 소프트웨어
- 사용자와 하드웨어 간 인터페이스로서 응용프로그램 실행 환경을 제공
## 키워드
* 프로세스 관리, 부트로더, BIOS, POST, MBR, init, Run Level, Monolithic/Micro/Hybrid/Exo Kernel
## 암기법
* 프파네메보입명: 프로세스·파일·네트워크·메모리·보조기억·입출력·명령어해석 관리(주요기능)
## 특징
- 자원관리: 프로세스·메모리·파일·I/O 등 시스템 자원 통합 관리
- 인터페이스 제공: 사용자·응용프로그램과 하드웨어 간 매개
- 부팅 절차 주도: BIOS→부트로더→커널 적재→init 순 단계적 초기화
- 커널 구조 다양성: Monolithic·Micro·Hybrid·Exo 등 목적별 커널 구조 선택
## 목적
- 컴퓨터 자원의 효율적 배분과 관리로 시스템 성능 극대화
- 사용자 편의성과 응용프로그램 실행 환경의 일관성 제공
## 구성요소
- BIOS/POST: 하드웨어 인식 및 초기화, 이상 유무 점검
- 부트로더(MBR/GRUB): 부팅매체 검색 후 커널 이미지 로드
- 커널(PID=0/1): 루트 파일시스템 마운트, init 프로세스 호출
- init 프로세스: 모든 프로세스의 부모, Run Level별 초기화 스크립트 실행
- 커널 종류: Monolithic(UNIX/Linux), Micro(AmigaOS), Hybrid(ReactOS), Exo(Nemesis)
## 구성도
```
[BIOS/POST] → [부트로더(MBR/GRUB)] → [커널 이미지 로드]
     → [루트FS 마운트] → [init(PID=1) 호출] → [Run Level 스크립트]
                              ↓
        Kernel 구조: Monolithic | Micro | Hybrid | Exo
```
