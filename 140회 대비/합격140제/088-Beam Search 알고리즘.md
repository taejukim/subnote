#정보관리기술사 #알고리즘 #BeamSearch #DecodingStrategy
## 정의
Beam Search 알고리즘
- LLM의 Text Generation 과정에서 매 단계마다 점수가 높은 상위 k개 후보 시퀀스만 유지하며 탐색하는 디코딩 알고리즘
- Greedy Search와 Sampling의 중간 지점에서 품질과 계산효율의 균형을 취하는 대표적 Decoding Strategy
## 키워드
* Beam Width(k), 후보 시퀀스, 조건부 확률, 누적 로그확률, Top-k 선택, 가지치기, Greedy Search, Sampling
## 암기법
* 초예후점상종: 초기화·다음토큰예측·후보확장·점수계산·상위k선택·종료조건 (Beam Search 6단계)
## 특징
- 상위 k개 유지: Beam Width(k) 설정으로 매 단계 후보 시퀀스 개수를 제한해 탐색범위·계산량 결정
- 누적확률 기반 평가: 로그확률 합(Score)으로 후보 시퀀스의 품질을 정량 비교
- 문맥 일관성 우수: 여러 후보 비교로 Greedy 대비 문장 전체 일관성 확보에 유리
- 계산비용 증가: 시간복잡도 O(T×k×V)로 Greedy(O(T×V)) 대비 Beam Width만큼 비용 증가
## 목적
- 단일 최적 선택의 국소최적 함정을 회피해 더 높은 품질의 출력 시퀀스 탐색
- 번역·요약·코드생성 등 정합성이 중요한 생성 작업의 품질 향상
## 구성요소
- 초기화: Beam Width k 설정, 초기 후보 시퀀스 생성
- 다음토큰 예측: 조건부 확률분포 P(y_t+1|y_1...y_t) 계산
- 후보확장: 각 후보에 다음토큰 결합해 새로운 후보 생성
- 점수계산: 누적 로그확률 Score(Y)=Σlog P(y_i|...) 산출
- 상위k선택: Top-k 기반 가지치기로 상위 k개 후보만 유지
- 종료조건 확인: 종료토큰 생성 또는 최대길이 도달 시 최고점수 시퀀스 최종 출력
## 구성도
```
[초기 토큰] → 후보 확장(V개 토큰) → 점수계산 → Top-k 선택(k개 유지)
                                        ↓ 반복
                              [종료조건 충족?] → 최고점수 시퀀스 출력
비교: Greedy Search = k=1 (단일경로만 유지)
```
