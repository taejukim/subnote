#정보관리기술사 #데이터베이스 #데이터레이크 #DataLake
## 정의
데이터 레이크(Data Lake)
- 정형·반정형·비정형 데이터를 원본 그대로 저장해 사용 시 필요한 형태로 제공하는 대용량 데이터 저장소
- 다양한 데이터 소스를 스키마 없이(Schemaless) 원시형태로 저장하는 AI시스템의 핵심 저장소
## 키워드
* 대용량 데이터 저장소, Schemaless, 확장성, 데이터 카탈로그, 메타데이터, ELT, Parquet/ORC
## 암기법
* 모고유확: 모든형태저장·고성능처리·유연변환·확장성 (데이터 레이크 4대 기술적 필요성)
## 특징
- 무스키마성: Schema-on-Read로 저장 시 스키마 강제 없이 원시 저장
- 전형식수용성: 정형·반정형·비정형 데이터 모두 원본 그대로 저장
- 고확장성: 오브젝트 스토리지 기반으로 무제한 확장 가능
- 데이터늪위험성: 관리 소홀 시 품질 저하된 데이터 늪(Data Swamp)으로 전락
## 목적
- 분산된 전사 데이터를 통합해 데이터 사일로 해소
- AI/ML 분석 및 예측모델 구축을 위한 원천 데이터 확보
## 구성요소
- 데이터 소스: RDB(정형), 비정형(이미지·텍스트), 스트리밍(IoT·클릭스트림)
- 데이터 수집·처리: Kafka/Pub-Sub(메시징), Spark/Flink(분산처리), ETL/ELT 파이프라인
- 데이터 레이크 저장: S3/ADLS/HDFS(원시저장), Parquet/ORC(컬럼압축), 데이터 카탈로그
- AI/ML 플랫폼: TensorFlow/PyTorch, Feature Engineering, MLOps(MLflow, Kubeflow)
- 서비스 계층: REST API/gRPC, BI/대시보드, AI 서비스(추천·이미지인식)
## 구성도
```
[RDB][비정형][스트리밍] → [Kafka/Spark ETL/ELT]
                                  ▼
                    [데이터 레이크: S3/HDFS + Parquet/ORC]
                                  ▼         (데이터 카탈로그: 메타데이터 관리)
                    [AI/ML 플랫폼: Feature Eng./MLOps]
                                  ▼
                    [REST API / BI 대시보드 / AI 서비스]
```
