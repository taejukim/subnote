#정보관리기술사 #자료구조 #해시테이블 #해시충돌
## 정의
해시(Hash) 테이블
- 해시함수를 사용해 변환한 값을 인덱스로 삼아 키와 값을 저장, 빠르게 검색 가능한 자료구조
- 나눗셈법·폴딩법 등 다양한 해시함수 기법과 개방주소법·체이닝 등 충돌 해결방안으로 구성
## 키워드
* 키, 해시함수, 버킷, 충돌, 오버플로우, 나눗셈법, 폴딩법, 중간제곱법, 개방주소법, 체이닝
## 암기법
* 나중기자: 나눗셈법·중간제곱법·기수변환법·자릿수분석법(폴딩법 포함) (해시함수 5대 기법)
## 특징
- 빠른 접근성: 해시함수로 계산된 인덱스를 통해 평균 O(1) 시간에 데이터 접근
- 충돌 불가피성: 서로 다른 키가 동일 주소로 매핑되는 충돌(Collision) 발생 가능
- 기법 다양성: 나눗셈법·중간제곱법·기수변환법·폴딩법·자릿수분석법 등 수학적/키특성 기반 기법 존재
- 충돌해결 이원화: 개방주소법(선형·이차조사·이중해싱)과 체이닝(연결리스트)으로 대응
## 목적
- 대용량 데이터에서 검색·삽입·삭제를 평균 O(1)에 수행하는 효율적 자료구조 제공
- 키-값 매핑을 통한 신속한 데이터 접근 및 캐싱·인덱싱 지원
## 구성요소
- 해시함수: 키를 물리적 주소로 사상하는 단방향 함수
- 해시테이블·버킷·슬롯: 직접 접근 가능한 배열 구조와 저장 단위
- 수학적 기법: 나눗셈법(모듈러 연산), 중간제곱법(제곱 후 중간비트 추출), 기수변환법(진법 변환)
- 키특성 기법: 폴딩법(부분 분할 후 XOR/덧셈), 자릿수분석법(고른 분포 자릿수 선택)
- 충돌해결: 개방주소법(선형조사·이차조사·이중해싱), 체이닝(연결리스트로 폐쇄주소법)
## 구성도
```
[Key] → 해시함수(나눗셈법 등) → Index
                                    ↓
                     [버킷0][버킷1][버킷2]...
                        ↓ 충돌 발생 시
        개방주소법: 다음 빈 버킷 탐색(선형/이차/이중해싱)
        체이닝: 해당 버킷에 연결리스트로 추가
```
