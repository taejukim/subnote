#정보관리기술사 #SW공학 #위험기반테스트 #RiskBasedTesting
## 정의
위험 기반 테스트(Risk Based Testing)
- 영향도와 발생가능성을 기준으로 위험도 높은 부분에 테스트 자원을 집중하는 기법
- 한정된 테스트 자원의 효율적 배치를 위한 위험 우선순위 기반 테스트 전략
## 키워드
* STA, STTA, ITA, FTA, PI 매트릭스, 위험대응계획
## 암기법
* 식분위계수: 식별·분석·위험대응계획·계획·수행/모니터링 (RBT 5단계 절차)
## 특징
- 위험우선순위화: 영향도×발생가능성으로 테스트 영역을 등급 구분(STA~FTA)
- 자원효율화: 한정된 자원을 고위험 영역에 집중 배치
- 단계별차등: 완료조건·인력·보고방법을 위험수준별로 차등 적용
- 상황적응성: 업무중심/사용자중심 등 시스템 특성별 전략 선택
## 목적
- 제한된 테스트 자원으로 결함 발견 효과를 극대화
- 고위험 영역 우선 검증을 통한 품질 리스크 최소화
## 구성요소
- STA(Severe Test Area): 발생가능성·영향도 모두 높아 필수 테스트
- STTA(Strong Test Area): 테스트 권고 영역
- ITA(Intensive Test Area): 상황에 따라 진행하는 영역
- FTA(Fundamental Test Area): 테스트 생략 가능 영역
- 절차: 식별(Risk Item) → 분석(PI Matrix) → 위험대응계획 → 테스트계획 → 수행/모니터링
## 구성도
```
Likelihood(발생가능성)
   ↑
   │  STA(필수)     STTA(권고)
   │  ITA(권고)      FTA(생략가능)
   └──────────────────────────→ Impact(영향도)
```
