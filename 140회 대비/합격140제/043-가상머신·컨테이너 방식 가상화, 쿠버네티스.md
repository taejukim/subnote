#정보관리기술사 #운영체제 #컨테이너가상화 #쿠버네티스
## 정의
가상머신/컨테이너 방식 가상화와 쿠버네티스
- 하이퍼바이저 기반 가상머신과 커널 공유형 컨테이너로 나뉘는 가상화 방식 및 컨테이너 워크로드 관리 플랫폼
- 마이크로서비스 배포에 최적화된 경량 실행환경과 이를 오케스트레이션하는 쿠버네티스 체계
## 키워드
* 하이퍼바이저, 컨테이너, Virtual Machine, Kubelet, Etcd, Bin/Library, Pod
## 암기법
* 이효신라: 이식성·효율성·신속성·라이선스비용 관점에서 VM과 컨테이너 비교
## 특징
- 격리수준: VM은 게스트OS 단위 완전분리, 컨테이너는 커널 공유 격리
- 경량성: 컨테이너는 Bin/Library만 패키징해 MB단위로 생성
- 이식성: 컨테이너는 실행환경 일관성 확보로 마이크로서비스에 최적
- 자원효율성: 컨테이너는 필요한 만큼만 자원 사용, VM은 오버헤드 큼
## 목적
- 서버 자원의 논리적 분할을 통한 다중 워크로드 실행 및 비용 절감
- 컨테이너 기반 마이크로서비스의 이식성·확장성 있는 배포 운영
## 구성요소
- 가상머신 방식: 하이퍼바이저 + 게스트OS(1VM당 1서비스, 높은 안정성)
- 컨테이너 방식: 컨테이너 런타임 + Bin/Library(호스트OS커널 공유, 높은 효율성)
- 쿠버네티스 마스터: 컨트롤매니저, API서버, Etcd, 스케줄러
- 쿠버네티스 워커노드: Kubelet, Kube-proxy, 컨테이너 런타임
## 구성도
```
[HW] → [Host OS] → 하이퍼바이저 → [Guest OS1][Guest OS2] (VM방식, 무겁고 안정적)
[HW] → [Host OS] → 컨테이너 런타임 → [App+Bin/Lib1][App+Bin/Lib2] (컨테이너, 경량·효율적)
[Master: API서버-Etcd-스케줄러-컨트롤매니저] ↔ [Worker: Kubelet-Kubeproxy-컨테이너런타임(Pod)]
```
