#정보관리기술사 #디지털네트워크 #IMT2030 #6G
## 정의
IMT-2030(6G)
- ITU-R이 제시한 2030년 이후 이동통신(6G)의 비전·사용 시나리오·핵심역량·기술 발전 방향을 정의한 국제 프레임워크
- TN-NTN 통합 초공간 연결성과 AI-Native Network 자율운영을 핵심으로 하는 차세대 통신 비전
## 키워드
* 몰입형 통신, 초신뢰초저지연, 대규모 통신, 센싱-통신 융합, TN, NTN, LEO/MEO/GEO, HAPS, ISL, IBN, SON, Agentic AI, NWDAF
## 암기법
* 몰초대인센유: 몰입형·초신뢰초저지연·대규모통신·인공지능융합·센싱융합·유비쿼터스 (6G 6대 사용시나리오)
## 특징
- 초공간성: 지상·해상·공중 전 영역 커버리지 확장
- 지능내재화: AI를 네트워크 핵심 구성요소로 통합(AI-Native)
- 초연결성: TN-NTN 통합으로 음영지역 없는 유비쿼터스 연결
- 자율운영성: SON·Self-healing 기반 자가 구성·복구·최적화
## 목적
- 지상·비지상 전 영역의 끊김 없는 초연결 서비스 실현
- AI 전주기 내재화를 통한 지능형 자율운영망 구현
## 구성요소
- TN 접속: gNB 지상기지국, 저지연·고용량 무선접속 제공
- NTN 접속: LEO/MEO/GEO 위성, HAPS/UAV로 광역·재난 커버리지 제공
- 링크연동: NTN Gateway, ISL(위성간 링크), Feeder/Service Link
- 이동성/자원: Handover Algorithm, Dual Connectivity, DSA/DSS 동적 자원할당
- AI for Network: IBN, SON, Self-healing, Agentic AI, Closed-Loop Automation
- Network for AI: Edge AI, In-network Computing, Distributed AI, AI Traffic Orchestration
## 구성도
```
[LEO/MEO/GEO 위성] [HAPS/UAV]
        │  ISL/Feeder Link │
        └──────┬───────────┘
          [NTN Gateway] ── Service Link ── [단말]
               │
        ┌──────┴──────┐
        │  TN-NTN 통합망 │ ← DSA/DSS 자원공유, Handover
        └──────┬──────┘
               │
      [gNB 지상기지국] ── [코어망]
               │
     [AI-Native Network: IBN/SON/Agentic AI/NWDAF]
```
