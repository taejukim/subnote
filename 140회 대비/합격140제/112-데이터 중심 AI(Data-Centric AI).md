#정보관리기술사 #AI #DataCentricAI #데이터품질
## 정의
데이터 중심 AI(Data-Centric AI)
- AI 성능 향상의 초점을 모델 개선이 아닌 데이터 품질에 두어 학습데이터를 체계적으로 관리·정제·최적화하는 방법론
- 데이터의 정확성·일관성·라벨 품질 향상을 통해 성능과 신뢰성을 높이는 접근
## 키워드
* 자동 어노테이션, 합성데이터, 센서 퓨전, 데이터 품질 지표, 커리큘럼 학습, 능동 학습
## 암기법
* 실자센데: 실시간수집·자동어노테이션·센서퓨전·데이터품질측정(데이터중심AI 핵심기술)
## 특징
- 데이터 품질 우선: 모델 개선보다 데이터 정확성·일관성·라벨 품질 향상 중시
- 지속적 데이터 개선: 정제·검증·수정·재수집 반복으로 품질 강화
- 효율적 일반화: 소량 데이터·적은 파라미터로도 높은 정확도 확보
- Model-Centric과의 상호보완: 모델 고정, 데이터 반복 개선이라는 접근 차별화
## 목적
- 데이터 품질 기반 AI 모델 성능·신뢰성의 지속적 향상
- 데이터 부족·불균형 환경에서도 실제환경 적합성 있는 모델 구축
## 구성요소
- 데이터 수집·라벨링: 실시간 수집, 자동 어노테이션, 합성데이터, 센서퓨전
- 데이터 품질관리: 품질측정지표, 정제·통합, 품질진단 자동화도구
- 데이터중심 학습기술: 커리큘럼 학습, 능동 학습, RAG
- 데이터중심 MLOps: 데이터 버전·이력·메타데이터 통합관리
## 구성도
```
[데이터 수집/라벨링] → [품질측정/정제/통합] → [커리큘럼·능동학습]
                                                     ↓
                          [모델 학습(고정 구조)] ← 데이터 중심 MLOps
                                                     ↓
                              (성능 미흡시 데이터 재수집·개선 반복)
```
