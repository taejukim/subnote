#정보관리기술사 #보안 #클라우드포렌식 #디지털포렌식
## 정의
클라우드 포렌식(Cloud Forensic)
- 클라우드 컴퓨팅 환경에서 발생하는 범죄에 초점을 맞춰 디지털 증거를 획득·분석하는 포렌식 기법
- IaaS·PaaS·SaaS 서비스 모델별 접근 가능 범위 차이로 인해 난이도가 상이한 조사 기법
## 키워드
* 디지털 포렌식 한계, IaaS(시스템접근 가능), PaaS(개발API접근 가능), SaaS(포렌식 가장 어려움), 클라우드 시그니처, 수사관할권, 국제공조
## 암기법
* 아파스: IaaS 쉬움·PaaS 중간·SaaS 어려움 (서비스모델별 포렌식 난이도)
## 특징
- 서비스모델 의존성: IaaS는 직접 접근 가능해 가장 쉽고, SaaS는 시스템 접근 불가로 가장 어려움
- 사법관할권 이슈: 클라우드 데이터의 물리적 위치가 해외에 있어 국제공조 필요
- 클라이언트 흔적 의존: SaaS는 웹브라우저 사용흔적(시그니처) 분석에 주로 의존
- 개인정보 수집 프로세스 한계: 클라우드 특성상 저장 시기·위치·방법 파악이 어려움
## 목적
- 클라우드 환경에서 발생하는 디지털 범죄의 증거 수집·분석 체계 확립
- 기존 디지털 포렌식 도구의 한계를 극복하는 클라우드 특화 포렌식 역량 확보
## 구성요소
- 서비스모델별 특성: IaaS(스토리지·NW, 시스템 직접접근), PaaS(개발환경, API접근), SaaS(SW서비스, 접근제한)
- 조사절차: 대상 확인(IaaS/PaaS/SaaS 서비스) → 증거확보(브라우저·로그인정보) → 협조요구(국제공조) → 증거수집(계정차단·데이터수집) → 증거분석(시그니처분석)
- 활성화 방안 - 기술: 시스템 로깅·접근성 향상, 클라우드 시그니처 전용 도구 개발
- 활성화 방안 - 법제도: 디지털증거법 제정, 개인정보 수집프로세스 개선, 국제 공조체계 구축
- 활성화 방안 - 기반구조: 협조요구 프로세스 간소화, 전문 인력 양성
## 구성도
```
[대상확인: IaaS/PaaS/SaaS] → [증거확보: 브라우저·로그인정보]
              ↓
[협조요구: 사법관할권·국제공조] → [증거수집: 계정차단·데이터수집]
              ↓
[증거분석: 클라우드 시그니처 분석] → 법적 증거 활용
```
