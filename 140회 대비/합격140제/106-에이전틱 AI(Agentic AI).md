#정보관리기술사 #디지털서비스 #에이전틱AI #AutonomousAgent
## 정의
에이전틱 AI(Agentic AI)
- 메모리·계획·환경감지·도구활용 등을 결합해 목표 달성을 위한 작업을 스스로 수행하는 자율적 AI
- 인식-추론-행동-학습의 순환구조로 동작하는 목표지향형 AI 패러다임
## 키워드
* 목표 설정, 자율 계획, 피드백 루프, RAG, API 통합, 멀티에이전트, 거버넌스
## 암기법
* 자적목지: 자율성·적응성·목표지향성·지속학습(에이전틱 AI 4대 특징)
## 특징
- 자율성·적응성: 환경 변화에 스스로 대응하고 학습
- 목표 지향성: 목표 달성을 위한 계획 수립·실행
- 지속적 학습: 피드백을 통한 성능 개선과 경험 축적
- 상호작용성: SaaS·IoT 등 다양한 시스템과 통합 연동
## 목적
- 반복적 의사결정·작업 수행을 자동화해 생산성 향상
- 실시간 환경 대응력을 갖춘 자율 업무 수행체계 구축
## 구성요소
- 인식(Perceive): 데이터 수집 및 특징 추출
- 추론(Reason): LLM 기반 추론, RAG로 정확성 강화
- 행동(Act): 목표설정·자율계획, API 통합 실행
- 학습(Learn): 피드백 루프, 데이터 플라이휠
- 관리: SaaS/IoT 통합, 보안·거버넌스 체계
## 구성도
```
[인식: 데이터수집/특징추출] → [추론: LLM+RAG]
        ↑                         ↓
[학습: 피드백루프/데이터플라이휠] ← [행동: 계획수립/API통합실행]
                (보안·거버넌스로 전체 통제)
```
