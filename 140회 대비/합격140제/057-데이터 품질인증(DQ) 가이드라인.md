#정보관리기술사 #데이터베이스 #데이터품질인증 #DQ가이드라인
## 정의
데이터 품질인증(DQ) 가이드라인
- 데이터 관리 원칙·표준·품질·구조·연계에 대한 업무기능·조직·프로세스를 체계적으로 실행하는 체계
- 데이터 품질 인증기관이 관리체계를 진단하여 요구사항 만족 여부를 평가·인증하는 제도
## 키워드
* 데이터 관리 프로세스, 지원 프로세스, 실행 프로세스, 관리체계 성숙도, DQP, DQC, DQA, DQI
## 암기법
* 사시신: 신규심사·사후심사·갱신심사 (인증 유효기간 관리 3대 심사 유형)
## 특징
- 대상포괄성: 데이터 활용사업·시스템·관리조직 전반을 인증 대상으로 함
- 성숙도기반: 사전(프로세스 확인)-사후(수준검증) 절차로 성숙도 결정
- 유효기간관리: 신규 3년, 매년 사후심사, 만료 전 갱신심사 체계
- PDCA기반: 실행 프로세스가 계획-실행-점검-조치 사이클로 운영
## 목적
- 데이터 관리 효율성 제고 및 실증체계 기반 신뢰성 확보
- 개선점 지원·점검을 통한 데이터 활용 품질 고도화
## 구성요소
- 인증 대상: 데이터 기반 사업, 데이터 시스템, 데이터 관리 조직
- 인증 심사 절차: 심사착수→1단계심사→2단계준비→2단계심사→보고서작성(5단계)
- 실행 프로세스: DQP(품질계획)→DQC(품질통제)→DQA(품질보증)→DQI(품질개선)
- 지원 프로세스: 실행 프로세스 지원을 위한 정보·기술 지원
- 자원 제공 프로세스: 조직 수준 자원·교육훈련 서비스 제공
## 구성도
```
[사전심사: 대상 프로세스 확인] → [사후심사: 성숙도 수준 검증]
                │
   ┌────────────┴────────────┐
[실행 프로세스: DQP→DQC→DQA→DQI]
   ↑ 지원(정보·기술)      ↑ 자원제공(조직·교육)
                │
      [인증서: 신규(3년)→사후(매년)→갱신]
```
