#정보관리기술사 #보안 #화이트박스암호화 #WhiteBoxCryptography
## 정의
화이트박스 암호화(White-box Cryptography)
- 암호 키가 알고리듬 내부에 암호학적 키 은닉 기술로 숨겨져 있어 내부 동작을 분석해도 키 해석이 어려운 암호 기술
- 공격자가 코드에 완전히 접근 가능한 화이트박스 환경에서도 안전한 소프트웨어 암호 구현 기법
## 키워드
* 부채널 공격, 권한 상승, 루팅, 정적키, 동적키, 난독화, Look-up Table
## 암기법
* 정동암복: 정적키설정·동적키암호화·동적키복호화·평문암복호화 (화이트박스 암호화 4단계 메커니즘)
## 특징
- 키은닉성: 정적/동적 분석으로도 알고리듬 내 비밀키 추출 불가
- 무결성보호: 실행코드 변조 시 암호기능 정상동작 차단
- 난독화기반: 정적키를 Look-up Table 형태로 알고리듬에 섞어 은닉
- 이중키구조: 정적키가 동적키를 암복호화하여 실제 평문 처리에 사용
## 목적
- 루팅·권한상승 등 화이트박스 환경(단말 완전노출)에서도 키 보호
- 하드웨어 보안모듈 없이 소프트웨어만으로 높은 안전성 제공
## 구성요소
- 정적키(Static Key): Look-up Table에 알고리즘과 함께 존재, 변경 시 테이블 재생성 필요
- 동적키(Dynamic Key): 난독화된 형태로 프로그램 실행 시 구동, 동적 변경 가능
- Obfuscation(난독화): 정적키를 암호 알고리듬 코드 속에 섞어 공격자가 식별 불가하게 함
- 처리단계: 정적키 설정 → 동적키 암호화 → 동적키 복호화 → 평문 암복호화
## 구성도
```
[정적키(난독화, Look-up Table)]
        │ 암호화/복호화
        ▼
   [동적키(암호화된 상태 보관)]
        │ 복호화 후 사용
        ▼
   [평문] --동적키로 암/복호화--> [암호문]
```
