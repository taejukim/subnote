#정보관리기술사 #운영체제 #BeladysAnomaly #페이지교체
## 정의
Belady's Anomaly
- FIFO 페이지 교체 알고리즘에서 페이지 프레임 수를 늘렸음에도 페이지 부재(Page Fault)가 오히려 증가하는 비정상 현상
- 자원 증가가 항상 성능 향상으로 이어지지 않음을 보여주는 페이지 교체의 대표적 이상 현상
## 키워드
* 페이지 부재 증가, FIFO 알고리즘, 비정상 현상, LRU, OPT, Second Chance, PFF
## 암기법
* FIFO프증부증: FIFO는 프레임 증가해도 부재율 증가 가능 (Belady's Anomaly 핵심)
## 특징
- FIFO 특유 현상: 스택 알고리즘(LRU·OPT)에서는 발생하지 않고 FIFO에서만 발생
- 프레임 증가의 역설: 프레임 3개→4개로 늘려도 부재율이 75%→84%로 오히려 상승
- 스택 속성 결여: FIFO는 스택 알고리즘 속성(프레임 증가 시 이전 페이지 집합 포함)을 만족하지 않음
- 예측 불가능성: 단순 자원 증설만으로는 성능 개선을 보장할 수 없음을 시사
## 목적
- 페이지 교체 알고리즘 선택 시 단순 자원 증설의 한계를 인식
- 스택 알고리즘(LRU·OPT) 등 안정적 교체 정책 채택의 필요성 제시
## 구성요소
- 발생 사례: 프레임 3개(부재 9회, 75%) vs 프레임 4개(부재 10회, 84%)
- 해결책 - 페이지 교체 알고리즘: LRU(최근 미사용 교체), OPT(이상적 최적교체), Second Chance(재기회 부여)
- 해결책 - 최적화 설계: Locality(지역성 원리) 기반 Working Set, PFF(페이지부재율 측정 후 프레임 동적할당)
## 구성도
```
프레임 3개: 참조열 1 2 3 4 1 2 5 1 2 3 4 5 → Fault 9회(75%)
프레임 4개: 참조열 1 2 3 4 1 2 5 1 2 3 4 5 → Fault 10회(84%) ← Anomaly!
FIFO(스택속성 없음) → Anomaly 발생 가능
LRU/OPT(스택속성 있음) → Anomaly 발생하지 않음
```
