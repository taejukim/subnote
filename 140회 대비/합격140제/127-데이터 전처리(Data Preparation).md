#정보관리기술사 #확률통계 #데이터전처리 #피처엔지니어링
## 정의
데이터 전처리(Data Preparation)
- 수집 데이터의 불완전·불일치·잡음을 제거해 분석에 적합한 형식으로 변환하는 데이터 처리 기법
- AI/ML 모델의 성능은 데이터 품질에 좌우되므로 학습 전 선행 수행이 필수
## 키워드
* 정제, 통합, 변환, 정리, 정규화, 표준화, 특성선택, 특성변환, 특성생성
## 암기법
* 정통변정: 정제·통합·변환·정리(데이터 전처리 4대 프로세스)
## 특징
- 정제성: 결측값·이상값 제거로 데이터 신뢰도 확보
- 통합성: ETL 등으로 다중 소스 데이터를 하나의 구조로 통합
- 변환성: 스케일링·인코딩으로 분석 적합 형식으로 변환
- 축소성: 차원축소·샘플링으로 데이터 크기와 복잡도 절감
## 목적
- AI/ML 모델 성능 향상 및 학습시간 단축
- 데이터의 다양한 활용 지원 및 과적합 방지
## 구성요소
- 데이터 정제(Cleansing): 결측치·이상치 처리
- 데이터 통합(Integration): ETL 기반 스키마·소스 통합
- 데이터 변환(Transformation): 정규화·표준화·인코딩
- 데이터 정리(Reduction): PCA 등 차원축소, 데이터셋 분할
- 피처 엔지니어링: 특성 생성·선택·변환으로 모델 입력 최적화
## 구성도
```
[원본 데이터] → [정제] → [통합] → [변환(정규화/표준화)] → [정리]
                                                              ↓
                                                    [피처 엔지니어링]
                                                              ↓
                                                    [AI/ML 모델 학습]
```
