#정보관리기술사 #알고리즘 #DFS #BFS
## 정의
그래프 탐색 알고리즘(DFS/BFS)
- 정점과 간선으로 구성된 그래프에서 시작 정점으로부터 연결된 정점을 체계적으로 방문하는 알고리즘
- 방문 순서와 탐색 방향에 따라 깊이우선탐색(DFS)과 너비우선탐색(BFS)으로 구분
## 키워드
* 깊이우선, 너비우선, 재귀함수, Stack, 백트래킹, Queue, 최소단계 탐색, LIFO, FIFO
## 암기법
* DFS스백, BFS큐최: DFS=Stack·백트래킹, BFS=Queue·최단경로
## 특징
- DFS 구조: Stack(LIFO) 또는 재귀함수로 한쪽 분기를 최대 깊이까지 탐색 후 백트래킹
- BFS 구조: Queue(FIFO)로 가까운 정점부터 레벨별 순차 탐색
- 최단경로 보장 차이: BFS는 비가중치 그래프에서 최단경로 보장, DFS는 보장 안 됨
- 메모리 특성 차이: DFS는 Stack Overflow 위험, BFS는 동일레벨 정점 저장으로 메모리 증가
## 목적
- 그래프 구조 분석 및 연결성·경로 탐색 문제 해결
- 사이클 탐지, 최단경로 탐색 등 다양한 응용문제에 대한 체계적 접근
## 구성요소
- DFS: 시작정점 Stack 삽입 → 인접정점 반복 삽입·출력 → 백트래킹으로 다른 분기 탐색
- BFS: 시작정점 Queue 삽입 → 인접정점 레벨별 삽입·출력 → 큐가 빌 때까지 반복
- DFS 활용: 백트래킹, 사이클탐지, 깊은 경로구조 분석
- BFS 활용: 최소단계 탐색, 네트워크 홉수·인맥단계 탐색
## 구성도
```
        0
      /   \
     1     2
    / \     \
   3   4     5,6
DFS: 0→1→3→4→2→5→6  (Stack, 깊이 우선)
BFS: 0→1→2→3→4→5→6  (Queue, 레벨 우선)
```
