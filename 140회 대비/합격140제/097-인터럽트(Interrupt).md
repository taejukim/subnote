#정보관리기술사 #운영체제 #인터럽트 #ISR
## 정의
인터럽트(Interrupt)
- CPU 외부·내부·SW적 원인으로 실행 중인 프로그램을 중단시키고 특수 이벤트 처리를 위해 제어를 이전하는 신호
- 하드웨어(외부/내부)와 소프트웨어 인터럽트로 구분되는 비동기 제어 전이 메커니즘
## 키워드
* 외부 인터럽트, 내부 인터럽트, 소프트웨어 인터럽트(SVC), 인터럽트 벡터 테이블, ISR, 우선순위
## 암기법
* 외내소우: 외부·내부·소프트웨어·우선순위
## 특징
- 외부 인터럽트: 전원 이상, 기계 착오, 외부신호, I/O 요청 등 하드웨어 외부 요인
- 내부 인터럽트: 오버플로/언더플로, 프로그램 예외 등 실행 중 오류
- 소프트웨어 인터럽트: SVC 호출에 의한 감시프로그램 요청
- 우선순위 처리: 전원>기계착오>외부신호>I/O>명령어오류>프로그램검사>SVC 순, HW>SW, 외부>내부
## 목적
- 컴퓨터 자원을 효율적으로 활용하며 예외적 상황에 신속 대응
- 다중 프로그래밍 환경에서 CPU와 I/O 장치 간 비동기 처리 지원
## 구성요소
- 인터럽트 벡터 테이블: ISR 주소를 저장한 참조 테이블
- ISR(Interrupt Service Routine): 인터럽트 발생 시 실행되는 사전 정의된 처리 루틴
- 핸들러(Handler): 인터럽트 발생을 감지하고 벡터 테이블 참조해 분기
- 우선순위 제어: 다중 인터럽트 발생 시 높은 우선순위 처리 보장
## 구성도
```
[프로세스 A 실행] → (인터럽트 발생)
        ↓
[인터럽트 벡터 테이블 조회] → [ISR 분기]
        ↓
[ISR] 인터럽트 금지→상태저장→처리→상태복구→인터럽트 허용
        ↓
[프로세스 A 복귀]
```
