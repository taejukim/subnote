#정보관리기술사 #AI #MLOps #DataOps
## 정의
MLOps·DataOps·AIOps
- 각각 모델·데이터·IT운영의 전 과정을 자동화하여 AI 서비스 품질과 신뢰성을 확보하는 운영 체계
- 데이터부터 모델 개발, 서비스 운영까지 전 과정을 연결하는 통합 운영 패러다임
## 키워드
* Machine Learning, Data Pipeline, IT Operations, Automation, CI/CD, Monitoring, Anomaly Detection
## 암기법
* 모데운: 모델(MLOps)·데이터(DataOps)·운영(AIOps) 자동화 체계
## 특징
- MLOps: 모델 생명주기(학습·배포·재학습) 자동화
- DataOps: 데이터 파이프라인 자동화로 품질·일관성 확보
- AIOps: AI 기반 장애예측·이상탐지·자동복구 수행
- 상호연계성: 데이터→모델→운영이 하나의 파이프라인으로 연결
## 목적
- 데이터·모델·운영 전 과정의 자동화로 개발·운영 효율성 제고
- AI 서비스의 품질·신뢰성·안정성 지속적 확보
## 구성요소
- MLOps: Feature Engineering, CI/CD 배포, Retraining, MLflow/Kubeflow
- DataOps: ETL 수집, Data Cleansing, Data Lake, Airflow/Talend
- AIOps: 로그수집, Anomaly Detection, RCA, Splunk/Dynatrace
- 공통 인프라: 모니터링·자동화 파이프라인, KPI/SLA 관리
## 구성도
```
[DataOps] ETL→정제→Data Lake→품질확보
      ↓
[MLOps] Feature→학습→CI/CD배포→재학습(모델 성능확보)
      ↓
[AIOps] 로그수집→이상탐지→RCA→자동복구(운영 최적화)
```
