#정보관리기술사 #AI #합성데이터 #SyntheticData
## 정의
합성데이터(Synthetic Data)
- 원본데이터의 형식·구조·통계적 분포 특성을 학습하여 생성한 모의(가상) 데이터
- 개인정보보호 규제와 데이터 부족·불균형 문제를 해결하는 AI 데이터 공급 전략
## 키워드
* 가상데이터, 규제준수, 공정성, GAN, VAE, Diffusion Model, 안전성, 유사성, 유용성
## 암기법
* 확규거: 확장성(데이터확장)·규제준수·거버넌스(합성데이터 중요성 3대 축)
## 특징
- 확장성: 희귀데이터 생성으로 데이터 부족·불균형 해소
- 규제준수: 민감정보 없이 개인정보보호법·GDPR 준수 가능
- 협업개방성: 프라이버시 노출 없이 데이터 공유·협업 가능
- 공정성: 편향 보정된 데이터로 AI 윤리성 향상
## 목적
- 데이터 수집 한계·불균형 문제 해결을 통한 모델 성능 향상
- 개인정보 규제 준수 및 안전한 데이터 공유 생태계 조성
## 구성요소
- 생성절차: 사전준비→합성데이터 생성→안전성/유용성 검증→심의위원회→활용·관리
- 통계모형 기반: Synthpop, 가우시안 혼합모델, 베이지안 네트워크
- AI모형 기반: VAE(인코더-디코더), GAN(생성자-판별자), Diffusion Model
- 품질평가 지표: 유사성(카이제곱, 상관계수), 유용성(pMSE, 모형성능), 안전성(구별/연결/추론 위험도)
## 구성도
```
[원본데이터] → [전처리] → [생성모델: 통계모형/GAN/VAE/Diffusion] → [후처리]
                                                                    ↓
                                        [안전성·유용성 검증] → [심의위원회] → [활용]
```
