#정보관리기술사 #AI #프롬프트튜닝 #파인튜닝
## 정의
프롬프트 튜닝 & 파인 튜닝
- 프롬프트 튜닝은 모델을 고정한 채 프롬프트(소프트 프롬프트)를 조정해 성능을 높이는 기법
- 파인 튜닝은 사전훈련 모델의 가중치를 특정 도메인 데이터셋으로 재학습시키는 기법
## 키워드
* 소프트 프롬프트, LoRA, 전이학습, One-shot/Zero-shot Prompting, 오버피팅
## 암기법
* 목방구소정: 목적·방법·구조변경·소요리소스·정확도(비교 5대 기준)
## 특징
- 목적 차이: 프롬프트튜닝은 출력 최적화, 파인튜닝은 도메인 특화 모델 구축
- 리소스 차이: 프롬프트튜닝은 경량 자원, 파인튜닝은 고성능 컴퓨팅 필요
- 모델 변경 여부: 프롬프트튜닝은 모델 고정, 파인튜닝은 파라미터 구조 변경
- 오버피팅 위험: 프롬프트튜닝은 발생 불가, 파인튜닝은 스몰데이터로 인한 위험 존재
## 목적
- 프롬프트 튜닝: 저비용·고속으로 다양한 작업에 유연하게 대응
- 파인 튜닝: 특정 도메인·태스크에서 최고 성능의 최적화 모델 확보
## 구성요소
- 프롬프트 튜닝 기반기술: One/Zero-Shot Prompting, Chain-of-Thought
- 파인 튜닝 기반기술: 전이학습(Transfer Learning), LoRA
- 적용기준: 목표와 환경(성능 vs 자원), 효율성과 성능의 균형
- 혼합 활용: 상황에 따라 두 기법 병행 적용 가능
## 구성도
```
[Prompt] → 프롬프트 조합 변경 → [LLM(고정)] → Response   (Prompt Tuning)
[Prompt] → [LLM] ← 특정 데이터셋 추가학습(파라미터 갱신) → Response  (Fine Tuning)
```
