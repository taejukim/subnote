#정보관리기술사 #컴퓨터구조 #입출력제어 #DMA
## 정의
입출력 제어기법(I/O Control Method)
- 입출력 장치와 컴퓨터 내부 장치 간 통신을 제어하는 기법으로 Programmed I/O, DMA, I/O Processor 방식이 존재
- CPU 개입도에 따라 효율성과 하드웨어 비용이 상반되는 3가지 제어 방식
## 키워드
* Programmed I/O, Interrupt-driven I/O, DMA, Burst Mode, Cycle Stealing, I/O Processor, 채널
## 암기법
* 프인디아: 프로그램I/O·인터럽트I/O·DMA·I/O프로세서(제어방식 4유형)
## 특징
- Programmed I/O: CPU가 모든 입출력을 직접 관여, 단순하나 성능저하
- Interrupt-driven I/O: 인터럽트로 CPU 효율 향상, 구현 복잡
- DMA: 별도 컨트롤러가 CPU 개입 없이 메모리-장치 간 데이터 전송
- I/O Processor: 전용 프로세서가 DMA 기능을 확장해 CPU와 독립적으로 동작
## 목적
- CPU의 입출력 관여를 최소화하여 시스템 전체 처리 효율 향상
- 장치별 특성에 맞는 제어 방식 선택으로 자원 활용 최적화
## 구성요소
- 프로그램 I/O: 상태 레지스터 검사 후 명령 전송·데이터 전송 반복
- 인터럽트 구동 I/O: 다중 인터럽트선/소프트웨어 폴링/데이지체인 방식
- DMA: 명령초기화→Bus REQ→Bus GNT→Data Transfer→INTR 절차
- I/O Processor: 선택기 채널, 멀티플렉서 채널로 다중 장치 제어
## 구성도
```
[CPU] --직접제어--> [I/O Module]           (Programmed/Interrupt I/O)
[CPU] --초기화-->[DMA Controller]--전송-->[Memory]↔[I/O Device] (DMA)
[CPU] --위임--> [I/O Processor] --채널제어--> [Disk][Terminal][Printer]
```
