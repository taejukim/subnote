#정보관리기술사 #디지털서비스 #무중단배포 #블루그린카나리
## 정의
무중단 배포(운영 안정성 중심 배포·관측)
- SLO 보전을 최우선으로 점진 배포(블루-그린·카나리)와 관측(로그·메트릭·트레이스)을 결합해 배포 리스크를 최소화하는 방식
- 자동 게이팅(SLO/에러버짓)을 통해 배포를 전진·보류·롤백으로 즉시 판정하는 릴리스 전략
## 키워드
* 블루그린, 카나리, SLO, SLI, 에러버짓, 롤백, p95/p99, Burn Rate
## 암기법
* 로메트: 로그(원인추적)·메트릭(SLO감시)·트레이스(호출경로가시화)가 관측 3요소
## 특징
- 즉시성: 블루-그린은 LB 스위치로 전체 즉시 롤백 가능
- 점진성: 카나리는 1~5%부터 단계적 트래픽 전환으로 영향 최소화
- 관측가능성: 로그·메트릭·트레이스 3요소로 이상징후 탐지
- 자동판정성: 에러율·p95/p99 기준 자동 게이팅으로 전진/롤백 결정
## 목적
- 서비스 중단 없이 신속한 배포와 장애 시 즉각 복구 실현
- 사용자 체감 신뢰성(SLO)을 해치지 않는 위험관리형 릴리스
## 구성요소
- 블루-그린 배포: 동일 스택 2세트, LB 스위치로 즉시 전체 전환
- 카나리 배포: 소량 인스턴스부터 점증 전환, 실사용 지표 비교 검증
- 관측 3요소: 로그(사건 재구성), 메트릭(SLO 모니터링), 트레이스(분산호출 가시화)
- 핵심 지표: 에러율(5xx비율·Burn Rate), 지연시간(p95·p99)
- 자동 게이팅: 회귀확정(즉시롤백)/회귀의심(전진중단)/정상(단계전진)
## 구성도
```
[CI] → 배포전략 선택
   ├─ Blue-Green: [Blue 운영] ↔ LB스위치 ↔ [Green 신규] (즉시 전체 전환)
   └─ Canary: [기존버전 95%] + [신규버전 5%→점증] (부분 트래픽 전환)
          ↓
   [로그/메트릭/트레이스 관측] → 에러율·p95/p99 판정 → 전진/보류/롤백
```
