#정보관리기술사 #데이터베이스 #분산데이터베이스 #투명성
## 정의
분산 데이터베이스(Distributed Database)
- 네트워크를 통해 물리적으로 분산되어 존재하지만 하나의 논리적 통합구조로 관리되는 데이터베이스
- 논리적으로는 단일 시스템, 물리적으로는 분산화된 형태로 운영되는 데이터베이스
## 키워드
* 위치 투명성, 복제 투명성, 병행 투명성, 분할 투명성, 장애 투명성, 2PC
## 암기법
* 위복병분장: 위치·복제·병행·분할·장애 투명성 (분산DB 5대 투명성)
## 특징
- 위치투명성: 데이터 물리적 위치를 몰라도 접근 가능
- 병행투명성: Locking·Timestamp로 동시 트랜잭션 처리 시 이상 없음 보장
- 장애투명성: 2PC 활용해 일부 노드 장애에도 무결성 보존
- 지역화성: 데이터 처리·운영을 지역별로 분산해 통신비용·부하 절감
## 목적
- 데이터 처리·운영의 지역화를 통한 통신비용 절감 및 관리 효율화
- 병렬처리와 복제를 통한 처리속도·가용성·신뢰성 향상
## 구성요소
- 스키마 구성: 전역 스키마, 단편화 스키마, 할당 스키마, 지역 사상 스키마
- 위치 분산: 테이블 구조 불변, 위치만 다르게 배치
- 분할 분산: 테이블을 수평/수직 분할해 여러 사이트에 분산 저장
- 복제 분산: 동일 테이블을 부분복제/광역복제로 여러 서버에 생성
- 요약 분산: 지역·서버 간 유사하나 다른 형태로 테이블 요약 저장
- 2PC(Two-Phase Commit): 분산 트랜잭션의 원자성 보장을 위한 Commit/Rollback 프로토콜
## 구성도
```
[전역 스키마]
   │ 단편화/할당/지역사상
   ▼
[Site A: 위치분산] [Site B: 분할분산(수평/수직)] [Site C: 복제분산]
        └──────────────┬──────────────┘
                  [2PC: 준비→Commit/Rollback]
                  (원자성·일관성 보장)
```
