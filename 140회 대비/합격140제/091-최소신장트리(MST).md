#정보관리기술사 #알고리즘 #최소신장트리 #Kruskal
## 정의
최소신장트리(MST, Minimum Spanning Tree)
- 가중치가 부여된 무방향 그래프에서 생성 가능한 여러 신장트리 중 간선 가중치 합이 최소인 신장트리
- 모든 정점을 사이클 없이 n-1개 간선으로 연결하는 최소비용 부분 그래프
## 키워드
* 모든 정점 연결, 사이클 부재, n-1 간선, Greedy, 간선 가중치, 프림(Prim), 크루스칼(Kruskal), Union-Find
## 암기법
* 프정크간: 프림=정점중심, 크루스칼=간선중심 (MST 2대 알고리즘 접근방식)
## 특징
- Greedy 기반: 매 단계 가장 이득이 되는 최소간선을 선택해 전체 최적해(MST) 구성
- n-1 간선 제약: 신장트리는 항상 (노드수-1)개 간선으로 구성되며 사이클 없음
- 유일성 조건: 모든 간선 가중치가 서로 다르면 MST는 유일하게 존재
- 그래프 밀집도별 적합성: 프림은 밀집그래프, 크루스칼은 희소그래프에서 효율적
## 목적
- 전력망·도로망·통신망 등 네트워크 구축 시 연결 비용 최소화
- 한정된 자원으로 전체 시스템의 연결성 확보
## 구성요소
- 프림 알고리즘: 시작정점에서 인접한 최소간선을 우선순위큐로 선택하며 트리 확장
- 크루스칼 알고리즘: 전체 간선을 가중치순 정렬 후 Union-Find로 사이클 검사하며 간선 선택
- 신장트리 구성요소: Vertex(전체 정점 포함), Edge(부분집합 선택), n-1 조건, 비순환성
- MST 구성요소: Greedy 최적화, 최적부분구조, 가중치 데이터, 무방향성
## 구성도
```
프림(노드중심):         크루스칼(간선중심):
root → 인접최소간선     전체간선 정렬 → Find(u),Find(v)
   ↓ 확장                    ↓ 다르면 Union, 같으면 skip
[MST 트리로 성장]        [분리된 트리들이 점진 합쳐짐]
       공통: n-1개 간선, 사이클 없음, 가중치 합 최소
```
