#정보관리기술사 #컴퓨터구조 #HPC #RDMA
## 정의
HPC(High Performance Computing)
- 대규모 연산·데이터 처리를 위해 병렬처리·클러스터링·고속 네트워크 기술을 결합한 고성능 컴퓨팅 체계
- AI 학습·빅데이터 분석 등 대량 연산 수요에 대응하는 컴퓨팅 인프라
## 키워드
* 병렬처리, 병행처리, 클러스터링, 로드밸런싱, Fail-over, RDMA, InfiniBand, HPCaaS
## 암기법
* 로분페확: 로드밸런싱·분산컴퓨팅·페일오버·확장성(클러스터링 핵심기술)
## 특징
- 병렬처리: 다중 코어로 여러 작업을 물리적으로 동시 실행
- 클러스터링: 다수 서버를 하나의 시스템처럼 묶어 성능·가용성 향상
- RDMA: OS/CPU 개입 없이 원격 메모리 직접 접근으로 초저지연 전송
- 서비스화(HPCaaS): 클라우드와 융합해 초기 투자비 절감하며 제공
## 목적
- 대규모 AI 학습·빅데이터 처리의 연산 속도 향상
- 고가용성·확장성 확보를 통한 안정적 대용량 처리 환경 구축
## 구성요소
- 병렬처리 vs 병행처리: 다중코어 동시 실행 vs 시분할 교차 실행
- 클러스터링 핵심기술: 로드밸런싱, 분산컴퓨팅, Fail-over, 데이터복제, 작업스케줄링
- RDMA 구성: RDMA Adapter, RDMA Operations, Queue Pair
- RDMA 프로토콜: InfiniBand, RoCE, iWARP, SRP
## 구성도
```
[Node1][Node2][Node3] ── 클러스터링(로드밸런싱/Fail-over) ──→ 통합 시스템
        ↓ RDMA(Queue Pair, Adapter)
[주메모리] ←──직접 R/W(CPU 미개입)──→ [원격 노드 메모리]
        (InfiniBand / RoCE / iWARP)
```
