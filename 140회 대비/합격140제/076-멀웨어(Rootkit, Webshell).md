#정보관리기술사 #보안 #멀웨어 #루트킷
## 정의
멀웨어(Malware)
- 컴퓨터 및 네트워크에 해를 끼치기 위해 의도적으로 제작된 악성 소프트웨어 전반
- 루트킷·웹쉘 등 국가배후 공격그룹(Big 4)이 활용하는 고도화된 공격 인프라 도구 포함
## 키워드
* 운영체제 커널, 루트 권한, 웹쉘, 시스템콜 후킹, C2(Command and Control), EDR/XDR, 위협 헌팅
## 암기법
* 초권은백: 초기침투·권한상승·은닉후킹·백도어설치 (루트킷 동작원리)
## 특징
- 커널 권한 장악: 루트킷은 User Mode에서 Kernel Mode로 권한 상승해 시스템 전체 통제
- 은닉·탐지회피: SSDT·IDT 등 시스템콜 테이블 변조로 존재 은폐, 탐지 매우 어려움
- 웹쉘 상대적 접근성: 웹서버 취약점 이용, 서버 애플리케이션 권한 수준으로 탐지 용이
- 지속성 확보: 백도어 설치·부팅시 자동실행으로 장기간 C2 기반 악성행위 수행
## 목적
- 시스템 관리자 권한 획득 후 데이터 탈취·시스템 조작 등 악성행위 은밀 수행
- 원격 명령 실행을 통한 서버 제어 및 지속적 침해 유지
## 구성요소
- 루트킷 동작단계: 초기침투 → 권한상승(User→Kernel) → 은닉·후킹 → 백도어 설치 → C2 수행
- 루트킷 vs 웹쉘: 동작위치(커널모드 vs 웹앱레벨), 권한수준(루트권한 vs 서비스권한), 탐지난이도(매우어려움 vs 상대적쉬움)
- 대응 - 모니터링: EDR/XDR, NTA(네트워크 트래픽 분석), SIEM 로그 상관분석
- 대응 - 위협인텔리전스: CTI, 위협 헌팅, MITRE ATT&CK 프레임워크
- 대응 - AI기반: UEBA 이상행위 탐지, SOAR 자동대응, 자동 위협분석·분류
## 구성도
```
[공격자] → 초기침투(취약점/사회공학)
              ↓ User Mode
         권한상승 → Kernel Mode
              ↓
      은닉·후킹(SSDT/IDT 변조) → 백도어 설치
              ↓
            C2 통신 ← [원격 명령/데이터탈취]
```
