#정보관리기술사 #운영체제 #가상메모리 #메모리단편화
## 정의
가상 메모리 관리 기법
- 물리적 메모리 한계를 극복하고 다수 사용자의 메모리 공유를 위해 할당·배치·인출·교체 기법으로 관리하는 기법
- 페이징·세그멘테이션 등 불연속 할당 방식으로 메모리를 효율적으로 운용하는 체계
## 키워드
* 할당, 배치, 인출, 교체, 페이징, 세그멘테이션, 내부단편화, 외부단편화, 버디시스템, 슬랩할당자
## 암기법
* 할배인교: 할당·배치·인출·교체 (가상메모리 관리 4대 기법)
## 특징
- 4대 관리기법: 할당(연속/불연속)·배치(First-Fit 등)·인출(요구/예측)·교체(FIFO/LRU/OPT/NUR)
- 페이징 고정분할: 페이지번호(VPN)-프레임번호(PPN) 매핑으로 내부단편화 발생 가능
- 세그멘테이션 가변분할: 논리적 블록(세그먼트) 단위 할당으로 외부단편화 발생 가능
- 단편화 해결 다각화: 내부단편화는 슬랩할당자, 외부단편화는 버디메모리시스템으로 대응
## 목적
- 프로세스에 메모리를 효율적으로 할당해 성능 향상
- 내부·외부 단편화 문제를 최소화하여 메모리 활용률 극대화
## 구성요소
- 할당기법: 연속할당(고정/가변), 불연속할당(페이징/세그멘테이션/페이지드세그멘테이션)
- 배치기법: First-Fit, Best-Fit, Next-Fit, Worst-Fit
- 인출기법: 요구인출(Demand Fetch), 예측인출(Pre Fetch)
- 교체기법: FIFO, LFU, LRU, OPT, NUR
- 페이징: VPN·PPN 매핑, 제어부분(접근권한·존재비트)
- 세그멘테이션: 세그먼트테이블, Limit, Base address
- 단편화 해결: 내부단편화(슬랩할당자), 외부단편화(버디메모리시스템, 압축·통합·재배치)
## 구성도
```
[가상메모리] → 할당(연속/불연속) → 배치(Fit기법) → 인출(요구/예측) → 교체(LRU 등)
                        ↓                                    ↓
                  페이징(내부단편화)               세그멘테이션(외부단편화)
                  → 슬랩할당자 해결                → 버디시스템 해결
```
