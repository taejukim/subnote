#정보관리기술사 #프로젝트관리 #몬테카를로시뮬레이션 #PERT
## 정의
몬테카를로 시뮬레이션과 PERT
- 몬테카를로는 확률분포와 반복적 무작위 샘플링으로 결과 발생가능성을 추정하는 기법
- PERT는 낙관·비관·최빈치 3점 추정으로 일정을 확률적으로 산정하는 기법
## 키워드
* 난수, 확률분포, 3점추정, 임계경로, 민감도분석, CPM
## 암기법
* 변무시결: 변수정의·무작위샘플링·시뮬레이션실행·결과집계 (몬테카를로 절차)
## 특징
- 확률기반예측: 몬테카를로는 결과분포로 확률적 예측을 제공
- 3점추정: PERT는 낙관치·최빈치·비관치 기반으로 기대시간을 산출
- 민감도분석: 몬테카를로는 개별변수 영향도를 정량화
- 임계경로강조: PERT는 최장경로 식별로 핵심 관리대상을 도출
## 목적
- 프로젝트 일정·비용·리스크의 불확실성을 정량적으로 예측
- 임계경로·민감요인 식별을 통한 리스크 선제 대응
## 구성요소
- 몬테카를로: 변수정의, 무작위샘플링, 시뮬레이션실행, 결과집계
- PERT: 작업분해, 네트워크구성, 3점추정(a,m,b), 임계경로분석
- 비교: 몬테카를로(다변수·확률분포), PERT(3점추정·선형관계)
- 결합활용: PERT 확률분포를 몬테카를로 입력으로 활용해 리스크관리 고도화
## 구성도
```
[PERT: 3점추정(a,m,b) → 네트워크구성] → [확률분포 할당]
                                              ↓
                    [몬테카를로: 무작위샘플링 반복 시뮬레이션]
                                              ↓
                 [결과분포 분석 → "60일 내 완료 확률 85%"]
```
## 연관 토픽
- [[CPM]] - 여유시간 0인 임계경로 식별 기법
- [[EVM]] - 일정·비용 통합 성과 추적 기법
- [[리스크관리]] - 확률기반 예측결과가 활용되는 상위 관리영역
- [[일정관리]] - PERT·몬테카를로가 속하는 프로젝트관리 지식영역
