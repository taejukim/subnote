#정보관리기술사 #디지털서비스 #데이터스페이스 #KDataSpace
## 정의
데이터 스페이스(Data Space)
- 데이터 주권을 전제로 특정 조직에 집적하지 않고 참여자 간 데이터를 안전하게 유통·거래하는 분산형 데이터 공유 체계
- 과학기술정보통신부의 K-Data Space 정책 기반 신뢰형 데이터 교환 생태계
## 키워드
* 데이터 주권, 신뢰, 상호운용성, 분산형 구조, 연합 카탈로그, DID, Policy as Code
## 암기법
* 신주상보확: 신뢰성·주권통제·상호운용성·보안프라이버시·확장성/모듈성
## 특징
- 신뢰성: 참여자 간 역할·데이터 사용규칙 일관 적용
- 주권성: 자신의 데이터 주권과 통제권 유지한 채 연결
- 상호운용성: 이기종 참여자·시스템 간 유연한 연계
- 확장성: 초기 구축 이후에도 모듈형 구조로 확장 가능
## 목적
- 중앙집중 없이 참여자 간 안전한 데이터 유통·거래 실현
- 데이터 생산·창출·유통의 선순환 생태계 조성
## 구성요소
- 거버넌스 계층: 참여구조, 운영규칙, 유연성·자율성 체계
- 비즈니스 계층: Use Case 개발, 참여자 등록·계약, 접근권한 정책
- 기술 계층: 표준 API·데이터 커넥터, ID/신뢰관리(DID·VC), 정책관리(Policy as Code), 연합 카탈로그, 클리어링하우스
## 구성도
```
[도메인A 데이터]        [도메인B 데이터]
      │   표준 데이터 커넥터   │
      └────────┬──────────────┘
   [연합 카탈로그 / 메타데이터 브로커]
      │ Policy-as-Code / DID·VC │
   [거버넌스: 참여구조·규칙] → 데이터 소비자
```
