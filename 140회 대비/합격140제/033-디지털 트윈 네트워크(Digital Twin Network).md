#정보관리기술사 #디지털네트워크 #디지털트윈네트워크 #DTN
## 정의
DTN(Digital Twin Network)
- 데이터·모델·인터페이스 기반으로 네트워크를 실시간 매핑·분석·진단·에뮬레이션·제어하는 양방향 네트워크
- 6G 시대 네트워크 운영관리 최적화를 위한 물리-가상 네트워크 결합 기술
## 키워드
* 데이터, 모델, 매핑, 인터페이스, 이중 폐쇄루프, 6G, ITU-T
## 암기법
* 데매모인: 데이터·매핑·모델·인터페이스가 DTN의 4대 특징
## 특징
- 데이터: 물리 네트워크 데이터를 통합 저장소에 축적해 정확한 모델 제공
- 매핑: 물리-가상 네트워크 간 실시간 인터랙티브 매핑
- 모델: 다양한 모델을 내장·결합해 애플리케이션 지원
- 인터페이스: 물리망-가상망-애플리케이션 간 정보 교환 지원
## 목적
- 물리적 네트워크의 분석·진단·에뮬레이션·제어 자동화
- 6G 네트워크 운영 최적화 및 신속한 장애 대응 체계 구축
## 구성요소
- 물리적 네트워크 계층: 실제 6G 네트워크 요소와 운영환경
- 디지털 트윈 계층: 데이터/모델/관리 3대 도메인으로 구성
- 네트워크 애플리케이션 계층: 인텐트 기반 서비스 에뮬레이션·제어
- 요구사항: 효율적 데이터수집, 통합 데이터저장소, 확장성, 신뢰성, 보안성, 동기화
## 구성도
```
[6G 물리 네트워크] ⇄(데이터/제어)⇄ [디지털 트윈: 데이터·모델·관리 도메인] ⇄(인텐트/제어)⇄ [네트워크 애플리케이션]
              └────────────── 이중 폐쇄루프(Double Closed-loop) ──────────────┘
```
