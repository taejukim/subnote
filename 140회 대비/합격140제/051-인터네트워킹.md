#정보관리기술사 #디지털네트워크 #인터네트워킹 #AutonomicNetworking
## 정의
인터네트워킹(Internetworking)
- 네트워크 장비로 연결된 개별 네트워크 간 사용자 단말 통신을 수행하여 하나의 거대한 네트워크를 구성·제어하는 과정
- 독립적인 네트워크들이 연결되어 복잡한 인터네트워크를 형성하는 과정
## 키워드
* 리피터, 브릿지, 라우터, 게이트웨이, 자율네트워킹, Self-configuration, Self-healing, IBM
## 암기법
* 리브라게: 리피터·브릿지·라우터·게이트웨이 (OSI 계층별 인터네트워킹 장비 순서)
## 특징
- 계층성: OSI 계층별로 리피터~게이트웨이 장비 구분 동작
- 오버헤드 보완: 상위 계층 장비일수록 처리 오버헤드 단점 보완
- 자율성: 인간 개입 최소화하며 환경변화에 스스로 대응(Autonomic Networking)
- Self-* 속성: 자기구성·최적화·복구·보호 4대 자율관리 속성 보유
## 목적
- 독립적 네트워크 간 통신을 통한 하나의 통합 네트워크 구성
- 집중관리 방식의 확장성·복잡도 한계를 극복하는 자율적 관리·제어
## 구성요소
- 리피터(물리계층): 신호 증폭·중계
- 브릿지(데이터링크계층): 세그먼트 연결, 트래픽 관리
- 라우터(네트워크계층): 패킷 경로 지정, 서브네트워크 연결
- 게이트웨이(응용계층): 이종 프로토콜 간 통신 변환
- Autonomic Manager: 센서 정보 수집·분석·판단·실행하는 자율 관리기
- 연구동향: Auto(가상네트워크 구획화), ANA(목표지향 실행), BIONETS(무선메쉬 자율관리)
## 구성도
```
[네트워크A] -Repeater- [네트워크B] -Bridge- [네트워크C]
                              │
                          [Router]
                              │
        [네트워크D] -Gateway(이종 프로토콜)- [네트워크E]
자율네트워킹: [센서] → [Autonomic Manager] → Self-config/optimize/heal/protect
```
