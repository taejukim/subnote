#정보관리기술사 #SW공학 #FaganInspection #정형검토
## 정의
인스펙션(Fagan Inspection)
- 역할분담·정형절차로 소프트웨어 결함을 조기 발견·제거하는 정형 검토기법
- 정적 분석 기법 중 가장 형식적이며 결함제거 ROI가 높은 검토 방법
## 키워드
* Fagan Inspection, 정형 검토, 결함 조기발견, 역할분담, 진입·종료 기준
## 암기법
* 역정정품: 역할기반진행·정형화프로세스·정량적결함관리·품질게이트운영
## 특징
- 역할기반 진행: 진행자·저자·검토자·기록자 등 명확한 역할분담
- 정형화 프로세스: 계획-개요-준비-검토회의-재작업-후속조치 6단계 고정절차
- 정량적 결함관리: 결함유형·심각도 분류·기록으로 데이터기반 개선
- 품질게이트 운영: 단계별 진입·종료 기준을 명시해 품질 통제
## 목적
- 개발 초기 결함의 조기 발견·제거로 수정비용 최소화
- 데이터 기반 결함분석을 통한 프로세스 지속 개선
## 구성요소
- 계획(Planning): 검토범위·일정·역할배정, 진입기준 확인
- 개요(Overview): 작성자가 산출물 내용을 검토자에게 설명
- 준비(Preparation): 검토자 개별 결함·질문목록 작성
- 검토회의(Inspection Meeting): 중재자 주도 결함 확인·분류·기록
- 재작업(Rework): 작성자가 발견된 결함 수정
- 후속조치(Follow-up): 중재자가 수정완료·종료기준 확인
## 구성도
```
계획 → 개요 → 준비(개인 결함목록) → 검토회의(공식 결함목록)
                                              │
                                       재작업(결함수정)
                                              │
                                   후속조치(종료기준 확인) → 완료
```
