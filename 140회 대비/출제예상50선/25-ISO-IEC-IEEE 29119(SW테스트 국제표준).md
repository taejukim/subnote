#정보관리기술사 #SW공학 #ISO29119 #SW테스트
## 정의
ISO/IEC/IEEE 29119(SW테스트 국제표준)
- SW 테스트의 개념·프로세스·기법·문서화를 규정한 소프트웨어 테스트 국제표준
- 테스트 전문성 없이도 최소 수준의 체계적 테스트를 가능케 하는 공통언어
## 키워드
* 테스트 프로세스, 테스트 설계기법, 테스트 문서화, 테스트 레벨, 테일러링
## 암기법
* 파프유이: Part구조화·프로세스계층화·유연한테일러링·ISTQB정합성
## 특징
- Part 구조화: 개념(P1)-프로세스(P2)-기법(P3)-문서(P4)-키워드테스트(P5) 구성
- 프로세스 계층화: 조직-관리-동적테스트 3계층 프로세스 체계
- 유연한 테일러링: 조직·프로젝트 특성에 맞게 선택적 적용 가능
- ISTQB 정합성: ISTQB 커리큘럼과 높은 정합성으로 역량개발 지원
## 목적
- 조직 간 상이한 테스트 방식의 표준화로 품질 일관성 확보
- 테스트 프로세스 개선 및 테스터 역량 개발 지원
## 구성요소
- Part 1(개념 및 정의): SW 테스트 개념·어휘 표준화
- Part 2(테스트 프로세스): 조직/관리/동적 테스트 프로세스 정의
- Part 3(테스트 문서화): 테스트계획서·케이스·결과리포트 템플릿
- Part 4(테스트 설계기법): 블랙박스·화이트박스·경험기반 기법
- Part 5(키워드기반 테스트): 스크립트리스 자동화 프레임워크
## 구성도
```
Part1(개념) → Part2(프로세스: 조직/관리/동적) → Part3(문서화)
                                                       │
                              Part4(설계기법) ↔ Part5(키워드기반 자동화)
                                       │
                    단위→통합→시스템→인수 테스트 레벨에 적용(테일러링)
```
