#정보관리기술사 #AI #에이전틱AI #AgenticSoftware
## 정의
에이전틱(Agentic) 소프트웨어 개발
- LLM 기반 AI 에이전트가 목표를 이해하고 계획·도구호출·코드생성·테스트를 반복하며 SW 생명주기를 자율 수행하는 개발 방식
- 추론-행동-관찰(ReAct) 루프와 외부 도구 활용을 통한 목표 지향적 자율 개발 패러다임
## 키워드
* 자율 계획·실행, 도구 호출, HITL, ReAct, 멀티에이전트 협업, MCP
## 암기법
* 자도반인: 자율적 목표지향성·도구활용능력·반복적 자기평가·인간개입 병행
## 특징
- 자율적 목표지향성: 목표만 제시하면 스스로 하위작업 분해·계획
- 도구 활용능력: 웹검색·코드실행·DB접근 등 외부도구 상황별 선택·호출
- 반복적 자기평가: 실행결과 스스로 점검, 오류시 계획 수정 피드백 루프
- 인간개입 병행: 중요결정 시 HITL 승인게이트로 안전성 확보
## 목적
- 반복적 개발업무 자동화로 생산성 향상
- 복잡한 문제해결을 위한 자율적 계획·실행 역량 확보
## 구성요소
- 계획수립(Planning): 목표를 서브태스크로 분해, CoT·ToT 활용
- 도구호출(Tool Use): Function Calling·MCP로 외부 API·코드실행 연동
- 메모리 관리(Memory): 단기(컨텍스트)·장기(벡터DB) 기억 활용(RAG)
- HITL(인간개입): 중요 결정시 승인게이트·감사로그
- 멀티에이전트 협업: 복수 전문 에이전트 역할분담·오케스트레이션
- 자기평가(Self-Evaluation): LLM-as-Judge, Reflexion으로 결과 검토·수정
## 구성도
```
목표 입력 ▶ [계획수립] ▶ [도구호출/코드생성] ▶ [실행] ▶ [관찰·자기평가]
               ▲                                              │
               └──────────── 재계획(오류/피드백) ◀─────────────┘
                        ↕ HITL 승인 게이트(중요 결정)
```
