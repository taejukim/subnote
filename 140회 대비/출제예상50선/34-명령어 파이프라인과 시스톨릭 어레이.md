#정보관리기술사 #컴퓨터구조 #파이프라인 #시스톨릭어레이
## 정의
명령어 파이프라인과 시스톨릭 어레이
- 명령어 중첩 실행과 PE 데이터 재사용을 활용한 CPU·AI 가속기의 병렬 처리 구조
- 범용 처리량 향상(파이프라인)과 행렬연산 특화 가속(시스톨릭 어레이)을 담당하는 두 핵심 구조
## 키워드
* 파이프라인 해저드, RAW/WAR/WAW, 분기예측, 시스톨릭 어레이, Weight Stationary, TPU
## 암기법
* 목데해재: 목적 차이·데이터흐름 차이·해저드 관리·재사용 극대화
## 특징
- 목적 차이: 파이프라인은 범용 명령어 처리량, 시스톨릭 어레이는 행렬연산 가속
- 데이터 흐름 차이: 파이프라인은 명령어가 단계 이동, 시스톨릭은 데이터가 PE 배열을 규칙적으로 흐름
- 해저드 관리: 구조적·데이터·제어 해저드를 포워딩·예측·지연삽입으로 해결
- 데이터 재사용 극대화: Weight/Output Stationary로 외부 메모리 접근 최소화
## 목적
- 명령어 수준 병렬성(ILP)으로 CPU 처리량과 클럭당 명령어 수 향상
- 데이터 수준 병렬성(DLP)으로 GEMM 등 AI 행렬연산의 에너지·성능 최적화
## 구성요소
- 파이프라인 5단계: IF→ID→EX→MEM→WB
- 구조적 해저드 해결: 자원 복제(캐시 분리), 추가 포트
- 데이터 해저드 해결: 포워딩(Bypassing), Stall
- 제어 해저드 해결: 분기예측(정적·동적), BTB, 지연분기
- 시스톨릭 어레이 PE 격자: MAC 연산 반복 수행, Weight/Output Stationary로 TPU 구현
## 구성도
```
[파이프라인] IF → ID → EX → MEM → WB   (해저드: 구조적/데이터/제어)
[시스톨릭 어레이 3x3]
A행렬→ ●→●→●
        ↓  ↓  ↓   ← B행렬
       ●→●→●
        ↓  ↓  ↓
       ●→●→●   (각 PE: MAC 연산, 데이터 규칙적 흐름)
```
