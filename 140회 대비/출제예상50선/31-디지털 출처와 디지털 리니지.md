#정보관리기술사 #데이터베이스 #디지털프로비넌스 #데이터리니지
## 정의
디지털 출처(Digital Provenance)와 디지털 리니지(Digital Lineage)
- 데이터의 기원·생성 근거를 증명(Provenance)하고 변환·이동 경로를 추적(Lineage)하는 데이터 신뢰 체계
- AI 신뢰성과 데이터 거버넌스를 뒷받침하는 핵심 메타데이터 인프라
## 키워드
* 데이터 출처, 데이터 계보, C2PA, W3C PROV, Apache Atlas, OpenLineage
## 암기법
* 초시활그: 초점 차이·시간범위 차이·활용목적 차이·그래프(DAG) 추적
## 특징
- 초점 차이: 출처는 기원·생성주체 증명, 리니지는 변환·이동 경로 추적
- 시간범위 차이: 출처는 특정 시점 생성근거, 리니지는 전체 생명주기 흐름
- 활용목적 차이: 출처는 신뢰성·진위 검증, 리니지는 품질문제 원인·영향 분석
- 그래프 기반 추적: 리니지를 DAG(방향성 비순환 그래프)로 표현해 상류·하류 영향 분석
## 목적
- AI 생성 콘텐츠의 진위성 검증과 딥페이크 등 조작 탐지
- 데이터 파이프라인 품질 문제의 원인 추적과 영향 분석
## 구성요소
- 출처(Provenance): W3C PROV·C2PA Manifest로 생성주체·처리과정 증명
- 진위성(Authenticity): 디지털 서명·해시·타임스탬프로 원본성 보장
- AI 콘텐츠 Provenance: C2PA·IPTC로 AI 생성물 출처·조작 여부 증명
- 비즈니스 리니지: 데이터 활용 방식의 영향분석(Impact Analysis)
- 기술/운영 리니지: Apache Atlas·OpenLineage·DataHub로 ETL·파이프라인 경로 추적
## 구성도
```
[데이터 생성] --Provenance(서명/타임스탬프)--> [원본 증명]
      ↓ ETL/변환/이동 (Lineage 추적, DAG)
[가공1] → [가공2] → [소비/AI 학습] ← 상류·하류 영향분석
```
