#정보관리기술사 #디지털서비스 #디지털트윈 #스마트시티
## 정의
도시 디지털트윈(UDT, Urban Digital Twin)
- 도시 인프라를 3D 공간데이터와 IoT로 실시간 재현한 도시 시뮬레이션 플랫폼
- 데이터 기반 도시 거버넌스의 핵심 인프라이자 스마트시티 구현의 중추 플랫폼
## 키워드
* 3차원 도시모델, 실시간 데이터 연동, 도시문제 시뮬레이션, CityGML, BIM
## 암기법
* 실시다양: 실시간동기화·시뮬레이션예측·다계층데이터통합·양방향피드백
## 특징
- 실시간 동기화: IoT 센서데이터 실시간 반영, 물리-가상 상태 일치
- 시뮬레이션 예측: What-if 시나리오로 정책시행 전 결과 사전예측
- 다계층 데이터통합: 교통·환경·에너지 등 이기종 데이터 단일 플랫폼 융합
- 양방향 피드백: 물리도시-디지털트윈 간 양방향 흐름으로 실시간 제어
## 목적
- 정책 시행 전 도시문제 사전 예측 및 대응력 강화
- 데이터 기반 도시운영·재난대응 의사결정 지원
## 구성요소
- 3D 공간모델링: CityGML·BIM 기반 건물·지형 정밀 구현
- 실시간 IoT 연동: 교통·환경·에너지 센서데이터 반영
- AI 시뮬레이션: 홍수·화재·교통 시뮬레이션으로 피해 예측
- 시민서비스 연계: 3D 지도기반 민원신청·시민참여
- 데이터 플랫폼: 다기관 데이터통합, 개방형 API 제공(OGC)
## 구성도
```
[물리 도시: IoT센서·교통·환경] ⇄ [디지털트윈: 3D모델+AI시뮬레이션]
              ▲                              │
        피드백 제어(정책·재난대응) ◀── What-if 시나리오 분석 결과
```
