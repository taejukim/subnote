#정보관리기술사 #보안 #가명정보 #개인정보보호법
## 정의
가명정보와 가명처리 기법
- 추가정보 없이는 특정 개인을 알아볼 수 없도록 처리하는 개인정보 비식별화 기법
- 개인정보와 익명정보의 중간 지점에서 데이터 활용과 프라이버시를 균형있게 실현하는 법·기술 수단
## 키워드
* 가명처리, 추가정보 분리보관, 데이터 결합, 재식별 위험, k-익명성, 데이터 3법
## 암기법
* 재법안기: 재식별가능성·법적근거·안전조치의무·기법다양성
## 특징
- 재식별 가능성: 추가정보 결합 시 식별가능해 익명정보와 구분
- 법적 근거: 2020년 데이터 3법 개정으로 통계·연구목적 활용 허용
- 안전조치 의무: 추가정보 별도 분리보관·접근통제로 재식별 방지
- 기법 다양성: 가명화·일반화·마스킹·잡음추가 등 목적별 조합 적용
## 목적
- 개인정보 보호와 데이터 경제 활성화의 균형 실현
- 통계작성·연구 등 목적의 안전한 데이터 활용 지원
## 구성요소
- 가명화(Pseudonymization): 식별자를 임의 코드·토큰으로 대체
- 일반화(Generalization): 구체값을 범위·범주로 대체(k-익명성 등)
- 데이터 마스킹: 일부 값을 특수문자로 은폐
- 잡음 추가(Noise Addition): 수치데이터에 랜덤 오차 삽입
- 데이터 스와핑: 레코드 간 필드값 교환
- 범주화(Micro-aggregation): 유사 레코드 그룹화 후 대푯값 대체
## 구성도
```
[개인정보]──가명처리(가명화/일반화/마스킹/잡음/스와핑)──▶[가명정보] + [추가정보(분리보관)]
                                                              │
                                                     결합전문기관 통해 재결합(통계·연구 목적)
```
