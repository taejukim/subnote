#정보관리기술사 #SW공학 #동등분할 #경계값분석
## 정의
동등분할과 경계값 분석
- 입력을 동치 파티션으로 분류하고 경계값에서 결함을 탐지하는 블랙박스 테스트 기법
- 동등분할로 테스트케이스를 최소화하고 경계값 분석으로 결함 집중지점을 보강하는 보완적 기법
## 키워드
* 동등분할, 경계값분석, 등가클래스, 테스트케이스 최소화, 블랙박스 테스트
## 암기법
* 동경상결: 동등분할 원리·경계값 원리·상호보완성·결합 커버리지
## 특징
- 동등분할 원리: 입력 도메인을 유효/무효 동등클래스로 나눠 대표값 1개 선정
- 경계값분석 원리: 동등클래스 경계(최소·최대·경계±1)에서 결함 집중 발생
- 상호 보완성: 동등분할로 범위 축소, 경계값분석으로 결함 가능성 높은 지점 보강
- 결합 커버리지: ISO/IEC 29119가 권고하는 블랙박스 테스트 기본 커버리지 경제적 달성
## 목적
- 무한한 입력 조합에서 최소 테스트케이스로 최대 결함 발견
- 결함이 집중되는 경계 지점을 체계적으로 검증
## 구성요소
- 유효 파티션: 입력 유효범위 내 대표값 선택(정상처리 기대)
- 무효 파티션: 입력 유효범위 외 대표값 선택(오류처리 기대)
- 최솟값/최댓값 경계: 유효범위의 min·max 경계값 테스트
- min-1/max+1: 경계 바로 안팎의 무효값으로 초과·미만 처리 검증
- 예시(나이 18~60세): 17,18,19 / 59,60,61로 경계 전후 테스트
## 구성도
```
무효      |         유효(18~60)              |  무효
 ...17  [18]  19 ... 대표값 ... 59  [60]  61 ...
        ↑경계값                    경계값↑
   (min-1/min)                   (max/max+1)
```
