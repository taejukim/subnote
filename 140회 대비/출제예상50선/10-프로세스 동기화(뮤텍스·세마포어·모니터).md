#정보관리기술사 #운영체제 #프로세스동기화 #세마포어
## 정의
프로세스 동기화(뮤텍스·세마포어·모니터)
- 공유자원 동시접근 시 데이터 일관성 보장을 위한 실행순서 제어 메커니즘
- 상호배제·진행·한계대기 3조건을 만족하는 병행성 제어 기법
## 키워드
* 상호배제, 세마포어, 모니터, 스핀락, 임계구역, 경쟁조건
## 암기법
* 경임소언: 경쟁조건방지·임계구역보호·소유권차이·언어수준통합
## 특징
- 경쟁조건 방지: 공유데이터 동시수정 시 결과 비결정성 해소
- 임계구역 보호: 공유자원 접근구간 동시진입 차단
- 소유권 차이: 뮤텍스는 소유권 있음, 세마포어는 소유권 없음
- 언어수준 통합: 모니터는 조건변수+상호배제를 언어차원에서 결합
## 목적
- 공유자원 동시접근으로 인한 데이터 불일치 방지
- 병렬처리 환경에서 정확한 연산결과 보장
## 구성요소
- 뮤텍스(Mutex): Lock/Unlock으로 임계구역 단독점유, 동일스레드만 해제
- 이진 세마포어: P(wait)/V(signal) 연산, 0/1 상태관리
- 계수 세마포어: N개 자원 동시접근 허용, 프로듀서-컨슈머 패턴
- 모니터(Monitor): 조건변수+상호배제 통합, Java synchronized
- 스핀락(Spinlock): Busy Waiting 방식, 단시간 임계구역에 적합
## 구성도
```
[프로세스A] ──Lock/P()──▶ [임계구역: 공유자원] ◀──Lock/P()── [프로세스B]
                    │ 대기(Block or Busy-wait)
              Unlock/V() 시 다음 프로세스 진입 허용
   (모니터: 조건변수로 대기·신호를 언어차원에서 자동 관리)
```
