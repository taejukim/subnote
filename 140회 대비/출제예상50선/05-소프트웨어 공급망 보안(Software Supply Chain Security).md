#정보관리기술사 #보안 #SBOM #공급망보안
## 정의
소프트웨어 공급망 보안(Software Supply Chain Security)
- 개발·빌드·배포 전 과정의 오픈소스·서드파티 구성요소 무결성을 보호하는 보안 체계
- SolarWinds·Log4Shell 사건처럼 단일 취약점이 전체 서비스로 확산되는 것을 방지하는 전 생명주기 보안
## 키워드
* SBOM, 오픈소스 취약점, 공급망 공격, DevSecOps, SLSA, Sigstore
## 암기법
* 신취가전: 신뢰사슬확장·취약점전파성·가시성확보곤란·전생명주기검증
## 특징
- 신뢰사슬 확장: 개발-빌드-배포 전 단계에 다수 이해관계자 개입
- 취약점 전파성: 상류 구성요소 결함이 하류 전체로 연쇄 전파
- 가시성 확보 곤란: 전이적 의존성 심화로 구성요소 파악 어려움
- 전 생명주기 검증: 개발부터 운영까지 단계별 무결성 검증 필요
## 목적
- 오픈소스·서드파티 취약점의 조기 탐지와 확산 차단
- 공급망 전 단계 가시성 확보를 통한 신속한 규제 대응
## 구성요소
- SBOM 생성·관리: SW 구성요소(이름·버전·라이선스·의존성) 목록화
- 취약점 지속 모니터링: CVE·NVD와 SBOM 대조, 신규 취약점 알림
- 무결성 서명·검증: 코드서명·컨테이너 이미지 서명(Sigstore)
- 보안 파이프라인 내재화: CI/CD에 SAST/SCA/컨테이너 스캔 자동화(DevSecOps)
- 오픈소스 거버넌스: 라이선스 관리, 금지 컴포넌트 블랙리스트
- 공급자 보안평가: 공급업체 보안 성숙도 평가, SLA 보안요건 포함
## 구성도
```
[개발]──SBOM 생성──▶[빌드]──서명·SCA 스캔──▶[배포]──취약점 모니터링──▶[운영]
   └────────────── DevSecOps CI/CD 파이프라인(전 단계 관통) ──────────────┘
```
