#정보관리기술사 #AI #과적합 #편향분산트레이드오프
## 정의
과적합(Overfitting)과 과소적합(Underfitting)
- 학습 데이터에 과도하게 또는 불충분하게 맞춰져 일반화 성능이 저하되는 모델 학습 문제
- 편향-분산 트레이드오프의 양 극단에서 발생하는 대표적 학습 실패 현상
## 키워드
* 일반화 성능, 편향-분산 트레이드오프, 정규화, 드롭아웃, 교차검증
## 암기법
* 과과편총: 과적합 증상·과소적합 증상·편향분산 관계·총오차 최소화
## 특징
- 과적합 증상: 훈련 정확도↑·검증 정확도↓, 분산 높음
- 과소적합 증상: 훈련·검증 정확도 모두 낮음, 편향 높음
- 편향-분산 관계: 단순 모델(고편향)→과소적합, 복잡 모델(고분산)→과적합
- 총오차 최소화: 편향²+분산+노이즈가 최소인 최적 복잡도 존재
## 목적
- 학습 데이터에만 최적화되는 것을 방지해 실제 데이터 일반화 성능 확보
- 편향과 분산의 균형점을 찾아 모델의 예측 신뢰성 향상
## 구성요소
- 과적합 해결: L1/L2 정규화, 드롭아웃, 데이터 증강
- 과소적합 해결: 모델 복잡도 증가, 피처 추가, 학습 에폭 연장
- 교차검증(K-Fold CV): 일반화 성능의 불편 추정
- 학습곡선 분석: 훈련·검증 손실 격차로 과적합·과소적합 진단
- 앙상블: 다수 모델 예측 결합으로 분산 감소
## 구성도
```
오차

```
