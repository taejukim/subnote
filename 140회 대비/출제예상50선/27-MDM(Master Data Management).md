#정보관리기술사 #데이터베이스 #MDM #데이터거버넌스
## 정의
MDM(Master Data Management)
- 고객·제품·공급업체 등 핵심 기준정보를 단일화·표준화하는 기준정보 관리 체계
- 데이터 거버넌스 정책을 실제 데이터에 적용·집행하는 핵심 실행 수단
## 키워드
* 기준정보 통합, 단일 진실 공급원(SSOT), 데이터 표준화, 데이터 품질, 데이터 스튜어드십
## 암기법
* 단품거계: 단일진실공급원·품질관리·거버넌스연계·계층관리
## 특징
- 단일 진실 공급원(SSOT): 조직 전체가 참조하는 하나의 신뢰 기준정보
- 데이터 품질 관리: 표준화·중복제거·정제로 지속적 품질 향상
- 거버넌스 연계: 소유권·접근권한 정책을 기준정보에 실제 적용
- 계층 관리: 제품 카테고리·조직 계층 등 마스터 데이터 모델 관리
## 목적
- 부서별 이질적 기준정보로 인한 의사결정 오류 방지
- AI·분석 성과의 신뢰성 있는 데이터 기반 확보
## 구성요소
- 데이터 통합: 이기종 소스 ETL로 단일 레코드 생성
- 데이터 품질: 중복제거·결함탐지·완전성 검증
- 데이터 스튜어드십: 비즈니스 담당자의 데이터 소유·검수
- 거버넌스 연계: 표준 정의·정책 집행·카탈로그 연동
- 아키텍처 유형: 레지스트리(분산저장)·공고화(허브복사)·공존(동기화)·트랜잭션(MDM=SOR)
## 구성도
```
[Registry] 소스 분산 저장·낮은 실시간성
   ↓
[Consolidation] MDM Hub로 복사·분석 위주
   ↓
[Coexistence] MDM+소스 동기화·운영+분석 병행
   ↓
[Transaction] MDM이 SOR·최고 실시간성
```
