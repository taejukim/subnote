#정보관리기술사 #AI #하네스엔지니어링 #AIAgent
## 정의
하네스 엔지니어링(Harness Engineering)
- AI 에이전트의 안전한 실행을 위한 실행환경·도구 통합·안전장치를 설계하는 공학 분야
- 에이전트와 외부 환경 사이의 안전 미들레이어로 행동을 통제·기록·평가하는 인프라
## 키워드
* 에이전트 실행환경, 도구 연동, 평가루프, HITL, 샌드박싱, 권한관리
## 암기법
* 안신확성: 안전성 확보·신뢰성 확보·확장성 확보·성숙도 단계화
## 특징
- 안전성 확보: 비의도적·위험 행동을 사전 차단·통제
- 신뢰성 확보: 에이전트 출력의 정확성·일관성을 지속 검증
- 확장성 확보: 다양한 도구·환경을 안전하게 추가·교체
- 성숙도 단계화: 로깅→권한제어→샌드박싱·HITL→자가치유로 단계적 고도화
## 목적
- 강력한 자율 에이전트를 안전하게 운영하기 위한 필수 인프라 마련
- 에이전트 행동의 감사 가능성과 통제력 확보
## 구성요소
- 도구 래퍼(Tool Wrapper): 샌드박싱·입출력 검증(Docker, E2B)
- 권한 관리(Permission): 최소권한 원칙, RBAC·OAuth Scopes
- 감사 로그(Audit Log): 행동 전체 기록·추적(OpenTelemetry)
- HITL 게이트: 고위험 행동 전 인간 승인 요구
- 평가 루프(Eval Loop): LLM-as-Judge 등으로 출력 품질 자동 평가
## 구성도
```
[사용자 지시] → [AI 에이전트] ↔ [하네스: 도구래퍼·권한관리·감사로그·HITL게이트·평가루프] ↔ [외부 도구/환경]
                                     ↑ Level1(기본)→Level4(자가치유) 성숙도 진화
```
