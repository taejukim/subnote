#정보관리기술사 #운영체제 #시스템콜 #커널모드
## 정의
시스템 콜(System Call)
- 사용자 모드에서 커널 모드로 전환하여 OS 서비스를 요청하는 시스템 인터페이스 메커니즘
- 응용과 OS 사이의 유일한 공식 경계로 시스템 보안·안정성의 핵심 게이트키퍼
## 키워드
* 사용자모드/커널모드 전환, 트랩, 인터럽트, 특권 명령, seccomp-BPF
## 암기법
* 트모결성: 트랩 발생·모드 전환·결과 반환·성능 오버헤드
## 특징
- 트랩 발생: 시스템콜 명령 실행 시 소프트웨어 인터럽트(트랩) 발생
- 모드 전환: 사용자 모드에서 커널 모드로 전환해 커널이 처리
- 결과 반환: 처리 완료 후 사용자 모드로 복귀, 결과값 반환
- 성능 오버헤드: 모드 전환 비용 존재, vDSO로 일부 최적화
## 목적
- 응용 프로그램의 직접적 하드웨어 접근을 차단해 시스템 안정성 확보
- OS가 제어하는 안전한 인터페이스로 자원 접근 통제
## 구성요소
- 프로세스 제어: fork(), exec(), exit(), wait()
- 파일 관리: open(), read(), write(), close(), stat()
- 장치 관리: ioctl(), mmap()
- 정보 유지: getpid(), time(), uname()
- 통신: socket(), send(), recv(), pipe(), signal()
## 구성도
```
[사용자 프로그램] --시스템콜 호출(트랩)--> [CPU 모드전환: User→Kernel]
                                              ↓
                                     [커널: 핸들러 테이블 조회·처리]
                                              ↓
[사용자 프로그램] <--결과반환(Kernel→User)-- [처리 완료]
```
