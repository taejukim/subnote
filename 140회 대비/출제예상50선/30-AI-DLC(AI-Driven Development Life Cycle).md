#정보관리기술사 #SW공학 #AIDLC #AI코드생성
## 정의
AI-DLC(AI-Driven Development Life Cycle)
- AI를 SDLC 전반에 활용해 요구사항·구현·배포를 자동화·증강하는 개발 방법론
- 개발자 역할을 코드 작성자에서 AI 협력자·검증자로 전환하는 패러다임
## 키워드
* AI 주도 개발, 단계 압축, 지속적 생성·검증, Human-in-the-loop, 프롬프트 엔지니어링
## 암기법
* 주개반검: 주도주체 변화·개발자역할 전환·반복주기 단축·검증게이트
## 특징
- 주도 주체 변화: AI가 코드 생성·검증을 주도, 개발자는 명세·검토 담당
- 개발자 역할 전환: 코드 작성자에서 검증자(Reviewer)·아키텍트로 이동
- 반복 주기 단축: 자동 생성·검증으로 개발-테스트 사이클 대폭 압축
- 검증 게이트 필수: AI 환각·오류 방지 위한 Human-in-the-loop 검증
## 목적
- AI 코드 생성 도구 확산에 맞춘 개발 방법론의 근본적 재설계
- 코딩 생산성 극대화와 동시에 생성 코드의 품질·보안 리스크 통제
## 구성요소
- Context & Spec Engineering: 요구사항·수용기준을 LLM과 협력 정제(HITL 필수)
- 코드 생성·리뷰: AI 자동 코드생성·리팩토링·취약점 탐지(Provenance 추적)
- 테스트·검증(Evaluation Gate): AI 기반 테스트케이스 생성·커버리지 분석·회귀 자동화
- 배포·운영: 성능 모니터링·이상탐지·자동 롤백, SBOM·모델버전 거버넌스
- 모델·도구 관리: 사용 AI 모델·플러그인 선택·위험평가·버전 거버넌스
## 구성도
```
[명세정제(Human+LLM)] → [AI 코드생성/리뷰] → [Evaluation Gate(테스트·검증)] → [배포·운영(모니터링)]
        ↑──────────────── 개발자: 검증·감독(Human-in-the-loop) ────────────────┘
```
