#정보관리기술사 #보안 #LLM보안 #OWASPLLM
## 정의
OWASP LLM Top 10:2025
- LLM 애플리케이션에서 발생하는 10대 보안 위험을 커뮤니티가 선정한 보안 가이드라인
- 위험 기반 우선순위화와 정기 개정을 통해 진화하는 LLM 보안 국제 표준
## 키워드
* 프롬프트 인젝션, 민감정보 유출, 과도한 권한 위임, 공급망 취약점, 시스템 프롬프트 유출, 벡터·임베딩 취약점
## 암기법
* 커위정전: 커뮤니티 주도·위험기반 우선순위화·정기개정·전단계 위협존재
## 특징
- 커뮤니티 주도: 보안전문가·산업계 참여로 실제 사고데이터 기반 항목 선정
- 위험기반 우선순위화: 발생빈도·비즈니스 영향도 고려한 Top10 랭킹
- 정기개정: 2023(v1.1)→2025(v2.0) 등 기술변화 반영한 주기적 갱신
- 전단계 위협존재: 입력-처리-출력 전 단계에 위협 존재, 단계별 통제 필요
## 목적
- LLM 서비스의 보안 위험을 체계적으로 식별하고 대응체계 수립
- 신종 AI 보안 위협에 대한 공통언어와 국제 표준 기준 제공
## 구성요소
- LLM01 프롬프트 인젝션: 입력 조작으로 지시 변조(직접·간접)
- LLM02 민감정보 공개: 학습데이터·시스템프롬프트 등 민감정보 노출
- LLM03 공급망 취약점: 모델·플러그인·데이터셋 신뢰사슬 취약점
- LLM04 데이터·모델 오염: 훈련데이터 조작으로 백도어·편향 삽입
- LLM05 부적절한 출력처리: 출력 미검증으로 XSS·SSRF·RCE 유발
- LLM06 과도한 자율성: 에이전트 과도권한으로 시스템 오조작·데이터 삭제
- LLM07 시스템 프롬프트 유출: 기밀지침·API키 노출(신규)
- LLM08 벡터·임베딩 취약점: RAG 벡터DB 오염·역공학(신규)
- LLM09 허위정보·환각: 신뢰불가 정보 생성(v1.1 과의존 통합)
- LLM10 무제한 소비: 쿼리 제한 없이 DoS·비용폭증 유발(확장)

