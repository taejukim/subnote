#정보관리기술사 #보안 #PET #프라이버시강화기술
## 정의
PET(Privacy Enhanced Technology)
- 차분 프라이버시·SMPC·동형암호 등으로 개인정보 보호와 데이터 활용을 동시 달성하는 기술군
- AI 시대의 "데이터 활용 vs 프라이버시 보호" 딜레마를 기술적으로 해소하는 수단
## 키워드
* 동형암호, 차분 프라이버시, 연합학습, 합성데이터, SMPC
## 암기법
* 데연접트: 데이터변환기반·연산환경기반·접근제어기반·트레이드오프
## 특징
- 데이터 변환 기반: 동형암호·차분 프라이버시로 데이터 자체를 수학적 변환
- 연산 환경 기반: TEE·SMPC 등 안전한 계산 환경에서 데이터 처리
- 접근 제어 기반: 익명화·가명처리로 식별정보 제거·대체
- 트레이드오프 존재: 프라이버시 보호 수준과 계산 비용 간 상충 관계
## 목적
- 데이터 공유·분석 시 개인정보 노출 위험 최소화
- AI 학습 데이터의 프라이버시 위험을 해소하며 데이터 활용 극대화
## 구성요소
- 동형암호(HE): 암호화된 채로 연산, 복호화 없이 결과 획득
- 차분 프라이버시(DP): 집계 결과에 랜덤 노이즈 추가, DP-SGD로 AI 학습 적용
- 연합학습(FL): 데이터 이동 없이 모델 파라미터만 공유
- 합성데이터(Synthetic Data): 실제 통계 특성을 가진 인공 데이터 생성(GAN)
- SMPC: 다자간 비밀 공유로 입력 노출 없는 공동 연산
## 구성도
```
[원본 데이터] → 변환기반(HE/DP) → 연산환경기반(TEE/SMPC) → 접근제어기반(익명화) → [활용 가능 데이터]
              프라이버시 보호↑ ←──────── 계산비용↑ (Trade-off) ────────→
```
