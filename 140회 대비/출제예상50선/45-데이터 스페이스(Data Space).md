#정보관리기술사 #데이터베이스 #데이터스페이스 #GaiaX
## 정의
데이터 스페이스(Data Space)
- 데이터 주권을 유지하며 표준 인프라로 신뢰 기반 데이터를 교환하는 데이터 공유 생태계
- 데이터 경제의 공정한 성장을 위한 신뢰 기반 공유 인프라의 핵심 구조
## 키워드
* 데이터 주권, 연합형 아키텍처, 상호운용성, IDS 커넥터, Gaia-X
## 암기법
* 주연신정: 데이터주권 보장·연합형 아키텍처·신뢰·상호운용성·정책 실시간 집행
## 특징
- 데이터 주권 보장: 제공자가 자신의 데이터 통제권을 유지한 채 공유
- 연합형 아키텍처: 중앙집중 저장 없이 각 참여자가 데이터 보유한 채 연결
- 신뢰·상호운용성: 공통 거버넌스·표준 인터페이스로 신뢰 기반 교환
- 정책 실시간 집행: IDS 커넥터가 데이터 이동 시 출처·사용정책 함께 전달
## 목적
- 데이터 독점 문제 해소와 개인정보보호 요구를 동시에 충족
- 데이터를 안전하게 공유·활용해 데이터 경제 가치 창출
## 구성요소
- Federated Catalog: 참여자별 데이터 자산의 연합 카탈로그
- Identity·Trust Framework: 참여자 신원·신뢰 검증 체계
- Usage Control: IDS/EDC 커넥터로 데이터 사용정책 실시간 집행
- Data Contract·Product: 데이터 이용 계약·제품 단위 관리
- 사례: Gaia-X(EU), IDSA, CATENA-X(자동차), 마이데이터(개인)
## 구성도
```
[참여자A: 데이터 보유] ↔ [IDS/EDC 커넥터: 출처·정책 전달] ↔ [참여자B: 데이터 보유]
                              ↑ Federated Catalog·Identity·Trust Framework(연합 거버넌스)
```
