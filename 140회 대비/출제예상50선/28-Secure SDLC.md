#정보관리기술사 #보안 #SecureSDLC #DevSecOps
## 정의
Secure SDLC
- SDLC 전 단계에 보안 활동을 내재화하여 결함을 조기에 제거하는 보안 개발 방법론
- "보안을 나중에 붙이는" 방식에서 "처음부터 설계하는" 방식으로 전환한 개발 체계
## 키워드
* Shift-Left, 시큐어코딩, 위협모델링, SAST/DAST/SCA, 보안 게이트, DevSecOps
## 암기법
* 전쉬자게: 전단계 내재화·Shift-Left·자동화 연계·보안게이트
## 특징
- 전 단계 보안 내재화: 요구사항부터 배포·운영까지 보안 활동 통합
- Shift-Left 원칙: 보안 검증을 개발 초기로 앞당겨 수정비용 최소화
- 자동화 도구 연계: SAST·DAST·SCA를 파이프라인에 통합
- 보안 게이트 운영: 단계별 보안 기준 미충족 시 다음 단계 진입 차단
## 목적
- 운영 단계 취약점 발견 시 발생하는 고비용 수정 방지
- 개발 초기부터 보안을 설계에 반영해 안전한 SW 생산
## 구성요소
- 요구사항 단계: 보안 요구사항 도출, Abuse Case 분석
- 설계 단계: 위협 모델링(STRIDE·DREAD), 보안 아키텍처 검토
- 구현 단계: 시큐어 코딩, 정적분석(SAST, SonarQube·Checkmarx)
- 테스트 단계: 동적분석(DAST), 침투테스트, 퍼징(OWASP ZAP·Burp Suite)
- 배포·운영 단계: 보안 형상관리, 취약점 패치, SBOM 유지
## 구성도
```
요구사항(Abuse Case) → 설계(위협모델링) → 구현(SAST) → 테스트(DAST·퍼징) → 배포·운영(SBOM·패치)
        └────────────── 각 단계 보안 게이트(Gate) 통과 필요 ──────────────┘
                     ↓ CI/CD 자동화 통합 = DevSecOps
```
