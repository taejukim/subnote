#정보관리기술사 #컴퓨터구조 #DMA #GPUDirect
## 정의
DMA(Direct Memory Access)
- CPU 개입 없이 메모리와 I/O 장치 간 데이터를 직접 전송하는 메모리 접근 메커니즘
- CPU를 데이터 이동 부담에서 해방시켜 연산에 집중하게 하는 핵심 I/O 최적화 기술
## 키워드
* CPU 부담 경감, 사이클 스틸링, 버스트 전송, GPUDirect RDMA, 메모리 대역폭
## 암기법
* 전독완버: 전송요청 위임·독립적 전송·완료 인터럽트·버스 공유 방식
## 특징
- 전송 요청 위임: CPU가 DMA 컨트롤러에 주소·크기 설정 후 위임
- 독립적 데이터 전송: 컨트롤러가 CPU 개입 없이 메모리-장치 직접 전송
- 완료 인터럽트: 전송 완료 시 인터럽트로 CPU 통지
- 버스 공유 방식: 사이클 스틸링·버스트·투명 모드로 버스 점유 조절
## 목적
- 대용량 데이터 전송 시 CPU 부담을 줄여 연산 처리 효율 극대화
- GPU·NPU 등 가속기와의 고속 데이터 이동으로 AI 연산 병목 해소
## 구성요소
- DMA 컨트롤러: 전송 주소·크기 관리, 독립적 전송 수행
- 사이클 스틸링: CPU-DMA가 버스를 번갈아 사용
- 버스트 모드: DMA가 전송 완료까지 버스 독점
- 투명 모드: CPU 버스 미사용 시에만 DMA 동작
- PCIe DMA/GPUDirect RDMA: CPU-GPU, GPU-NIC 간 직접 텐서 전송
## 구성도
```
[CPU] --전송요청(주소·크기)--> [DMA 컨트롤러] --직접전송--> [메모리] ↔ [I/O·GPU 장치]
   ↑─────────── 전송완료 인터럽트 통지 ───────────┘
[GPU] ---GPUDirect RDMA(CPU 우회)--- [NIC]
```
