#정보관리기술사 #보안 #선제적보안 #CTEM
## 정의
선제적 사이버보안(Preemptive Cybersecurity)
- EASM·CAASM·CTEM 등으로 공격 전 위협 노출을 선제 식별·검증하는 능동적 방어 방법론
- "침해는 불가피"라는 전제 하에 탐지 속도와 대응 능력을 극대화하는 보안 전략
## 키워드
* 사전 위협 헌팅, 공격표면 관리, ASM, BAS, MTD, 이동목표방어
## 암기법
* 대접목이: 대응시점 차이·접근방식 차이·목표지표 차이·이동목표방어(MTD)
## 특징
- 대응 시점: 침해 전 노출·경로를 사전 식별(반응적 보안은 침해 후 대응)
- 접근 방식: 공격자 관점의 지속적 검증(BAS), 시그니처 기반 탐지 지양
- 목표 지표: 공격표면·노출 자체 축소가 목표(단순 탐지시간 단축 아님)
- 이동 목표 방어: 공격 표면을 동적으로 변경해 정찰·익스플로잇 방해
## 목적
- 공격자의 드웰타임(침해 후 탐지까지 평균 200+일) 단축
- 사후 대응 중심에서 사전 예방 중심으로 보안 패러다임 전환
## 구성요소
- EASM(외부 공격표면 관리): 외부 자산·취약점 지속 발견·모니터링
- CAASM(사이버자산 공격표면 관리): 내부 자산 통합 가시성 확보
- CTEM(지속적 위협노출 관리): 범위설정→발견→우선순위화→검증→동원화 5단계
- 위협헌팅·BAS: 위협 정보 기반 탐색과 실제 TTP 시뮬레이션 검증
- MTD(이동목표방어): IP 셔플·다양성·디셉션으로 공격표면 동적 변경
## 구성도
```
[EASM/CAASM: 자산·노출 발견] → [CTEM: 우선순위화·검증(BAS)] → [MTD: 공격표면 동적변경]
                    ↓ 알기→예측→행동 사이클 반복
              공격자보다 먼저 취약점 발견·방어
```
