#정보관리기술사 #SW공학 #클라우드네이티브 #Kubernetes
## 정의
클라우드 네이티브(Cloud Native)
- 컨테이너·마이크로서비스·CI/CD·불변인프라 기반의 클라우드 최적화 설계 방식
- 단순 클라우드 이전(Lift & Shift)을 넘어 클라우드 설계원칙을 내재화하는 아키텍처
## 키워드
* 컨테이너, 마이크로서비스, CI/CD, 오케스트레이션, 서비스 메시, GitOps
## 암기법
* 이독선자: 이식성·독립배포성·선언적자동화·자가치유
## 특징
- 이식성: 컨테이너 기반 OS·인프라 독립적으로 어디서나 동일 실행
- 독립배포성: 마이크로서비스 기능단위 독립 배포·확장 가능
- 선언적 자동화: 원하는 상태 선언 시 시스템이 자동으로 유지·복구
- 자가치유: 오케스트레이션 기반 장애 자동 감지·복구
## 목적
- 빠른 배포와 탄력적 확장이 가능한 아키텍처 확보
- 장애 격리를 통한 높은 가용성 실현
## 구성요소
- 컨테이너: OS 독립 실행단위, 경량격리(Docker, containerd)
- 마이크로서비스: 독립배포 가능한 기능단위(REST API, gRPC)
- 오케스트레이션: 자동배포·스케일링·자가치유(Kubernetes, OpenShift)
- CI/CD 파이프라인: 소스→빌드→테스트→배포 자동화(GitHub Actions, ArgoCD)
- 서비스 메시: 서비스 간 트래픽·보안·관찰가능성 관리(Istio, Linkerd)
- 불변인프라: 배포 시 인스턴스 교체, 구성 불변 유지(GitOps, Helm)
## 구성도
```
[CI/CD 파이프라인] → [컨테이너 이미지] → [오케스트레이션(K8s)]
                                              │
                                     [서비스 메시: 트래픽·보안 제어]
                                              │
                                  마이크로서비스 A ↔ B ↔ C (불변 인프라)
```
