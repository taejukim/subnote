#정보관리기술사 #AI #GraphRAG #RAG
## 정의
GraphRAG와 Advanced RAG
- 지식그래프·멀티홉추론·재랭킹으로 기본 RAG를 고도화한 검색증강생성 기법
- 단순 벡터 유사도 검색을 넘어 구조적·맥락적 정보를 반영하는 차세대 RAG
## 키워드
* 지식그래프 기반 검색, 모듈형 RAG, 재순위화, 멀티홉 추론, 환각 감소
## 암기법
* 단구커신: 단계별최적화·구조적추론·커뮤니티요약·신뢰도교정
## 특징
- 단계별 최적화: Advanced RAG는 사전·검색중·사후검색 단계별 기법 적용
- 구조적 추론: GraphRAG는 노드·엣지 관계 활용한 멀티홉 추론
- 커뮤니티 요약: 지식그래프 커뮤니티 요약으로 글로벌 문맥 파악
- 신뢰도 교정: CRAG·Self-RAG로 검색결과 신뢰도 평가·자기교정
## 목적
- 기본 RAG의 단편 문서검색 한계 극복
- 복잡한 멀티홉 추론과 글로벌 문맥 이해를 통한 환각 감소
## 구성요소
- 쿼리 재작성(Query Rewriting): 모호한 질의 명확화·다각화
- 하이브리드 검색: 벡터+키워드(BM25+ANN) 결합으로 재현율 향상
- 재순위화(Reranking): Cross-Encoder로 검색결과 관련성 재정렬
- GraphRAG: 지식그래프 커뮤니티 요약으로 글로벌 문맥·멀티홉 추론
- CRAG(교정 RAG): 검색결과 신뢰도 평가 후 웹검색 보완
- Self-RAG: 검색필요여부·품질·답변적절성 토큰 기반 자기평가
## 구성도
```
질의 → [쿼리재작성] → [하이브리드 검색: 벡터+BM25] → [재순위화(Reranker)]
                                                              │
                              [GraphRAG: 지식그래프 멀티홉·커뮤니티요약]
                                                              │
                        [CRAG/Self-RAG: 신뢰도 평가·자기교정] → 답변 생성
```
