#정보관리기술사 #보안 #프롬프트인젝션 #모델전도공격
## 정의
AI 모델 보안 위협(프롬프트 인젝션과 모델 전도 공격)
- LLM 입력·출력 인터페이스를 악용해 모델을 조작하거나 학습정보를 추출하는 보안 위협
- 모델 무력화(인젝션)와 지식재산 탈취(전도)라는 상반된 목표를 가진 두 공격 유형
## 키워드
* 프롬프트 인젝션, 모델 전도 공격, 모델 추출, 멤버십 추론, 데이터 오염, 차분 프라이버시
## 암기법
* 인반대방: 인젝션 이중경로·반복질의 복원·대량질의 복제·방어심층화
## 특징
- 인젝션 이중경로: 직접(사용자 입력)·간접(외부데이터) 경로로 지시 변조
- 반복질의 복원: 모델 전도는 반복 쿼리로 학습데이터·내부표현 역추출
- 대량질의 복제: API 대량질의로 원본 모델 기능·파라미터 복제
- 방어심층화 필요: 입력-추론-출력 단계별 다층 보안통제 요구
## 목적
- LLM 입력 조작으로 인한 서비스 오남용·정보유출 방지
- API 질의를 통한 모델·지식재산 탈취 차단
## 구성요소
- 직접 프롬프트 인젝션: 사용자가 시스템 프롬프트 직접 변조
- 간접 프롬프트 인젝션: 외부데이터(웹·RAG)에 숨긴 명령 자동실행
- 모델 전도(Model Inversion): 입력기반 학습데이터·내부표현 복원
- 모델 추출(Model Extraction): 대량질의로 대체모델 학습·기능복제
- 멤버십 추론: 특정데이터의 학습 포함여부 통계적 확인
- 학습데이터 오염: 훈련데이터 백도어·편향 삽입
## 구성도
```
사용자/외부데이터 ──(직접·간접 인젝션)──▶ [ LLM ]
                                            │  ▲
                                  응답 관찰  │  │ 반복 질의(전도·추출·멤버십추론)
                                            ▼  │
                                     공격자(정보·모델 복제)
```
