#정보관리기술사 #컴퓨터구조 #지능형반도체 #컴퓨터구조/반도체 #NEW
## 정의
지능형 반도체
- 데이터를 저장하는 메모리 반도체와 연산 기능을 수행하는 시스템 반도체가 융합된 형태의 반도체
## 키워드
* 지능화, 저전력화, 안정화, 스마트 인지·제어, 스마트 통신, 초고속 컴퓨팅
## 암기법
* 컴통신인: 초고속컴퓨팅·스마트통신·스마트인지제어
## 특징
- 메모리+시스템 융합, 병목 완화
- 뉴로모픽: 연산·저장·통신 융합, Neuron/Synapse 구조
- 저전력·지능화·안정화 지향
## 목적
- AI·IoT·통신 등에서 고속·저전력 지능 처리
## 구성요소
- 초고속 컴퓨팅: 뉴로모픽, 지능형메모리, 빅데이터 고속처리, IoT 프로세서
- 스마트 통신: 5G/6G·AV, 광대역 네트워크, 초저전력 커넥티비티
- 스마트 인지제어: 얼굴인식, 추천, 자동통역, 음성비서
## 구성도
```
기존: CPU ─BUS(병목)─ Memory
뉴로모픽: Neuron↔Synapse 격자 (연산·저장·통신 융합, 병목 없음)
```
