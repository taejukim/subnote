## 정의
이레이저 코딩(Erasure Coding)
- 분할과 패리티로 데이터를 인코딩하고, 손실 시 디코딩으로 원본을 복구하는 기술
## 키워드
* Reed-Solomon, Tahoe-LAFS, Weaver Code, 분할, 인코딩, 디코딩, n+k
## 암기법
* 분인디: 분할·인코딩·디코딩
## 특징
- n 분할 + k 패리티 = n+k 저장
- 임의 n개만 있으면 원본 복구
- RAID 대비 저장 효율·내결함성 유연
## 목적
- 데이터 손실에 대비한 분산 저장·복구
## 구성요소
- 분할: 동일 크기 n 블록
- 인코딩: RS/Tahoe-LAFS/Weaver로 패리티 k 추가 저장
- 디코딩: 손실 시 생존 n개로 복원
- RS: n+k 중 n으로 재구성
- Tahoe-LAFS: 암호화 분산 저장
- Weaver: 동일 스트립 데이터/패리티, XOR 기반 고내결함
## 구성도
```
DATA → n등분 → 인코딩(+k 패리티) → 저장(n+k)
손실 시 → 생존 n개 → 디코딩 → 원본 n
```
