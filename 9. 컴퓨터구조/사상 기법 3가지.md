#컴퓨터구조 #캐시 #사상 #필수 #컴퓨터구조/메모리
## 정의
캐시 메모리와 주기억장치 간 주소 매핑 방식, Cache Mapping
- 주기억장치의 블록을 캐시 메모리의 슬롯에 매핑하는 3가지 기법
## 키워드
* 직접사상(Direct), 연관사상(Associative), 집합연관사상(Set-Associative), 태그, 슬롯
## 암기법
* "지연집 태라단" - 직접/연관/집합연관, 태그/라인/단어
## 구성요소/특징/유형
- 캐시메모리는 태그, 테이터(단어)로 구성

| 구분     | 설명                                                                                                | 비고                                                |
| ------ | ------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 직접사상   | 주소→특정 슬롯 고정 매핑(하나의 캐시라인 적재)<br>ㄴ슬롯비트(s)의 번호로 캐시 슬롯을 특정해 슬롯 선택<br>ㄴ 해당 슬롯의 태그 비트와 주소 비교, 일치시 단어 인출 | 구현 단순, 충돌 多<br>Swap out 발생<br>슬롯 교체가 빈번, 캐시 성능 저하 |
| 연관사상   | 어느 슬롯이든 저장 가능<br>ㄴ 캐시의 모든 슬롯들의 태그 영역과 내용 비교                                                       | 적중률 高, 비용 高<br>실제 사용되지 않음                         |
| 집합연관사상 | 집합 내 자유 배치 (캐시 슬롯을 묶음)<br>메모리 주소의 집합 비트(d)를 이용, 캐시 집합 선택<br>Set 내 태그와 비교                          | 직접+연관 절충<br>2way : 세트당 2개 (일반적)<br>4way : 성능 향상   |
 - CPU가 캐시메모리에서 원하는 데이터를 찾은 경우 Hit, 그렇지 않은 경우 Miss


## 구성도
```
[직접사상]        [연관사상]        [집합연관사상]
주소→슬롯 1:1    주소→전체 탐색    주소→집합→슬롯
태그|슬롯|단어    태그|단어          태그|집합|단어
적중률 낮음       적중률 높음        절충 방식
```
