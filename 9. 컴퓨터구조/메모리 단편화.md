## 정의
메모리 단편화(Fragmentation)
- 메모리 상에서 프로그램에 의해 사용되지 못하고 낭비되는 공간이 발생하는 현상
## 키워드
* 낭비 공간, 내부/외부 단편화, Coalescing, Compaction, Memory Pool, Buddy, Slab
## 암기법
* 내외: 내부(파티션 내 잔여)·외부(분산 free로 할당불가)
## 특징
- 내부: 고정 파티션에 적재 후 남는 공간 낭비
- 외부: 가변 분할 후 작은 free들이 모여도 큰 요청 불가
## 목적
- 낭비 공간 유형 파악 및 해결로 메모리 이용률 향상
## 구성요소
- 해결: Coalescing(인접 통합), Compaction(압축·GC)
- 가상메모리: Paging(외부↓), Segmentation(내부↓)
- Memory Pool, Buddy System, Slab Allocator
## 구성도
```
내부: [50KB|잔여][50KB|잔여]…
외부: [60][15free][90][10free]… ← 40KB 할당 불가
해결: 통합·압축·페이징/세그·풀/버디/슬랩
```
