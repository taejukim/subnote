## 정의
워치독 타이머(WDT, Watchdog timer)
- 프로세서 동작을 감시하여 외부 잡음·비정상 동작으로 오작동 시 시스템을 리셋하여 복구하는 디바이스
## 키워드
* Kick, Reset, Clock, Time out
## 암기법
* 킥리클타: Kick·Reset·Clock·Timeout
## 특징
- Alive 감시: 주기 Kick(Clear)
- Timeout 시 Reset으로 복구
- HW/다단계 구현 가능
## 목적
- 프로세서 행(hang)·오동작 시 자동 리셋 복구
## 구성요소
- Clock: WDT·MCU 공통 클럭
- Kick: Task 정상 동작 Alive 신호
- Reset: 만료 시 MCU 초기화
- 절차: Setup → Timer Start(카운트다운) → Kick 반복 → Task runaway 시 refresh 중단 → Expire → Reset MCU
- 구현: 내부/외부 WDT, 단단계/다단계 WDT
## 구성도
```
CLOCK → WDT ←─Kick─ MCU
         └─Reset─→ MCU
Timeout = refresh 중단 시 expire
```
