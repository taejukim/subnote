#정보관리기술사 #컴퓨터구조 #MMU #컴퓨터구조/메모리 #NEW
## 정의
MMU(Memory Management Unit)
- CPU가 메모리에 접근하도록 관리하는 하드웨어로, 가상 메모리 주소를 실제 메모리 주소로 변환하는 장치
## 키워드
* 가상 주소, 물리주소, 주소변환, TTB
## 암기법
* 가물페: 가상주소→페이지테이블→물리주소
## 특징
- 주소 변환: VA → PA
- 페이지 테이블: TTB 기반 검색
- CPU-메모리 중재: 접근 관리
## 목적
- 가상 메모리 주소를 물리 주소로 변환하여 메모리 접근 관리
## 구성요소
- ① CPU가 MMU에 가상주소 전달
- ② MMU가 TTB부터 페이지 테이블 검색
- ③ 물리주소 엔트리 MMU 전달
- ④ MMU가 RAS/CAS 등 주소신호로 물리 접근
- ⑤ Memory→CPU 데이터 전달
## 구성도
```
CPU ─①VA─→ MMU ─②TTB검색─→ Memory(Page Table)
              ↑③PA        │④물리접근
CPU ←─⑤Data──────────────┘
```
