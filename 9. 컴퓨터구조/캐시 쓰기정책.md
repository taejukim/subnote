#정보관리기술사 #컴퓨터구조 #캐시쓰기정책 #컴퓨터구조/메모리 #NEW
## 정의
캐시 쓰기정책(Write Policy)
- 캐시와 주기억장치에 기록하는 시점에 대한 정책
## 키워드
* Write Through, Write Back, Cache Coherence, Dirty Bit
## 암기법
* 동나: Write Through(동시)·Write Back(나중)
## 특징
- Write Through: 캐시·주기억 동시쓰기, 일관성 항상 보장, 구조 단순, Bus traffic·Write Time 증가
- Write Back: 캐시에만 쓰고 Dirty Bit, Swap Out 시 복사, Write 최소화·시간 단축, Coherency·Dirty 확인 부담
## 목적
- 쓰기 성능과 캐시-메모리 일관성 균형
## 구성요소
- Write Through: CPU → Cache + Main Memory 동시
- Write Back: CPU → Cache → (교체 시) Main Memory
- Dirty Bit: 변경 블록 표시
## 구성도
```
Through: CPU ⇉ Cache
              ⇉ Main Memory
Back:    CPU → Cache (Dirty) … SwapOut → Main Memory
```
