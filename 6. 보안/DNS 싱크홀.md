#정보관리기술사 #보안 #DNS싱크홀 #Sinkhole #NEW
## 정의
DNS 싱크홀(Sinkhole)
- 악성봇에 감염된 PC가 C&C 서버에 접속하려 할 때, 해당 DNS 질의 응답을 싱크홀 서버로 우회시켜 해커의 제어 명령을 받지 못하게 하는 보안 시스템
## 키워드
* 블랙홀 라우팅, C&C 서버, 좀비 PC, 타겟시스템, 악성봇, KISA 싱크홀
## 암기법
* DNS우회: DNS 응답을 싱크홀로 우회 → C&C 차단
## 특징
- C&C 차단: 봇 명령 수신 경로 차단
- ISP DNS 활용: DNS 응답을 싱크홀 IP로 치환
- 감염 식별: 싱크홀로 유입된 호스트 파악 가능
- 선제 방어: 봇넷 조직화·추가 공격 억제
## 목적
- 감염 PC의 C&C 통신 차단
- 봇넷 기반 추가 공격(DDoS 등) 완화
- 감염 호스트 탐지·대응
## 구성요소
- 좀비 PC(악성봇 감염 시스템): C&C 도메인 DNS 질의
- ISP DNS 서버: 싱크홀 정보 반영, 악성 IP 대신 싱크홀 IP 응답
- 싱크홀 서버(예: KISA): 우회 접속 수신, 명령 전달 차단
- C&C 서버: 해커 제어 인프라(접속 차단 대상)
## 구성도
```
적용 전: [감염PC] → [ISP DNS] → 실제 C&C IP → [C&C] 명령 수신
적용 후: [감염PC] → [ISP DNS] → 싱크홀 IP → [싱크홀 서버]
                                              ✕ C&C 연결·명령 차단
```
