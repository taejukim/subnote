#정보관리기술사 #보안 #암호화 #키교환 #옵션 #정리

## 정의
이산대수 기반 비밀키 공유 프로토콜, Diffie-Hellman 키 교환
- 암호화되지 않은 통신망을 통해 두 사람이 공통의 비밀키를 안전하게 공유하도록 하는 키 교환 알고리즘
- 이산대수 문제의 어려움에 기반한 최초의 공개키 기반 키 교환 방식

## 키워드
* 이산대수, 공개키, 비밀키, 키 교환, 중간자 공격, g, p, 모듈러 연산

## 암기법
* 이공비중: (특징) 이산대수, 공개키 사용, 비밀키 공유, 중간자 공격 취약

## 특징
- 이산대수 기반: g^x mod p 계산은 쉬우나 역산은 어려움
- 공개키 사용: 공개된 채널로 키 교환 가능
- 비밀키 생성: 양측이 동일한 비밀키 도출
- 중간자 공격 취약: 인증 메커니즘 부재 시 취약

## 목적
- 안전하지 않은 채널에서 비밀키 공유
- 대칭키 암호화를 위한 세션 키 생성
- SSL/TLS 등 보안 프로토콜의 키 교환

## 구성요소

| **절차**                 | **생성키**                                                      | **설명**                                                                                                                                                              |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **① 사전 공개값 공유**        | • $p$ : **충분히 큰 소수 $p$**                                     | - 충분히 큰 소수 선택으로 키의 경우의 수를 증가시켜 보안성 향상                                                                                                                               |
|                        | • $g$ : 소수 $p$의 **원시근**(Primitive Root)                      | - 자기 자신의 거듭제곱을 이용하여 $1$부터 $p-1$까지의 정수를 모두 생성 가능한 수                                                                                                                  |
| **② 각자의 비공개 정수(키) 선정** | • $x$ : Alice의 **임의의 선택 정수** (비공개키)<br>• $R_1 = g^x \pmod p$ | - Alice와 Bob은 각자 임의의 정수를 선택하고 선택한 값과 1단계에서 사전 공유한 $p$와 $g$를 이용하여 연산                                                                                                 |
|                        | • $y$ : Bob의 **임의의 선택 정수** (비공개키)<br>• $R_2 = g^y \pmod p$   | - $R = g^{(\text{임의의 선택 정수})} \pmod p$<br>- $0 \le (\text{임의의 선택 정수}) \le p - 1$                                                                                    |
| **③ 공개키 공유**           | • **$R_1$과 $R_2$ 교환** (공개키)                                  | - Alice의 $R_1$과 Bob의 $R_2$를 상호 전송                                                                                                                                   |
| **④ 비공개 정수를 이용하여 재연산** | • Alice: $K_1 = (R_2)^x \pmod p$                             | - Alice와 Bob은 기존에 선택한 임의의 정수와 $R_1$, $R_2$를 이용하여 연산                                                                                                                 |
|                        | • Bob: $K_2 = (R_1)^y \pmod p$                               | - $K = (\text{상호 공유한 } R)^{(\text{임의의 선택 정수})} \pmod p$                                                                                                             |
| **⑤ 공통의 비밀키 공유**       | • $K_1 = K_2$                                                | - $(g^x \pmod p)^y \pmod p = (g^x)^y \pmod p$<br>- $(g^y \pmod p)^x \pmod p = (g^y)^x \pmod p$<br>- $\therefore (g^x)^y \pmod p = (g^y)^x \pmod p = g^{xy} \pmod p$ |
$$K = g^{xy} \pmod p$$


## 구성도
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260408234834.png|700]]
```
[사전 준비: g, p 공유]
         │
    ┌────┴────┐
    ▼         ▼
[Alice]     [Bob]
x 선택      y 선택
    │         │
    ▼         ▼
R1=g^x mod p  R2=g^y mod p
    │         │
    └────┬────┘
    (R1, R2 교환)
    ┌────┴────┐
    ▼         ▼
K=R2^x mod p  K=R1^y mod p
    │         │
    └────┬────┘
         ▼
   [동일 비밀키 K]
   K = g^(xy) mod p
```
