## 정의
다자간 계산(MPC, Multiparty Computation / Secure Multi-Party Computation)
- 여러 참여자가 각자 입력을 공개하지 않은 채, 합의된 함수의 결과만 공동으로 계산하는 암호 프로토콜
- 단일 주체가 원본 데이터를 보지 않도록 하여 협업 분석·공동 연산을 가능하게 하는 PEC(Privacy-Enhancing Computation) 기술
## 키워드
* MPC, Secret Sharing, 원본 비공개, PEC, Secure Computation, 연합분석
## 암기법
* "비공비결" - 비밀분산, 공개없이 계산, PEC 계열, 결과만 공유
## 특징
- 입력 기밀성: 각 당사자의 원본은 타 참여자·연산 중개자에게 노출되지 않음
- 비밀 분산(Secret Sharing): 값을 여러 Share로 쪼개 분산 보유, 임계치 미만으로는 복원 불가
- 결과만 공개: 합의된 출력(합·통계·모델 갱신 등)만 공개하거나 권한자에게 전달
- PEC 위치: 소프트웨어 Computation 영역(영지식증명·연합학습과 함께 분산화 처리)
## 목적
- 경쟁·규제 제약 하에서도 기관 간 데이터 협업·공동 분석 수행
- 중앙 집적 없이 프라이버시를 유지한 채 유용한 연산 결과 도출
## 구성요소
- 참여자(Parties): 입력 보유자·연산 노드, Honest/Semi-honest 등 위협 모델
- Secret Sharing / Garbled Circuit 등: 입력을 보호하며 게이트·연산을 수행
- 프로토콜: 덧셈·곱셈 등 기본 연산의 안전한 조합으로 목표 함수 구성
- 출력 정책: 누가 어떤 결과를 받을지, 중간값 노출 최소화

## 구성도
```
[Party A: x] ──Share──┐
[Party B: y] ──Share──┼──▶ Secure MPC Protocol ──▶ f(x,y) only
[Party C: z] ──Share──┘         (원본 x,y,z 비공개)

PEC 계열:
  데이터 변환     : 동형암호, 차분프라이버시, 재현데이터
  SW Computation  : MPC, ZKP, 연합학습
  HW 환경         : 기밀컴퓨팅
```
