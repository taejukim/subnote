#정보관리기술사 #보안 #IPSec #보안/인증/접근제어
## 정의
- IP계층의 취약점 보완 목적, IP 계층 기반으로한 보안 프로토콜들 제공하는 개방 구조의 프로토콜 모음

## 키워드
- IP 계층봉안, AH, ESP, SAD, SPD, IKE, SA, 전송모드, 터널모드

## IPSec 구조와 구성요소
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260410001338.png|500]]

| 분류     | 구성 요소                                                 | 설명                                                                                                |
| ------ | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 프로토콜   | - 인증 프로토콜 (**AH**)                                    | - Authentication Header: 인증 프로토콜  <br>- 데이터 무결성, 인증, Replay 공격 방지                                 |
|        | - 암호화 프로토콜 (**ESP**, Encapsulation Security Protocol) | - 보안 페이로드 캡슐화  <br>- 패킷 암호화 프로토콜, IETF 표2준  <br>- Packet에 대한 기밀성, 무결성, 인증: 별도 제공 가능 - 암호화 기능 제공   |
| 데이터베이스 | - 보안 연계데이터베이스 (**SAD**)                               | - 특정 연결에 대해 정의되는 SA 데이터베이스  <br>- SA는 SAD 안에 하나의 엔트리(Entry)로 저장 (IP Address, IPSec 프로토콜, SPI로 구분) |
|        | - 보안 정책데이터베이스 (**SPD**)                               | - 특정 관리자에 의해 정의되는 보안정책에 관한 데이터 베이스  <br>- 해당 트래픽을 버릴지 IPSec을 통과할지 결정                              |
| 키 교환   | - **IKE** (Internet Key Exchange Protocol)            | - 키 관리 서비스: 키 생성과 분배 담당  <br>- IPSec을 위해 2쌍의 키 필요(AH와 ESP를 위해 한방향 당 2개)                           |
| 보안 연계  | - **SA** (Security Association)                       | - 데이터를 시스템간 교환 전에 암호 알고리즘, 키 교환 방법/주기 등 교환 전 통일되어야 할 요소                                           |
## IPSec 전송 모드
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260410001354.png|500]]

|분류|지원(보호) 구간|대상(주요 사용)|설명|
|---|---|---|---|
|**전송 모드** (Transport Mode)|- **IP 페이로드**(Payload)만 보호(원본 IP 헤더는 보호 X)|- **종단 호스트** (Host-to-Host)(예: PC ↔ PC, PC ↔ 서버)|- 원본 IP 헤더를 그대로 사용하여 라우팅  <br>- 종단 장치(PC, 서버 등)가 직접 IPSec을 처리|
|**터널 모드** (Tunnel Mode)|- **원본 IP 패킷 전체**를 보호(원본 IP 헤더 + 페이로드)|- **게이트웨이** (Gateway-to-Gateway)(예: 본사 방화벽 ↔ 지사 방화벽)|- 새로운 IP 헤더를 생성하여 덧붙이고, 이 새 헤더를 기반으로 라우팅  <br>- 주로 VPN(가상 사설망)을 구성할 때 사용되며, 게이트웨이(라우터, 방화벽) 간의 보안 통신을 담당|
