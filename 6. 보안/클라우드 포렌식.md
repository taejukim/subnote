#정보관리기술사 #보안 #클라우드포렌식 #CloudForensic #NEW
## 정의
클라우드 포렌식(Cloud Forensic)
- 클라우드에 존재하는 전자적 증거물을 사법기관에 제출하기 위해 클라우드 시그니처 데이터를 수집·분석·보고하는 과학수사 기법
## 키워드
* 가상화, 정보제공의무, 클라우드 시그니처, 사법관할권, 국제공조
## 암기법
* 대협증분: 대상확인·협조요구·증거수집·분석
## 특징
- 가상화성: SaaS·PaaS·IaaS 분산 환경의 증거
- 관할권 이슈: CSP 물리적 위치·국제공조 필요
- 시그니처 중심: 클라이언트 측 클라우드 사용 흔적 분석
- 법적 제약: 통신비밀보호법 등 압수·수색 권한 준수
## 목적
- 클라우드 전자증거의 적법 수집·분석
- 사법기관 제출용 포렌식 보고서 작성
## 구성요소
- 절차: 대상 클라우드 식별 → 로그인 정보 확인 → 관할권 확인 → (국제공조/임의제출) → 계정 접근 차단 → 압수권한 확보 → 데이터 수집 → 시그니처 분석
- 대상 확인: SaaS(Google Drive·Dropbox), PaaS(Salesforce·Heroku), IaaS(AWS·Azure·GCP·NCP)
- 증거 확보: 웹브라우저·레지스트리 포렌식, 서비스 로그 분석
- 협조 요구: CSP 위치 확인, 국제형사사법공조, 사용자 동의 기반 임의제출
- 증거 수집: 계정 로그인 잠금·IP 통제, 분산 인덱싱·파일 카빙·스테가노그래피
- 증거 분석: 클라이언트 측 클라우드 시그니처(사용 기록) 분석
## 구성도
```
[대상 식별] → [로그인 확인] → [관할권?]
                    ├─No→ 국제공조 (거부 시 상세분석 불가)
                    └─Yes→ 임의제출
                              ↓
              계정차단 → 압수권한 → 데이터수집 → 시그니처 분석
```
