#정보관리기술사 #보안 #사이버게놈 #CyberGenome #프로파일링 #NEW
## 정의
사이버 게놈(Cyber genome)
- 악성코드 샘플에서 유사점·불변 고유 특성을 추출하여 DB화하는 기법
- 해커의 과거 행동을 분석하고 향후 공격을 추론하여 사전에 차단
## 키워드
* Artifact-Centric, Case-Centric, Human-Centric, API Sequence, 서열 정렬, 유사도 분석
## 암기법
* ACH: Artifact·Case·Human 센트릭
## 특징
- 고유성: 변하지 않는 악성코드 특성 인자 추출
- 삼원 분석: 아티팩트·케이스·휴먼 상호 연계
- 예측성: 과거 행동 기반 향후 공격 추론
- 프로파일링: 캠페인·해커 성향 DB화
## 목적
- 악성코드·공격자 고유 특성의 DB 구축
- 유사 공격의 사전 탐지·차단
## 구성요소
- 아티팩트 센트릭: 악성코드·IP/URL·도메인·이메일·컴파일러·코드조각 / RE·샌드박스·시그니처·IoC
- 케이스 센트릭: 공격 이벤트·TTPs·동기·목적 / 5W1H·범죄 프로파일링·ATT&CK 매핑·시나리오 재구성
- 휴먼 센트릭: 해커 정보·SNS·언어·성향·관심사 / OSINT·온톨로지·SNA·NLP
- 연계 정보: 해커 ID·이메일·IP, 지역·성격·관심사 프로파일
- 휴먼 프로세스: 해킹·정보수집 → 필터링·DM·ML → 대응책 구축
## 구성도
```
        [Artifact]
       ↗    ↕    ↖
  ID/IP/Email   사건IP/Email
     ↗              ↖
[Human] ←지역·성향·관심→ [Case]
         (TTPs·캠페인)
```
