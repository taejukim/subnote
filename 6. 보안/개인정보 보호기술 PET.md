#정보관리기술사 #보안 #개인정보 #PET #프라이버시 #정리 #보안/개인정보/정책

## 정의
프라이버시 강화 기술, PET(Privacy Enhancing Technology)
- 개인정보의 수집, 저장, 처리, 공유 과정에서 프라이버시를 보호하기 위한 기술적 수단의 총칭
- 데이터 활용과 개인정보 보호를 동시에 달성하는 기술

## 키워드
* 동형암호, 차분 프라이버시, 연합학습, 영지식 증명, 가명화, 익명화
[[개인정보 보호기술 PET]]
## 암기법
* 동차연영가익: (PET 기술) 동형암호, 차분 프라이버시, 연합학습, 영지식 증명, 가명화, 익명화

정책 협상기술 P3P(W3C 제정 개인정보보호 정책 표준규격)
암호 기술 DES/RSA/ECC, SSL/VPN
필터링 기술 방화벽/IDS/IPS/NAC, 안티바이러스/캡쳐방지, 피싱 모니터링
익명화 기술 Mix-net(클라이언스 서버 익명성 제공), ISO25237, ISO20889
인증 기술 PKI, i-PIN, SSO, Open ID


## 특징
- 데이터 활용: 프라이버시 보호하면서 데이터 분석 가능
- 기술적 보호: 법적 보호를 기술로 구현
- 다양한 기법: 암호화, 익명화, 분산 처리 등
- 규제 대응: GDPR, 개인정보보호법 준수 지원

## 목적
- 개인정보 보호와 데이터 활용의 균형
- 프라이버시 침해 위험 최소화
- 법적 규제 준수 지원

## 개인정보 보호기술 종류
| **보호기술**                 | **설명**                                                                                                                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **정책협상기술**               | - W3C에서 개발한 개인정보보호 표준 기술 플랫폼으로 웹 사이트에서 이루어지는 데이터 처리에 관한 표준 제시<br>- 목표는 웹 사이트 운영자에게 이용자 자신의 정보를 관리할 수 있는 권한을 넘겨 주는 것이며, 이용자 정보가 잘못된 방법으로 사용되지 않도록 보호하기 위해 만들어 짐.                        |
| **프라이버시 정책 생성**          | - 정보보호 생성 소프트웨어가 요구하는 절차에 따라 실제 운영중인 개인인 정보보호 방침을 입력하면, 해당 기업이나 조직의 개인정보 보호방침 문구를 HTML 문서로 자동 작성하 출력하는 기능을 갖고 있음.                                                                      |
| **Cookie 관리 (통제 및 필터링)** | - 이용자로 하여금 언제 쿠키가 자신의 컴퓨터에 저장되는지를 결정하게 함으로써 쿠키의 수용 여부를 결정하고 관리하도록 하며, 개별적인 쿠키에 저장된 정보가 무엇인지를 판단할 수 있는 방법<br>- 개인에게 자신의 컴퓨터에 저장된 쿠키에 대해 통제권을 제공                                         |
| **암호화 S/W**              | - 암호화를 통해 자신의 전자메일, 메시지, 저장된 파일, 온라인에서 커뮤니케이션을 보호할 수 있게 하는 기능을 제공.<br>- 암호화 되면 당사자만 디지털 키를 사용하여 암호화된 정보 열람 가능<br>- 디지털 키는 브라우저, 생체인증, 스마트카드 등과 결합하여 생성                                 |
| **익명화 (anonymizers) 기술** | - 웹 사이트가 방문객의 IP주소를 식별하거나 쿠키를 개인 컴퓨터에 저장하는 것을 막아 줌으로써, 소비자가 웹 브라우징 하거나 보내는 이가 누구인지 알 수 없도록 익명화된 메일을 보낼 때 유용.<br>- 반대로 개인화된 서비스나 온라인 계정관리, 과거의 구매기록 보관 또는 열람 등에 대한 특정한 기능을 사용 할 수 없게 함. |
|                          |                                                                                                                                                                                        |

## 개인정보보호 기술적 통제 방안
|**분류**|**통제그룹**|**통제요소**|**설명**|
|---|---|---|---|
|**필터링 기술**|네트워크 필터링|방화벽, IDS/IPS, TMS|- 외부/내부 네트워크 사이의 접근제어, 침해행위 탐지/방어, 위협 사전 감지 및 조기 경보|
||개인정보 노출차단|ILP, 개인정보스캐너|- Information Leakage Prevention(e-mail, SMS 등), 웹사이트 내 개인정보 노출 검색|
||개인정보 침해차단|애드 브로커, 스파이웨어 필터, 스팸 방지|- 무분별한 광고 차단, 스파이웨어 실행차단, 베이시안 필터/Black list 기반 차단|
||개인정보 은닉|리메일러, 경로 제거기, 익명화|- 익명 메시지 전송, 서비스 이용정보 노출 방지, IP주소 은닉, Proxy/Mix-net 등 활용|
|**개인정보 통신**|개인정보 암호화|VPN, 보안서버|- 암호화 터널링 통한 가상 사설 망 기술, HTTPS 기반 웹 서버 통신|
||개인정보 인증|i-PIN, PKI, OpenID|- 주민번호 대체 인증, 공개/비밀 키 이용 인증(기밀성/무결성), 개방/분산형 인증 시스템|
|**개인정보 저장**|DB암호화|DB암호화 솔루션|- DB에 저장된 데이터의 암호화 저장|
||OS 보안|Secure OS|- 기존 OS의 취약성 보강을 위한 강한 인증 및 접근제어 제공 운영체제|
|**개인정보 정책**|XML기반|P3P (Platform for Privacy Preferences Project)|- W3C 제정 표준, 이용자가 방문하는 웹 사이트에서 자신의 개인정보 제어 가능|
