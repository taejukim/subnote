## 딥보이스(Deep Voice) 피싱 공격 절차

| 구분   | 단계         | 설명                                                               |
| ---- | ---------- | ---------------------------------------------------------------- |
| 사전준비 | ① 음성수집     | - 대상자의 음성 데이터를 SNS, 영상, 통화 등에서 수집 <br> - 통화 녹음, 유튜브, SNS 등 도구 활용 |
| 음성합성 | ② 음성합성     | - 수집한 음성을 기반으로 딥러닝으로 음성 복제 <br> - 딥페이크, Voice Cloning AI         |
| 음성합성 | ③ 공격 시나리오  | - 긴급 상황 위장 등 신뢰 유도용 대화 내용 준비 <br> - 사회공학, 사칭 대본                  |
| 공격수행 | ④ 전화사기 실행  | - 합성 음성으로 피해자에게 직접 전화 시도 <br> - 실시간 음성 합성, 발신번호 조작               |
| 공격수행 | ⑤ 금전/정보 탈취 | - 피해자로부터 송금, 인증번호, 개인정보 요구 <br> - 계좌 정보, OTP, 인증 문자              |
## 딥보이스(Deep Voice) 피싱의 음성 추출 및 합성 기법

| 단계 | 기법 | 주요 기술 | 설명 |
|------|------|-----------|------|
| 샘플 추출 단계 | 음성 클로닝 (Speaker Embedding) | - x-vector, d-vector | - 짧은 음성 샘플(단 몇 초)만으로 개인의 고유한 목소리 특징(음색, 억양 등)을 추출하여 음성 지문(Embedding)으로 생성 |
| 재현 단계 | 텍스트-음성 합성 (Neural TTS) | - WaveNet, HiFi-GAN, VALL-E 등 | - 공격자가 원하는 텍스트(대본)를 입력하면, 추출한 음성 지문을 입혀 해당 인물의 목소리로 말하는 음성을 생성 |
| 재현 단계 | 음성 변환 (Voice Conversion) | - Autoencoder, GAN 계열, 스펙트로그램 변환 | - 공격자가 자신의 목소리로 먼저 녹음한 뒤, 추출한 음성 지문을 사용해 목소리만 대상의 것으로 변경 |
