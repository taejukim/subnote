#정보관리기술사 #보안 #드라이브바이다운로드 #보안/공격/위협
Drive by Download
## 정의
- 직접 파일 다운로드 하거나 실행하지 않아도 웹사이트 접속하는 것만으로 악성 코드가 자동으로 다운로드 및 실행되는 공격 기법

## 키워드
* Landing Site, Exploit Server, Malware Server, Dropper, API 오용, 브라우저 취약점

## 드라이브 바이 다운로드 공격 절차
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260409002518.png|500]]

| 단계  | 공격과정                                                    | 기법                      |
| --- | ------------------------------------------------------- | ----------------------- |
| 1   | - 사용자가 방문하는 사이트의 Banner, 게시판에 URL Redirection 가능한 코드 삽입 | - iFrame Injection, XSS |
| 2   | - 공격자가 공격 코드를 삽입한 웹 페이지 방문                              | - 피싱, 파밍                |
| 3   | - 공격자가 사전에 개설된 웹 페이지로 이동                                | - URL Redirection       |
| 4   | - 악성코드 유포 사이트로 이동                                       | - URL Redirection       |
| 5   | - 악성코드 다운로드 및 악성 행위 수행                                  | - 드로퍼(Dropper), 키로깅     |
