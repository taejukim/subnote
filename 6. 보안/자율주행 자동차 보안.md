#정보관리기술사 #보안 #자율주행 #스마트카 #V2X #NEW
## 정의
자율주행 자동차 보안취약점 및 대응방안
- 자율주행 차량·통신채널·백엔드 인프라의 보안 위협을 식별하고 구간별 대응 기술을 적용하는 체계
## 키워드
* 펌웨어변조, CAN위변조, 원격해킹, DoS, Secure Boot, EDR, SecOC, V2V/V2I
## 암기법
* 계취위대: 계획·현황분석·취약점점검·위험도검토·대책수립
## 특징
- 삼영역: 차량·통신채널·백엔드 인프라
- 물리연계: 사이버 공격이 차량 제어·인명 위험으로 전이
- V2X 확장: V2V·V2I·V2R·I2I 등 다구간 통신 위협
- 점검체계: 계획→분석→점검→위험검토→대책 절차화
## 목적
- 자율주행 환경의 구간별 보안 위협 식별
- Secure Boot·SecOC·EDR 등 대응 기술로 안전성 확보
## 구성요소
- 위협 - 차량: 펌웨어 변조, 원격제어 해킹, CAN 위변조, 불법 조작, DoS
- 위협 - 통신채널(V2V·V2I·V2R·I2I): 도청, 메시지 위변조, 무단획득, 거짓정보, 부인
- 위협 - 백엔드: 정보유출, 권한상승, DoS
- 대응 - 차량: HPSE(HSM), Secure Boot/Debug/Diagnosis/Flash, SW Update, Secure Access, IDS, SecOC
- 대응 - 통신: IPsec, TLS/DTLS, WAVE 통신 보안
- 대응 - 백엔드: Firewall(WAF·UTM·NGFW), DB 암호화, Access Control, EDR
- 점검절차: 계획 → 현황분석 → 취약점점검 → 위험도검토 → 대책수립
## 구성도
```
[차량] ──V2V/V2I/V2R──▶ [통신채널] ──▶ [백엔드 인프라]
 펌웨어·CAN·원격해킹      도청·위변조·부인      유출·권한상승·DoS
 Secure Boot·SecOC·IDS    IPsec·TLS·WAVE       WAF·EDR·접근통제
```
