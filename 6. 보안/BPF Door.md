#정보관리기술사 #보안 #BPFDoor #백도어 #NEW
## 정의
BPF(Berkeley Packet Filter) Door
- 리눅스 커널 BPF를 악용해 네트워크 패킷을 감시하며 외부 명령을 수신·실행하는 리눅스 기반 백도어형 공격 기법
## 키워드
* 리눅스 커널, BPF, BPF Filter, 매직 패킷, 백도어, Reverse Shell, iptables
## 암기법
* 잠필매방백원: 잠입설치·필터로드·매직감시·방화벽우회·백도어활성·원격제어
## 특징
- 포트리스: 별도 포트 개방 없이 매직 패킷으로 활성화
- 커널 수준: iptables 도달 전 패킷 열람으로 방화벽 우회
- 프로세스 위장: 정상 리눅스 데몬으로 위장 설치
- 루트 제어: Reverse/Bind Shell로 시스템 완전 장악
## 목적
- 감염 서버에 은밀한 원격 백도어 유지
- 방화벽·포트 기반 탐지를 우회한 C2 통신
## 구성요소
- 잠입·설치: 프로세스 위장으로 BPFDoor 악성코드 설치
- BPF 필터 로드: 커널에 커스텀 패킷 스니퍼 등록
- 매직 패킷 감시: 특정 시그니처 패킷 스캔
- 방화벽 우회: 커널 레벨 패킷 열람
- 백도어 활성화: iptables 임시 조작 → Reverse/Bind Shell
- 원격 제어: 루트 권한으로 시스템 장악
- 대응 - 관리: 최소권한·접근통제, 정기 점검·침투 테스트
- 대응 - 기술: IoC 기반 EDR/NIDS/SIEM, 비정상 트래픽 탐지
## 구성도
```
[위협행위자] --Magic Packet--> [감염 서버]
       ↑                         |
       └──── Reverse Connection ─┘
       ↕ Commands (Root Shell)
```
