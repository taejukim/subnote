#정보관리기술사 #보안 #SW난독화 #역공학방지 #NEW
## 정의
SW난독화(Software Obfuscation)
- 소스코드나 바이너리를 의도적으로 변형하여 사람이 쉽게 이해하지 못하게 함으로써 SW를 보호하는 기술
- 난독화 전·후 실행 결과는 동일해야 함
## 키워드
* 구획, 데이터, 집합, 제어, 예방, 심볼제거, 코드암호화, 제어흐름변환, 자료난독화
## 암기법
* 구데집제예: 구획·데이터·집합·제어·예방
## 특징
- 의미 보존: 동작 동일, 가독성·역공학 난이도만 상승
- 다기법 조합: 특성에 맞는 기법 추천·적용
- 레이아웃~예방: 포맷 변경부터 디옵fuscation 차단까지
- 보호 목적: 무단복제·크랙·취약점 노출 억제
## 목적
- 리버스 엔지니어링 방지
- SW 무단 복제·크랙 방지
- 보안 강화 및 취약점 보호
- 저작권·라이선스 보호
## 구성요소
- 절차: 소스 분석 → 특성별 기법 추천 → 난독화 수행 → 난독화 코드
- 주요 기술: 심볼 정보 제거, 코드 암호화, 제어 흐름 변환, 자료 난독화
- 구획: 포맷 변경, 주석 제거, 식별자 변형
- 데이터: 변수 분할, 정적 데이터 절차화
- 집합: 순서 변환, 병합·평탄화, 클래스 분할
- 제어: Aggregation·Ordering·Computation
- 예방: Targeted·Inherent (알려진 디옵fuscation 차단)
## 구성도
```
[소스분석] → [기법추천: 구획·데이터·제어·예방]
                    ↓
            [난독화 수행] → [난독화 소스]
         (실행결과 전=후 유지)
```
