#정보관리기술사 #보안 #전자봉투 #보안/암호화
Digital Evelope
## 정의
- 대칭키, 비대칭키의 장점 이용, 컨텐츠는 비밀키, 비밀키는 공개키로 암호화하여 전송하는 시스템

## 키워드
- 기밀성, 공개키, 개인키, 비밀키, 해시 함수, 메시지 다이제스트
- Message → 비밀키 암호화, 비밀키 → 공개키 암호

## 디지털 봉투 송신절차
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260410220742.png|600]]

| 절차                         | 설명                                                     |
| -------------------------- | ------------------------------------------------------ |
| 1. Message Digest 생성       | - 메시지를 해시함수로 축약하여 Message Digest 생성                    |
| 2. 전자서명 생성                 | - 송신자의 개인키(Private Key)로 Message Digest를 암호화하여 전자서명 생성 |
| 3. 비밀키(Secret Key)로 암호문 생성 | - 비밀키(대칭키)로 전자서명 + 메시지 + 송신자의 공개키가 포함된 인증서를 암호화        |
| 4. 전자봉투 생성                 | - 수신자의 공개키(Public Key)로 비밀키를 암호화 → 전자봉투 생성             |
| 5. 암호문 + 전자봉투 전송           | - 암호문과 전자봉투를 수신자에게 전송                                  |

## 디지털 봉투 수신절차
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260410220755.png|600]]

|절차|설명|
|---|---|
|1. 전자봉투 복호화|- 수신자의 개인키로 전자봉투 복호화 → 비밀키(대칭키) 획득|
|2. 암호문 복호화|- 비밀키로 암호문 복호화 → 메시지, 전자서명, 인증서 획득|
|3. 전자서명 복호화|- 송신자의 공개키로 전자서명 복호화 → Message Digest 획득|
|4. 무결성 검증|- 메시지를 해시한 값과 Message Digest 비교 → 무결성 확인|
