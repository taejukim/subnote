#정보관리기술사 #보안 #XDR #보안/보안관제
Extended Detection Response
## 정의
- [[EDR]] 솔루션을 확장하여 단일 플랫폼에 네트워크, 애플리케이션 등 다양한 보안 데이터를 통합분석하여 고수준 위협 탐지, 보안 사고를 분석 및 대응하느 보안 솔루션
## 키워드
- EDR, SIEM, SOAR, End Point, 위협 탐지, 위협 대응, 보안 데이터 통합 분석

|---|---|---|---|
|**보안 데이터 수집**|- 네트워크, 엔드포인트, 애플리케이션 등|- 네트워크, 엔드포인트, 애플리케이션 등|- 네트워크, 엔드포인트, 애플리케이션 등|
|**보안 데이터 분석**|- 위협 탐지|- 위협 탐지 및 대응|- 위협 탐지 및 대응|
|**위협 탐지**|- 위협 이벤트 기반|- 위협 이벤트 기반|- 위협 이벤트 기반, 시계열 분석, AI/ML|

|**단점**|- 위협 탐지에만 집중|- 보안 데이터 수집 및 분석에 의존|- 도입 비용 고가|
## XDR 동작 절차
| **Working Flow** | **주요 기술**                                                                                           | **측정 지표**                                                             | **설명**                                               |
| ---------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ---------------------------------------------------- |
| **데이터 수집**       | - EDR 에이전트 - API 통합 및 클라우드 커넥터                                                                      | - 데이터 커버리지(Data Coverage) - 수집 지연 시간(Data Latency)                    | - 에이전트와 API를 통해 엔드포인트, 클라우드, 네트워크 등 여러 소스로부터 데이터를 수집 |
| **중앙 집중식 저장소**   | - SIEM 통합 - 데이터 정규화 및 상관분석 엔진                                                                       | - 로그 상관 정확도(Correlation Accuracy) - 데이터 처리량(Throughput)               | - 로그와 이벤트를 상관 분석하여 분석 및 저장을 위한 통합 데이터베이스로 통합         |
| **위협 인텔리전스**     | - Threat Feed 통합 - IOC(Indicators of Compromise) 매칭 엔진                                              | - 위협 탐지 커버리지(Threat Detection Coverage) - 인텔리전스 신뢰도(Feed Reliability) | - 외부 피드와 내부 분석을 통해 실시간 인사이트로 데이터를 보강                 |
| **머신러닝 및 인공지능**  | - 이상 탐지(Anomaly Detection) - 행위 기반 분석(Behavioral Analytics, UEBA)                                   | - 탐지 정확도(Detection Accuracy) - 오탐률(False Positive Rate)               | - 이전 사고로부터 학습하며, 데이터에서 이상 징후와 패턴을 분석해 탐지             |
| **대응 도구**        | - SOAR(Security Orchestration, Automation and Response) - Endpoint Isolation / Network Segmentation | - MTTD (Mean Time To Detect) - MTTR (Mean Time To Respond)            | - 엔드포인트 격리나 방화벽 차단 등의 자동화된 조치를 수행하며, 수동 대응 옵션도 제공    |
