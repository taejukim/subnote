#정보관리기술사 #보안 #웹쉘 #바인드웹쉘
## 정의
바인드 웹쉘(Bind Web Shell)
- 해커가 웹브라우저를 통해 서버에 직접 명령을 내릴 수 있는 업로드된 서버 스크립트
- 공격자가 서버에 능동적으로 접속해 명령·데이터를 송수신하는 인바운드 형태의 웹쉘
## 키워드
* Web Shell, Inbound, 업로드 취약점, RCE, WAF 차단, 정보 탈취
## 암기법
* 업명결: 업로드·명령전송·결과반환
## 특징
- 인바운드형: 공격자 → 서버 직접 접속
- GUI 운용성: 웹 기반 콘솔로 지속 제어
- 방화벽 차단 가능성: 인바운드 정책으로 차단 용이
- 직접 제어성: 파일·DB·시스템 명령 즉시 수행
## 목적
- 웹 서버 원격 제어와 지속 접근
- 정보 탈취·DB 접근·내부 서버 공격 발판 확보
## 구성요소
- 동작: 공격자 → 서버(스크립트 실행)
- 절차: 공격자가 서버에 업로드 → 명령 전송 → 결과 반환
- 리스너 위치: 호스트 서버, 해커가 웹쉘로 접속
- 방화벽 우회: 불가
- NIC 역할: 관련 없음
- 해커 선호: GUI 형태, 지속 제어 용이
- 차단 방법: 방화벽·웹방화벽 차단
- 리버스 웹쉘 비교: 인바운드(바인드) vs 아웃바운드(리버스), 방화벽 우회 가능 여부 차이
## 구성도
```
[공격자] ─── 인바운드 접속 ───→ [웹 서버: 업로드된 웹쉘 스크립트]
                                       ↓
                                명령 실행 → 결과 반환
                          ↑ 방화벽(인바운드) 차단 가능
```
