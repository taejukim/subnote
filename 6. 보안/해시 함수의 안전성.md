## 해시 함수의 정의
- 가변길이의 Data를 입력으로 받아 고정길이의 Message Digest를 출력으로 하는 단방향 암호 알고리즘

## 키워드
- 역상 저항성, 제2 역상저항성, 충돌 정상성, 제1역상 저항 공격, 제2 역상 저항 공격

| **성질(속성)**   | **특징**    | **개념도**                                   | **설명**                                                                                                                                           |     |
| ------------ | --------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | --- |
| **역상 저항성**   | 일방향 함수    | ![[Pasted image 20260408233312.png\|300]] | - 임의의 출력에 대한 입력값을 구하는 것이 계산상 불가능<br>- 주어진 $Y$ 값에 대해 $H(X) = Y$를 만족하는 $X$ 값을 찾는 것이 힘든 특성<br>- **제1역상저항공격 대상**                                     |     |

## 역상 공격

| **성질(속성)**   | **특징**                                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **제 1역상 공격** | - 해시 값이 주어졌을 때, **그 해시 값을 출력하는 입력값**을 찾는 공격<br>- 예) 5가 주어졌을 때, 5를 출력하는 임의의 입력값을 찾는 공격                                   |
| **제 2역상 공격** | - 입력 값이 주어졌을 때, 그 입력과 **같은 해시값을 출력하는 다른 입력값**을 찾는 공격<br>- 예) 12가 주어졌고 그 해시값이 5일 때, 동일한 5를 출력하는 12가 아닌 다른 임의의 입력값을 찾는 공격 |

## 해시함수 개념도
