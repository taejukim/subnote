## 생체 정보 정의
1. 개인의 신체적, 생리적, 행동적 특징에 관한 정보로서
2. 특정 개인을 인증, 식별하거나
3. 개인에 관한 특징(연력, 성별, 감정 등)을 알아보기 위해
4. 일정한 기술적 수단을 통해 처리되는 정보

## 키워드
- 특정 개인, 신체적, 생리적, 행동적 특징, 원본 정보, 특징정보, 적법성, 비례성, 목적 제한, 투명성, 통제권 보장, 안정성
- 5단계(기획, 설계 → 수집 → 이용, 제공 → 보관, 파기 단계 → 기획, 설계 단계 → 상시 점검)

## 개인정보, 생체정보, 생체인식정보 간의 관계

- 개인정보 : 그 자체만으로 특정개인을 알아볼 수 있거나 다른 정보와 쉽게 결함하여 알아볼 수 있는 정보
- 원본정보 : 생체인식정보 중 입력장치 등을 통해 수집, 입력된 특징 정보 생성에 이용되는 정보
- 특징정보 : 원본정보로부터 특징점을 추출하는 등의 일정한 기술적 수단을 통해 생성되는 정보
## 생체 인식 정보 보호 6대 원칙
| 6대 원칙 | 설명                                            |     |
| ----- | --------------------------------------------- | --- |
| 비례성   | - 생체인식정보 처리에 따른 편익 대비 개인정보 침해 위험이 과도하지 않은지 고려 |     |
| 적법성   | - 생체인식정보 수집·이용·제공 등 처리의 근거는 적법하고 명확해야 함       |     |
| 목적제한  | - 정보주체 동의를 받은 인증·식별 목적 외 다른 용도로 활용 금지         |     |
| 투명성   | - 생체인식정보 보호 관련 사항을 정보주체에게 알기 쉽게 공개            |     |
| 안전성   | - 분실, 도난, 유출, 위조·변조, 훼손 방지를 위한 안전한 처리 필요      |     |
| 통제권보장 | - 정보주체가 자신의 생체인식정보를 직접 통제할 수 있는 수단 제공         |     |
- **비례성** 👉 과도한 수집 금지
- **적법성** 👉 법적 근거 필요
- **목적제한** 👉 목적 외 사용 금지
- **투명성** 👉 공개 및 고지
- **안전성** 👉 보호 조치 필수
- **통제권보장** 👉 사용자 권리 보장
