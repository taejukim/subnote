#정보관리기술사 #보안 #개인정보 #가명화 #익명화 #정리 #보안/개인정보/정책

## 정의
개인정보 비식별 처리 기술, 가명화/익명화
- 가명화: 추가 정보 없이는 특정 개인을 알아볼 수 없도록 처리하는 것 (재식별 가능)
- 익명화: 더 이상 개인을 알아볼 수 없도록 처리하는 것 (재식별 불가능)

- 개인 정보의 일부를 삭제하거나 전부를 대체하는 등의 방법으로 추가 정보가 없이는 특정 개인을 알아 볼 수 없도록 처리 하는 기술(개인정보보호법 제2조 1의 2)
- 직접식별자(고유식별자), 간접식별자(준식별자), 속성정보, 특이정보(민감정보), 삭제(삭제, 마스킹), 통계(총계), 일반화(랭덤/제어/일반 라운딩, 범주화), 암호화(동형, 순서보존, 형태보조으 다형성), 무작위화(잡음, 치환, 토큰화), 기타(차분 프라이버시, 샘플링), ISO/IEC 20889
## 키워드
* 가명처리, 익명처리, k-익명성, l-다양성, t-근접성, 재식별, 적정성 평가

## 가명 처리 기법

|구분|항목|
|---|---|
|**삭제기술**|- 삭제, 마스킹|
|**통계도구**|- 총계처리, 부분 총계|
|**일반화**|- 일반 라운딩, 랜덤 라운딩(Random rounding), 제어 라운딩(Controlled rounding), 상하단코딩(Top and bottom coding), 로컬 일반화, 범위 방법(Data range), **문자 데이터 범주화**|
|**암호화**|- 양방향 암호화, 암호학적 해쉬함수, 순서보존 암호화, 형태보존 암호화, 동형암호화, 다형성 암호화|
|**무작위화 기술**|- 잡음 추가, 치환, 토큰화, (의사)난수생성기((P)RNG, (Pseudo) Random Number Generator)|
|기타 기술|- 표본추출(Sampling), 해부화(Anatomization), 재현데이터(Synthetic data), 동형비밀분산(Homomorphic secret sharing), 차분 프라이버시(Differential privacy)|

> **가명정보**: 개인정보를 가명처리함으로써 원래의 상태로 복원하기 위한 추가 정보의 사용·결합 없이는 **특정 개인을 알아볼 수 없는 정보**(개인정보보호법 제2조1)

## 가명 처리 대상

|대상|설명|
|---|---|
|**직접식별자(고유식별자)**|- 해당 정보주체에게만 고유하게 부여되어 있는 정보로써 그 자체만으로 개인식별성이 강한 정보|
|**간접식별자(준식별자)**|- 정보주체에게만 고유하게 부여된 정보는 아니지만 보편적으로 널리 이용되고 있는 정보  <br>- 다른 정보와 결합하면 특정 개인을 식별하기 쉬운 정보|
|**속성정보**|- 해당 개인정보처리자만 보유하고 있어 개인정보처리자 이외의 자는 다른 정보와 결합해도 특정 개인을 식별하기 어려운 정보|
|**특이정보(민감정보)**|- 해당 정보주체에게 고유하게 부여된 정보는 아니지만 해당 정보주체에 대해서만 해당되는 정보여서 누구든지 쉽게 식별이 가능한 정보|

> **개인식별정보(PII) = 직접 식별자 + 간접 식별자**

## 암기법
* k l t: (익명화 모델) k-익명성, l-다양성, t-근접성
* 가삭범총마: (가명처리 기법) 가명처리, 삭제, 범주화, 총계처리, 마스킹

## 특징
- 가명화: 추가 정보와 결합 시 재식별 가능, 개인정보로 취급
- 익명화: 재식별 불가능, 개인정보 아님
- 법적 차이: 가명정보는 제한적 활용, 익명정보는 자유 활용
- 적정성 평가: 비식별 수준 검증 필요

## 목적
- 개인정보 보호와 데이터 활용의 균형
- 빅데이터 분석, AI 학습 데이터 확보
- 법적 규제 준수 (개인정보보호법, GDPR)

## 구성요소
| 구분 | 기법 | 설명 |
|------|------|------|
| 가명처리 | 가명처리 | 식별자를 다른 값으로 대체 |
| 가명처리 | 마스킹 | 일부 값을 *로 대체 |
| 가명처리 | 범주화 | 값을 범위로 대체 (25세→20대) |
| 가명처리 | 총계처리 | 개별 값을 합계/평균으로 대체 |
| 가명처리 | 삭제 | 식별 가능 정보 삭제 |
| 익명화 모델 | k-익명성 | k명 이상 동일 속성 보장 |
| 익명화 모델 | l-다양성 | 민감 속성 l개 이상 다양성 |
| 익명화 모델 | t-근접성 | 민감 속성 분포 유사성 |
