#정보관리기술사 #보안 #기밀컴퓨팅 #보안/개인정보/정책
Confidential Computing
## 정의
- 사용중인 데이터 보호와 개인 정보 보안에 중점을 둔 컴퓨팅 환경을 제공하는 기술적 접근 방식의 컴퓨팅
## 키워드
- 신뢰 실행 환경(TEE(Trusted Execution Environment)), 실행증명(Attestation), 주변장치(Peripheral), 시스템 소프트 웨어, 응용

## 기밀컴퓨팅 구성요소
|**구성요소**|**핵심기술**|
|---|---|
|**신뢰 실행 환경 (TEE(Trusted Execution Environment))**|격리(isolation) 실행 / Intel SGX / Intel TDX와 AMD SEV / ARM TrustZone|
|**실행증명 (Attestation)**|원격(remote) 실행증명 / 내장형 시스템과 같이 단순한 시스템 / TrustZone|
|**주변장치 (peripheral)**|GPU나 FPGA와 같은 가속기 / Smart NIC / 암호화 / 머클 트리와 같은 구조체를 유지|
|**시스템 소프트웨어 응용**|ECALL / OCALL / Trusted Platform Module(TPM)|
