#정보관리기술사 #보안 #보안강도 #SecurityStrength #NEW
## 정의
암호학적 보안 강도(Security Strength)
- 특정 암호 알고리즘·해시 함수에 대해 공격자가 키 탐색·충돌 탐색·역상 탐색 등을 성공시키는 데 필요한 계산량을 $2^n$ 수준의 연산량으로 나타낸 척도
## 키워드
* $2^n$, 연산량, 암호 키 길이, 해시 출력 길이, 운용 모드, IV·Nonce, 112/128/192/256bit
## 암기법
* 키해운IV: 키길이·해시출력·운용모드·IV/Nonce
## 특징
- 키 공간성: 키 길이가 길수록 무차별 대입 계산량 증가
- 해시 저항성: 출력 비트 수에 따라 충돌·역상 저항성 결정
- 운용 모드 의존: 평문 노출·무결성·전체 보안 수준이 모드별로 상이
- IV/Nonce 유일성: 재사용·예측 가능 시 기밀성 저하
## 목적
- 암호 알고리즘·키 길이의 적정 보안 수준 판단
- 안전성 유지기간에 맞는 암호 체계 선정
## 구성요소
- 결정 요소: 암호 키 길이, 해시 출력 길이, 운용 모드, IV·Nonce 사용 방식
- 대칭키: 키 길이 기준 (예: AES-128 ≈ 128bit 강도)
- 공개키: 대칭키 대응 수준 (128bit ↔ RSA 3072 / ECC 256)
- 해시: n비트 해시 → 충돌 ≈ n/2, 역상 ≈ n
- 강도별 비교: 112(2011~2030) / 128·192·256(2030년 이후)
## 구성도
```
보안강도(2^n) ← 키길이 + 해시출력 + 운용모드 + IV/Nonce
      ↓
대칭키(키길이) | 공개키(대응수준) | 해시(충돌 n/2·역상 n)
      ↓
112 / 128 / 192 / 256 bit (안전성 유지기간)
```
