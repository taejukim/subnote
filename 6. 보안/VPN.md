Virtual Private Network
## 정의
- 암호화된 터널을 통해 인터넷에 연결함으로써 공중망(인터넷망)을 사설망(전용회선)처럼 이요할 수 있는 네트워크 서비스
## 키워드
- 터널링, 암호화, 기밀성, 무결성, SSL VPN, IPSec VPN, MPLS VPN

## VPN 기술 요소
- 터널링 : 패킷이 공중망을 통과할때, 가상 경로를 설정 해줌으로써 터널이 뚫린것 같은 통로를 제공하는 기술
- 암호화 : 터널을 통과하는 패킷을 암호화함으로써 기밀성 제공, 공개키 암호화 방식
- 인증 : MAC, 해시 함수를 이용한 메시지 인증 제공으로 무결성 제공
- 접근 제어 : 패킷 필터링을 통해 회선 접근 제어

## VPN 종류

| 항목            | 설명                                                           |
| ------------- | ------------------------------------------------------------ |
| **SSL VPN**   | - SSL/TLS 프로토콜 사용 하며, 별도 장비없이 웹 브라우저로 접속 가능                  |
| **IPSec VPN** | - IPSec 프로토콜 사용하여, 보안성 우수 하나 초기도입비용이 높음                      |
| **MPLS VPN**  | - MPLS 패킹 스위칭 기술 이용, 확장성과 통합성이 우수  <br>- 동일 ISP망 내부에서만 운영 가능 |

## IPSec VPN과 SSL VPN 비교

|비교|IPSec VPN|SSL VPN|
|---|---|---|
|**정의**|- 네트워크 계층에서 데이터 패킷을 암호화하고 터널링을 사용하여 데이터를 보호|- 애플리케이션 계층에서 SSL/TLS 프로토콜을 사용하여 데이터를 보호|
|**Network Layer**|- Layer 3|- Layer 4 ~ Layer 7|
|**동작 방식**|- IP Packet 자체를 암호화하여 종단간 보호|- SSL 통한 터널링 실시, Packet 암호화 방식|
|**인증 방식**|- 비밀키 공유|- 인증서|
|**장단점**|- 설치, 운영 및 관리 부담  <br>- SSL VPN 대비 빠른 속도  <br>- 다수 동시 접속자 지원|- IPSec VPN 비해 설치 및 관리 편리  <br>- IPSec VPN 대비 속도 느림  <br>- 동시 접속자 수 적음  <br>- 비용 절감|
