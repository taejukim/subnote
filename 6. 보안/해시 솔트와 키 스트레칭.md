## 솔트 정의
- 해시 함수 입력값에 임의 문자열을 추가하여 Digest를 생성하는 기법
## 키 스트레칭 정의
- 해시 함수 결과 값을 다시 입력 값으로 실행하여 해시 함수를 반복 실행하여 다이제스트를 생성하는 기법
## 키워드
- 임의 문자역, 해시 함수 반복 실행, 해시, Salt Iteration Count, 단방향 암호화, Brute Force Attack, Rainbow table attack

## 해시 솔트(Salt)의 매커니즘
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260408234049.png|600]]
1. 사용자 Data 입력 : Password와 같은 보안성 강화가 필요한 Data에 적용
2. 임의의 Salt값 생성 : Random한 값의 Salt값을 Data에 추가하여 Message digest 생성
3. 변경된 Digest 값 생성 : Messages Digest 값과 Salt값을 매핑하여 DB 저장

## 해시 솔트와 페퍼 비교
| **비 교**   | **솔트(Salt)**                                | **페퍼(Pepper)**                              |
| --------- | ------------------------------------------- | ------------------------------------------- |
| **정의**    | - 해시 함수 입력 데이터에 **임의의 데이터**를 추가하여 해시 함수를 수행 | - 해시 함수 입력 데이터에 **동일한 데이터**를 추가하여 해시 함수를 수행 |
| **목적**    | - 동일한 입력 데이터에 대해 서로 다른 해시 값을 생성             | - 해시 값을 복잡하게 하여 보안 강화                       |
| **추가 문자** | - **각 데이터마다 고유한 무작위 값**<br>- 각 사용자에게 다르게 적용 | - 전체 데이터에 대해 모두 동일한 값<br>- 모든 사용자에게 동일하게 적용 |
| **저장**    | - 데이터베이스에 평문 상태 저장 가능                       | - 외부 공개 안되도록 별도로 암호화하여 저장                   |
## 해시 키 스트레칭의 매커니즘
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260408234305.png|600]]
1. 사용자 Data 입력 : Password와 같은 보안성 강화가 필요한 Data에 적용
