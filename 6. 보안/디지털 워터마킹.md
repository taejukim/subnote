
## 정의
디지털 워터마킹(Digital Watermarking)
- 오디오·비디오·이미지 등 콘텐츠에 특정 표식을 삽입하여, 불법 복제 시 소유권 정보를 추적할 수 있는 정보은닉 기술
## 키워드
* 공간영역, 주파수영역, Blind/Public, non-Blind/Private, 비가시성, 견고성, 복잡성, 효율성, DFT·DCT·DWT
## 암기법
* 공주파 / 공비: 공간·주파수 삽입 / 공개형·비공개형 검출
## 특징
- 비가시성: 인지 품질 유지하며 표식 삽입
- 견고성: 변형·압축에도 검출 가능해야 함
- 삽입 영역: 공간(저연산) vs 주파수(삭제 어려움)
- 검출형: Blind(원본 불필요) vs Non-Blind(원본 필요)
## 목적
- 불법 복제 콘텐츠의 소유권·저작권 추적
- 저작권자 정보(Contents ID, CP ID, Date) 입증
## 구성요소
- 개념: 원본+워터마크정보 → 워터마크이미지 → KEY 비교로 소유권 검증
- 공간영역: 저연산·품질손실 적음 / 노이즈·필터·JPEG에 취약
- 주파수영역: DFT·DCT·DWT·FMT, 전역 분산으로 삭제 어려움 / 연산·구현 복잡
- Blind(공개형): 원본 불필요, 응용 넓음 / 키 의존·보안·견고성 상대적 낮음
- Non-Blind(비공개형): 보안·견고성 우수 / 원본 필요·응용 제한
- 공격: Filtering, Copy, Mosaic, Template(동기화 파괴)
## 구성도
```
[저작권자] 원본 + 워터마크정보(ID·CP·Date)
              ↓ 삽입
        [워터마크 이미지] ←소유→ [사용자]
              ↓ 추출 + KEY 비교
           소유권 검증
```
