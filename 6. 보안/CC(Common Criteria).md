#정보관리기술사 #보안 #CC #보안/인증/접근제어
## 정의
- IT 시스템 보안기능 요구사항 대로 안전하게 동작 여부 평가 기관 검증 제도
- 특징 : CCRA 협약국 상호인정, 신뢰성 확보, 표준화, ISO 15408

## 절차 및 구성요소
CC의 주요 구성요소 및 절차
- CC의 주요 구성요소
	- PP  : 보호 프로파일 공통적인 보안 요구사항
	- ST : 목표 명세 요구사항 구현 보안 기능
	- EAL :  등급 EAL0 ~ EAL7
- CC의 인증 절차
	- 신청 기관 > 평가 기관 > 인증 기관 
## ISMS-P와 CC 비교
* 성격 : 관리 체계 인증 / 제품 평가, 인증
- 평가 대상 : 기업/기관의 정보보호/개인정보 관리 체계 / 방화벽, 네트워크, 보안 SW 등
- 평가 관점 : 조직의 체계적 보안 / 제품의 보안 요구사항 충족
- 기준 체계 : KISA ISMS–P / ISO/IEC 15408
- 주요 산출물 : 인증서, 심사결과 / 인증서, ST, EAL
