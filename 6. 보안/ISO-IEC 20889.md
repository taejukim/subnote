#정보관리기술사 #보안 #ISO20889 #비식별조치 #NEW
## 정의
ISO/IEC 20889
- 프라이버시를 침해하지 않고 개인정보를 처리하기 위한 비식별 기법·관련 기술을 제시하는 국제 표준
## 키워드
* 개인정보 비식별조치, 통계도구, 일반화, 해부화, 가명화, 재현데이터
## 암기법
* 대제거변생: 대체·제거·변경·생성 / KLT: K익명성·L다양성·T근접성
## 특징
- 식별→비가식별 전환 프로세스 표준화
- 기법 분류: 대체·제거·변경·생성
- 프라이버시 모델: K-익명성, L-다양성, T-근접성
- 공격 대응: 연결·동질성·배경지식·쏠림·유사성 공격 완화
## 목적
- 개인정보 활용과 프라이버시 보호의 균형
- 비식별 기법·모델의 표준적 적용 기준 제시
## 구성요소
- 개념: 특정인 식별정보 → PII(가명 등) → 특정인 식별 불가 정보
- 대체 - 통계도구: 표본추출, 집계
- 대체 - 일반화: 범주화, 일반화, 반올림, Top/Bottom Coding
- 대체 - 해부화: 테이블·컬럼 해부화
- 대체 - 가명화: 암호화, 토큰화, 임의할당, 스와핑, 휴리스틱
- 제거 - 삭제: 마스킹, 식별자·컬럼·레코드 삭제
- 변경 - 암호화: 결정적·순서보존·형식보존·동형암호 등
- 변경 - 무작위화: 순열, 잡음 추가, Partial Totals
- 생성 - 재현데이터: Full / Partial / Hybrid Synthesis
- 모델: K-익명성(연결공격) → L-다양성(동질성·배경지식) → T-근접성(쏠림·유사성)
## 구성도
```
[비식별 조치]
   → K-익명성 (연결공격 완화)
   → L-다양성 (동질성·배경지식 완화)
   → T-근접성 (쏠림·유사성 완화)
   → [비식별 정보]
```
