## 정의
- 개발과 운영의 융합과 엽형의 개발 주기에 보안 측면을 포함한 개발 방법론

## 키워드
- 개발과 운영에 보안 통합, CI/CD 구현 도구

## DevSecOps 작동 방식

| 요소        | 작동 방식 설명                                                                                                       |
| --------- | -------------------------------------------------------------------------------------------------------------- |
| DevOps    | - 개발 팀과 운영 팀을 하나로 모아 개발 진행                                                                                     |
| CI/CD     | - 자동화된 구축 및 테스트를 통해 신규 애플리케이션을 제공                                                                              |
| DevSecOps | - CI/CD 프로세스 전반에 보안 평가를 통합하여 DevOps 방식에 보안 도입  <br>- 개발팀: 코드 구현 전 보안 팀과 협업  <br>- 운영팀: 배포 후 소프트웨어의 보안 문제를 모니터링 |
## DevSecOps 구현 요소

|요소|핵심 성공 요소|
|---|---|
|문화|- 보안 조직의 조기 참여|
|프로세스|- 프로세스 초기에 보안 분석 및 테스트|
|자동화|- 코드 보안 관리(Security as Code)|
|도구|- 보안 점검 도구|
|성과 평가|- 보안코드 품질 점수|

## DevSecOps 구현 도구와 보안 기능

|구분|SDLC|기술|
|---|---|---|
|도구|- Code|- 형상관리, 코드 추적성|
||- Build|- 자동화된 코드 빌드 도구|
||- Test|- 동적, 정적 커버리지 자동화 테스트 도구|
||- Release|- 변경관리, 변경 승인, 릴리즈 계획 & 자동화|
|보안 기능|- Security Engineering|- 보안에 대한 공학적 접근 방법 및 자동화 도구 제공|
||- Security Operations|- 보안성 확보를 위한 지속적 모니터링, Detecting 제공|
||- Security Science|- 보안 모델에 대한 수립, 학습, 전파 및 예측성 제공|
