#정보관리기술사 #보안 #간편인증인터페이스가이드라인 #보안/인증/접근제어
## 정의
- 긴 패스워드를 입력하는 대신 PIN 번호, 바이오 정보, 패턴입력 등 간편한 방법으로 전자서명 서비스를 이용하는 방식

## 키워드
- 클라이언트 시크릿, 마스터 시크릿, 인터페이스 인증, 메시지 인증, 중요 정보 암호화

## 간편 인증 서비스 절차 도
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260410220234.png|600]]
1. 사용자는 이용하고자 하는 전자서명수단을 선택하고 요구되는 정보를 입력
2. 이용기관의 클라이언트는 사용자가 선택한 전자서명 수단과 입력한 정보를 서버로 전송하여 사용자 인증을 요청
3. 이용기관의 서버는 사용자가 입력한 정보를 전자서명인증사업자에게 전송하여 사용자 인증을 요청
4. 전자서명인증사업자는 이용기관으로부터 전달받은 사용자 정보를 통해 인증앱을 호출(호출방법: 앱스킴, 딥링크, 앱푸시, 큐알코드 등)
5. 사용자는 전자서명 인증 사업자의 인증앱을 통해 전자서명을 수행
6. 전자서명인증사업자는 사용자의 인증결과를 이용기관에 제공, 이용기간은 전자서명인증사업자로부터 받은 인증결과를 확인

## 간편인증 서비스의 키 종류

| 키 종류                         | 유형  | 생성/배포 대상                                                                                                                 | 용도                                          | 유효기간     |
| ---------------------------- | --- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------- | -------- |
| 클라이언트 시크릿 (ClientSecret, CS) | 유도키 | - (생성) 전자서명 인증 사업자  <br>- (배포) 이용기관  <br><br>- (생성) 전자서명 인증 사업자  <br>- (배포) 중계사업자  <br><br>- (생성) 중계사업자  <br>- (배포) 이용기관 | - 접근토큰 발급을 위한 클라이언트 인증  <br>- 인증 메시지 무결성 검증 | 최대 2년 권고 |
| 마스터 시크릿 (MasterSecret, MS)   | 유도키 | - (생성) 전자서명 인증 사업자  <br>- (배포) 이용기관  <br><br>- (생성) 전자서명 인증 사업자  <br>- (배포) 중계사업자                                        | 중요 정보 암호화                                   | 최대 2년 권고 |

## 키의 사용처

|키 사용처|설명|
|---|---|
|인터페이스 인증|- 인터페이스 사용 승인을 위해 클라이언트 시크릿을 해시하여 사용|
|메시지 인증|- 전송 메시지 무결성 보장을 위한 메시지 인증(HMAC) 생성 시 사용  <br>- 클라이언트 시크릿 + 랜덤 솔트(salt) → 새로운 비밀키(MacK) 생성|
|중요정보 암호화|- 거래 당사자 간 중요정보 보호  <br>- 마스터 시크릿 + 랜덤 솔트 → 암호키(EncK) 생성|
