#정보관리기술사 #보안 #암호화 #정리 #보안/암호화

## 정의
정보의 기밀성 보장을 위한 데이터 변환 기술, 암호화
- 평문(Plaintext)을 암호문(Ciphertext)으로 변환하여 인가되지 않은 사용자가 정보를 읽을 수 없도록 하는 기술
- 인증(Authentication), 기밀성(Confidentiality), 무결성(Integrity), 부인방지(Non-Repudiation) 보장

## 키워드
* 대칭키, 비대칭키, 해시함수, 혼돈(Confusion), 확산(Diffusion), 블록암호, 스트림암호, CIA

## 암기법
* 대체블치확혼확압: (원리) 대체, 블록, 치환, 확장, 혼돈, 확산, 압축
* 이소타전: (공개키 유형) 이산대수기반, 소인수분해기반, 타원곡선방식, 전자서명방식
* 스블: (대칭키 유형) 스트림암호, 블록암호

## 특징
- 기밀성: 인가되지 않은 사용자의 정보 접근 방지
- 무결성: 데이터 변조 여부 확인 가능
- 인증: 송신자 신원 확인
- 부인방지: 송신 사실 부인 불가


## 암호화 방식과 목적

| 암호방식         | 기밀성 (Confidentiality) | 인증 (Authentication) | 무결성 (Integrity) | 키 관리    | 주요 알고리즘            |
| ------------ | --------------------- | ------------------- | --------------- | ------- | ------------------ |
| 대칭키 암호화      | ○                     | ✕ (별도 인증 필요)        | ✕ (MAC 필요)      | 키 공유 필요 | AES, DES, Blowfish |
| 비대칭키 암호화     | ○                     | ○ (전자서명)            | ○ (전자서명)        | 공유 불필요  | RSA, ECC           |
| 단방향 암호화 (해시) | ✕                     | ○ (서명과 결합 시)        | ○               | 키 없음    | SHA-256, bcrypt    |

## 암호화 종류
- 정보 단위 기준

| 분류   | 유형     | 설명                                            |
| ---- | ------ | --------------------------------------------- |
| 정보단위 | 스트림 암호 | - 한번에 **1비트 또는 1바이트** 단위 암호화- 속도 빠름, 오류 전파 적음 |
| 정보단위 | 블록 암호  | - 평문을 **단위 블록**으로 나누어 암호화- 혼돈성 증가, 변경/추가 어려움  |
- 키 형태 기준

| 분류   | 유형             | 설명                                                 |
| ---- | -------------- | -------------------------------------------------- |
| 키 형태 | 비밀키 암호화 (대칭키)  | - 송신자/수신자가 **동일한 비밀키** 공유- 구현 용이, 속도 빠름            |
| 키 형태 | 공개키 암호화 (비대칭키) | - 공개키/비밀키 **한 쌍 사용**- 공개키로 암호화 → 비밀키로 복호화- 전자서명 지원 |
- 암호화 기반 기술

| 분류       | 유형                                     | 설명                                                        |
| -------- | -------------------------------------- | --------------------------------------------------------- |
| 암호화 기반기술 | SPN (Substitution-Permutation Network) | - 치환 + 전치 구조- 128비트를 4×4 행렬로 처리- 적용: AES, ARIA            |
| 암호화 기반기술 | Feistel (피스텔)                          | - 블록을 N/2로 나눠 R라운드 반복- XOR 연산 기반- 적용: DES, SEED           |
| 암호화 기반기술 | 인수분해                                   | - n → p,q 추출 어려움 활용- 적용: RSA                              |
| 암호화 기반기술 | 이산대수                                   | - 로그 연산은 어려움, 지수 연산은 쉬움- 적용: Diffie-Hellman, DSA          |
| 암호화 기반기술 | 해시함수                                   | - 임의 길이 입력 → 고정 길이 출력- 단방향, 역상 저항성- 적용: MD5, SHA-1, SHA-2 |
## 구성요소
| 구분   | 구성요소            | 설명                    |
| ---- | --------------- | --------------------- |
| 입력   | 평문(Plaintext)   | 암호화 대상 원본 데이터         |
| 알고리즘 | 암호화 알고리즘        | 평문을 암호문으로 변환하는 수학적 함수 |
| 키    | 암호키(Key)        | 암호화/복호화에 사용되는 비밀 값    |
| 출력   | 암호문(Ciphertext) | 암호화된 결과 데이터           |
| 방식   | 대칭키/비대칭키        | 키 사용 방식에 따른 분류        |
