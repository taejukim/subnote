#정보관리기술사 #보안 #WAAP #보안/클라우드보안
Web Application and API Protection
## 정의 
- 웹방화벽(WAF) 기능에 추가로 API 보안 등 웹 환경에서 발생 가능한 각종 공격에 대한 보완책을 종합 적용 한 웹 애플리케이션 및 API보호 솔루션

## 키워드
- WAF + 웹 애플리케이션 보호 + API 보호
- DDoS, Bot 보호

## WAAP 주요 기능
| **주요기능**                                            | **방어 공격**                                                      |
| --------------------------------------------------- | -------------------------------------------------------------- |
| **웹 애플리케이션 방화벽**<br>(WAF, Web Application Firewall) | - 웹 공격, 정보 유출<br>- 부정 접근<br>- 웹 위변조                            |
| **DDoS(분산 서비스 거부) 보호**                              | - DDoS (분산 서비스 거부)                                             |
| **API 보호**                                          | - API 통신                                                       |
| **Bot 보호**                                          | - 무차별 대입공격<br>- 핑거프린팅<br>- 크리덴셜 스터핑<br>- 런타임 애플리케이션 자가방어(RASP) |
|                                                     |                                                                |

## 웹 방화벽(WAP)의 기능
| **분류**        | **기능**                                                                       |
| ------------- | ---------------------------------------------------------------------------- |
| **사용자 요청 검사** | - **어플리케이션 접근 제어**<br>- Web DoS 제어<br>- 업로드 파일/요청 형식 검사<br>- 버퍼오버플로우/스크립트 차단 |
| **컨텐츠 보호**    | - **정보 유출 차단**<br>- 웹 변조 방지                                                  |
| **보안**        | - URL 및 서버 위장<br>- SSL/TLS 지원                                                |

## WAAP와 기존 보안 시스템 비교
|**비교항목**|**WAAP**|**WAF**|**Firewall**|
|---|---|---|---|
|**주요 목적**|API 보호, Bot 보호|웹공격 및 정보유출 방어|접근제어, 인증|
|**OSI Layer**|Layer 7 (Application)|Layer 7 (Application)|Layer 3 (Network)|
|**제어대상**|Http(s), API G/W|Http(s)|IP, Port|
|**제어기법**|Cloud, 사용자행위기반 탐지|Application 로직|Rule Set, Logging|
