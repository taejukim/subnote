#정보관리기술사 #보안 #위험분석방법론 #ISO13335
## 정의
위험 분석 방법론
- 정보시스템 자산에 대한 위협·취약점·영향을 식별·분석·평가하는 보안 위험 관리 활동
- ISO/IEC 13335·27005 기반의 정성적·정량적 위험 평가 접근법 체계
## 키워드
* 베이스라인, 비정형 접근법, 상세 위험 분석, 복합 접근법, 정성/정량 평가
## 암기법
* 베비상복: 베이스라인·비정형·상세·복합
## 특징
- 다양성: 4가지 접근법 선택 가능
- 정량/정성성: 두 가지 평가 방식 혼용
- 표준 기반성: ISO 13335·27005 기반
- 의사결정 지원성: 위험 우선순위·대응 도출
## 목적
- 정보 자산 위험을 객관적으로 식별·평가
- 적절한 보안 통제·대응 방안 도출
## 구성요소
- 베이스라인 접근법: 표준 통제 적용 (간단·시간 절약)
- 비정형 접근법: 전문가 경험 의존 (소규모 적합)
- 상세 위험 분석: 모든 자산 정량 분석 (대규모·정밀)
- 복합 접근법: 여러 방법 혼합 (실무 권장)
- 평가 방식: 정성적(High/Medium/Low), 정량적(ALE = SLE × ARO)
- 절차: 자산 식별 → 위협·취약점 분석 → 위험 평가 → 통제 선택 → 잔여 위험 수용
- 표준: ISO/IEC 13335-1, ISO 27005, NIST SP 800-30
## 구성도
```
[자산 식별]
   ↓
[위협 식별] + [취약점 식별]
   ↓
[위험 평가] (정성/정량) ← 4가지 접근법(베이스/비정형/상세/복합)
   ↓
[통제 선택·구현]
   ↓
[잔여 위험 평가·수용]
```
