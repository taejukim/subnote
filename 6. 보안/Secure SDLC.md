#정보관리기술사 #보안 #SecureSDLC #보안내재화
## 정의
Secure SDLC(Secure Software Development Life Cycle)
- 안전한 소프트웨어 개발을 위해 SDLC 전 단계에 보안 활동을 통합하는 개발 방법론
- 요구·설계·구현·테스트·배포·운영 전 단계의 보안 내재화 체계
## 키워드
* MS SDL, OWASP CLASP, NIST SSDF, BSIMM, Threat Modeling, Shift-Left
## 암기법
* 요설구테배운: 요구·설계·구현·테스트·배포·운영
## 특징
- 보안 내재화: 모든 단계에 보안 활동 통합
- 단계별 보안 활동: 위협 모델링·코드 리뷰·보안 테스트
- 자동화 통합성: CI/CD 보안 점검 자동화
- 표준 기반성: MS SDL·NIST SSDF 등 글로벌 표준 적용
## 목적
- 보안 결함 조기 발견·수정으로 비용 최소화
- 컴플라이언스 준수와 안전한 SW 출시
## 구성요소
- 요구사항 수집: 보안 및 개인정보 요구사항
- 설계: 위협 모델링(STRIDE 등)
- 구현: 시큐어 코딩, 동료 검토
- 테스트: 보안 테스트(SAST/DAST/IAST)
- 배포: CI/CD 보안 점검 결과
- 운영·유지보수: 보안성 검토, 취약점 모니터링
- 방법론: Microsoft SDL, OWASP CLASP, NIST SSDF, BSIMM
## 구성도
```
요구사항(보안 요건) → 설계(위협 모델링) → 구현(시큐어 코딩·리뷰)
   → 테스트(SAST/DAST) → 배포(CI/CD 보안) → 운영(보안성 검토)
   ↑___________________ 보안 활동 환류 ___________________|
```
