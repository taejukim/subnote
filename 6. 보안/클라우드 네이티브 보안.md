#정보관리기술사 #보안 #클라우드네이티브보안 #보안/클라우드보안
## 정의
- 클라우드 환경에서 애플리케이션 설계, 개발, 배포 및 운영 과정에 보안을 통합하는 보안 기술
- 특징 : [[1. ITPE/0. Sub-Note/5. 디지털서비스/SecaaS]], 확장성, 유연한 과금, 낮은 CAPEX

## 구성요소
- 클라우드 네이티브 보안의 구성도
- 4C 모델 기반 
	- Cloud > Cluster > Container > Code
	- Cloud : 인프라 및 플랫폼 보안(CSP 책임)
	- Cluster : 쿠버네티스 및 오케스트레이션 보안
	- Container : 이미지 취약점 및 런타임 보안
	- Code : 애플리케이션 보안(DevSecOps)
- 클라우드 네이티브 보안의 구성요소
	- 인프라 보안
		- CSPM(Cloud Security Posture Management) : 클라우드 설정 오류 탐지
		- CWPP(Cloud Workload Protection Platform) : 클라우드 워크로드 보호
		- [[SIEM]], SOAR : 관제, 복구
	- 네트워크/개발 보안
		- Micro-Segmentation : 네트워크 통제로 위협 수평전개 방지
		- DevSecOps : CI/CD에 보안 적용
		- CIEM : 클라우드 권한 리스크를 탐지하고 최소 권한 원칙을 구현하는 IAM 확장 보안 솔루션
- AI 환경의 클라우드 네이티브 보안 발전 방향
	- AIOps for Security
	- AI 공급망 보안
	- [[제로 트러스트]] AI 결합
	- 자가 치유 인프라
