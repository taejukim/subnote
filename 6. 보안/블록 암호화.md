## 정의
고정 크기 블록 단위 데이터 암호화 기술, 블록 암호화
- 평문을 고정된 크기의 블록으로 나누어 각 블록을 독립적으로 암호화하는 대칭키 암호화 방식
- Feistel 구조 또는 SPN 구조를 기반으로 혼돈(Confusion)과 확산(Diffusion) 원리 적용

## 키워드
* Feistel, SPN, S-Box, P-Box, ECB, CBC, CTR, DES, AES, SEED, ARIA

## 암기법
* 혼대치수 확전순P: (암호화 원리) 혼돈-대치-치환-S-BOX / 확산-전치-순열-P-BOX
* 운모: ECB CBC CFB OFB CTR (운영모드)
* 피스: Feistel(DES,SEED), SPN(AES,ARIA)

## 특징
- 고정 블록 크기: 64bit, 128bit 등 고정 크기 단위 처리
- 라운드 반복: 여러 라운드를 거쳐 보안 강도 향상
- 운영 모드: ECB, CBC, CTR 등 다양한 모드 지원
- 패딩: 블록 크기에 맞지 않는 데이터 처리

## 목적
- 대용량 데이터의 효율적 암호화
- 높은 보안 강도 제공
- 다양한 운영 모드를 통한 유연한 적용

## 구성요소
| 구분  | 구성요소    | 설명                                     |
| --- | ------- | -------------------------------------- |
| 구조  | Feistel | 좌우 분리, XOR, Swap, Round 반복 (DES, SEED) |
| 구조  | SPN     | S-Box, P-Box 이용 병렬 처리 (AES, ARIA)      |
| 연산  | S-Box   | 비선형 치환, 혼돈(Confusion) 제공               |
| 연산  | P-Box   | 순열 변환, 확산(Diffusion) 제공                |
| 모드  | ECB     | Electronic CodeBook, 사용 금지 권고          |
| 모드  | CBC     | Cipher Block Chaining, 권장 모드           |
| 모드  | CTR     | Counter 모드, 병렬 처리 가능, 권장               |

## 블록 암호화 운영 모드
![[Pasted image 20260408235344.png|600]]

| **운영모드**                           | **설명**                                                                                             | **운영모드**                      | **설명**                                                                                                           |
| ---------------------------------- | -------------------------------------------------------------------------------------------------- | ----------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **ECB**<br>(Electronic Code Book)  | - 평문/암호문 블록 **1:1 관계** 가진 기본적인 블록암호화 모드<br>- 가장 간단한 처리, **고속/병렬 처리 가능**, 기밀성 다른 운영모드에 비해 **가장 낮음** | **CFB**<br>(Cipher Feed back) | - 데이터를 암호화하는 것이 아니라 **IV를 암호화**로, 블록 암호를 자기 동기 스트림 암호로 변환하는 방식 <br>- 암호화에서 병렬 처리 불가능                             |
| **CBC**<br>(Cipher Block Chaining) | - 맨 첫 블록은 **Initialization Vector**를 통해 **XOR 처리**하여 암호화, **두 번째 블록**은 **이전 암호화 결과**를 XOR 처리 암호화   | **OFB**<br>(Output Feedback)  | - **IV를 암호화**하여 그 Key Stream을 생성해 두어 **XOR 처리만 나중에 수행**하여 성능을 향상시키는 암호화 운영모드<br>- 암/복호화가 같은 구조                   |
| **PCBC**<br>(Propagating CBC)      | - **데이터와 암호화 결과를 한번 더 XOR 처리**를 통해 복호화로 복잡도 높인 암호화<br>- 증식적 암호블록 체인 방식                             | **CTR**<br>(Counter)          | - **Counter 처리를 추가**하여 Key Stream을 생성해 두어 **XOR 처리**를 통해 **복잡도를 증가**시킨 암호화 운영모드<br>- 패딩이 필요 없고 암/복호화가 사전에 준비가 가능 |
