#정보관리기술사 #보안 #KCMVP #암호모듈검증
## 정의
KCMVP(Korea Cryptographic Module Validation Program)
- 비밀로 분류되지 않은 중요 자료 보호를 위해 국가·공공기관에서 도입하는 암호 모듈의 안전성과 구현 적합성을 검증하는 제도
- 사이버안보 업무 규정 제9조, 전자정부법 시행령 제69조 근거
## 키워드
* 국가용 암호, 검증대상 알고리즘, ARIA, SEED, LEA, HIGHT, 보안 등급
## 암기법
* 신계보심심목: 신청·계약·보고·심의·심의통보·목록등재
## 특징
- 의무성: 국가·공공기관 도입 암호 모듈 의무 검증
- 표준성: 국정원 지정 알고리즘만 사용
- 갱신성: 검증 만료 6개월 이내 재신청
- 적합성: 안전성 + 구현 적합성 동시 검증
## 목적
- 국가·공공기관 정보의 기밀성·무결성 확보
- 검증된 암호 모듈로 보안 사고 예방
## 구성요소
- 시험·검증 절차: 시험 신청 → 시험 계약 → 시험 결과 보고 → 시험 검증 결과 심의 의결 → 심의 결과 통보 → 목록 등재
- 블록암호·공개키: ARIA, SEED, LEA, HIGHT, RSAES
- 해시 함수: SHA2, SHA3, LSH
- 메시지 인증: CMAC, GMAC, HMAC
- 난수 발생기: CTR-DRBG, HASH-DRBG, HMAC-DRBG
- 키 설정·유도: DH, ECDH, KBKDR, PBKDF
- 전자서명: RSA-PSS, KCDSA, EC-KCDSA, ECDSA
- 재신청: 만료 6개월 이내 → 재검증 신청 → 시험·보완 → 결과 보고 → 심의 → 목록 갱신
## 구성도
```
시험 신청 → 시험 계약 → 시험 결과 보고
   → 시험검증결과 심의의결 → 심의결과 통보 → 검증필 목록 등재
                            ↑
                    (만료 6개월 이내 재신청)
```
