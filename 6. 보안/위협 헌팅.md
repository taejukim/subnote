#정보관리기술사 #보안 #위협헌팅 #보안/보안관제
Threat Hunting
## 정의
- 네트워크와 엔드포인트를 검색하여 보안통제를 우회하는 위협이 공격을 실행하거나 목표를 달성 전 위협을 사전에 식별하는 프로세스

## 키워드
![[Pasted image 20260410224956.png|600]]
- 수집 → 가설 수립 → 헌팅 → 탐지자 개발 → 위협 탐지 → 조사 및 대응
- Cyber Kill Chain


| **요소**     | **세부**               | **설명**                                                                        |
| ---------- | -------------------- | ----------------------------------------------------------------------------- |
| **절차**     | **수집**               | - End Point 포함한 모든 데이터 수집                                                     |
|            | **가설 수립**            | - ATT&CK/사이버 킬 체인 모델 활용, 발생 가능 가설 수립                                          |
|            | **헌팅**               | - 수립된 가설을 기반으로 현재 환경을 반복적 분석 수행                                               |
|            | **탐지자 개발**           | - 위협 요소 식별을 위한 행동을 프로그램화 하여 자동화                                               |
|            | **위협 탐지**            | - 의심이 가거나 위협이 될 것 같은 행동 발견                                                    |
|            | **조사 및 대응**          | - 탐지된 위협에 대한 분석 및 분석 내용에 대한 대응 진행                                             |
| **조직적 요소** | **보안 전담 조직**         | - 지속적 탐지 및 대응을 위한 보안 전담 조직 필요<br>- 보안 전담 조직 구성 및 운영을 통한 기업 위협 최소화 가능          |
|            | **보안 정책**            | - 가설 수립 및 탐지를 위한 기본적인 보안 정책 필요<br>- 해당 정책 및 가이드라인 등을 기반으로 탐지자 개발              |
|            | **교육/훈련**            | - 조직 내부적 위협 요소에 대한 대응 작업 필요<br>- 발생 가능 상황 및 위협 요소에 대한 사전 관리 필요                |
| **기술적 요소** | **EDR**              | - 엔드 포인트에서 행위 기반 시스템 탐지 및 대응 기술<br>- 시스템의 전반적인 상태의 가시화를 통한 대응력 확보             |
|            | **SIEM**             | - 시스템의 모든 데이터 분석을 통한 보안 확보 기술<br>- 빅데이터 기반의 분석 및 가시화를 통한 위협 요소 탐지 가능          |
|            | **Cyber Kill Chain** | - 프로세스 기반 분석을 통한 위협 요소 파악 및 공격 방법 유추<br>- 공격, 방어 체인 모델을 기준으로 위협 요소 탐지 및 대응 진행 |
