#정보관리기술사 #보안 #DMARC #SPF #DKIM #NEW
## 정의
DMARC(Domain-based Message Authentication, Reporting and Conformance)
- SPF(메일서버 등록)와 DKIM(도메인 키 인증)을 활용하는 이메일 인증 프로토콜
- RFC 7489 기반, DNS 정책 배포 및 인증 실패 시 보고
## 키워드
* SPF, DKIM, e-mail 인증, RFC 7489, DMARC 정책, 인증실패 보고서
## 암기법
* 스디정보: SPF·DKIM·정책(DNS)·보고서
## 특징
- 표준성: RFC 7489
- 이중인증: SPF(IP·서버) + DKIM(서명·무결성)
- DNS 기반: 정책·레코드를 DNS에 배포
- 보고성: 인증 실패 시 등록 주소로 보고서 발송
## 목적
- 이메일 스푸핑·피싱 방지
- 도메인 소유자에게 인증 실패 가시성 제공
## 구성요소
- 표준: RFC 7489
- 인증: SPF·DKIM 메일 검증
- DNS: 정책·레코드 배포
- 보고: 실패 보고서 작성·발송
- SPF: DNS에 메일서버 사전 등록 → 수신측이 발신정보와 실제 서버 일치 검증
- DKIM: 메일 헤더 전자서명으로 내용 위변조·훼손 여부 확인
- 정책 예: None / Quarantine / Reject
## 구성도
```
[발신자]→[발신 메일서버]──메일──→[수신 메일서버]─┬─성공→[수신자]
       ↑                         │ SPF/DKIM/DMARC│
  ①정책등록                      │ 조회(송신DNS) ├─실패→[차단·격리]
[송신 DNS]←──────────────────────┘               ↓
  (SPF/DKIM/DMARC)                    ⑦⑧ 보고서 → 등록주소
```
