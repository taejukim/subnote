#정보관리기술사 #보안 #웹쉘 #리버스웹쉘
## 정의
리버스 웹쉘(Reverse Web Shell)
- 방화벽 우회가 가능한 웹서버가 공격자에게 역으로 연결하여 쉘을 획득하는 침투 공격
- 아웃바운드 정책의 느슨함을 악용한 역방향 접속형 웹쉘
## 키워드
* Outbound, Firewall Bypass, Listener, C2, Internal Pivot, 우회 통신
## 암기법
* 대실패수: 대기·실행·패킷전송·수신
## 특징
- 아웃바운드형: 서버 → 공격자 역방향 접속
- 방화벽 우회성: 인바운드 차단 무력화
- 내부망 침투성: 발판 후 횡적 이동에 유리
- IP 은폐성: 공격자 IP 노출 최소화
## 목적
- 방화벽 인바운드 정책 우회와 안정적 쉘 확보
- 내부망 침투·횡적 이동을 위한 거점 확보
## 구성요소
- 동작: 오염서버 → 공격자
- 절차: 공격자 대기 → 리버스 웹쉘 스크립트 서버 실행 → 패킷 전송 → 웹쉘 메시지 수신 → 공격자에게 전송
- 리스너 위치: 해커, 리버스 웹쉘이 해커에게 접속
- 방화벽 우회: 용이(아웃바운드 느슨한 정책)
- NIC 역할: 해커가 수행 메시지를 NIC로 전송, 쉘이 NIC에서 메시지 획득
- 해커 선호: 방화벽 우회 탁월, 내부망 침투 유리, IP 숨기기
- 차단 방법: Outbound 리스너 모두 확인, 미확인 IP 차단
- 바인드 웹쉘 비교: 아웃바운드(리버스) vs 인바운드(바인드)
## 구성도
```
[공격자 (Listener)] ←─── 아웃바운드 역접속 ─── [감염된 웹서버 (리버스 쉘)]
                                                  ↑ 방화벽 우회
                                          내부망 침투·횡적 이동
```
