#정보관리기술사 #보안 #SECaaS #보안/클라우드보안
Security as a Service
## 정의
- 직접 보안 인프라를 구축할 필요 없이, 클라우드 서비스 형태로 보안 기능을 제공받는 모델

## 키워드
- CSP, SSP, Cloud 보안 서비스

## SECaaS 유형
- CSP SECaaS : 기존 클라우드 서비스 제공자가 자신의 안전한 서비스 제공을 위한 보안서비스
- SSP SECaaS : 모든 시스템들에 대해 전문적인 보안서비스를 제공하기 위한 서비스

## SECaaS(Security as a Service) 제공 서비스

| 제공 서비스                                             | 설명                                              |
| -------------------------------------------------- | ----------------------------------------------- |
| **IAM (Identity & Access Management)**             | 사용자 인증 및 접근 제어 (예: Okta, Microsoft Entra ID)    |
| **DLP (Data Loss Prevention)**                     | 데이터 유출 방지 및 보호 (예: McAfee, Symantec)            |
| **SIEM (Security Information & Event Management)** | 보안 로그 분석 및 위협 탐지 (예: Splunk, IBM QRadar)        |
| **EDR (Endpoint Detection & Response)**            | 엔드포인트 보안 및 위협 탐지 (예: SentinelOne, CrowdStrike)  |
| **FWaaS (Firewall as a Service)**                  | 클라우드 기반 방화벽 제공 (예: Zscaler, Palo Alto Networks) |
| **MDR (Managed Detection & Response)**             | 보안 모니터링 및 위협 대응 (예: Trend Micro, Rapid7)        |
