#정보관리기술사 #보안 #포렌식 #데이터카빙
## 정의
데이터 카빙(Data Carving)
- 메타 영역에 있는 데이터가 손실된 경우 시그니처·문자열 등 콘텐츠 정보로 파일을 복구하는 기법
- 파일 헤더·푸터·구조를 분석하여 메타데이터 없이도 데이터를 식별·복원하는 디지털 포렌식 기술
## 키워드
* Header/Footer, Signature, File Carving, PE Carving, 포렌식, Hex 분석
## 암기법
* 연비카: 연속·비연속·카빙
## 특징
- 메타 독립성: 파일 시스템 정보 없이 복구
- 시그니처 기반성: 파일 형식 특유 마커로 식별
- 다양한 대상성: 이미지·실행파일·문서·로그
- 한계성: 단편화·암호화 시 복구 어려움
## 목적
- 삭제·손상 데이터의 디지털 포렌식 복구
- 사고 조사·증거 확보를 위한 데이터 복원
## 구성요소
- 데이터 카빙 종류: PE(Portable Executable) 카빙(윈도우 실행), 이미지 카빙, 음성 카빙, 로그 카빙
- 연속적 카빙: 헤더-푸터 기반, 헤더 크기 기반, 파일 서명 기반
- 비연속적 카빙: 구조 기반, 콘텐츠 기반, 해시 기반, 그래프 기반
- 활용: 사고 조사, 증거 확보, 삭제 파일 복구
## 구성도
```
[원본 디스크/이미지]
     ↓ Hex 스캔
[시그니처 매칭] 헤더 → 푸터 / 헤더 + 크기
     ↓
[연속적 카빙] 단순 추출 / [비연속적 카빙] 구조·콘텐츠·해시·그래프
     ↓
[복구된 파일]
```
