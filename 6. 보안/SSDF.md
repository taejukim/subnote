#정보관리기술사 #보안 #SSDF #보안/개발보안
Secure Software Development Framework
## 정의
- 소프트웨어 개발 생명 주기(SDLC)의 모든 단계에 걸친 보안 관핸 통합 및 조직이 보안 소프트웨어 개발에 대한 체계적인 접근 방식

## 키워드
- 1. 조직준비(PO)
- 2. SW 보호(PS)
- 3. 보안이 잘된 SW 제작(PW)
- 4. 취약점 대응(RV)

## SSDF의 단계

| 구성                                                  | 주요 수행 활동                                                                                                                      | 설명                                                                   |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **조직 준비**(PO, Prepare the Organization)             | - 소프트웨어 개발을 위한 보안 요구 사항 정의  <br>- 역할과 책임을 구분  <br>- 지원 툴체인 구현  <br>- 안전한 개발 환경을 시행하고 유지                                       | - 모든 팀, 프로세스 및 기술이 개발 프로세스의 모든 단계에 보안을 포함할 준비가 되었는지 확인하여 조직을 구성하는 단계 |
| **SW 보호**(PS, Protect the Software)                 | - 모든 형태의 코드를 무단 액세스 및 변조로부터 보호  <br>- 소프트웨어 릴리스 무결성을 검증하기 위한 메커니즘을 구성  <br>- 각 소프트웨어 릴리스를 보관하고 보호                             | - 소프트웨어를 보호하는 방법, 작업, 구현 사례, 참조 자료를 식별하는 단계                          |
| **보안이 잘된 SW 제작**(PW, Produce Well Secured Software) | - 보안 요구 사항을 충족하고 위험을 완화하도록 소프트웨어를 설계  <br>- 기능을 복제하는 대신 소프트웨어를 재사용  <br>- 보안 코딩 Practices를 준수  <br>- 보안 결함을 찾기 위해 코드를 검토하고 분석 | - 코드를 안전하게 작성하는 방법에 맞춰 Pratices를 포함하는 단계                             |
| **취약점 대응**(RV, Respond to Vulnerabilities)          | - 지속적 취약점 검색  <br>- 취약성을 평가하고 우선순위화  <br>- 식별된 각 보안 결함의 근본 원인을 분석                                                             | - 지속적으로 취약점을 검색하고 대응하는 단계                                            |
