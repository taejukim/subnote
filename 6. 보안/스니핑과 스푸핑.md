#정보관리기술사 #보안 #스니핑 #스푸핑 #NEW
## 정의
스니핑(Sniffing) & 스푸핑(Spoofing)
- 스니핑: 네트워크상 타 시스템 간 패킷 교환을 도청·가로채는 공격 기법
- 스푸핑: 네트워크·웹 등에서 데이터를 위·변조해 정상 시스템으로 위장하는 해킹 기법
## 키워드
* MITM, ARP 캐시변조, MAC Address Table Overflow, Fail Safe, IP Forward, Ack Storm, RST
## 암기법
* 패액 / AIPD: 패시브·액티브 스니핑 / ARP·IP·DNS·Email 스푸핑
## 특징
- 수동/능동: 허브 환경 패시브 vs 스위치 환경 액티브(ARP 스푸핑 등)
- 계층성: L1~L4 도청·위변조·세션 탈취로 분류
- 상호의존: 스푸핑이 스니핑 전제, 세션 하이재킹은 둘 다 활용
- 목적 차이: 스니핑=정보 탈취, 스푸핑=위장·트래픽 유도
## 목적
- 로그인·금융 등 민감 패킷 탈취
- 신뢰 관계 위장으로 MITM·세션 가로채기
## 구성요소
- 스니핑 유형: Passive Sniffing, Active Sniffing
- 스푸핑 유형: ARP, IP, DNS, Email Spoofing
- 계층별 - L1: Switch Jamming, Port Mirroring, ARP Redirect/Spoofing
- 계층별 - L2: ICMP Redirect, IP Spoofing
- 계층별 - L3: Session Hijacking
- 계층별 - L4: DNS Spoofing
- 방어: VPN·HTTPS·TLS / ARP·DNS 보호·이메일 인증·방화벽
## 구성도
```
[스푸핑] 신뢰관계 위장 ──전제──→ [스니핑] 패킷 도청
         ↘                         ↙ Seq 획득
              [Session Hijacking]
           (TCP 3-Way Handshake 가로채기)
```
