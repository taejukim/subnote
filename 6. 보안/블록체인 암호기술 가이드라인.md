#정보관리기술사 #보안 #블록체인 #암호기술 #가이드라인 #NEW
## 정의
블록체인 암호기술 가이드라인
- 블록체인의 보안성·무결성 확보를 위해 사용되는 각종 암호 기술의 적용 기준·가이드
## 키워드
* 암호사용기준, 계정관리, 데이터전송보안, 합의프로토콜, 원장, 스마트컨트랙트, DB
## 암기법
* 계전합원스DB: 계정·전송·합의·원장·스마트컨트랙트·DB (+암호기준)
## 특징
- 다기술성: 다중·임계·은닉·환서명, ZKP, MPC 등 다양
- 검증성: KCMVP 검증대상 알고리즘 사용 권고
- 전주기: 계정·전송·합의·원장·계약·DB 전 구간 보안
- 무결성: 해시 체인·서명·재전송 방지로 원장 보호
## 목적
- 블록체인 솔루션의 암호 적용 기준 제시
- 보안성·무결성·신뢰성 확보
## 구성요소
- 주요 암호기술: 다중서명(Openchain), 임계서명(Libra), 은닉서명(Fabric), 환서명(CryptoNote)
- 주요 암호기술: 영지식증명(Zcash·Monero), 다자간계산(Enigma·Hawk), 비밀분산(SHARVOT), VRF(Algorand)
- 가이드① 암호 사용 기준: KCMVP 검증대상 알고리즘 사용
- 가이드② 계정 관리: 상호인증, 키쌍 안전생성·교체·폐기
- 가이드③ 데이터 전송 보안: 상호인증·전송 데이터 보호
- 가이드④ 합의 프로토콜: 보안·효율성 충족, 참여 노드 수 고려
- 가이드⑤ 원장: 식별자·서명·재전송방지, 이전 블록 해시·생성시각
- 가이드⑥ 스마트 컨트랙트: 실행결과 검증가능, 알려진 취약점 부재
- 가이드⑦ 데이터베이스: 일부 저장소 장애 시에도 기록 신뢰성 유지
## 구성도
```
[암호 사용 기준(KCMVP)]
        ↓
계정관리 → 전송보안 → 합의프로토콜
        ↓
   원장 ←→ 스마트컨트랙트 ←→ DB
```
