Cyber Deception
## 정의
- 사이버상의 공격자가 서버 또는 시스템을 공격할때 미끼(Decoy)를 이요하여 유인하는 함정

## 키워드
- 미끼(Decoy), 함정(Traps), 허니팟

## 사이버 디셉션 구성 요소

| 분류               | 구성요소                       |
| ---------------- | -------------------------- |
| Decoy(미끼)        | 쿠키, 서버 접근정보, 로그인정보, 자동생성기술 |
| Trap(함정)         | EndPoint, Network, OS      |
| Deception System | NW 탐지, 포렌식, User Interface |


## 사이버 디셉션과 허니팟(Honey Pot) 비교

| 구분   | 사이버디셉션            | 허니팟              |
| ---- | ----------------- | ---------------- |
| 대응범위 | 내,외부 접근           | 외부 접근            |
| 라이선스 | 라이선스 최소화          | 가상화 등 많은 라이선스 필요 |
| 오탐율  | 오탐율 최소화(제로화)      | 오탐지 높음           |
| 탐지방식 | 포괄적 탐지(자동화 구현/확장) | 로그분석 기반          |
| 확장   | 포괄적 배치            | 제한적 배치           |
