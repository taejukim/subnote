#정보관리기술사 #보안 #사이버레질리언스 #보안/사이버레질리언스
Cyber Resilience
## 정의
- 사이버 공간상에서 예상 밖의 위협들의 부정적인 영향에도 조직의 목표 성과(outcome)를 전달할 수 있는 기업 능력

## 키워드
- 성과전달(outcome), 기업능력(Ablilty), 비즈니스 영향 분석, 보안 정책 통제, 종합적 테스트 정책, 매니지드 보안 도구 설치, 사이버 복구 계획

## 사이버 레질리언스 구성요소
| **구성요소**          | **설명**                          |
| ----------------- | ------------------------------- |
| **비즈니스 영향 분석**    | - 위협 요인 분석 기반 우선순위 도출           |
| **보안 정책 통제**      | - 비즈니스 목적 설명 및 문서화를 통한 보안 기틀 마련 |
| **종합적 테스트 정책**    | - 지속적 테스트와 측정를 통한 보안 정책 검증      |
| **매니지드 보안 도구 설치** | - 비즈니스 이슈 관련 도구, 서비스에 대한 투자     |
| **사이버 복구 계획**     | - 보안 이슈 발생 대응절차 및 신속한 복구 계획     |
## 사이버 레질리언스 확보 단계
① 위협 평가 역량 확보 $\rightarrow$ ② 사이버 보안 방법 도입 $\rightarrow$ ③ 위험 기반 계획 $\rightarrow$ ④ 외부 위협으로부터 보호 $\rightarrow$ ⑤ 내부 위험 최소화 $\rightarrow$ ⑥ 보안 문화 유지

## 사이버 보안과 사이버 레질리언스 비교
| **비교 항목** | **사이버 보안(Cybersecurity)** | **사이버 레질리언스(Cyber Resilience)** |
| --------- | ------------------------- | ------------------------------- |
| **수행 대상** | - 알려진 위협으로부터 보호된 IT 시스템   | - 비즈니스 결과물(outcome) 전달 보장       |
| **목적**    | - 안전 장치(fail-safe)        | - 실패에도 안전(Safe-to-fail)         |
| **접근 방식** | - 외부로부터의 보안               | - 내부에서 보안 구축                    |
| **범위**    | - 단일 조직                   | - 조직 네트워크                       |
