# 1. BB84 프로토콜 개요

|구분|내용|
|---|---|
|정의|양자 키 분배 기반으로 양자의 물리적 특성을 이용해 도청 탐지와 안전한 키 분배를 수행하는 프로토콜|
|제안|Charles Bennett, Gilles Brassard (1984년)|
|목적|안전한 암호키 공유 및 도청 탐지|
|특징|양자 중첩, 측정 불확정성 기반 / 정보이론적 안전성 확보|

---

# 2. BB84 동작 절차

|단계|구분|설명|
|---|---|---|
|1|키 생성|Alice가 랜덤 비트 및 랜덤 기준(+, ×) 선택|
|2|전송|편광 상태 광자를 통해 Bob에게 전송|
|3|측정|Bob이 랜덤 기준으로 측정 수행|
|4|기준 비교|공개 채널로 기준 비교 후 일치 데이터 선택 (Sifting)|
|5|도청 검증|일부 비트 비교하여 오류율 확인|
|6|키 생성|검증된 비트로 최종 암호키 생성|

---

# 3. BB84 구성 요소

|구성요소|설명|
|---|---|
|Alice (송신자)|랜덤 비트 생성 및 양자 상태 인코딩|
|Bob (수신자)|랜덤 기준으로 측정|
|양자 채널|광자 전송 경로 (Fiber, Free-space)|
|고전 채널|기준 정보 교환 및 검증|
|Eve (공격자)|도청 시 양자 상태 변화 발생|

---

# 4. 보안 원리

|구분|내용|
|---|---|
|도청 탐지|불확정성 원리로 측정 시 상태 변화 발생|
|복제 방지|양자 복제 불가능 정리 적용|
|안전성|물리 법칙 기반 정보이론적 보안|
