#정보관리기술사 #보안 #ISO27701 #PIMS #NEW
## 정의
ISO 27701
- 개인정보 보호를 위한 ISO/IEC 27001·27002의 확장판으로, PIMS 요구사항과 가이드라인을 동시에 제공하는 표준
## 키워드
* PIMS, PII 통제자, PII 처리자, ISO 27001/27002, GDPR 매핑, SOA
## 암기법
* 범규용일요지통처: 범위·규범·용어·일반·요구·지침·통제자·처리자
## 특징
- 확장성: ISMS(27001)에 프라이버시(PIMS) 확장
- 이중성: 요구사항(5) + 지침(6) 동시 제공
- 역할 구분: PII 통제자(7, Annex A) / 처리자(8, Annex B)
- 매핑: 29100·GDPR·27018·29151 연계
## 목적
- 조직의 개인정보보호 요구사항·지침 체계화
- ISMS와 PIMS 통합 운영·인증 기반 마련
## 구성요소
- 1~4: 범위, 규범 참조, 용어·약어, 일반
- 5: 27001 관련 PIMS 요구사항
- 6: 27001 관련 PIMS 지침
- 7: PII 통제자용 27002 추가 지침
- 8: PII 처리자용 27002 추가 지침
- Annex A/B(Normative): 통제자·처리자 통제 목적·수단
- Annex C~F(Informative): 29100·GDPR·27018/29151 매핑, 적용 방법
- 점검: Scope → Gap Analysis → Control 구현 → SOA → 내부감사 → Audit Ready → Maintenance
