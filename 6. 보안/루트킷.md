#정보관리기술사 #보안 #루트킷 #보안/공격/위협
Rootkit
## 정의
- 최고 관리자 권한(Root)를 탈취해 시스템을 장악한 뒤, 탐지를 피해 숨어 지내며 해커에게 지속적인 불법 접근을 허용하는 악성 소프트웨어 모음

## 키워드
- 익명 네트워크, 랜섬웨어, 서비스

## 루트킷의 침투 매커니즘
![[Pasted image 20260409003136.png|600]]

|단계|동작원리|설명|
|---|---|---|
|초기침투|공격자, 악성코드|운영체제나 소프트웨어 취약점 또는 사회공학 기법 등으로 시스템에 침투. 사용자 모드에서 악성코드 실행 시작.|
|지속성 확보|**권한상승 (User Mode → Kernel Mode)**|악성코드가 제한된 사용자 권한을 넘어 커널 권한 획득 시스템의 핵심 부분에 접근 권한 상승|
|지속성 확보|**은닉 및 후킹(감시/변조)**|커널 모드에서 시스템 콜 테이블(SSDT, IDT) 등을 변조 루트킷 존재와 악성 행위 은폐, 탐지 회피|
|지속성 확보|**백도어 설치**|커널 모드에서 백도어 설치 (인증 없는 접속) 원격 접속 경로 확보 및 부팅 시 자동 실행|
|악성 공격 수행|**명령 및 제어 (C2, Command and Control)**|원격에서 명령을 내려 시스템 조작, 데이터 탈취, 네트워크 조정 등 다양한 악성 행위 수행|
|악성 공격 수행|은폐 유지 및 탈취|커널 수준 은폐 및 사용자 모드 활동 감시 회피 장기적으로 악성 행위를 은닉하며 시스템 자원 탈취|

## 루트킷(Rootkit)의 유형

|분류|유형|설명|
|---|---|---|
|실행 레벨|**사용자 모드 루트킷 (User-Mode Rootkit)**|Windows API 등을 후킹하여 특정 프로세스나 파일이 보이지 않게 조작하는 방식 (비교적 탐지 쉬움)|
|부팅 과정|**부트킷 (Bootkit) / MBR 루트킷**|운영체제가 로드되기 전 단계인 MBR이나 VBR을 감염시켜, OS를 재설치해도 지워지지 않는 강력한 지속성 확보|
|하드웨어|**펌웨어 루트킷 (Firmware Rootkit)**|메인보드의 BIOS/UEFI, 네트워크 카드, 하드디스크 펌웨어 자체에 기생하여 하드웨어 수준에서 악성 행위를 은폐|
|가상화|**하이퍼바이저 루트킷 (Hypervisor Rootkit)**|가상화 기술을 악용해 OS 자체를 가상 머신 위로 밀어내고, 그 아래 계층에서 하위 시스템을 완벽히 통제|

## 루트킷(Rootkit) 대응 방안

| 구분            | 대응방안                                  | 설명                                                                              |
| ------------- | ------------------------------------- | ------------------------------------------------------------------------------- |
| 보안 모니터링       | XDR (Extended Detection and Response) | 엔드포인트, 네트워크, 클라우드 등 다양한 데이터 소스를 통합해 위협을 신속하게 탐지 및 대응                            |
| 보안 모니터링       | 네트워크 트래픽 분석 (NTA)                     | 비정상 네트워크 흐름이나 통신 패턴을 분석                                                         |
| 보안 모니터링       | 로그 관리 및 분석 (SIEM)                     | 다양한 시스템 로그를 수집, 상관 분석                                                           |
| 위협 인텔리전스      | CTI (Cyber Threat Intelligence)       | 최신 멀웨어 위협 동향과 공격 정보 수집·분석                                                       |
| 위협 인텔리전스      | 위협 헌팅 (Threat Hunting)                | 능동적으로 시스템을 탐색하여 알려지지 않은 멀웨어 위협을 찾아내는 활동                                         |
| 위협 인텔리전스      | MITRE ATT&CK 프레임워크                    | 공격자 행위 기반 위협 기법 체계화                                                             |
| AI 기반 침해사고 대응 | 이상행위 탐지 (UEBA, AI/ML 기반)              | 사용자, 엔드포인트 등의 행위 데이터를 AI가 분석                                                    |
| AI 기반 침해사고 대응 | SOAR                                  | 보안정보 자동화, AI 기반 의사결정 지원 및 신속 대응 (Security Orchestration, Automation & Response) |
| AI 기반 침해사고 대응 | 자동화된 위협 분석 및 분류                       | AI가 멀웨어 샘플 및 행동 분석을 자동 수행해 빠른 대응과 차단 가능                                         |
