## 정의
페르소나 (Persona)
- 제품·서비스를 사용할 목표 인구 집단 내 다양한 사용자 유형을 대표하는 가상의 인물
- 사용자 중심 설계를 위한 분석 모형
## 키워드
* 사용자 분석, 사용자 범주, 기간구조, 페르소나 평가, 프로파일
## 암기법
* 범단세기우평프: 범주 파악 → 단서분류 → 세부·기간구조 → 평가·우선순위 → 작성 → 평가 → 프로파일
## 특징
- 페르소나: 대표 가상인물 기반 분석
- 인지: 시스템 인지 방식 분석
- 역할: 사용 형태·관계 분석
- 사회기술: 조직 특성 중심 분석
## 목적
- 목표 사용자 유형을 구체화해 요구·UX 설계 기준 제공
- 이해관계자 간 사용자 이미지 공유
## 구성요소
- 사용자 범주 파악: 주요 사용자군 식별
- 주요 단서분류: 행동·니즈 단서 정리
- 기간구조 잡기: 세부 범주·프레임워크
- 우선순위 선정: 기간구조 평가
- 페르소나·프로파일 작성: 설문 기반 상세 프로필
