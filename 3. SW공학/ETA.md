#정보관리기술사 #SW공학 #ETA #위험분석 #NEW
## 정의
ETA(Event Tree Analysis)
- 초기 이벤트로부터 모든 사건의 발생 확률을 산출하여 최종 사고 시나리오의 총 발생 확률을 도출하는 정량적 위험분석 기법
- 성공/실패 분기로 사건 트리를 전개해 사고 경로를 파악
## 키워드
* Event Tree, 초기이벤트, 중간이벤트, 성공/실패, 사고시나리오, 정량분석
## 암기법
* 범위초트결경: 범위정의-위험정의-초기이벤트-트리전개-결과리스크-경감대책
## 특징
- 사건 기반: 초기→중간→결과로 시나리오 전개
- 정량성: 분기 확률로 최종 사고 확률 산출
- 상향 전파: 원인(초기)에서 결과로 전개(Bottom-up 성격)
- FTA/FMEA 연계: FTA(연역)·FMEA(귀납)과 상호 보완
## 목적
- 초기 사건에서 대형 사고로 이어지는 경로·확률 파악
- 위험 경감·예방 대책 수립
## 구성요소
- 범위·위험 정의: 분석 대상·사고 정의
- 초기 이벤트: 트리 시작점
- 중간 이벤트: 성공/실패 분기
- 결과·시나리오: 결과1~n 사고 경로
- 경감 대책: 리스크 저감·예방 조치
## 구성도
```
[초기이벤트]─→[이벤트1]─성공/실패─→[이벤트2]─→[이벤트3]
                    └──────── 사고 시나리오 → 결과1~5
절차: 범위→위험→초기→트리전개→결과리스크→경감
```
## 연관 토픽
- [[FTA]] - 연역(결과→원인)
- [[FMEA]] - 귀납(원인→영향)
- [[HAZOP]] - 탐색적 위험식별
- [[STPA]] - 시스템이론 기반 분석
