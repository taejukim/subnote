#정보관리기술사 #SW공학 #테스트오라클 #테스트 #NEW
## 정의
테스트 오라클(Test Oracle)
- 수행된 테스트 결과가 기대 결과인지 판단·분석하는 메커니즘
- 기대값 생성·비교로 Pass/Fail을 결정하는 기준
## 키워드
* 참 오라클, 샘플링 오라클, 휴리스틱 오라클, 일관성 검사, AI 테스트
## 암기법
* 참샘휴일: 참·샘플링·휴리스틱·일관성 검사
## 특징
- 완전 검증형: 참 오라클은 모든 입력에 기대결과 생성
- 표본 검증형: 샘플링은 특정 입력만 검증
- 추정 보완형: 휴리스틱은 표본+추정으로 확장
- 회귀 비교형: 일관성 검사는 이전·현재 결과 비교
## 목적
- 테스트 결과의 정합성·기대부합 여부 판정
- 회귀·자동화 테스트에서 판정 기준 제공
## 구성요소
- 참 오라클: 모든 입력의 기대결과 생성, 누락 없이 오류 탐지
- 샘플링 오라클: 특정 입력만 기대결과 제공(예: sin 0·90·180…)
- 휴리스틱 오라클: 특정 입력은 정확, 나머지는 추정으로 보완
- 일관성 검사 오라클: 수정 전후 결과 일치 여부(상용 자동화·회귀)
- AI 한계: 명세 불완전, 비정형 입력, 자가학습, 비결정성, 복잡성
- AI 블랙박스: 조합·백투백·A/B·변성·탐색적 테스트
## 구성도
```
[입력] → [SUT 실행] → [실제결과]
                ↓
         [Test Oracle] ← 기대결과/휴리스틱/이전결과
                ↓
           Pass / Fail
유형: 참 | 샘플링 | 휴리스틱 | 일관성 검사
```
