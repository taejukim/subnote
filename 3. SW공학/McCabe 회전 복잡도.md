#정보관리기술사 #SW공학 #McCabe #복잡도 #NEW
## 정의
McCabe 회전 복잡도(Cyclomatic Complexity)
- 제어 흐름 그래프의 회전(사이클로매틱) 수를 구해 SW 논리 복잡도를 계산하는 방법
- 독립 경로 수·최소 테스트 케이스 규모 산정에 활용
## 키워드
* V(G)=e-n+2, 폐구간+1, 의사결정+1, CFG, 경로커버리지
## 암기법
* 이엔투 / 폐일 / 결일: e-n+2, 폐구간+1, 결정점수+1
## 특징
- 그래프 기반: 노드·간선으로 복잡도 정량화
- 다중 공식: e-n+2, 폐구간+1, 결정+조건+1 동등
- 등급 해석: ≤5 단순, 5~10 안정, ≥20 과도 복잡
- 테스트 연계: 독립경로=최소 경로 테스트 수
## 목적
- 프로그램 논리 복잡도 측정
- 경로 커버리지용 최소 테스트 케이스 규모 산정
## 구성요소
- Node(노드): 코드 블록 실행 단위
- Edge(간선): 노드 간 제어 흐름
- Decision: if/while/case 등 분기점
- Condition: and/or/not 등 조건
- V(G): e-n+2 = 폐구간+1 = 의사결정(+조건)+1
## 구성도
```
V(G)=e-n+2 = 폐구간+1 = 결정(+조건)+1
복잡도: ≤5 단순 | 5~10 안정 | ≥20 과도복잡
예) while+if+case0+case1 → 결정4 → V(G)=5
```
