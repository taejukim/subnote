#정보관리기술사 #SW공학 #TestProcess #IEEE829 #NEW
## 정의
Test Process
- 테스트 계획부터 오류 추적·수정까지 수행하는 표준화된 테스트 절차
- IEEE 829 기반 문서화와 산출물 중심의 5단계 프로세스
## 키워드
* 계케실결오, IEEE 829, 테스트 계획, 테스트케이스, 결함추적
## 암기법
* 계케실결오: 계획·케이스설계·실행측정·결과분석·오류추적
## 특징
- 단계 완결성: 계획→설계→실행→분석→수정 일관 흐름
- 산출물 중심: 단계별 명세·보고서 명확
- 표준 정합성: IEEE 829 테스트 문서 체계
- 피드백성: 결함 수정 후 재검토로 품질 폐쇄
## 목적
- 체계적 테스트로 결함 조기 발견·추적
- 테스트 활동의 재현성·감사 가능성 확보
## 구성요소
- 테스트 계획: 요구정의·계획수립·검토 → Test Plan
- TC 설계: 기법정의·케이스도출·Raw Data
- 실행·측정: 환경구축·실행 → 측정결과
- 결과 분석·보고: 분석·보고 → 결과보고서·상태보고
- 오류 추적·수정: 원인분석·수정계획·수정·사후검토
## 구성도
```
테스트 계획 → TC 설계 → 실행·측정 → 결과 분석·보고 → 오류 추적·수정
 (Plan)      (Cases)    (Measure)     (Report)         (Fix/Track)
```
