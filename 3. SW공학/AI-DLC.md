#정보관리기술사 #SW공학 #AIDLC #SDLC #NEW
## 정의
AI-DLC(AI-Driven SDLC)
- AI Agent 중심 협업으로 SW 개발 생명주기를 재구성한 방법론
- AI가 주도하고 사람이 검증하는(AI leads, Human verifies) 개발 패러다임
## 키워드
* AI-Centric, Intent, Unit, Bolt, 대화 방향 역전
## 암기법
* 착구운: Inception·Construction·Operations
## 특징
- 3단계: Inception(착수), Construction(구축), Operations(운영)
- Intent→AI Draft→Human Review→Implementation→Verification
- Unit(DDD Sub-domain), Bolt(최소 반복 단위≈Sprint)
## 목적
- 계층적 업무 분해·Context 보존
- AI 가속 + Human 통제
## 구성요소
- Inception: Intent, PRFAQ, User Story, NFR
- Construction: Design, Code, Test, Bolt 단위
- Operations: Deploy, Observability, Feedback
- 핵심: Hierarchical Inception, Context Preservation, External Context
## 구성도
```
Intent → AI Draft → Human Review → Implement → Verify → Shared Memory
Inception | Construction(Bolt) | Operations
```
