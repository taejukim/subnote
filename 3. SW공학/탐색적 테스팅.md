## 정의
탐색적 테스팅(Exploratory Testing)
- 학습(Learn)·테스트 설계(Design)·실행(Execute)을 동시에 수행하며 테스터의 경험·직관으로 결함을 찾는 경험기반 테스트
- 사전 완전 스크립트보다 실시간 가설·차터(Charter) 기반으로 탐험하는 동적 접근
## 키워드
* Exploratory Testing, Session-based, Charter, 경험기반, Scripted 대비
## 암기법
* "동학실" - 동시 학습·설계·실행, 세션 기반, 스크립트와 대비
## 특징
- 동시 수행: 제품 이해, 테스트 아이디어 생성, 실행·관찰을 한 흐름에서 진행
- 세션 기반(SBTM): 시간 상자(Time-box)·차터·노트·디브리프로 탐색을 구조화
- 적응성: 발견에 따라 다음 탐험 경로를 즉시 조정(휴리스틱·오라클 활용)
- 스크립트 대비: 재현·자동화에 강한 Scripted vs 미지 결함·사용성·리스크 탐지에 강한 Exploratory
## 목적
- 명세 공백·예상 밖 동작·사용 시나리오 기반 결함의 조기 발견
- 리스크 높은 영역에 대한 집중 탐색과 테스트 아이디어 확장
## 구성요소
- Charter: 세션 목표·범위·초점(무엇/왜/주의점)
- Session: Time-box 내 탐험·기록(노트, 이슈, 질문, 아이디어)
- Debrief: 결과 공유, 리스크·후속 세션 우선순위 조정
- Oracle/Heuristic: 기대 결과 판단 기준과 탐험 전략(경계, 상태, 사용자 여정 등)
## 구성도
```
        ┌─────────────────────────────────┐
        │     Exploratory Testing Loop    │
        │  Learn ←→ Design ←→ Execute     │
        │         (동시·반복)              │
        └──────────────┬──────────────────┘
                       │
         ┌─────────────┼─────────────┐
         ▼             ▼             ▼
     [Charter]    [Session]     [Debrief]
      목표·범위    Time-box       공유·후속
                   노트·이슈
                       │
        Scripted: 사전 TC → 실행 → 결과 기록 (재현·자동화↑)
        Exploratory: 가설 탐험 → 발견 적응 (미지 결함↑)
```
