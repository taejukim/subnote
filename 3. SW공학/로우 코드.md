#정보관리기술사 #SW공학 #로우코드 #LowCode
## 정의
로우 코드(Low-Code)
- 최소한의 코딩으로 시각적 모델링·드래그&드롭 등으로 애플리케이션을 빠르게 개발할 수 있는 플랫폼·방법론
- 시민 개발자(Citizen Developer)와 전문 개발자가 협업하여 생산성을 높이는 차세대 개발 방식
## 키워드
* No-Code, Citizen Developer, Visual Modeling, Drag & Drop, RAD, 시민개발자
## 암기법
* 시드재: 시각적·드래그&드롭·재사용
## 특징
- 시각적 개발성: 코드 대신 시각적 모델 활용
- 빠른 배포성: 프로토타이핑·MVP에 적합
- 시민 개발 친화성: 비개발자 참여 가능
- 통합 친화성: 외부 API·DB 손쉬운 연결
## 목적
- 개발 생산성 향상과 IT 적체 해소
- 비개발자 포함 다양한 협업으로 비즈니스 민첩성 확보
## 구성요소
- 비주얼 IDE: GUI 기반 화면·로직 설계
- 컴포넌트 라이브러리: 재사용 가능한 UI/로직
- 데이터 통합: API 커넥터, DB 연결, 워크플로우
- 거버넌스: 권한·배포·버전·감사
- 대표 도구: OutSystems, Mendix, PowerApps, Salesforce Lightning
## 구성도
```
[시민/전문 개발자] → [비주얼 IDE]
       ↓ 컴포넌트·커넥터·워크플로우 조합
[로우코드 플랫폼] → 자동 코드 생성·빌드 → 배포
       ↑ 거버넌스·보안·통합 ↑
```
