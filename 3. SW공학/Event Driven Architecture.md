#정보관리기술사 #SW공학 #EDA #이벤트기반 #NEW
## 정의
Event Driven Architecture
- 데이터 생성·변경·삭제 등 상태 변화에 반응하여 서비스가 동작하는 소프트웨어 아키텍처
- 이벤트 발행·구독 기반의 느슨한 결합 구조
## 키워드
* 이벤트 프로듀서, 이벤트 채널, 이벤트 처리 엔진, 다운스트림 활동, Broker/Bus
## 암기법
* 프처엔다: 프로듀서 → 채널 → 처리엔진 → 다운스트림 활동
## 특징
- 확장성: 성능보다 확장·복합 이벤트 처리에 적합
- 병렬 처리: 다수 서브시스템이 동일 이벤트 동시 처리
- 비동기: 채널 큐잉 후 엔진에서 처리
- Pub/Sub: 구독 기반 소비자 분리
## 목적
- 서비스 간 결합도를 낮추고 확장·병렬 처리 용이성 확보
- 상태 변화 중심으로 비즈니스 반응을 구성
## 구성요소
- 이벤트 프로듀서: 이벤트 감지·메시지로 표현 후 채널 전달
- 이벤트 채널: 큐 저장·비동기 전달(Router/Broker/Bus)
- 이벤트 처리 엔진: 이벤트 식별·비즈니스 로직 반응
- 다운스트림 활동: 알림·경고 등 결과 표현
## 구성도
```
[Producers] --이벤트--> [Router/Broker/Bus] --이벤트--> [Consumers]
 Web/Mobile/Retail         ^ 구독                    Inventory/Order/Payment
```
