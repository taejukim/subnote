## 정의
위험 기반 테스트(Risk-Based Testing)
- 위험을 측정해 우선순위가 높은 영역에 한정된 테스트 자원을 집중하는 전략
- 전체 영향(리스크)을 줄이기 위해 테스트 순서를 설계
## 키워드
* 테스트 자원 한정, STA, STTA, ITA, FTA, 리스크 매트릭스
## 암기법
* 식분대계분: 식별·분석·대응·계획·분석/모니터링
* N자(사업): STA→STTA→ITA→FTA / S자(기술): STA→ITA→STTA→FTA
## 특징
- 자원 집중성: 고위험 영역에 우선 투입
- 매트릭스 기반: 발생가능성×영향도로 4영역 분류
- 이중 경로성: 사업(N)·기술(S) 관점 순서 상이
- 계획 연계성: Exit Criteria·인력·일정과 결합
## 목적
- 한정 자원으로 핵심 리스크 최소화
- 테스트 우선순위·범위의 합리적 결정
## 구성요소
- 위험 식별: 항목별 위험·테스트 아이템 도출
- 위험 분석: 가능성·영향 평가 및 우선순위화
- 위험 대응 계획: STA/STTA/ITA/FTA 분류
- Test 계획: 종료조건·인력·일정·자원
- 분석/모니터링: Low/High Level 테스트 수행
- STA: 고가능·고영향(반드시 테스트)
- ITA: 고가능·저영향 / STTA: 저가능·고영향(테스트 권장)
- FTA: 저가능·저영향(생략 가능)
## 구성도
```
가능↑  ITA(집중)     | STA(심각)
성     Item2,5       | Item15
      ---------------+---------------
      FTA(기본)      | STTA(강력)
      Item4          | Item7
      ----------------→ 영향도
절차: 식별→분석→대응→계획→분석/모니터링
```
