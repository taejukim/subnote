#정보관리기술사 #SW공학 #EU디지털3법 #DSA_DMA_DGA
## 정의
유럽 디지털 3법
- 유럽연합이 디지털 시장·서비스·데이터 규율을 위해 제정한 3대 핵심 입법: 디지털시장법(DMA), 디지털서비스법(DSA), 데이터거버넌스법(DGA)
- 글로벌 빅테크 규제·이용자 보호·데이터 공유 활성화를 위한 EU 통합 규제 프레임워크
## 키워드
* DMA, DSA, DGA, Gatekeeper, Very Large Online Platform, 데이터 중개
## 암기법
* 시서데: 디지털시장(DMA)·서비스(DSA)·데이터(DGA)
## 특징
- 통합 규제성: 시장·서비스·데이터 통합 규율
- 빅테크 표적성: Gatekeeper 의무 부과
- 이용자 보호성: 불법 콘텐츠·다크 패턴 규제
- 데이터 공유성: 데이터 중개·이타주의 활성화
## 목적
- 디지털 시장 공정성·경쟁성 확보
- 이용자·소비자 보호와 데이터 활용 활성화
## 구성요소
- DMA(Digital Markets Act): Gatekeeper 지정·금지·의무 행위 규제
- DSA(Digital Services Act): 불법 콘텐츠·VLOP 투명성·이용자 보호
- DGA(Data Governance Act): 데이터 중개 서비스, 데이터 이타주의, 공공 데이터 재사용
- 적용 대상: 글로벌 빅테크 플랫폼, EU 내 디지털 서비스 제공자
- 위반 제재: 매출의 일정 비율 과징금, 시정명령
## 구성도
```
[DMA] 시장 공정성 (Gatekeeper)
   +
[DSA] 서비스 안전성 (콘텐츠·이용자 보호)
   +
[DGA] 데이터 거버넌스 (중개·이타주의·재사용)
   = 통합 EU 디지털 규제 프레임워크
```
