## 정의
리뷰(Review)
- 요구명세·설계·코드 등 중간산출물을 실행하지 않고 검토하는 핵심 정적 테스트 기법
- 개발 초기에 결함을 발견·예방하여 후반 비용 증가를 억제
## 키워드
* 비공식 리뷰, 기술 리뷰, 워크쓰루, 인스펙션, Fagan Inspection
## 암기법
* 계시사미RF: 계획·시작·사전검토·미팅·Rework·Follow-up
* 관중기작검: 관리자·중재자·기록자·작성자·검토자
## 특징
- 정적성: 실행 없이 산출물 검토
- 형식 다양성: Informal·Technical·Walkthrough·Inspection
- 조기 개입성: 요구·설계 단계 집중 투입이 효과적
- 역할 분화성: 중재자·기록자·작성자·검토자 등 역할 분리
## 목적
- 조기 결함 발견으로 테스트·수정 비용 절감
- 산출물 품질·완전성 확보 및 지식 공유
## 구성요소
- 계획: 참여자·역할·대상 선정, 진입/종료 기준(공식)
- 시작: 문서 배포·절차 설명, 진입 기준 확인
- 사전검토: 개별 결함·질의·의견 기록
- 리뷰 미팅: 결함 확정·처리방안, 회의록
- Re-Work: 발견된 결함 수정
- Follow-Up: 수정 확인, 메트릭·종료 기준 점검
- 참여자: 관리자, 중재자, 기록자, 작성자, 검토자
## 구성도
```
계획 → 시작 → 사전검토 → 리뷰 미팅 → Re-Work → Follow-Up
[형식] Informal / Technical Review / Walkthrough / Inspection
[Fagan] 요구·설계에 숙련 인력 집중(약 15% 비용) → 후반 공수 감소
```
