#정보관리기술사 #SW공학 #품질속성시나리오 #비기능요구 #NEW
## 정의
소프트웨어 품질 속성 시나리오
- SW 비기능 요구사항을 시스템·이해관계자 상호작용으로 표현하는 시나리오 기반 요구 도출 기법
- 품질속성을 측정·검증 가능한 형태로 구체화
## 키워드
* 자극유발원, 자극, 환경, 대상, 응답, 응답측정
## 암기법
* 자자환대응측: 자극유발원, 자극, 환경, 대상, 응답, 응답측정
## 특징
- 자극유발원: 사람·시스템·장치
- 자극: 시스템 반응을 유발하는 조건
- 환경: 정상·과부하 등 발생 상황
- 응답측정: 검증 가능한 정량 결과
## 목적
- 비기능 요구를 모호하지 않게 명세
- 아키텍처 평가·테스트 가능한 품질 목표 제시
## 구성요소
- 자극 유발원(Source): 자극을 만드는 존재
- 자극(Stimulus): 반응 원인 조건
- 환경(Environment): 자극 발생 시 시스템 상태
- 대상(Artifact): 자극을 받는 시스템/일부
- 응답(Response): 도달 후 동작
- 응답 측정(Response Measure): 측정 가능 결과값
## 구성도
```
[자극유발원] --자극--> [대상체] --응답--> (응답측정)
                        [환경]
예) 외부시스템 / 예기치못한메시지 / 정상운영 / 프로세스
    → 운영자통지후계속 / 정지수없음(가용성)
```
