#정보관리기술사 #SW공학 #UtilityTree #품질속성 #NEW
## 정의
유틸리티 트리 (Utility Tree)
- 품질 특성 기준으로 시나리오를 작성하는 분석법 또는 그 구조
- SW 아키텍처 품질 평가에서 시나리오 우선순위를 도출
## 키워드
* 유틸리티, 품질속성, 세분화 품질속성, 시나리오, 우선순위, Bottom-up
## 암기법
* 유품세시: 유틸리티 → 품질속성 → 세분화 품질속성 → 시나리오
## 특징
- 참여자: 아키텍트·PL, 평가자 2~3명
- 목표: 품질속성 요구 도출·구체화·우선순위
- 접근: 부분→전체 Bottom-up, MECE Tree
- vs 브레인스토밍: Top-down, 전원 합의·적합성 검증
## 목적
- 품질속성 시나리오를 체계적으로 도출·우선순위화
- ATAM 등 아키텍처 평가 입력 준비
## 구성요소
- 유틸리티: 최상위 품질 목표
- 품질속성: 성능·확장성·신뢰성 등
- 세분화 품질속성: 세부 측정 관점
- 시나리오: 구체적 자극·응답 서술
## 구성도
```
유틸리티
├─ 성능 ─ 메시지속도 / 데이터지연 → 시나리오
├─ 확장성 ─ 동시연결 / 서버자원 → 시나리오
└─ 신뢰성 ─ 보장전달 → 시나리오
```
