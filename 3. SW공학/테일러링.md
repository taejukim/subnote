#정보관리기술사 #SW공학 #테일러링 #표준프로세스 #NEW
## 정의
테일러링 (Tailoring)
- 조직의 표준 프로세스를 커스터마이징하여 프로젝트 요구에 맞는 적합한 프로세스를 얻는 과정
- 표준과 프로젝트 특성 간 간극을 맞추는 프로세스 조정
## 키워드
* 표준 프로세스, 커스터마이징, 프로젝트 프로파일, WBS, 테일러링 메트릭스
## 암기법
* 특선상세문: 특징 정의 → 선정·검증 → 상위 커스터마이징 → 세부 커스터마이징 → 문서화
## 특징
- 관리: How-To-Do 제시, 지속적 개선
- 기술: 최적 기술·방법론 도출, 최신 기술 수용
- 프로젝트 측면: 규모·기간, 조직원 경험, 위험수준
- 기술 측면: 기술혁신, 데이터전환, 시스템연계, 분산시스템
## 목적
- 프로젝트에 최적화된 프로세스·방법론 적용
- 표준 준수와 현장 적합성의 균형 확보
## 구성요소
- 프로젝트 특징 정의: 프로젝트 프로파일
- 표준 프로세스 선정·검증: 선정·검증 산출물
- 상위 수준 커스터마이징: 생명주기, WBS
- 세부 커스터마이징: 테일러링 메트릭스, 프로젝트 WBS, 산출물 구성도, 스케줄
- 문서화: WBS 테일러링 근거, 적용 결과서
## 구성도
```
특징정의 → 선정·검증 → 상위커스텀 → 세부커스텀 → 문서화
 (프로파일)  (표준검증)   (LC/WBS)    (메트릭스·WBS)  (근거·결과서)
```
