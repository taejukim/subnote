#정보관리기술사 #SW공학 #디지털성숙도 #DigitalMaturity
## 정의
디지털 성숙도(Digital Maturity)
- 조직·기업이 디지털 기술을 활용하여 업무 프로세스·조직 문화·고객 경험·비즈니스 모델을 혁신적 수준으로 발전시킨 정도
- DX(디지털 트랜스포메이션) 추진 현황을 단계별로 측정·평가하는 지표
## 키워드
* DX, Maturity Model, KPI, 디지털 전략, BMC, 데이터 기반 의사결정
## 암기법
* 프조고비: 프로세스·조직·고객·비즈니스
## 특징
- 단계 평가성: 초보~선도 단계 등급화
- 다차원성: 기술·조직·문화·비즈니스 종합 평가
- 진단성: AS-IS 식별과 격차 분석
- 로드맵 기반성: 목표 단계 진화 경로 제시
## 목적
- 조직의 디지털 역량 객관 진단과 강·약점 식별
- DX 우선순위·투자 방향 의사결정 지원
## 구성요소
- 평가 영역: 전략·조직·프로세스·기술·데이터·문화·고객
- 성숙도 단계: 초기 → 도입 → 확산 → 최적화 → 혁신/선도
- 모델: TM Forum, Gartner, MIT, KISA 디지털 성숙도 모델
- 절차: 진단 → 평가 → 갭 분석 → 로드맵 수립 → 실행 → 재평가
## 구성도
```
[Lv1 초기] 단편 IT
   ↓
[Lv2 도입] 부분 디지털화
   ↓
[Lv3 확산] 전사 표준화
   ↓
[Lv4 최적화] 데이터 기반 운영
   ↓
[Lv5 선도] AI·자율·혁신 비즈니스 모델
```
