#정보관리기술사 #SW공학 #LoD #최소지식 #NEW
## 정의
데메테르의 법칙 (Law of Demeter)
- 객체는 주변 객체에 대해 제한된 정보만 갖고, 자신과 밀접한 객체만 이용해야 한다는 설계 원칙
- 최소지식의 원칙(Principle of Least Knowledge), 느슨한 결합 유도
## 키워드
* 최소지식의 원칙, loose coupling, Friend, Stranger, 메소드 호출 범위
## 암기법
* Don't talk to strangers: 친구의 친구는 낯선 자
* 자신·인자·생성객체·컴포넌트·전역만 호출
## 특징
- Friend만 메시지 허용, Stranger 직접 호출 지양
- 결합도 감소, 변경 영향 범위 축소
- this/파라미터/생성객체/소유 컴포넌트/접근가능 전역만 호출
- A→B OK, A→C(via B) discouraged
## 목적
- 객체 간 불필요한 의존성 최소화
- 유지보수성과 캡슐화 강화
## 구성요소
- 객체 자체: this.method()
- 메소드 변수: 파라미터 객체의 메소드
- 메소드 내 생성 객체: 지역 생성 객체 메소드
- 직접 관리 컴포넌트: 소유 필드 객체의 메소드
- 스코프 내 전역 변수: 접근 가능한 전역 객체 메소드
## 구성도
```
[A] --friend--> [B] --friend--> [C]
 |                |
 | Messages OK    | C = stranger to A
 +----X----------> [C]  (discouraged)
```
