#정보관리기술사 #SW공학 #규모산정 #비용산정 #NEW
## 정의
SW 규모산정
- SW의 양적 규모·질적 수준을 파악해 소요공수·투입자원·기간을 산정하고 실행 가능한 계획을 수립하는 비용 추정 활동
- 하향식·상향식·수학적 방식으로 규모·원가를 도출
## 키워드
* 하향식, 상향식, 수학적산정, LOC, FP, COCOMO, 전문가감정, 델파이
## 암기법
* 하상수 / 프자생: 하향·상향·수학 / 프로젝트·자원·생산성 요소
## 특징
- 하향식: 전체 시스템·유사사업 기반, 단순·신뢰감 / 비과학·낙관
- 상향식: 모듈별 합산(WBS), 객관성 / 세부 난이도 누락 가능
- 수학적: FP·COCOMO로 정량·자동화
- 다요소 고려: 프로젝트·자원·생산성 요인 반영
## 목적
- 실행 가능한 공수·자원·일정·비용 계획 수립
- 발주·계약·대가산정의 기초 규모 제공
## 구성요소
- 하향식: 전문가 감정, 델파이
- 상향식: LOC, Man/Month, WBS 합산
- 수학적: Function Point, COCOMO
- 고려요소: 복잡도·크기·신뢰도 / 인력·HW·SW / 개발자·고객·방법론
## 구성도
```
[규모산정]
 ├─하향식: 전문가·델파이 (전체→부분)
 ├─상향식: LOC·M/M (부분합→전체)
 └─수학적: FP·COCOMO (정량모델)
고려: 프로젝트·자원·생산성
```
