#정보관리기술사 #SW공학 #ISO14764 #유지보수 #NEW
## 정의
ISO/IEC/IEEE 14764
- ISO/IEC 12207 유지보수 프로세스를 6단계로 상세화한 S/W 유지보수 표준 프로세스
- 변경유형·기법까지 포함한 유지보수 생명주기 지침
## 키워드
* 수정·적응·완벽·예방, 재공학, 역공학, 재구조화, 유지보수 프로세스
## 암기법
* 공문수유이폐: 공정구현·문제수정분석·수정구현·검토승인·이전·폐기
* 수적완예: 수정·적응(반응) / 완벽·예방(순향)
## 특징
- 12207 상세화: 유지보수를 6단계로 구체화
- 이원 분류: Reactive(수정·적응) / Proactive(완벽·예방)
- 기법 지원: 이해·재공학·역공학·재구조화
- 이전·폐기 포함: 마이그레이션·Retirement까지 범위
## 목적
- 유지보수 활동의 표준화·체계화
- 변경 유형별 적절한 대응·기법 적용
## 구성요소
- 공정구현: 계획·절차·문서·형상관리 수립
- 문제·수정분석: 유형·범위·중요도(성능·안전·보안)
- 수정구현: 분석·설계·구현·테스트로 변경 반영
- 검토/승인: 무결성 검토·정식 승인
- 이전(Migration): 계획·통지·병행운영·데이터 관리
- SW 폐기: 소유자 요청 기반 Retirement
- 기법: Program Understanding, Re-engineering, Reverse Engineering, Restructuring
## 구성도
```
공정구현 → 문제·수정분석 → 수정구현 → 검토/승인
                ↓                        ↓
            [Migration]              [SW Retirement]
분류: Reactive(Corrective, Adaptive)
      Proactive(Perfective, Preventive)
```
