#정보관리기술사 #SW공학 #CBAM #비용효용 #NEW
## 정의
CBAM (Cost Benefit Analysis Method)
- 아키텍처 접근법별 시나리오 효용을 이익·비용으로 분석해 가장 비용 효율이 높은 방법을 선정하는 평가 프레임워크
- ATAM 시나리오를 경제적 관점으로 확장
## 키워드
* 비용 효율, 2단계 반복, 효용-반응 곡선, 불확실성, ROI
## 암기법
* 시효이RO: 시나리오 결정 → 효용-반응곡선 → 이익 계산 → ROI·선정
## 특징
- 2단계 반복: 1차 접근법 우선순위, 2차 위험·불확실성·자원 재평가
- 효용-반응 곡선: W/C/E/D/B로 응답수준↔효용 시각화
- 불확실성 고려: 이해관계자 경험 기반 추정 오차 반영
- ROI로 아키텍처 접근법 순위 결정
## 목적
- 품질 향상과 비용 간의 트레이드오프 정량화
- 비용 대비 효용이 최대인 아키텍처 전략 선정
## 구성요소
- 시나리오 결정: 수집·정제(B/W/C/D)·우선순위(상위 1/2, 가중치)
- 효용-반응 곡선 작성: 4값 기반 곡선 추정
- 이익 계산: 예상 반응값·효용·가중 전체 이익
- 접근법 선정: ROI 계산·순위, 비용·일정 고려 검증
## 구성도
```
경영목표 → 전략 ┬→ QA(성능·보안·사용성…) → 이익
                └→ 비용 ←── 차이 극대화 ──┘
Utility: W→C→E→D→B  (vs QA Response Level)
```
