#정보관리기술사 #SW공학 #디자인패턴 #싱글턴
## 정의
싱글턴 패턴(Singleton Pattern)
- 클래스 인스턴스를 단 하나만 생성하도록 보장하는 생성 디자인 패턴
- 전역 접근 지점을 제공하여 자원·설정을 공유 관리
## 키워드
* GoF, 생성 패턴, Lazy/Eager Initialization, DCL, Enum Singleton, Thread-Safe
## 암기법
* 유전자: 유일성·전역접근·자원절약
## 특징
- 유일성: 인스턴스 1개만 보장
- 전역 접근성: 어디서든 동일 인스턴스 사용
- 자원 절약: 중복 생성·메모리 낭비 방지
- 동기화 필요성: 멀티스레드 환경에서 동시성 제어 필수
## 목적
- 설정·로깅·DB 커넥션 풀 등 공통 자원 통합 관리
- 인스턴스 일관성 보장과 메모리 사용 최소화
## 구성요소
- Private 생성자: 외부 인스턴스 생성 차단
- Static 인스턴스 변수: 단일 인스턴스 보관
- Public 정적 메서드: getInstance() 진입점
- 구현 방식: Lazy, Eager, Double-Checked Locking, Enum
## 구성도
```java
public class Singleton {
  private static Singleton instance;
  private Singleton() {}
  public static Singleton getInstance() {
    if (instance == null) instance = new Singleton();
    return instance;
  }
}
```
