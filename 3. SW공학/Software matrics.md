#정보관리기술사 #SW공학 #SoftwareMetrics #품질지표
## 정의
Software Metrics
- SW 개발·유지보수 과정에서 품질·성능·생산성 등을 정량적으로 측정·평가하는 지표
- 객관적 데이터로 프로세스·제품 품질을 관리하기 위한 기준
## 키워드
* LOC, Cyclomatic Complexity, Function Point, Halstead, Code Coverage, Defect Density
## 암기법
* 품성생: 품질·성능·생산성
## 특징
- 정량성: 수치 기반 객관적 측정
- 다면성: 프로세스·제품·프로젝트 측면 포괄
- 추세성: 시계열 비교로 개선 추적
- 표준 연계성: ISO/IEC 25010 품질 특성과 매핑
## 목적
- 객관적 품질·생산성 측정 기반 의사결정
- 결함 조기 식별과 프로세스 개선
## 구성요소
- 규모/복잡도: LOC, Cyclomatic Complexity, Function Point, Halstead Metrics
- 품질: Code Coverage, Defect Density, MTTR
- 프로젝트: Effort, Schedule Variance, Burn-down Chart
- 측정 프로세스: 품질 요구사항 설정 → Metrics 식별 → 자료 수집 → 계산 → 결과 분석 → 검증
- ISO 25010 연계: 기능 적합성, 신뢰성, 사용성, 효율성, 유지보수성, 이식성, 보안성, 호환성
## 구성도
```
요구사항 정의 → 측정 항목 식별 → 자료 수집 → 계산·분석 → 검증·환류
                       ↘ ISO 25010 8대 품질특성 매핑 ↙
```
