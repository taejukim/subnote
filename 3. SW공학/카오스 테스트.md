#정보관리기술사 #SW공학 #테스트 #카오스테스트
## 정의
카오스 테스트(Chaos Test)
- 의도적으로 장애를 주입하여 시스템 신뢰성·회복력을 검증하는 시험 기법
- 분산·클라우드 환경의 잠재 결함을 사전에 발견하기 위한 능동 테스트
## 키워드
* Chaos Engineering, 장애 주입, 가설 기반, Resilience, Auto Rollback
## 암기법
* 정실장결수: 정상수립·실험·장애주입·결과분석·수정
## 특징
- 능동성: 장애를 의도적으로 발생시켜 검증
- 가설 기반성: 정상 상태 기준 가설 수립 후 실험
- 회복력 지향성: MTTR 단축, 자가복구 검증
- 점진성: Blast Radius 통제로 위험 최소화
## 목적
- 분산 시스템의 잠재 장애 시나리오 사전 식별
- 장애 대응·복구 절차의 실효성 검증
## 구성요소
- 절차: 정상 상태·가설 수립 → 실험 설계 → 장애 주입 → 결과 분석 → 수정·보완
- 기술요소: System Call, [[Traffic Shaping]], Bytecode Injection
- Memory Hog, 시계열 분석, Kill SW, Auto Rollback
- 도구: Chaos Monkey, Gremlin, LitmusChaos
## 구성도
```
정상 상태 정의 → 가설 수립 → 장애 주입(네트워크/CPU/Pod kill)
   → 모니터링 → 결과 분석 → 시스템 보강
```
