#정보관리기술사 #SW공학 #FunctionPoint #FP #NEW
## 정의
Function Point(기능점수)
- 정보처리 규모와 기능 복잡도 요인에 근거한 SW 규모 산정 방식
- 미조정 FP에 조정인자를 반영해 조정 기능점수를 산출(ISO 14143-1)
## 키워드
* EI, EO, EQ, ILF, EIF, UFP, VAF, ISO 14143-1
## 암기법
* 유범이의 데트: 유형-범위-데이터-트랜잭션(+미조정-조정인자-조정FP)
## 특징
- 기능 중심: LOC가 아닌 사용자 관점 기능 규모
- 5기능: ILF·EIF(데이터) + EI·EO·EQ(트랜잭션)
- 조정: 14개 일반시스템특성(0~5)으로 VAF 반영
- 측정유형: 개발·개선·어플리케이션
## 목적
- SW 규모를 기능 단위로 객관적 산정
- 개발비·생산성·계약 규모 산정의 기초 제공
## 구성요소
- 측정유형: 개발 / 개선 / 어플리케이션
- 범위·경계: 측정범위, 어플리케이션 경계
- 데이터기능: ILF(내부논리파일), EIF(외부연계파일)
- 트랜잭션: EI(입력), EO(출력·파생처리), EQ(조회)
- 산식: FP = 미조정FP × 조정상수(VAF)
- 조정인자14: 통신·분산·성능·사용환경·처리율·온라입력·편리성·온랭신·복잡성·재사용·설치·운영·복수사이트·변경용이
## 구성도
```
유형결정→범위·경계→데이터기능→트랜잭션기능
         →미조정FP→조정인자→조정FP
데이터: ILF, EIF | 트랜잭션: EI, EO, EQ
```
