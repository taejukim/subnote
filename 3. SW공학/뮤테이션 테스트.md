## 정의
뮤테이션 테스트(Mutation Test)
- 소스 구문을 규칙에 따라 변형한 뒤, 동일 입력에서 원본과 다른 결과를 내는 TC를 선정하는 결함 기반 테스트
- 테스트케이스의 결함 탐지 능력을 뮤턴트로 검증
## 키워드
* 정상 코드, 뮤턴트, 테스트케이스 검증, 의도적 소스 변경, 뮤턴트 점수
## 암기법
* 대변삭: 대치·변형(치환)·삭제 연산자
## 특징
- 결함 주입성: 의도적으로 돌연변이 코드 생성
- TC 품질 측정: R1≠R2인 TC만 유용한 케이스로 채택
- 연산자 다양성: 대치·변형·삭제로 결함 유형 모사
- 정량 지표성: Mutant Score로 스위트 강도 평가
## 목적
- 테스트 스위트의 결함 탐지력 향상
- 약한 테스트케이스 식별·배제
## 구성요소
- 정상 코드 / 돌연변이 코드(뮤턴트)
- 비교: R1=R2 → TC 제외, R1≠R2 → TC 포함(killed)
- 대치: 상수·변수·상수↔변수 대치
- 변형/치환: 입출력·서비스 순서·속성 변경
- 삭제: Cast·Overload·반환문 등 삭제
- 점수: MS=죽은 뮤턴트/(전체−동등 뮤턴트)
## 구성도
```
입력 a ─┬→ 정상코드 → R1
        └→ 뮤턴트코드 → R2
              ↓
        R1=R2: TC 제외 / R1≠R2: TC 포함
MS(P,T) = Killed / (Total − Equivalent)
```
