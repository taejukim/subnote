#정보관리기술사 #SW공학 #APIGateway #MSA #NEW
## 정의
API Gateway
- 클라이언트가 요청한 API를 내부에서 처리 가능한 형태로 변환·전달하는 Gateway
- MSA에서 단일 진입점(Proxy) 역할
## 키워드
* 프록시, 프로토콜 변환, 보안(인증·로깅), 라우팅, 마이크로서비스
## 암기법
* 보라프기: 보안, 라우팅, 프로토콜변환(+오케스트레이션·디스커버리·통계)
## 특징
- 보안: 암호화, 접근통제, 로깅·모니터링
- 서비스 연결: 요청 변환, 백엔드 결과 반환
- 라우팅·LB: 엔드포인트 매칭, 부하분산
- Mediation: HTTP/JSON 등 프로토콜 변환
## 목적
- 클라이언트와 다수 마이크로서비스 간 결합 완화
- 인증·라우팅·변환을 중앙에서 일원화
## 구성요소
- 보안: 인증·인가(토큰), SSL, 로그
- 라우팅: 서비스 매칭, 로드밸런싱
- Mediation: 프로토콜 변환
- 기타: 오케스트레이션, 서비스 디스커버리, 서비스 통계
## 구성도
```
[Mobile]┐
        ├→ [API Gateway: Security|Routing|Protocol] → MS#1/DB
[Web]───┘                                          → MS#2/DB
                                                   → MS#3/DB
```
