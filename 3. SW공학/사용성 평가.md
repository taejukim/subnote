#정보관리기술사 #SW공학 #사용성평가 #UX #NEW
## 정의
사용성 평가
- 사용자가 실제 제품을 사용하는 과정을 관찰·분석하여 효율성·학습용이성·문제점·개선요구를 발견하는 공학적 테스트
- UX 리서치 방법론에 기반한 질적·양적 평가
## 키워드
* UX 리서치, SUS, 편의성, 정확성, 만족도, 탐색·평가·검증·비교 테스트
## 암기법
* 계설실분: 계획-설계-실행-분석보고 / 탐평검비: 탐색·평가·검증·비교
## 특징
- 사용자 관찰: Verbal·행동 관찰로 문제 도출
- 4유형: 탐색(초반 컨셉)·평가(효율)·검증(표준)·비교(대안)
- 다지표: 작업시간·패턴·정확성·완성도·학습·일관성
- 산출물: 계획서·설계서·Raw Data·결과보고서
## 목적
- 제품 효율성·학습용이성·사용 문제 발견
- 개선 요구사항 도출 및 사용성 보증
## 구성요소
- 절차: 계획수립→평가설계→평가실행→분석/보고
- 유형: 탐색적(페이퍼목업), 평가(정량과업), 검증(속도·정확·선호), 비교(대안I/F)
- 지표: 작업시간, 사용패턴, 정확성, 완성도, 학습용이성, 일관성
## 구성도
```
[계획]→[설계]→[실행]→[분석/보고]
유형: 탐색(초반) | 평가(초중) | 검증(후반) | 비교(전구간)
```
