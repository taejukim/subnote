#정보관리기술사 #SW공학 #테스트 #백투백테스트
## 정의
백투백 테스트(Back-to-Back Test)
- 두 개 이상의 서로 다른 구현·시스템에 동일 입력을 실행, 출력 일치 여부를 비교 검증하는 테스트 기법
- 모델·SW·HW 단계를 동일 명세로 검증하는 안전 중심 테스트
## 키워드
* MIL/SIL/HIL, ASIL, 명세 기반, 자동차 안전, 회귀 비교
## 암기법
* 동일출신: 동일입력·일치출력·신뢰성·안전
## 특징
- 신뢰성: 동일 입력 동일 출력으로 일관성 검증
- 안전 지향성: ASIL 등 Safety Critical 요구 충족
- 명세 기반성: 설계 명세를 단일 기준으로 비교
- 자동화성: 회귀·변경 검증에 효과적
## 목적
- Safety Critical 시스템의 기능적 일치성 보장
- 설계·구현 단계 간 결과 불일치 조기 검출
## 구성요소
- 절차: 준비 → 설계 → 테스트(MIL·SIL·HIL) → 검토·보고
- MIL(Model-in-the-Loop): 모델 단계 검증
- SIL(SW-in-the-Loop): SW 코드 단계 검증
- HIL(HW-in-the-Loop): 실차·HW 통합 검증
- 비교: A/B 테스트(사용자 반응 비교)와 구분
## 구성도
```
명세 → [구현 A] → 출력 A
        ↓ 동일 입력
명세 → [구현 B] → 출력 B  → 결과 비교(일치성 검증)
```
