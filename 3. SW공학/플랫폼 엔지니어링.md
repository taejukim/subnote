#정보관리기술사 #SW공학 #플랫폼엔지니어링 #PlatformEngineering
## 정의
플랫폼 엔지니어링(Platform Engineering)
- 여러 애플리케이션·서비스를 지원하고 수명주기를 관리하기 위한 SW 플랫폼을 설계·구축하여 개발자에게 제공하는 엔지니어링
- 내부 개발자 플랫폼(IDP)을 통해 개발자 생산성·인지부하 최소화를 추구하는 방식
## 키워드
* IDP(Internal Developer Platform), Golden Path, Self-Service, DevEx, Backstage
## 암기법
* 셀골인: 셀프서비스·골든패스·인지부하
## 특징
- 셀프서비스성: 개발자 자율적 환경 구성
- 표준화성: 골든 패스로 일관된 개발 흐름
- 추상화성: 인프라 복잡성 은닉
- 측정 가능성: DevEx·개발 생산성 KPI 관리
## 목적
- 개발자 생산성·만족도 향상과 인지부하 최소화
- DevOps·NoOps 진화를 위한 표준 플랫폼 제공
## 구성요소
- 내부 개발자 플랫폼(IDP): Backstage, Port, Humanitec
- 골든 패스(Golden Path): 표준화된 권장 워크플로우
- 셀프서비스 포털: 환경·리소스 자율 프로비저닝
- 추상화 계층: K8s·IaC·CI/CD 통합 추상화
- 관측성·DevEx 측정: SPACE·DORA 지표
## 구성도
```
[개발자] → [Self-Service Portal]
            ↓ 골든 패스
[Internal Developer Platform (IDP)]
            ↓ 추상화
[K8s · CI/CD · IaC · Observability · 보안]
```
