## 정의
릴리즈 엔지니어링(Release Engineering)
- 개발 과정의 신뢰성·효율성을 추구해 안정적·예측 가능한 배포·구현·개선 방법을 연구하는 SW 엔지니어링
- 배포·구현·유지보수를 파이프라인으로 체계화하는 활동
## 키워드
* 배포·구현·유지보수, 파이프라인, CI/CD, IaC, 자동화
## 암기법
* 통지빌아배릴: 통합·CI·빌드·IaC·배포·릴리즈
## 특징
- 파이프라인성: 통합부터 사용자 공개까지 단계화
- 자동화 중심성: 사람 개입 최소화 배포
- 환경 일관성: IaC로 테스트·배포 환경 재현
- 피드백 순환성: 릴리즈 결과 분석으로 지속 개선
## 목적
- 안정적·예측 가능한 소프트웨어 배포 실현
- CI/CD·모니터링으로 릴리즈 품질·속도 향상
## 구성요소
- 통합: 브랜칭·병합(Git, SVN)
- 지속적 통합(CI): 자동 빌드·초기 테스트(Jenkins, Bamboo, TFS)
- 빌드 시스템: 바이너리·패키지 명세(Make, Ant, Maven, CMake)
- IaC: 환경 자동 구성(Puppet, Chef, Ansible, Docker)
- 배포: Blue/Green, Canary, A/B Test
- 릴리즈: DNS 변경·스토어 게시로 사용자 공개
- 역할: CI/CD 구축, 배포 자동화, 설정 관리, 모니터링·분석
## 구성도
```
Code → VCS(통합) → CI(빌드/테스트) → Build System
                         ↓
                   Artifact Repo
                         ↓
              Test Env(IaC/Docker) → Production Deploy → User Release
                         ↑________________ Feedback ________________↓
```
