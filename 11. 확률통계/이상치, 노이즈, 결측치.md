#확률통계 #데이터전처리 #이상치 #필수 #확률통계/데이터전처리
## 정의
데이터 품질을 저해하는 비정상 데이터 유형, Outlier/Noise/Missing Value
- 이상치: 기준에서 벗어난 값, 특이 패턴 탐지 대상
- 노이즈: 불규칙하고 무의미한 오류 값
- 결측치: 수집되지 않거나 누락된 데이터
## 키워드
* Z-Score, IQR, Boxplot, KNN, DBSCAN, 평균대체, 삭제법, 보간법
## 암기법
* "이노결" - 이상치(탐지), 노이즈(제거), 결측치(대체)
## 구성요소/특징/유형
| 구분 | 설명 | 처리방법 |
| ---- | ---- | ---- |
| 이상치 | 데이터 분포에서 크게 벗어난 값 | Z-Score, IQR, DBSCAN |
| 노이즈 | 불규칙 오류 값, 센서 오작동 등 | 필터링, 평활화 |
| 결측치 | 수집 누락 데이터 | 삭제, 평균대체, 보간 |
## 시험 대비 (2교시) — 이상치·편향 문항

**1분 정의**
> 이상치 = 데이터 분포에서 **극단적으로 벗어난 개별 관측값**

**탐지 → 처리**
| 단계 | 방법 |
|------|------|
| 탐지 | **IQR**(Q1−1.5×IQR ~ Q3+1.5×IQR), **Z-Score**(|Z|>3), **Boxplot** |
| 처리 | 삭제, **Winsorizing**, Log 변환, **Robust 모델**(Random Forest 등) |

**분석 결과 영향**
- 대표 지표(평균·표준편차) 왜곡
- 가짜 상관관계, 회귀선·예측 모델 왜곡

**금지·주의**
- ⚠️ 이상치 **무조건 삭제 X** — fraud·품질 이상 **신호**일 수 있음
- [[편향(Bias)]]과 혼동 X — 이상치=**개별값**, 편향=**전체 분포·수집 체계**
- ⚠️ 「이상치·편향 영향 동일」 X — **영향 범위가 다름**

**1분 답안 골격**
1. 개념 + 산점도
2. 영향(지표·모델 국소 왜곡)
3. 탐지(IQR, Z) → 처리
4. [[편향(Bias)]]과 비교(수준·탐지 난이도)
