## 정의
- 평균을 중심으로 종모양의 좌우 대칭인 분포로 평균과 분산(또는 표준편차)에 따라 분포의 위치와 모양이 결정되는 [[확률 분포]]

## 키워드
- 확률 변수, 종모양, 표준편차, 평균 분산, 분산, 표준 정규 분포, Z값

### 정규분포(Normal Distribution)의 정의
$$X \sim N(\mu, \sigma^2)$$ 
$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)}$$
### 경험적 규칙 (The Empirical Rule)

- **표준편차 $\pm 1\sigma$ 범위 내:** 전체 데이터의 약 **68.3%** 존재
- **표준편차 $\pm 2\sigma$ 범위 내:** 전체 데이터의 약 **95.5%** 존재
- **표준편차 $\pm 3\sigma$ 범위 내:** 전체 데이터의 약 **99.7%** 존재
## 특징
| **구분**     | **특징 구분**   | **상세 특징 설명**                                                                                                                             |
| ---------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **모양 특징**  | **분포 모양**   | - 평균을 중심으로 좌우 대칭인 종모양 형태<br>- 모양과 위치는 평균($\mu$)과 표준편차($\sigma$)에 의해 결정<br>- 평균($\mu$)에서 확률 밀도 곡선의 높이가 가장 큼                               |
|            | **분포 폭**    | - 표준편차($\sigma$)에 의해 결정, 곡선의 모양의 변화<br>- 표준편차가 클수록 곡선은 평평해지고 작을수록 높아짐                                                                    |
|            | **분포 위치**   | - 평균($\mu$)에 의해 결정, 곡선의 대칭축 이동                                                                                                           |
|            | **곡선**      | - 평균에서 멀어질수록 x축에 무한히 접근하지만, x축에 닿지 않음                                                                                                    |
| **확률적 특징** | **표기**      | - $X \sim N(\mu, \sigma^2)$ ($X$: 확률변수, $\mu$: 평균, $\sigma$: 표준편차, $\sigma^2$: 분산)                                                       |
|            | **넓이**      | - 정규곡선과 X축 사이의 전체 면적은 **1**                                                                                                              |
|            | **평균**      | - 평균 값이 최대값<br>- **평균 = 중앙값 = 최빈값** 모두 동일                                                                                                |
|            | **확률변수**    | - 확률변수($X$)가 취할 수 있는 값은 $-\infty < X < \infty$                                                                                           |
|            | **확률값**     | - **68 - 95 - 99.7 규칙** 적용<br>- 경험규칙: 정규분포를 따르는 관측 데이터의 대부분(99.7%)이 평균으로부터 $\pm 3\sigma$ 내에 존재                                           |
|            | 확률밀도함수(PDF) | $$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)}$$<br>(단, $-\infty < x < \infty$, $e \approx 2.71828$) |
