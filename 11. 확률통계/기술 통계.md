## 정의
기술 통계(Descriptive statistics)
- 주어진 표본 자체의 속성을 정량적으로 기술·요약하는 데 초점을 두는 데이터 분석 통계
## 키워드
* 중심경향값, 변산도, 분포, 히스토그램, 상자수염그림, 산점도
## 암기법
* 중변분 / 히상산: 중심·변산·분포 / 히스토그램·상자·산점
## 특징
- 표본 요약 중심 (모수 추론이 아님)
- 수치 요약 + 시각화 병행
## 목적
- 표본의 중심·산포·분포 형태를 요약·표현
## 구성요소
- 중심경향: 평균·중위수·최빈값
- 변산도: 최대·최소·범위, 분산·표준편차
- 분포: 왜도·첨도
- 시각화: 히스토그램(빈도), 상자수염(사분위·이상치, IQR), 산점도(두 변수 관계)
## 구성도
```
기술통계
 ├─ 요약: 중심 / 변산 / 분포(왜·첨)
 └─ 시각화: Histogram / Boxplot / Scatter
```
