#정보관리기술사 #확률통계 #표본추출 #확률통계/데이터전처리
## 정의
### 확률 추출
- 모집단의 모든 요소가 동일한 확률로 표본으로 선택될 기회를 갖는 방법
### 비확률 추출
- 모집단의 요소들이 동일한 확률로 선택되지 않는 방법

## 암기법
- 확률 추출
	- 단층계집(단순 확률 추출, 층화 확률 추출, 계통 추출, 집락(군집)추출)
- 비확률 추출
	- 눈편할유판(눈덩이 추출법, 편의 표출, 할당 추출, 유의 추출법, 판단추출법)
## 키워드
- 확률 추출, 비확률 추춘

## 확률 추출
| **방법**                                      | **설명**                                                                                                |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **단순확률 추출**<br>(Simple Random Sampling)     | - 모집단을 구성하는 요소 하나 하나가 뽑힐 확률이 동일한 상황에서 뽑는 방법 (기본이 되는 추출법)<br>예) S대학 1000명 중 100명을 난수를 이용해 추출           |
| **층화확률 추출**<br>(Stratified Random Sampling) | - 모집단을 먼저 서로 겹치지 않는 여러 개의 층으로 분할한 후, 각 층별로 단순 임의 추출법을 적용시켜 표본을 얻는 방법<br>예) A레스토랑 만족도 조사 위해 손님 연령대별 추출 |
| **계통 추출**<br>(Systematic Sampling)          | - 모집단의 추출 틀에서 $k$번째 간격마다 하나씩 표본으로 추출<br>예) A레스토랑 만족도 조사하기 위해 손님 표본 추출 ($k=3$)                         |
| **집락(군집) 추출**<br>(Cluster Sampling)         | - 서로 인접한 기본 단위들로 구성된 군집을 만들고, 추출된 군집 내의 일부 또는 전체를 조사<br>예) A레스토랑 만족도 조사 위해 손님 거주 지역별 추출               |

## 비확률 추출
| **방법**                                     | **설명**                                                                                                                                   |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **눈덩이 추출법**<br>(Snowball Sampling)         | - 소수의 응답자를 찾은 다음 이들과 비슷한 사람들을 소개받아가는 식으로 표본을 추출하는 방법                                                                                     |
| **편의 표출**<br>(Convenience Sampling)        | - 모집단에 대한 정보가 전혀 없는 경우, 표본 선정의 편리성에 기준을 두고 조사원이 마음대로 선정하는 방법<br>- 연구자가 이용 가능한 대상을 임의로 선택                                                 |
| **할당 추출**<br>(Quota Sampling)              | - 모집단이 여러 특성으로 구성되어 있는 경우, 각 특성에 따라 층을 구성한 다음 조사원이 그 층 내에서 직접 선정하여 조사<br>- 확률적 근거 없이 임의로 연구자가 표본을 분류하여 추출                                |
| **유의추출법 (포커스 그룹)**<br>(Purposive Sampling) | - 모집단 특성에 대해 조사원이 정확히 알고 있는 경우에 제한적으로 사용되는 방법<br>- 조사자의 풍부한 경험을 활용하여 주관적 판단에 따라 표본을 추출<br>예) S전자는 새로운 휴대폰 개발 위해 소비자 10명을 추출하여 아이디어 회의 진행 |
| **판단추출법**<br>(Judgement Sampling)          | - 조사원이 자신의 지식과 경험에 의해 모집단을 가장 잘 대표한다고 여겨지는 표본을 주관적으로 판단하여 추출하는 방법<br>- 일반적으로 표본의 크기가 아주 작은 경우에 사용                                        |
