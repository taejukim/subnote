#정보관리기술사 #자료구조 #이진탐색트리 #자료구조/트리
## 정의
- 이진탐색(Binary Search)과 연결 리스트(Linked List)를 결합한 자료구조
- 이진 탐색의 효율적인 탐색 능력을 유지하면서, 빈번한 입력과 삭제라 가능하드록 고안된 자료 구조
- 작은 값은 왼쪽 큰 값은 오른쪽에 위치하는 규칙을 가진 트리

## 키워드
- 이진 탐색, 재귀

## 개념도
![[Pasted image 20260323234038.png|500]]
-  이진탐색 트리는 아래의 성질을 만족함
	- 각 노드의 좌측 서브 트리에는 해당 노드의 값보다 작은 값을 지닌 노드들로 구성
	- 각 노드의 우측 서브 트리에는 해당 노드의 값보다 큰 값을 지닌 노드들로 구성
	- 중복되 노드가 없음
	- 좌측 서브 트리와 우측 서브 트리도 모두 이진 탐색 트리

 ■ 이진 탐색 트리(BST) 검색 원리

이진 탐색 트리 순회 시 **중위순회(in-order)** 방식을 사용하면 모든 값들을 **정렬된 순서대로** 읽을 수 있습니다.
이진 탐색 트리에서 키 $x$를 가진 노드를 검색 시
1. 트리에 해당 노드가 존재 시 해당 노드 리턴, 미 존재 시 **NULL** 리턴
2. 검색 값을 루트 노드와 먼저 비교, 일치하면 루트 노드 리턴
3. **불일치 & (검색 값 < 루트 노드 값) :** 좌측 서브 트리에서 재귀적 검색
4. **불일치 & (검색 값 $\ge$ 루트 노드 값) :** 우측 서브 트리에서 재귀적 검색
    
**예) 10 탐색 시**
1. 루트 노드(7), 10 비교 ($10 > 7$, 좌측 서브 트리(1, 3, 5)는 탐색 제외)
2. 우측 서브 트리의 루트 노드(8)과 10 비교 ($10 > 8$)
3. 우측 서브 트리의 루트 노드(10)과 10 원하는 값 찾음
### 전위 순회
먼저 출력하고 왼쪽, 오른쪽 트리 순회
### 후위 순회
순회하고 마지막에 출력
