#정보관리기술사 #자료구조 #선형자료구조와비선형자료구조 #자료구조/선형구조
## 정의
- 데이터 사이의 대응 구조에 따라 선형, 비성현 자료 구조로 분류
## 키워드
- 선형자료 구조 (Array, Linked List, Stack(LIFO), Queue(FIFO))
- 비선형자료구조(트리, 그래프)

# ■ 선형 자료구조

```

┌───┬───┬───┬───┬───┬───┐
│ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │
└───┴───┴───┴───┴───┴───┘
자료 순차 배열

```

| 구분     | 내용                                                    |
| ------ | ----------------------------------------------------- |
| **정의** | 데이터를 저장하는 방식이 데이터와 데이터를 **1:1 대응 구조로 관계로 저장**시키는 자료구조 |
| **특징** | - 구조가 간단 - access 속도가 빠름                              |
  
| 유형               | 개념도                                                           | 설명                                                                                     |
| ---------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **Array**        | `[0][1][2][3][4][5]`<br>`\|1\|2\|3\|4\|5\|6\|`                | 같은 데이터형의 요소들이 동일한 크기로 순서를 갖고 순차적으로 나열되어 있는 자료구조                                        |
| **Linked List**  | `[1]→[2]→[3]`                                                 | 각 노드가 데이터와 포인터를 가지고 한 줄로 연결되는 방식으로 데이터를 저장하는 자료구조                                      |
| **Stack (LIFO)** | `후입선출`<br>`ESP→\|Buffer\|`<br>`EBP→\|이전함수의EBP\|`<br>`\|RET\|` | 모든 원소들의 삽입과 삭제가 리스트의 한쪽 끝에서만 수행되는 제한 조건을 가지는 선형 자료 구조. **먼저 들어온 데이터가 나가는 자료구조 (LIFO)** |
| **Queue (FIFO)** | `전단(Front)→[1][2][3][4][5][6]←후단(Rear)`<br>`→ 데이터 삽입 방향 →`    | 선형리스트의 한쪽에서는 삽입, 다른 한쪽에서는 삭제되도록, **먼저 들어온 데이터가 먼저 나가는 자료구조**                           |

# ■ 비선형 자료구조  
```

(1)───(3)

│

(2)

```

|        | 내용                                        |
| ------ | ----------------------------------------- |
| **정의** | 데이터를 저장하는 방식이 데이터와 데이터를 1:N 또는 M:N 구조로 관계 |
| **특징** | - 자료 간의 관계를 표현<br>- 1:N, M:N 구조를 형성       |
  
| 유형        | 개념도                                                                                      | 설명                                                                                                       |
| --------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Tree**  | `(3)` ← 1 level<br>`/ \`<br>`(2) (5)` ← 2 level<br>`/ \ / \`<br>`(1)(4)(6)(3)` ← 3 level | 노드들이 나무 가지처럼 연결된 비선형 계층적 자료구조. 그래프의 일종으로, 한 노드에서 시작해서 다른 정점들을 순회하여 자기 자신에게 돌아오는(**순환이 없는**) **연결 그래프**   |
| **Graph** | `(A)───(C)`<br>`│ │`<br>`(B) (D)`                                                        | 정점(Vertex)의 집합 V와 간선(Edge)의 집합으로 구성된 비선형 데이터 구조. 정점의 집합을 V, 간선의 집합을 E, 그리고 그래프를 G라고 했을 때, **G = (V, E)** |
