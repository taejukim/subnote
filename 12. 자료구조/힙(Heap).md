#정보관리기술사 #자료구조 #힙 #자료구조/트리
## 정의
- 여러 개의 노드들 가운데서 가장 큰 키 값을 가지는 노드나 가장 작은 키 값을 가지는 노드를 빠른 시간 내에 찾아 내도록 만들어진 자료 구조
## 키워드
- 완전 이지 트리, 최대 힙(Max-Heap), 최소 힙(Min-Heap)

| **구분**    | **최대 힙 (Max-Heap)**                                                                                                                        | **최소 힙 (Min-Heap)**                                                                                                     |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **개념**    | - 완전 이진 트리이며, 한 노드의 키 값이 자손 노드들의 키 값보다 **크거나 같음**<br>![[Pasted image 20260323234920.png\|300]]<br>- 루트에 항상 가장 큰 값이 위치하므로 **우선순위 큐** 구현에 적합 | - 완전 이진 트리이며, 한 노드의 키 값이 후손 노드들의 키 값보다 **작거나 같음**<br>- 루트에 항상 가장 작은 값이 위치함<br>![[Pasted image 20260323234942.png\|300]] |
| **노드 특징** | 자손 노드보다 큰 값                                                                                                                                | 자손 노드보다 작은 값                                                                                                            |
|           |                                                                                                                                            |                                                                                                                         |
