#정보관리기술사 #AI #KMeansClustering
## 정의
K-Means Clustering(K-평균 군집화)
- N개 데이터를 K개 군집으로 분할하는 거리 기반 비지도 학습 알고리즘
- 중심값(Centroid) 갱신을 반복하여 군집 내 분산을 최소화
## 키워드
* K(군집수), Centroid, 유클리디안 거리, 비지도 학습, Elbow Method, DBSCAN 비교
## 암기법
* 군중할갱: 군집수 → 중심결정 → 할당 → 갱신
## 특징
- 단순성: 알고리즘 구조와 구현이 단순
- 확장성: 대규모 데이터 처리에 빠른 결과 산출
- 한계: K 사전 결정 필요, 노이즈/이상치에 민감
- 대안: 밀도 기반 DBSCAN과 보완적 사용
## 목적
- 고객 세분화·이미지 양자화 등 군집 기반 분석 자동화
- 대규모 데이터의 유사 그룹 탐색을 위한 빠른 클러스터링
## 구성요소
- 군집 수 K, 초기 Centroid
- 거리 함수: 유클리디안
- 갱신 규칙: 평균 이동
- 평가지표: SSE, Silhouette
- 비교 알고리즘: DBSCAN(밀도), 계층적 군집
## 구성도
```
데이터 → K 결정 → Centroid 초기화 → 군집 할당 → Centroid 갱신 → (수렴 시) 종료
K-Means(거리·구형 가정) ↔ DBSCAN(밀도·임의 형태)
```
