## 정의
정규화·규제화·표준화
- 정규화(Normalization): 특성 간 스케일 차이를 맞추기 위해 데이터를 특정 범위로 변환
- 표준화(Standardization): 평균 0·표준편차 1의 표준정규분포로 변환하는 전처리
- 규제화(Regularization): 손실함수에 페널티 항을 더해 과적합을 막는 기법
## 키워드
* Min-Max Scaling, Z-score Scaling, Overfitting, Penalty Term, L1(Lasso), L2(Ridge)
## 암기법
* 표입정입규가: 표준화·정규화=입력데이터 / 규제화=모델가중치
## 특징
- 정규화: $x_{new}=(x-x_{min})/(x_{max}-x_{min})$, 이상치에 취약, 거리기반 알고리즘에 유리
- 표준화: $x_{new}=(x-\mu)/\sigma$, 큰 스케일 지배 완화·학습속도 향상
- 규제화: $J(w)=MSE+\lambda\|w\|^2$ (Ridge 예), 모델 복잡도 제어
## 목적
- 입력 스케일 통일로 학습 안정·속도 개선
- 모델 복잡도 제어로 일반화 성능 향상
## 구성요소
| 구분 | 표준화 | 정규화 | 규제화 |
|------|--------|--------|--------|
| 대상 | 입력 데이터 | 입력 데이터 | 모델 가중치 |
| 목적 | 평균0·분산1 | 특정 구간(보통 0~1) | 과적합 방지 |
| 대표 | Z-score | Min-Max | L1, L2 |
| 효과 | 경사하강 속도↑, 이상치 영향↓ | 거리기반 성능↑ | 일반화↑ |
## 구성도
```
[입력 스케일링] 정규화(Min-Max) / 표준화(Z-score)
[모델 제약]     규제화(L1/L2) → 손실 + λ·||w|| → 과적합 억제
```
