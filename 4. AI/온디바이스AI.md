#정보관리기술사 #AI #온디바이스AI #OnDeviceAI
## 정의
온디바이스 AI(On-Device AI)
- 스마트폰·노트북·웨어러블 등 개별 디바이스 내부에서 AI 연산을 수행하는 단말 내장형 AI
- NPU·AI 가속기 기반 경량 모델로 데이터 외부 전송 없이 추론하는 방식
## 키워드
* NPU, sLLM, 모델 경량화, 오프라인 추론, 저전력, 프라이버시
## 암기법
* 단저프: 단말처리·저지연·프라이버시
## 특징
- 단말 내 처리: 디바이스 내부 NPU에서 추론
- 즉시성: 네트워크 지연 없는 실시간 처리
- 프라이버시 강화: 데이터 단말 보관·외부 전송 차단
- 저전력성: 모델 경량화·HW 가속 최적화
## 목적
- 오프라인·즉각 응답이 필요한 모바일 AI 서비스 구현
- 개인정보 노출 위험 최소화
## 구성요소
- 모델 경량화: 양자화, Pruning, 지식증류, sLLM
- HW 가속기: NPU, 모바일 GPU, AI 칩
- 실시간 처리: TFLite, ONNX Runtime, Core ML
- 적용 분야: 스마트폰 음성인식, 이미지 변환, 개인화 AI 서비스
- [[엣지 AI]] 비교: 단말 내 처리 vs 엣지 서버 근접 처리
## 구성도
```
[단말기 내부]
센서 → NPU/AI 칩 → 경량 모델 추론 → 결과 출력
   ↑ 데이터 외부 전송 없음 (프라이버시 보호)
```
