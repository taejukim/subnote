## 정의
프롬프트 엔지니어링(Prompt Engineering)
- 컴퓨터와 상호작용하는 사용자를 위한 AI 인터페이스 개발 분야로 높은 수준의 결과물을 얻기 위해 적절한 프롬프트를 구성하는 작업·엔지니어링 기법
## 키워드
* 생성형AI, Task Description, Input Indicator, Output Indicator, Zero-shot Prompting
## 암기법
* 태인커아 제원퓨C: Task·Input·Current·Output / Zero·One·Few·CoT / ToT·SelfConsistency·Meta
## 특징
- 구조화성: Task·Input·Output Indicator로 프롬프트 정형화
- 예시 기반성: Zero/One/Few-Shot으로 예제 밀도 조절
- 추론 강화성: CoT·ToT·Self Consistency로 단계적 추론
- 가이드 의존성: 구체·닫힌 지시문과 예제 품질이 결과 좌우
## 목적
- LLM으로부터 의도한 고품질·형식 일치 응답 확보
- 상황 설명과 답변 형식을 명시해 일관성·정확성 향상
## 구성요소
- 질문 구성: Task Description, Input Indicator, Current Input, Output Indicator
- 프롬프트 방식: Zero-Shot, One-Shot, Few-Shot, CoT
- 추론 방식: Zero-Shot CoT, ToT, Self Consistency, Meta-Reasoning over Multiple Chains
- 가이드라인: 대화 스타일 조정, 미사여구 최소화, 닫힌·구체 지시, 예제 제공
- 고도화: 마켓플레이스·프레임워크 활용
## 구성도
```
[Prompt]
 Task Description / Input Indicator / Current Input / Output Indicator
        ↓ (상황 설명·답변 형식 제시)
  Language Model → Generated Text(Completion)
```
