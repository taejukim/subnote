## 정의
- 개인이나 집단의 사전 적인 견해, 선입견, 편견, 문화적 영향 등으로 인해 객관성이나 공정성에서 벗어난 경향을 의미
## 키워드
- 인간의 편향, 숨겨진 편향, 데이터 표본 편향, 롱테일 편향, 고의적 현향, XAI
## 암기법
- 유형
	- 인숨데롱고(인간의 편향, 숨겨진 편향, 데이터 표본 편향, 롱테일 편향, 고의적 편향)
## 유형
| **구분**         | **편향성 유형**                         | **설명**                                             |
| -------------- | ---------------------------------- | -------------------------------------------------- |
| **Data 관점**    | **인간의 편향** (Human Bias)            | - 인공지능이 학습하는 데이터는 인간으로부터 기인<br>- 원시 데이터 자체에 편향이 개입 |
|                | **숨겨진 편향** (Hidden Bias)           | - 가장 발견하기 어려운 편향으로 절대 보거나 발견될 수 없는 의도하지 않은 편향      |
|                | **데이터 표본 편향** (Data Sampling Bias) | - AI 시스템에 공급되는 데이터 샘플링 편향에 기인한 편향                  |
| **Process 관점** | **롱테일 편향** (Long-tail Bias)        | - AI 시스템의 훈련 데이터에 특정 범주가 누락될 때 발생하는 편향             |
|                | **고의적 편향** (Intentional Bias)      | - 해킹 공격을 통해 AI가 의도적으로 편향되며, 발견이 어렵게 숨겨지므로 더 위험함    |

## 시험 대비 (2교시) — 이상치·편향 문항

**1분 정의 (데이터 분석 관점)**
> 편향 = 표본·수집·측정 과정의 **체계적 오차**로, 데이터가 한쪽으로 치우치거나 모집단을 대표하지 못하는 현象

| 관점 | 편향 의미 |
|------|-----------|
| **데이터·통계** | 표본 편향, 수집 체계 오류 → **대표성·일반화** 저하 |
| **ML(Bias-Variance)** | 고편향 = **과소적합** (모델 단순) — 데이터 편향과 **별개 맥락** |

**분석 결과 영향**
- 대표성 상실 → 일반화 불가
- 체계적 예측 오차, 실패 패턴 미학습
- 윤리·법적 차별 (AI·의사결정)

**처리 방안**
| 방법 | 설명 |
|------|------|
| **층화 추출** | 모집단 구조 반영한 표본 설계 |
| **재가중치** | 소수 집단 가중 보정 |
| **누락 Data 추적** | 생존자 편향(Survivorship Bias) 제거 |
| **교차 검증·A/B Test** | 편향 영향 검증 |

**이상치 vs 편향 비교**
| 구분 | 이상치 | 편향 |
|------|--------|------|
| 수준 | 개별 관측값 | 전체 data·수집 체계 |
| 원인 | 측정 오류, 극단값 | 표본·선입견·수집 설계 |
| 탐지 | 시각화·IQR **상대적 쉬움** | 구조적 → **탐지 어려움** |
| 영향 | 지표·모델 **국소** 왜곡 | **체계적·일반화** 실패 |

**금지·주의**
- ⚠️ 편향 = “정규분포인데 평균만 이동”만으로 끝내지 말 것 → **체계·표본 오차** 명시
- ⚠️ 「영향 동일」 X — 원인·수준·**영향 범위** 모두 다름
- Bias-Variance는 ML 맥락에서만 (데이터 편향과 혼동 주의)

**1분 답안 골격**
1. 개념(체계·표본) + 평균 이동 도식
2. 영향(대표성·공정성)
3. 처리(층화·재가중·수집 재설계)
4. [[이상치, 노이즈, 결측치]]와 비교 + "영향 범위 상이"
