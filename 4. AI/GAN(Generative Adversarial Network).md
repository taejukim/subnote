## 정의
 - Generator와 Discriminator가 서로 대립 과정을 통해 훈련 타겟을 생성하는 학습 모델로 두개의 네트워로 구성된 심층 신경망
## 키워드
- Generator, Discriminator, Min-Max 학습, Nash 균형, 모드 진동, 모드 붕괴, 준지도학습

## 생성방법

| **구분**            | **요소**                      | **설명**                                                                                                     |
| ----------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **생성자**           | $D(G(z)) = 1$               | - 가짜데이터 생성하여 1의 확률 판별 목표<br>- $V(D, G)$에서 최소화(min)하는 방향                                                    |
| **판별자**           | $D(x) = 1$<br>$D(G(z)) = 0$ | - 가짜데이터는 0, 실제데이터는 1의 확률 판별 목표<br>- $V(D, G)$에서 최대화(max)하는 방향                                              |
| **학습 데이터**        | $X(\text{Real Data})$       | - 학습할 Real Data<br>- 지속적인 학습 데이터 제공                                                                        |
| **Loss Function** | **Object Function**         | $$\min_{G} \max_{D} V(G, D) = E_{x \sim P_{data}(x)}[\log D(x)] + E_{z \sim P_{z}(z)}[\log(1 - D(G(z)))]$$ |
## 유형

| **유형**      | **설명**                                |
| ----------- | ------------------------------------- |
| **DCGAN**   | 사실적인 이미지를 생성하는 기술                     |
| **SRGAN**   | 저해상도 이미지를 고해상도 이미지로 변환하는 기법임          |
| **스택 GAN**  | 입력된 문장과 단어를 해석해 이미지를 생성하는 인공지능 기법     |
| **3D-GAN**  | 입체 모델 생성 네트워크로 가령 가구 사진을 통해 3차원 그림 생성 |
| **사이클 GAN** | AI가 자율적으로 학습해 이미지의 스타일을 다른 스타일로 변환    |
