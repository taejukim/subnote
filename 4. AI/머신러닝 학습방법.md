## 정의
머신러닝 학습방법
- 대량의 데이터를 스스로 학습·조직화하여 문제의 해법을 찾는 기법
- 학습한 내용을 기반으로 미래를 예측하는 기법
## 키워드
* 지도학습, 비지도학습, 준지도학습, 강화학습, 진화학습
## 암기법
* 지비준강진: 지도·비지도·준지도·강화·진화학습
## 특징
- 지도성: 라벨이 있는 훈련집합으로 분류·회귀 모델 학습
- 비지도성: 라벨 없이 유사성(우도·거리) 기반 구조 발견
- 준지도성: 소량 라벨 + 다량 비라벨 결합 학습
- 강화성: 환경과 상호작용하며 보상 최대화 정책 학습
## 목적
- 데이터로부터 자율적으로 패턴·모델을 학습해 예측·의사결정 지원
- 문제 유형에 맞는 학습 패러다임 선택
## 구성요소
- 지도학습: Bayesian, Decision Tree, Regression, Neural Network, HMM
- 비지도학습: K-Means, EM, SOM, PCA, ICA
- 준지도학습: 그래프생성모형, Self-training, Co-training, Label Propagation
- 강화학습: Monte Carlo, MDP, Value Function, Q-Learning, DQN, PPO
- 진화학습: 유전 알고리즘(Genetic Algorithm)
## 구성도
```
[데이터] → 지도학습(라벨O) / 비지도학습(라벨X) / 준지도학습(혼합)
         → 강화학습(Agent↔Environment, Reward)
         → 진화학습(유전 알고리즘)
```
