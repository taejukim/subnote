#정보관리기술사 #AI #합성데이터 #SyntheticData
## 정의
합성데이터(Synthetic Data)
- 원본 데이터의 형식·구조·통계적 분포·패턴을 학습하여 생성한 모의·가상 데이터
- 개인정보 보호·데이터 부족 문제 해결을 위한 AI 학습 데이터 생성 기술
## 키워드
* GAN, VAE, Diffusion, Synthpop, pMSE, FID, 안정성, 유용성, 유사성
## 암기법
* 유유안: 유사성·유용성·안정성
## 특징
- 대체성: 실제 데이터 대신 학습용 데이터 활용
- 확장성: 부족한 데이터 무제한 생성 가능
- 보호성: 개인정보·민감정보 노출 위험 최소화
- 평가성: 유사성·유용성·안정성 3대 지표로 검증
## 목적
- AI 모델 학습 데이터 확장과 성능 향상
- 개인정보 규제 준수 및 데이터 공유 활성화
## 구성요소
- 통계모형 기반: Synthpop, GMM, 베이지안 네트워크
- AI모형 기반: VAE, GAN, Diffusion Model
- 생성 절차: 사전 준비 → 합성 생성 → 안정성·유용성 검증 → 심의위원회 평가 → 활용·관리
- 품질 평가 절차: 측정 지표 결정 → 임계값 산출 → 안정성·유용성 측정 → 검토·처리
- 평가 지표: 유사성(카이제곱·피어슨), 유용성(pMSE·VTT·IS·FID), 안정성(구별·연결·추론 위험도)
- 거버넌스: 사용 목적, 전문가 협력, 데이터 거버넌스 체계
## 구성도
```
원본 데이터 → 학습(통계/AI 모델) → 합성데이터 생성
   → 품질 평가(유사성·유용성·안정성) → 심의 → 활용·관리
```
