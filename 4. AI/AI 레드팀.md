#정보관리기술사 #AI #AI레드팀 #AI/AI_보안/신뢰성/윤리 #NEW
## 정의
AI 레드팀(Red team) 테스트
- AI 모델·시스템의 잠재 취약점·편향·사회적 위해·보안 이슈를 식별하기 위해 의도적으로 다양한 공격과 한계 시험을 수행하는 적대적·탐색적 테스트 방법
## 키워드
* 의도, 비결정성, 탐색적 테스트, 잠재 위협
## 암기법
* 범구공분대: 범위정의·구성·공격실행·블루분석·대응보고
## 특징
- 적대 탐색성: 프롬프트 인젝션·Jailbreak·유출·편향 유도 등 공격 시뮬레이션
- 다학제 구성: 기술·윤리·법률·도메인·일반 사용자 포함(10~100+명)
- Red/Blue 협업: 공격과 실시간 방어·분석 병행
- 산출물 중심: 취약점 리포트·가드레일·신규 평가지표
## 목적
- 잠재 위협·편향·보안 취약점의 조기 노출
- 안전·윤리 평가 지표와 방어 규칙 개선
## 구성요소
- 팀: 내/외부·크라우드·전문가/사용자·혼합형
- 모델 테스트: Prompt Injection, Jailbreak, Bias/Harm, Agent Malfunction, Data Poisoning
- 시스템 테스트: 데이터유출·권한상승, 가드레일 무력화, 보안경계, 공격대응
- 절차: 범위·환경·목표 정의 → 팀 구성 → 시나리오 공격 → Blue 분석 → 보고·대응
- 산출물: 취약점/리스크 카탈로그, 가이드라인·필터, 평가 지표·테스트 기법
## 구성도
```
Red Team(공격) → AI 시스템 ← Blue Team(분석)
  인젝션·Jailbreak·유출·편향·적대입력
        → 취약점 리포트 / 가이드라인 / 평가지표
```
