#정보관리기술사 #AI #DataCentricAI #데이터품질
## 정의
데이터 중심 AI(Data-Centric AI)
- 모델 개선이 아닌 데이터 품질·라벨링·다양성 향상에 초점을 둔 AI 성능 개선 접근 방식
- 동일 모델 유지·데이터셋 개선 반복으로 신뢰성 높은 AI를 구현하는 방법론
## 키워드
* Andrew Ng, Data Quality, Active Learning, MLOps, Curriculum Learning, RAG
## 암기법
* 품지효: 품질우선·지속개선·효율학습
## 특징
- 품질 우선성: 모델 대신 데이터 품질에 투자
- 지속 개선성: 데이터셋 점진적 정제·보강
- 일반화 성능: 적은 데이터로 강건성 확보
- 실무 적합성: 의료·제조 등 도메인 특화에 강점
## 목적
- 노이즈·편향이 적은 고품질 학습 데이터 확보
- 데이터 개선만으로 모델 성능·신뢰성 향상
## 구성요소
- 데이터 수집·가공: 실시간 수집, 자동 어노테이션, 라벨링, 합성데이터, 센서 퓨전
- 품질 관리: 품질 측정 지표, 정제·통합, 자동화 도구, 산업별 준수 기술
- 데이터 중심 학습: Curriculum Learning, Active Learning, RAG, 데이터 중심 MLOps
- Model-Centric AI 비교: 데이터 개선 vs 모델 구조·하이퍼파라미터 개선
## 구성도
```
[Data-Centric AI]                       [Model-Centric AI]
모델 고정 → 데이터 정제·확장 반복   ↔  데이터 고정 → 모델 구조·튜닝 반복
적용: 의료영상·제조결함·OCR              적용: 이미지넷·SOTA 연구
```
