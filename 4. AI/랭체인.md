## 정의
랭체인(LangChain)
- 언어모델 서비스 개발 시 여러 언어모델과의 통합을 간소화하도록 설계된 SDK이자, 다양한 언어모델 기반 애플리케이션 개발 프레임워크
## 키워드
* Agent, Memory, Model I/O, Data Connection, Chains, Callbacks
## 암기법
* 모커에 체메콜: Model I/O·Data Connection / Agent·Chains·Memory·Callbacks
## 특징
- 통합성: Vector DB·Data Source·Embedding·LLM과 연결
- 체인성: 컴포넌트를 인터페이스로 연결해 파이프라인 구성
- 상태성: Memory로 실행 간 컨텍스트 유지
- 관찰성: Callbacks로 중간단계 로깅·모니터링·스트리밍
## 목적
- LLM 애플리케이션의 데이터·프롬프트·도구 오케스트레이션 단순화
- 실시간 데이터 반응형·맞춤형 응답 애플리케이션 구축
## 구성요소
- 메인: Model I/O(언어모델 인터페이스), Data Connection(로드·변환·저장·쿼리)
- 추가: Agent(도구 선택), Chains(기능 연결), Memory(상태 유지), Callbacks(기록·스트리밍)
- 주요기능: 데이터소스 통합, 프롬프팅·컨텍스트 관리, 파인튜닝·커스터마이징, 반응형 앱 구축
## 구성도
```
Application
     ↕
[LangChain: Agent / Memory / Callbacks]
[        Data Connection / Chains / Model I/O]
  ↕ Data Sources · Vector DB · Embedding · LLM
흐름: 외부데이터 수집 → 임베딩 → 벡터저장·검색 → 프롬프트·응답
```
