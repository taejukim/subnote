#정보관리기술사 #AI #모델추출 #AI/신뢰성/윤리 #NEW
## 정의
모델 추출 공격(Model Extraction Attack)
- 공격자가 모델에 반복 쿼리를 보내 출력을 분석하여 대상 모델을 복제(Surrogate Model)하는 공격
## 키워드
* Surrogate Model, Graybox, Blackbox, Knockoff Nets, Data-Free, ActiveThief, Black-Box Ripper
## 암기법
* 쿼수학검: 쿼리·수집·학습·검증
## 특징
- Graybox: 구조·학습데이터 일부 사전 지식
- Blackbox: 사전 지식 전무, API 기반 대규모 쿼리
- 기법: Knockoff Nets, Data-Free, ActiveThief, VAE/GAN, Marich, D-DAE
## 목적
- 상용 AI 모델 지적재산 탈취
- API 기반 MLaaS 모델 복제
## 구성요소
- 절차: 데이터 준비 → 쿼리 전송 → 결과 수집 → Surrogate 학습 → 검증·최적화
- 대응: API 접근 제어·Rate Limit, 쿼리 모니터링, 출력 최소화, DP, 워터마킹
## 구성도
```
Query → Target(Blackbox) → Output → Substitute Dataset → Surrogate Model
```
