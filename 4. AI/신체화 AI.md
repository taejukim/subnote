#정보관리기술사 #AI #EmbodiedAI #신체화AI
## 정의
신체화 AI(Embodied AI)
- AI가 물리적 신체를 기반으로 실제 환경에서 인간과 유사하게 감지·추론·행동·학습하는 인공지능
- 감각·인지·행동의 통합 아키텍처로 환경과 지속 상호작용하는 AI 패러다임
## 키워드
* Embodiment, SLAM, Sensor Fusion, RL, LLM Reasoning, Self-Learning
## 암기법
* 감인행: 감지·인지·행동
## 특징
- 통합 아키텍처: 감각·인지·행동 일체화 설계
- 물리적 상호작용: 실제 환경과 직접 상호작용
- 지속 자기학습: 경험 기반 학습·전이
- 실세계 검증성: 시뮬레이션과 현실 격차 최소화
## 목적
- 환경 변화에 대응하는 자율 지능 구현
- 로봇·휴머노이드의 범용 행동 능력 확보
## 구성요소
- 감지·인식: 센서 융합, 컴퓨터 비전, 음성 인식
- 인지·학습: 강화학습, 전이학습, LLM 기반 추론
- 행동·제어: 로보틱스 제어, SLAM, 경로 계획
- 피지컬 AI 비교: 신체화 AI는 인간 유사 외형 지향, 피지컬 AI는 더 포괄적 범위
## 구성도
```
[현실세계] → 감지/인식(센서·비전·음성)
              ↓
        인지/학습(RL·전이·LLM 추론)
              ↓
        행동/제어(로보틱스·SLAM·경로) → 물리적 행동 → [현실세계]
```
