#정보관리기술사 #AI #XAI #설명가능성AI
## 정의
설명 가능성 AI(XAI, Explainable AI)
- AI 모델의 예측 과정과 결과를 사람이 이해 가능하도록 설명하는 기술 체계
- 블랙박스 모델의 투명성·책임성·신뢰성을 확보하기 위한 해석 가능성 기법
## 키워드
* SHAP, LIME, Shapley Value, Black-box, 책임성, 모델 불가지론
## 암기법
* 투책설: 투명성·책임성·설명력
## 특징
- 투명성: 예측 과정의 가시화
- 책임성: 결정 근거의 설명·소명 가능
- 신뢰성: 모델 검증·편향 진단
- 적용 유연성: 모델 불가지론적 적용 가능
## 목적
- 블랙박스 AI의 의사결정 근거 명확화
- 규제·윤리 요구 대응과 사용자 신뢰 확보
## 구성요소
- SHAP(Shapley Additive Explanations): 게임이론 기반 XAI, 예측 결과에 입력별 기여도 정량화, 일관성·가산성 만족
- LIME(Local Interpretable Model-Agnostic Explanations): 국소 영역에서 해석 가능한 단순 모델 학습, 모델 불가지론적 설명
- SHAP 필요성: 투명성·책임성, 일관성·정량성, 전역 이해·품질 검증
- LIME 필요성: 직관성·즉시성, 개별 사례 설명·이상 탐지, 적용 용이성
- SHAP 사례: 금융 신용평가, 보험 언더라이팅, 보험사기 탐지, 공공행정, 의료 예측
- LIME 사례: 금융 상담, 보험심사, 이상거래 탐지, 의료진단, 고객이탈 예측, PoC
## 구성도
```
[입력 데이터] → [블랙박스 모델] → [예측 결과]
                       ↓ XAI
        SHAP(전역·기여도)  /  LIME(국소·근사 모델)
                       ↓
            설명/시각화 → 검증·책임성 확보
```
