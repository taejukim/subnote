#정보관리기술사 #AI #클래스불균형 #AI/ML_알고리즘/기법 #NEW
## 정의
클래스 불균형(Class Imbalance)
- 탐색 대상인 타깃 데이터 수가 극소수인 상태
- 불균형 데이터에서 Accuracy는 높게 유지되나 Recall이 크게 저하되는 문제
## 키워드
* 정확도, 재현율, Over sampling, Under sampling, Cut-Off
## 암기법
* 렌아스블디(Over): Random·ADASYN·SMOTE·BLSMOTE·DBSMOTE
* 랜토이발(Under): Random·Tomek·EasyEnsemble·BalanceCascade
## 특징
- Over-Sampling: 정보손실 없음, 과적합 위험, 학습↑·검증↓ 가능
- Under-Sampling: 정보손실·정상데이터 소실 위험, 계산 시간 짧음
- Cut-Off 이동: 학습 불변, 테스트 단계 임곗값 조정
## 목적
- 소수 클래스 탐지 성능(재현율 등) 회복
- 불균형에 적합한 평가 지표·샘플링 전략 선택
## 구성요소
- Over: Random, ADASYN, SMOTE, BLSMOTE, DBSMOTE
- Under: Random, Tomek Links, EasyEnsemble, BalanceCascade
- Cut-Off Value Moving: 다수 쪽 임곗값 이동
- 지표: G-Mean, Accuracy, F1/F0.5/F2, Brier, PR-AUC, ROC-AUC
## 구성도
```
불균형 데이터
 ├─ Over-Sampling(소수 복제·생성) → Final ↑
 ├─ Under-Sampling(다수 축소) → Final ↓
 └─ Cut-Off 이동(테스트 임곗값)
지표: 범주→G-Mean/F-score, 확률→Brier/PR-AUC/ROC-AUC
```
