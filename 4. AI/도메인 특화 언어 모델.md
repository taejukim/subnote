#정보관리기술사 #AI #도메인특화LLM #VerticalAI
## 정의
도메인 특화 언어 모델(Domain-Specific Language Model)
- 특정 산업·비즈니스 영역의 데이터셋으로 학습·파인튜닝된 LLM
- 도메인 정확도와 보안성을 강화한 수직형(Vertical) AI 모델
## 키워드
* DAPT, RAG, RLHF, PEFT, Vector DB, Foundation Model, Vertical AI
## 암기법
* 데학성: 데이터·학습·성능
## 특징
- 도메인 정밀성: 산업 용어·규제 정확 반영
- 보안 강화성: 내부 데이터 외부 유출 차단
- 환각 감소성: 사전 학습 영역 한정으로 hallucination 저감
- 효율성: PEFT 기반 저비용 적용
## 목적
- 산업·비즈니스 특화 정확도와 신뢰성 확보
- 기업 내부 데이터 보안과 규제 준수
## 구성요소
- 데이터: 데이터 큐레이션, Vector DB
- 학습: DAPT(Domain Adaptive Pre-Training), RLHF
- 성능: RAG, Prompt Chain, PEFT(LoRA·Adapter)
- 모델 흐름: Foundation Model → 도메인 사전학습 → 파인튜닝 → 도메인 특화 LLM(RAG/RLHF)
- 범용 LLM 비교: 도메인 데이터(특화) vs 범용 데이터, 도메인 정확↑/환각↓
## 구성도
```
[범용 데이터] → Foundation Model
                       ↓ DAPT
[도메인 데이터] → 도메인 사전학습 → 파인튜닝(LoRA/PEFT)
                       ↓ 추론 시 RAG/Prompt Chain → 도메인 특화 LLM
```
