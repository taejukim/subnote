## 정의
모델 드리프트(Model Drift)
- 고객·환경·제품·산업 등 변화하는 환경에 따라 모델 성능이 저하되는 현상
## 키워드
* 데이터와 라벨의 관계성 변화, 입력데이터 분포 변화, Concept Drift, Data Drift
## 암기법
* 컨데: Concept Drift(관계 변화) · Data Drift(분포 변화)
## 특징
- Concept Drift: 입력–라벨 관계·타깃 개념 변화로 마진 무력화
- Data Drift: 훈련 vs 배포 입력 분포 차이로 성능 저하
- 시계열성: 계절·환경 변화에 따른 점진·급격 저하
## 목적
- 운영 중 성능 저하 원인 유형화·조기 탐지
- 재학습·피처 조정 등 대응 전략 수립
## 구성요소
- Concept Drift: 원인(관계 변화), 예(사기 정의 변경), 해결(Online Learning, Feature dropping)
- Data Drift: 원인(분포 편향), 예(여름→겨울 계절성), 해결(Drift monitoring, 재학습·재배포)
## 구성도
```
Concept Drift: Class분포 이동 → Original Margin 무력화
Data Drift: 훈련분포 →(반년 후)→ 배포분포 → 성능감소
```
