#정보관리기술사 #AI #컨텍스트엔지니어링 #ContextEngineering
## 정의
컨텍스트 엔지니어링(Context Engineering)
- LLM 입력의 문맥을 사용자 의도에 맞게 정형화·구성하는 맥락 설계 기법
- 정확성·일관성·목적 적합성 향상을 위한 컨텍스트 주입·관리 엔지니어링
## 키워드
* RAG, Slot Filling, Function Calling, Semantic Indexing, Task Memory, Tool Use
## 암기법
* 맥구실: 맥락강화·구조화·실행기반
## 특징
- 맥락 중심성: 입력 명령보다 배경 맥락 설계
- 동적 구성성: 사용자 목표에 따라 맥락 재구성
- 도구 통합성: 외부 API·툴 호출과 결합
- 반복 개선성: 피드백 기반 맥락 튜닝
## 목적
- LLM 응답의 일관성·정확성·신뢰성 강화
- 사용자 의도와 도메인 맥락의 정렬
## 구성요소
- 문맥 강화: RAG, Semantic Indexing
- 구조화 구성: Slot Filling, Task Memory, Context Framing
- 실행 기반: Tool Use, Function Calling, API Orchestration
- 운영: 사용자 목표 정의 → 맥락 수집·구성 → 프롬프트 구성 엔진 → LLM 응답 → 평가·튜닝 → 피드백 환류
- [[프롬프트 엔지니어링]] 비교: 입력 명령문 최적화 vs 문맥·배경 정보 설계
## 구성도
```
사용자 목표/문제 정의 → 맥락 수집/구성(RAG/메모리)
   → Prompt 구성 엔진 → LLM 응답 → 평가·튜닝 → 피드백 환류
```
