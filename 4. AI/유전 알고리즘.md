## 정의
유전 알고리즘(Genetic Algorithm)
- 유전학과 자연진화를 모방하여 적합도 높은 개체가 살아남는 방식으로 세대를 거듭하며 최적해를 탐색하는 최적화 알고리즘
## 키워드
* 최적화 알고리즘, 반복, Selection, Crossover, Mutation
## 암기법
* 선교변대반: 선택·교차·변이·대체·반복
* 룰랭토 일다균산: 룰렛·랭크·토너먼트 / 단일·다점·균등·산술
## 특징
- 진화성: 세대 반복으로 해 공간 탐색
- 집단성: 다수의 유전자(해) 동시 유지
- 확률성: 교차·변이로 다양성 확보
- 지역해 주의: 파라미터 튜닝으로 Local Optima 회피
## 목적
- 복잡·비연속 최적화 문제에서 근사 최적해 탐색
- 진화학습 패러다임 구현
## 구성요소
- 절차: 초기화 → 선택 → 교차 → 변이 → 대체 → 수렴까지 반복
- 선택: Roulette Wheel(적합도 비례), Rank(순위), Tournament(부분집합 최강)
- 교차: 단일점/다점, Uniform(균등), Arithmetic(산술)
- 개념흐름: 초기집단 → 선택 → 교차 → 변이 → 대체 → 다음 세대
## 구성도
```
[초기화] 유전자 집단
   → [선택] 적합도 기반
   → [교차] 자손 생성
   → [변이] 일부 유전자 변경
   → [대체] 집단 갱신 → 반복(수렴)
```
