## 정의
- 대형 언어 모델 (LLM)의 설계부터 관리, 배포, 유지관리를  통합하고 효율화하는 과정 및 패러다임

## 키워드
- LLM, DevOps, 자동화, CI/CD

## LLMOps 단계별 구성요소
| **구분**          | **구성 요소**                  |
| --------------- | -------------------------- |
| **Data 수집, 처리** | 정형, 비정형 Data 수집, 전처리       |
| **기반모델**        | 기반모델 선정                    |
| **임베딩 처리**      | 벡터라이징 및 인덱싱, 벡터 데이터 베이스 저장 |
| **프롬프트 관리**     | 프롬프트 엔지니어링, 프롬프트 체이닝       |
| **테스트**         | 벌크 / 배치 테스트, 프롬프트 체이닝      |
| **버전 관리**       | CI / CD                    |
| **모니터링**        | 프롬프트 모니터링, 지연/ 안전성 모니터링    |
| **최적화**         | 기반 모델 파인튜닝, 프롬프트 iteration |
## 데이터 수집 및 모델 개발 단계 구현 기술
| **구분**          | **구현 기술**                                                             | **설명**                                                                                                           |
| --------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Data 수집, 처리** | - Spark / Kafka<br>- S3 / Blob Storage                                | - 인메모리 기반 대용량 텍스트 처리 또는 실시간 스트리밍<br>- 클라우드 기반 object Storage                                                     |
| **기반모델**        | - open AI GPT 모델<br>- LLAMA 2 / LLAMA 3<br>- Gemini<br>- Hugging Face | - open AI에서 개발한 LLM 모델<br>- Meta에서 개발한 LLAMA LLM 모델<br>- Google에서 개발한 Gemini 모델<br>- 텍스트처리, LLM 개발자 위한 오픈소스 커뮤니티 |
| **임베딩 처리**      | - Qdrant / Faiss index<br>- Milvus / Weaviate                         | - 임베딩 처리 된 결과를 저장하기 위한 벡터 Store<br>- SaaS형 벡터 DBMS 서비스                                                           |
| **프롬프트 관리**     | - Gradient J / HoneyHive<br>- Azure AI Studio                         | - 코드와 분리하여 다양한 버전 프롬프트 관리/개발<br>- UI/UX 기반 프롬프트 플로우를 통한 개발 지원                                                    |

## 모델 운영 및 평가 단계 구현 기술
| **구분**    | **구현 기술**                        | **설명**                                     |
| --------- | -------------------------------- | ------------------------------------------ |
| **테스트**   | - Fiddler AI<br>- Humanloop      | - RAI (Responsible AI, 신뢰성 있는 AI)를 위한 기반기술 |
| **버전 관리** | - AWS code commit<br>- Jenkins X | - 클라우드 CI/CD를 위한 지속적인 통합과 배포를 위한 기술        |
| **모니터링**  | - AnyScale<br>- Arize            | - 모델의 안전성, 지연성, 환각 등에 대한 모니터링              |
| **최적화**   | - Autoblock<br>- TruEra          | - 앱 인터랙션를 수집하여 테스트 베드에 전송하여 개선             |
