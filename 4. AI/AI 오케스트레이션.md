## 정의
AI 오케스트레이션(AI Orchestration)
- 여러 AI 모델·에이전트·데이터·API를 연계하여 실행 순서·동적 분기·상태·오류 처리를 자율 제어하는 워크플로우 구성
## 키워드
* Orchestrator, AI Agent, Data Pipeline, Centralized, Decentralized, Hierarchical, Federated
## 암기법
* 통분계연: 중앙·분산·계층·연합
## 특징
- Agent vs Orchestration: Agent=개별 자율 실행, Orchestration=다중 주체 조율
- 유형: 중앙집중·분산·계층·연합(Federated)
- AI 통합·자동화·관리 기능 수행
## 목적
- 복잡 AI 워크플로우 확장·관리
- 다중 Agent 협업·자원 최적화
## 구성요소
- Orchestrator: 작업 분해·순서·협업 제어
- AI Model/Agent: 추론·검색·생성
- Data Pipeline: 수집·정제·변환
- Integration Layer: API, MCP, A2A
- Computing/Ops: CPU·GPU·메모리 관리
## 구성도
```
App → [Orchestrator] → Agent1..N ↔ Internal DB/CRM + External API
```
