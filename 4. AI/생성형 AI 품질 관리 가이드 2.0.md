#정보관리기술사 #AI #생성형AI #품질관리가이드
## 정의
생성형 AI 데이터 품질관리 가이드 v2.0
- 대규모 데이터를 학습한 생성형 AI 모델의 데이터 구축·운영 전 과정에 대한 품질 관리 프레임워크
- 준비/계획·구축·운영 활용 3단계로 구성된 품질 관리 활동 가이드
## 키워드
* LLM, LMM, sLLM, On-Device AI, Vertical AI, NIA 가이드, 데이터 거버넌스
## 암기법
* 준구운: 준비계획·구축·운영활용
## 특징
- 단계 통합성: 계획~운영 전 단계 품질 활동 정의
- 표준화성: 100/200/300 코드 체계로 활동 식별
- 반복성: 데이터 획득→정제→가공→학습 반복 루프
- 거버넌스 기반성: 법적 근거·조직·도구 검토 포함
## 목적
- 생성형 AI 학습 데이터의 신뢰성·품질 일관성 확보
- 사업 수행·운영 단계별 품질 관리 책임 명확화
## 구성요소
- 100. 준비/계획: 110. 구축 계획 수립
- 200. 구축: 210. 데이터 획득/수집, 220. 정제, 230. 가공, 240. 학습
- 300. 운영 활용: 310. 데이터 운영 활용
- 110. 활동: 사업 수행·구축 계획 수립, 절차/조직, 임무 정의 적절성, 품질 목표/점검 기준
- 210. 활동: 획득 방법·기준 현행화, 법적 근거 검토, 도구·환경 검토, 원시데이터 품질검사
- 220. 활동: 정제 기준, 비식별화·법적 준거, 정제 도구, 원천데이터 품질검사
- 230. 활동: 가공 기준, 가공 도구, 가공 데이터 품질검사
- 240. 활동: 구축목적-AI 모델 합치성, 학습결과 최적화, 보완조치
- 310. 활동: 개방 전 점검, 데이터 하자·유지보수, 사용자 의견 반영
## 구성도
```
[100 준비/계획] → [200 구축] 획득 → 정제 → 가공 → 학습 (반복) → [300 운영/활용]
                       ↓ 품질 측정·검증·환류 ↑
```
