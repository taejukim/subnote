#정보관리기술사 #AI #버티컬AI #AI/LLM/생성AI #NEW
## 정의
버티컬 AI(Vertical AI)
- 특정 산업이나 도메인에 최적화된 데이터를 활용하여 해당 분야의 고유한 문제를 해결하는 인공지능
## 키워드
* 범용 데이터, 특화 데이터, 파인 튜닝, sLLM
## 암기법
* 범특파s: 범용데이터·특화데이터·파인튜닝·sLLM
## 특징
- 도메인 특화성: 의료·금융·제조 등 산업 특화 데이터 활용
- 소형모델성: sLLM·도메인 알고리즘 중심
- 고신뢰성: 정확도·신뢰성이 높은 특화 데이터 요구
- 저비용성: 빅테크 대비 상대적으로 낮은 인프라 비용
## 목적
- 산업별 고유 문제에 대한 맞춤형 AI 솔루션 제공
- 범용(수평적) AI를 도메인 데이터로 특화
## 구성요소
- 학습 데이터: 도메인 특화 데이터(소규모) vs 범용 비정형 데이터(대규모)
- 기술 요소: sLLM, Fine-tuning, 도메인 알고리즘 / LLM, 클라우드 AI
- 학습 방법: Fine-tuning 기반 맞춤 학습 / 대규모 Pre-training
- 적용: 의료(영상분석), 금융(신용평가), 제조(공정최적화)
- 비교축: 개발주체(스타트업·SME vs 빅테크), 확장성(산업 한정 vs 다중 도메인)
## 구성도
```
[범용 데이터·대규모] → Pre-training → Horizontal AI(사전학습 모델)
                                         +
[도메인 특화 데이터·소규모] → Supervised Fine-tuning → Vertical AI(파인튜닝 모델)
```
