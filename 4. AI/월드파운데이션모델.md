#정보관리기술사 #AI #월드파운데이션모델 #AI/LLM/생성AI
## 정의
- 단순히 텍스트나 이미지를 생성하는 것을 넘어 현실 세계의 물리적 법칙, 인과관계, 시공간적 역동성을 이해하고 시뮬레이션할 수 있는 기초 모델
- → LLM의 한계와, Embodied AI로 인해 등장

## 구성요소
- 인지 : Vision, Sensor Fusion, 멀티모델 데이터 큐레이션, 시각적 토큰화 
- 추론 : VLM, 동역학 엔진
- World Model : Dynamic Simulator
- 계획 : RL/MPC, 모델 예측 제어
- 행동 : VLA
- 제어 : Actuator Control
