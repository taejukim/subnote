#정보관리기술사 #AI #중첩학습 #NestedLearning
## 정의
중첩 학습(Nested Learning)
- 딥러닝 모델의 망각 문제를 극복하기 위해 서로 중첩된 작은 최적화 문제들의 집합으로 설계된 학습 패러다임
- 각각 다른 속도로 지속 학습을 제공하는 구글 제안 차세대 학습 프레임워크
## 키워드
* HOPE, Titans, CMS(연속 메모리), Catastrophic Forgetting, Deep Optimizer
## 암기법
* 중망지: 중첩·망각해결·지속학습
## 특징
- 중첩성: 작은 최적화 문제 다중 계층 구성
- 다중 시간성: 각 계층마다 다른 학습 속도
- 망각 방지성: Catastrophic Forgetting 완화
- 자기 참조성: 자기 수정 아키텍처 도입
## 목적
- 분리된 아키텍처와 최적화 통합
- 지속 학습 시 재앙적 망각 문제 해결
## 구성요소
- 구조/표현 관점: 계층적 다중 최적화, 연관 기억 기반 표현
- 메모리/시간 척도 관점: 연속 메모리(CMS), 지속 학습/망각 완화 프레임
- 학습 규칙·아키텍처 관점: Deep Optimizer, HOPE 아키텍처(자가 수정)
- HOPE 구현체: Titans 한계 보완, 자기 참조·자기 수정, 연속적 기억 시스템, 무한 반복 학습 루프
## 구성도
```
[Outer Loop] 메타 최적화 (느린 학습)
      ↓ 중첩
[Middle Loop] 컨텍스트 기억 (중간 속도)
      ↓ 중첩
[Inner Loop] 즉각 적응 (빠른 학습) → CMS 기억 갱신 → 자기 참조 환류
```
