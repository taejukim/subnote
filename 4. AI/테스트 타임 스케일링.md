## 정의
테스트 타임 스케일링(Test-Time Scaling, TTS)
- 추론 단계에서 입력 크기·샘플 수·자원 사용량을 시간축으로 조절해 성능을 향상시키는 기법
## 키워드
* 추론 성능 향상, 성능 향상, 연산량 조절, Best-of-N, MCTS, CoT
## 암기법
* 베빔체몬: Best-of-N·Beam·체인추론·MonteCarlo·SelfRefine·ComputeOptimal
## 특징
- 파라미터 불변: 모델 구조·가중치 유지하며 추론만 강화
- 연산 조절성: 샘플링·탐색 깊이로 비용·품질 트레이드오프
- 재학습 불요: 사전학습 모델로 즉시 고품질 추론
- 실시간 최적화: 난이도에 따른 Compute-Optimal Scaling
## 목적
- 추론 시점 응답 품질·정확도 향상
- 저비용·고정밀 응용에서 유연한 연산 배분
## 구성요소
- Sampling: Best-of-N, Confidence-based Sampling
- Decoding: Beam Search, Self-Consistency Decoding
- Reasoning: CoT, ToT, GoT
- Search/Verify: Search Against Verifiers, MCTS
- Self-Improve: Sequential Revision, Self-Refinement, Chain-of-Action-Thought
- Compute: Compute-Optimal Scaling(COS)
## 구성도
```
질문 → [Best-of-N / Beam / Lookahead] → Verifier/다수결 → 최종 답
사전학습(능력 확장, 고비용) ≠ TTS(추론 품질↑, 파라미터 고정)
```
