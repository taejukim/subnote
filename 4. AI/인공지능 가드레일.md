#정보관리기술사 #AI #AIGuardrails #가드레일
## 정의
인공지능 가드레일(AI Guardrails)
- LLM을 원하는 행동에 정렬시키고 환각·유해 출력 등 위협을 완화하기 위해 입력·출력을 모니터링·제어하는 알고리즘
- AI 안전·윤리 정책을 코드·정책 수준에서 강제하는 통제 메커니즘
## 키워드
* Prompt Injection Defense, RAG Grounding, RLHF, Output Monitoring, Fail-safe
## 암기법
* 입처출운: 입력·처리/추론·출력·운영
## 특징
- 입출력 통제성: 입력 검증과 출력 모니터링 결합
- 정렬성: 정책·인간 가치와 모델 행동 정렬
- 다층 방어성: 게이트웨이·앵커·모니터링 다층 구성
- 운영 중심성: 실시간 감시·Fail-safe 보장
## 목적
- LLM 고유 리스크(환각·유해성·유출) 완화
- AI 안전·신뢰성·법적 준거 확보
## 구성요소
- 입력: Gatekeeper Layer, Prompt Inspection, Prompt Injection Defense, System Prompt, Input Validation
- 처리·추론: Knowledge Anchor Layer, RAG Grounding, Alignment, Parametric Layer, Fine-Tuning, RLHF
- 출력: Output Monitoring, Response Validation, Safe Completion
- 운영: Testability, Fail-safe, Situational Awareness, Monitoring
- 도입 어려움: 정책 정의 어려움, 비용·성능 부담, 안전성 보장 한계
## 구성도
```
[Input Guardrail]      [Processing Guardrail]       [Output Guardrail]
Gatekeeper·Validation → RAG Grounding·RLHF      → Output Monitor·Safe
   ↓                          ↓                          ↓
              [운영 Guardrail: 모니터링·Fail-safe·재검증]
```
