#정보관리기술사 #AI #인공지능적대적공격 #AI/AI_보안/신뢰성/윤리
## 정의
- 딥러닝의 심층신경망을 이용한 모델에 적애적 교란(Adversarial Perturbation)을 적용하여 오분류 발생 시키는 공격기술
## 키워드
- Poisoning, Evasion, Inversion, Model Extraction
## 암기법
- 공격기법
	- 오회전추(오염공격, 회피공격, 전도공격, 모델 추출 공격)
- 방어기법
	- 적캔쿼결탐(적대적 훈련, Defense-GAN, 쿼리 횟수 제한, 결과값 분석 차단, 적대적 공격 여부 탐지)
## 공격기법
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260320233726.png|500]]

| **공격 기법**                                 | **설명**                                                    | **사례**                                                                 |
| ----------------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Poisoning attack**<br>(중독공격, 오염공격)      | - 의도적으로 악의적인 학습 데이터를 주입해 머신러닝 모델을 손상시키는 공격. 모델 자체를 공격     | - MS사 인공지능 채팅봇 ‘테이’<br>- 스캐터랩 ‘이루다’<br>- 의료 기계 대상 연구 결과에서 대상 장비 오작동 발생 |
| **Evasion attack**<br>(회피공격)              | - 입력 데이터에 최소한의 변조 가해 머신러닝 속이는 기법                          | - 도로 교통 표지판에 이미지 스티커 부착해 자율주행차가 ‘정지’ 표시를 ‘속도제한’ 표시로 오인식                |
| **Inversion attack**<br>(학습 데이터 전도 공격)    | - 머신러닝 모델에 다량 쿼리 던진 후, 산출된 결과값 분석해 모델 학습에 사용된 데이터 추출하는 공격 | - 얼굴인식 머신러닝 모델 학습 위해 사용한 얼굴 이미지 데이터 복원 가능                              |
| **Model extraction attack**<br>(모델 추출 공격) | - 머신러닝 모델 추출 공격<br>- 머신러닝 모델에 쿼리 계속 던지면서 결과값 분석하는 방식의 공격  | - 70초 동안 650번 쿼리만으로도 아마존 머신러닝 모델과 유사 모델 생성 가능하다는 연구 결과 발표              |
## 방어기법
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260320233745.png|400]]

| **방어 기법**                            | **설명**                                                                                  |
| ------------------------------------ | --------------------------------------------------------------------------------------- |
| **적대적 훈련**<br>(Adversarial training) | - 머신러닝 훈련 단계에서 예상 가능한 해킹된 데이터 충분히 입력해 머신러닝의 저항성 기르는 방식                                  |
| **Defense-GAN**                      | - 적대적 생성 신경망(GAN) 알고리즘 이용하여 적대적 공격 방어                                                   |
| **쿼리 횟수 제한**                         | - 모델에 반복적 쿼리 시도하는 Inversion attack이나 Model extraction attack 방어                         |
| **결과값 분석 차단**                        | - 학습모델 결과값 분석 통해 모델 추론하는 공격 차단 위해, 학습모델 결과값이 노출되지 않도록 하거나, 결과값 분석할 수 없게 변환하는 방식으로 공격 차단 |
| **적대적 공격 여부 탐지**                     | - 원래 모델과 별도로 적대적 공격 여부 판단 위한 모델 추가한 후, 두 모델의 추론 결과 비교해 두 결과 간에 큰 차이 발생하는 경우 적대적 공격으로 탐지 |
