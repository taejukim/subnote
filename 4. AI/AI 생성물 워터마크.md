#정보관리기술사 #AI #AI워터마크 #출처증명
## 정의
AI 생성물 워터마크(AI Watermark)
- AI가 생성한 콘텐츠(이미지·영상·오디오·텍스트)에 명시적 또는 비명시적 표식을 삽입하여 출처·진위를 검증하는 기술
- 인지형(가시) 워터마크와 비인지형(비가시) 워터마크로 구분
## 키워드
* SynthID, Stable Signature, C2PA, 인지/비인지형, LSB, DCT, 출처 증명
## 암기법
* 인비공: 인지형·비인지형·공간/변환/학습
## 특징
- 진위 검증성: AI 생성물 식별·검증 가능
- 강건성: 변형·압축에도 일부 보존
- 추적성: 콘텐츠 출처와 모델 식별 지원
- 표준 연계성: C2PA·EU AI Act 의무화 추세
## 목적
- 딥페이크·허위정보 확산 방지
- 저작권·책임소재 명확화
## 구성요소
- 생성 과정: 생성물 → 워터마크 임베딩 → 워터마킹된 생성물
- 검출 과정: 생성물 → 워터마크 추출 → 진위 확인
- 인지형(시각): 로고·텍스트, 억제효과·즉각 확인, 제거 취약
- 비인지형(비가시): 픽셀·주파수 영역 삽입, 강한 보안·미적 보존, 탐지 도구 의존
- 적용 기법: 공간기반 LSB, 변환기반 DCT, 학습기반(SynthID, Stable Signature, 텍스트 워터마크)
- C2PA(Coalition for Content Provenance and Authority): Asset(Content/Metadata), Manifest(Assertion/Claim/Signature)
## 구성도
```
[생성] AI 모델 → 콘텐츠 → 워터마크 임베딩(LSB/DCT/SynthID) → 배포
[검증] 콘텐츠 → 워터마크 추출 → 진위/출처 확인 → C2PA Manifest 검증
```
