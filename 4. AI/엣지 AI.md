#정보관리기술사 #AI #엣지AI #EdgeAI
## 정의
엣지 AI(Edge AI)
- 데이터 발생 지점 근처의 엣지 서버·게이트웨이에서 AI 모델을 실행하는 분산 추론 방식
- 중앙 클라우드 의존을 줄여 저지연·대역폭 절감·프라이버시를 확보하는 AI 처리 패러다임
## 키워드
* Edge Computing, Gateway, Inference, 경량 모델, MEC, 5G/6G
## 암기법
* 저대프현: 저지연·대역절감·프라이버시·현장처리
## 특징
- 저지연성: 현장 근처 처리로 응답 시간 단축
- 대역 효율성: 중앙 전송 데이터 최소화
- 프라이버시 보호성: 민감 데이터 엣지 보관
- 분산 운영성: 다수 엣지 노드 협업 처리
## 목적
- 실시간 추론·현장 의사결정 지원
- 클라우드 의존도 감소와 비용 최적화
## 구성요소
- 엣지 클러스터, 경량화된 서버 HW, MEC 게이트웨이
- 모델 분할(Split Inference), 컨테이너화 배포
- 적용 분야: 스마트 팩토리, 자율주행 보조
- [[온디바이스 AI]] 비교: 엣지(서버 근접) vs 단말 내부, 중형 모델 vs 초경량 모델
## 구성도
```
[디바이스] → [엣지 서버/게이트웨이 (AI 추론)] → [클라우드 (학습/관리)]
                  ↑ 저지연 응답·로컬 처리
```
