#정보관리기술사 #AI #밀도기반클러스터링 #AI/ML_알고리즘/기법
## 정의
- 임의의 클러스터 중심을 이동시키며 중심으로 부터 정해진 반경거리 내 **최소 데이터 포인트 개수**를 확인하며 **밀도 기반 군집화**를 수행하는 알고리즘

## 키워드
- 밀도, 군집화, Core Boarder, Epslion, Connected

## 암기법
- 구성요소
	- 코노보 (Core Point, Boarder Point, Connected, Noise Point)
- 동작방식
	- 엡민 (Epslion 설정, minPts 설정)

## 구성요소
| **구성요소**         | **설명**                                                              |
| ---------------- | ------------------------------------------------------------------- |
| **Core Point**   | - 거리 $\epsilon$(Epsilon) 이내에 데이터가 $m$개 이상 존재하여 하나의 군집으로 인정되는 데이터 집합 |
| **Border Point** | - 군집의 중심이 되는 core point는 되지 못하지만, core point로 하는 군집에는 속하는 데이터       |
| **Connected**    | - core point와 core point가 반경 내에 겹칠 경우 연결되어 있다고 보고 하나의 군집으로 정의       |
| **Noise Point**  | - 어떤 점의 중심으로도 조건을 만족시키지 못하는 데이터                                     |
