#정보관리기술사 #AI #MAS #멀티에이전트
## 정의
멀티 에이전트 시스템(Multi Agent System, MAS)
- 여러 자율적·지능적 에이전트가 협력·조정·경쟁하며 공동 목표를 달성하는 분산 인공지능 시스템
- LLM·도구 통합 기반 분산 자율 협업 구조의 차세대 AI 아키텍처
## 키워드
* A2A, MCP, BDI 모델, Orchestration, CoT/ToT, 분산 합의
## 암기법
* 자협분적: 자율성·협력성·분산성·적응성
## 특징
- 자율성: 개별 에이전트 독립 의사결정
- 협력성: 메시지 교환·역할 분담으로 공동 목표 달성
- 분산성: 분산 환경 통합·수평 확장
- 적응성: 환경 변화에 동적 재구성
## 목적
- 복잡 업무의 분산 처리·전문성 결합
- 단일 에이전트 한계를 다중 협업으로 극복
## 구성요소
- 통신: A2A, MCP, 메시지·이벤트 기반 통신
- 추론·계획: CoT, ToT, Task 스케줄러, Negotiation, 의사결정
- 역할 구조: 리더·서브, 역할 기반 오케스트레이션
- 전문가·통합: 전문가 에이전트, 메타 에이전트, 결과 통합
- 학습: BDI 모델, 멀티 에이전트 강화학습, LLM + 외부 툴
- 아키텍처: 오케스트레이션, 분산 MAS 플랫폼, 서비스 분해
- 보안·신뢰: 인증·인가, 분산 합의, 신뢰도 기반 상호작용
- 유형: 독립형(이산·자발), 협력형(통신·숙고·협상·비통신)
## 구성도
```
        ┌── Agent A (도메인 전문가)
사용자 → Orchestrator/Leader Agent ── Agent B (도구 호출)
        └── Agent C (검증/메타)
              ↑ A2A·MCP 메시지 교환·결과 통합
```
