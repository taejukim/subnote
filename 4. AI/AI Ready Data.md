#정보관리기술사 #AI #AIReadyData #AI/ML_알고리즘/기법 #NEW
## 정의
AI Ready Data
- AI·ML 모델의 훈련·검증·테스트에 바로 사용할 수 있도록 준비·구조화·정리된 데이터
## 키워드
* 원시데이터, 포맷, 가공 및 데이터 라벨링, 클래스 라벨(단일·다중)
## 암기법
* 획정제라: 획득·정제·라벨링
## 특징
- 즉시 가용성: 학습 파이프라인에 바로 투입 가능
- 모달별 절차: 텍스트·음성·이미지 / 영상(동적·정적) 획득·정제 체계
- 품질·윤리: 법제도·다양성·편향 방지·개인정보·저작권 고려
- 용어 계층: 원시→원천(미라벨)→라벨링데이터(참값·어노테이션)
## 목적
- 고품질 AI 학습용 데이터 구축·표준화
- 모달별 획득·정제·라벨링 일관성 확보
## 구성요소
- 절차: 데이터 정의 → 특성 분석 → 획득 절차·항목 → 정제 방식 → 도구 → 고려사항
- 용어: 데이터 획득, 정제, 라벨링, 라벨링데이터, 원시/원천데이터, 참값, 어노테이션
- 고려: 법·제도, 다양성, 편향·윤리, 보안·저작권, 데이터 균형
## 구성도
```
원시데이터 획득 → 정제(원천데이터) → 라벨링(참값·어노테이션)
                → AI Ready Data → 훈련/검증/테스트
```
