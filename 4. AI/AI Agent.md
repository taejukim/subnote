#정보관리기술사 #AI #AIAgent #AI/LLM/생성AI #NEW
## 정의
AI Agent
- 환경과 상호작용하며 데이터를 수집하고, 사전 정의된 목표 달성에 필요한 작업을 스스로 결정·수행할 수 있는 자율 시스템
## 키워드
* 인식, 추론, 행동, 학습
## 암기법
* 센프지액: Sensor·Process·Knowledge Base·Actuator
## 특징
- 자율성: 목표 달성을 위한 작업 자체 결정·수행
- 환경 상호작용: Sensor↔Environment↔Actuator
- 지식 기반: Process와 Knowledge Base 양방향 연동
- 진화성: AI Agent + 학습알고리즘 → Agentic AI
## 목적
- 단순 작업 자동화와 환경 적응형 의사결정
- 학습을 통한 자율 결정형 Agentic AI로의 기반 제공
## 구성요소
- 기술요소: Sensor, Process, Knowledge Base, Actuator, 학습 알고리즘, 엣지 컴퓨팅(Tiny ML)
- 유형: 단순 반사, 모델 기반, 목표 기반, 유틸리티 기반 에이전트
## 구성도
```
Environment ↔ Sensor → Process ↔ Knowledge Base
                    ↓
                 Actuator → Environment
AI Agent + RL/지도/비지도 = Agentic AI
```
