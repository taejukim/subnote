#정보관리기술사 #AI #머신언러닝 #MachineUnlearning
## 정의
머신 언러닝(Machine Unlearning)
- 한번 학습된 ML 모델에서 특정 데이터의 영향을 제거·무효화하여 학습하지 않은 것처럼 모델을 재구성하는 기술
- 잊혀질 권리·프라이버시 보호를 위한 데이터 삭제 요구 대응 기술
## 키워드
* 잊혀질 권리, GDPR, SISA, Differential Privacy, Impair-Repair, Membership Inference
## 암기법
* 영임수: 영향분석·임페어·수리(Repair)
## 특징
- 선택적 제거성: 특정 데이터의 학습 영향만 무력화
- 재학습 회피성: 전체 재학습 없이 효율적 처리
- 검증성: 언러닝 결과의 정량 평가 가능
- 보안 통합성: 멤버십 추론 방어와 결합
## 목적
- 잊혀질 권리·개인정보 삭제 요구 대응
- AI 모델의 윤리·정확성·신뢰성 유지
## 구성요소
- 절차: 언러닝 대상 정의 → 영향도 분석 → Impair → Repair → 평가·검증
- 기술요소: Error-Maximizing Noise, Impair&Repair Framework, Zero-glance Unlearning, SISA
- 보안 기술: Differential Privacy, Model Distillation
- 방어 기술: Membership Inference Defense, Certified Unlearning
## 구성도
```
[원본 모델] + 삭제 요청 데이터
    → 영향도 분석 → Impair(영향 무력화)
    → Repair(성능 복구) → 평가/검증 → [언러닝된 모델]
```
