#정보관리기술사 #AI #라벨링어노테이션 #AI/ML_알고리즘/기법 #NEW
## 정의
데이터 라벨링과 어노테이션
- 라벨링(Labeling): AI가 머신러닝에 활용할 수 있도록 기능·목적에 부합하는 정보를 원천데이터에 부착하는 활동
- 어노테이션(Annotation): 라벨링에서 사람이 부여한 식별 기준을 기계가 인식하도록 선정된 데이터에 추가 정보를 기입하는 과정
## 키워드
* 클래스 라벨, Bounding Box, Polygon, NER, 텍스트 전사
## 암기법
* 텍이비오: 텍스트·이미지·비디오·오디오(+기타)
## 특징
- 목적 부합성: 학습 목표에 맞는 정보 부착
- 모달리티별 방식: 텍스트·이미지·비디오·오디오 상이
- 정밀 표기: 박스·폴리곤·키포인트·전사 등
- 품질 의존: 라벨 품질이 모델 성능·신뢰성에 직결
## 목적
- 지도학습용 정답 신호 생성
- 알고리즘이 인식할 수 있는 형태로 인간 기준을 부호화
## 구성요소
- 텍스트: 분류(클래스), NER(단어·구문), 관계·의존성(관계 라벨)
- 이미지: 분류(클래스), 객체인식(Bounding Box, Polygon)
- 비디오: 분류, 객체인식(박스·키포인트), 객체추적(폴리곤·폴리라인)
- 오디오: 분류, 세그먼테이션·STT(텍스트 전사)
- 기타: 시계열 세그먼테이션, HTML 문서분류(클래스)
## 구성도
```
[원천데이터] → 라벨링(목적 정보 부착) → 어노테이션(기계 인식 가능 추가정보)
              → 모달별 방식(클래스/박스/폴리곤/전사 등) → 학습용 데이터셋
```
