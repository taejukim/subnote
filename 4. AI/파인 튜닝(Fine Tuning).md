#정보관리기술사 #AI #파인튜닝 #AI/LLM/생성AI
## 정의
- 일반적인 학습과정에서 얻은 모델의 가중치를 초기설정으로 사용하고, 새로운 데이터셋에 대하여 추가적인 학습을 진행하며 조정하는 과정
## 키워드
- 특정 작업 최적화, 전이 학습, 지도 파인 튜닝, 비지도 파인 튜닝, 미세조정

## 암기법
- 절차
	- 사조학최 (사전학습, 출력 계층 조정, 모델 학습, 모델 최적화)
## 절차
**사전 학습 모델** → **출력 계층 조정** → **모델 학습** → **모델 최적화**

| **구분**    | **핵심**    | **활용사례**                             |
| --------- | --------- | ------------------------------------ |
| **데이터처리** | 사전 훈련된 모델 | 대규모 범용 데이터셋으로 이미 훈련된 모델              |
| **인터렉션**  | 타깃 데이터셋   | 파인 튜닝을 위해 선택된 특정 작업이나 도메인 관련 데이터     |
|           | 추가 학습     | 사전 훈련된 모델에 타깃 데이터셋을 사용하여 추가적인 학습을 진행 |
|           | 성능 평가     | 추가 학습을 거친 모델의 성능을 검증하는 단계            |

## 고려사항
|**구분**|**고려사항**|**활용사례**|
|---|---|---|
|**학습측면**|학습률|대규모 범용 데이터셋으로 이미 훈련된 모델|
|**데이터 측면**|데이터 양|타깃 데이터셋의 크기는 파인 튜닝의 효과에 중요한 요소로 작용|
|**모델 측면**|모델의 복잡성|적절한 복잡성을 가진 모델을 선택하는 것이 중요|
## 파인튜닝 방법
| **방법**               | **내용**                                                                                            |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| **Full Fine-tuning** | - 사전 학습된 모델의 **모든 레이어와 매개변수를 업데이트**하여 대상 작업에 맞게 조정하는 방법<br>- 작업과 모델 간 차이가 크거나 높은 유연성이 필요          |
| **Repurposing**      | - 사전 학습된 모델의 **하위 레이어를 유지하고 상위 레이어만 파인튜닝**하여 특정 작업에 적용하는 방법<br>- 작업과 모델 간 유사성이 있거나 데이터셋이 작은 경우 적합 |
## 파인튜닝 유형
| **유형**       | **내용**                                                                                                |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| **지도 파인튜닝**  | - 레이블이 지정된 학습 데이터셋을 사용하여 모델을 조정하는 과정<br>- 샘플의 레이블을 통해 모델이 **목표 출력을 학습**하여 특정 작업에 더 잘 적응               |
| **비지도 파인튜닝** | - 레이블 없는 데이터셋을 사용하여 모델을 조정하는 과정<br>- 명시적 출력 없이 입력 데이터의 고유 구조를 활용해 **유용한 특징을 추출**하거나 모델의 표현 능력을 향상이 목적 |
## 프롬프트 튜닝(Prompt Tuning) - 파인튜닝과 병행
| **유형** | **내용**                                                                                          |
| ------ | ----------------------------------------------------------------------------------------------- |
| **개념** | - 사전 학습된 모델 자체를 변경하지 않고 **학습 가능한 프롬프트(임베딩 벡터)**를 추가하여 성능 개선<br>- LLM이 특정 작업을 수행하도록 유도하는 텍스트나 명령 |
| **목적** | - 주어진 작업의 요구사항과 목적에 따라 모델의 입력을 조정하여 성능을 최적화                                                     |
