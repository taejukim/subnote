## 정의
배치 정규화(Batch Normalization)
- 학습 시 배치를 한 단위로 정규화하여 분포의 평균이 0, 분산이 1이 되도록 하는 작업
## 키워드
* Vanishing Gradient, BN Layer, 데이터 분포 정규화(평균0·분산1)
## 암기법
* 평분활스: 평균·분산 계산 → 정규화 → 활성함수 → Scale/Shift
## 특징
- 배치 단위: 미니배치별 평균·분산으로 정규화
- 층 삽입: 은닉층에서 활성함수 직전에 BN Layer
- 학습 안정: 기울기 소실 완화, 학습률 상향 가능
- 정규화 효과: 내부 Regularizer로 Dropout 의존 감소 가능
## 목적
- 층별 입력 분포를 안정화해 효율적 학습
- 초기값 의존도 감소 및 학습 가속
## 구성요소
- 절차: 미니배치 평균·분산 계산 → BN 정규화 → Scale/Shift → 활성함수 → 출력 점검
- 필요성: 기울기 소실 해결, Learning Rate 증가, Regularizer, 초기값 의존↓
- 효과(알고리즘): 파라미터 스케일 영향↓ → 학습률 자유·빠른 학습
- 효과(절차): Dropout 생략 가능 → 학습 단계 단순화
## 구성도
```
Input → Weight → [Hidden: BN Layer(정규화→활성 효율화)] → Weight → Output
AS-IS: 치우친 분포  →  TO-BE: 평균0·분산1 정규분포
```
