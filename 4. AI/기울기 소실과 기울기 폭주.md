## 정의
기울기 소실과 기울기 폭주(Vanishing / Exploding Gradient)
- 기울기 소실: 심층 신경망 학습 시 역전파 과정에서 기울기가 점차 작아져 가중치가 갱신되지 않는 현상
- 기울기 폭주: 역전파 과정에서 기울기가 점차 커져 가중치가 비정상적으로 발산하는 현상
## 키워드
* ReLU, Leaky ReLU, Gradient Clipping
## 암기법
* 활시중 / 클초He배: 원인(활성·시그모이드·가중치), 해결(클리핑·초기화·He·배치정규화)
## 특징
- 깊이 의존성: 층이 깊을수록 역전파 누적 효과 심화
- 소실: 입력 측 가중치 수렴·학습 정지
- 폭주: 가중치 발산·수치 불안정
- 활성·가중치 원인: Sigmoid 포화, 부적합 초기화
## 목적
- 심층망에서 안정적인 기울기 흐름 유지
- 효과적인 역전파 기반 학습 가능하게 함
## 구성요소
- 발생원인(활성): 은닉층 Sigmoid → 출력 0/1 포화(소실), 임계 초과 기울기 전달(폭주)
- 발생원인(가중치): 역전파 중 가중치 폭발, 부적합 초기 가중치
- 해결(활성): ReLU·변형 ReLU 사용, 은닉층 Sigmoid 지양
- 해결(가중치): Gradient Clipping, Xavier/He 초기화, Batch Normalization
## 구성도
```
입력층 → [가중치 수렴(소실) / 발산(폭주)] → 은닉층 → 오류 역전파 → 출력층
출력측 큰 기울기 ──역전파──▶ 입력측으로 갈수록 소실(희미) 또는 폭주(증폭)
```
