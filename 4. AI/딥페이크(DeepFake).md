#정보관리기술사 #AI #딥페이크 #AI/AI_보안/신뢰성/윤리
## 정의
- 딥러닝과 Fake의 합성어로 딥러닝을 이용해 기존 영상에 다른 영상이나 이미지 정보를 합성하여 콘텐츠를 생성하는 기법
## 키워드
- GAN, 이미지 합성, 역기능

## 탐지기술
- 인공지능 기반 탐지
	- 얼굴 특징 분석
	- 영상 품질 분석

	- 픽셀 레벨 분석
	- 메타데이터 분석
## 요소 기술
| **구분**         | **과정**                        | **기술 또는 데이터**                        | **설명**                                         |
| -------------- | ----------------------------- | ------------------------------------ | ---------------------------------------------- |
| **수집**         | - 이미지, 영상 수집                  | - 이미지 영상<br>- 참고 데이터                 | - Source와 Target 이미지 및 영상정보 수집                 |
| **생성 (GAN활용)** | - 생성 모델 훈련<br>- 생성 모델 가짜표본 생성 | - Autoencoder<br>- **GAN**<br>- LSTM | - 수집 데이터 기반 훈련<br>- 잠재변수 이용하여 가짜 표본(이미지/영상) 생성 |
| **식별 및 학습 반복** | - Real/Fake 구분                |                                      | - 식별모델이 Real/Fake 구분하여 생성 모델에 피드백 (반복)         |
| **딥페이크 생성**    | - 딥페이크 결과 생성                  | - Fake 데이터<br>- Real 데이터             | - 딥페이크 결과 완성                                   |
