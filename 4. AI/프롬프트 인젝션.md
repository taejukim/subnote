## 정의
프롬프트 인젝션(Prompt Injection)
- LLM 응답을 조작하기 위해 공격자가 프롬프트에 정교히 조작된 입력값을 주입해 민감 데이터를 유출하는 공격 기법
## 키워드
* LLM 프롬프트, 자연어 명령어, 시스템 명령어, 입력값 조작, 탈옥(Jailbreak), 직접/간접 인젝션
## 암기법
* 직간 / 입권모: 직접·간접 / 입력검증·권한제어·모니터링
## 특징
- 명령·데이터 혼재: 시스템 프롬프트와 사용자 입력 구분 난이
- Jailbreak: 보안 경계 우회로 의도치 않은 결과
- 직접/간접: 프롬프트 직접 주입 vs 외부소스 경유 주입
- 영향: 프롬프트·데이터 탈취, RCE·멀웨어, 허위정보
## 목적
- LLM 기반 시스템의 프롬프트 조작·정보유출 위협 이해
- 입력 검증·권한·모니터링으로 대응 체계 수립
## 구성요소
- 공격절차: 시스템 프롬프트 + 악성 입력 → LLM 처리(Jailbreak) → 의도치 않은 결과
- 직접 인젝션: 프롬프트 직접 접근, 데이터 오남용·개인정보 침해
- 간접 인젝션: 외부소스 악성 주입, 가용성·무결성·프라이버시 침해
- 대응: Regex·화이트/블랙리스트·캡슐화·의미분석 / 최소권한·RBAC·신뢰경계 / 승인·모니터링·감사·RLHF
## 구성도
```
System Prompt(정상) + User Input(악성)
        → LLM(Jailbreak/Direct·Indirect)
        → 의도치 않은 결과(유출·오남용)
```
