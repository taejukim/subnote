## 정의
자기지도학습(Self-supervised Learning)
- 데이터에 스스로 레이블을 생성하여 학습하는 지도학습 형태의 비지도학습
- 지도학습이 필요한 작업에 비지도 학습을 활용하는 학습 방식
## 키워드
* 프리텍스트 태스크(pre-text task), 다운스트림 태스크(downstream task), 전이학습
## 암기법
* 프다: 프리텍스트·다운스트림
* 프다파: 프리텍스트·다운스트림·파인튜닝
## 특징
- 자기라벨성: 비라벨 데이터에서 자동으로 라벨 생성
- 2단계성: Pre-text로 특징 학습 후 Downstream에 전이
- 전이성: 소량 라벨로도 최종 태스크 적용 가능
- 다양성: 생성·Pre-text·대조학습 등 유형 존재
## 목적
- 대량 비라벨 데이터로 표현(특징) 학습
- 라벨 부족 환경에서 다운스트림 성능 확보
## 구성요소
- 유형: 생성 기반(오토인코더, GAN, MAE) / Pre-text 기반(공간·시간 관계) / 대조학습(SimCLR, MoCo)
- 프리텍스트 태스크: 비라벨 데이터로 특징 추출층 학습
- 다운스트림 태스크: 소량 라벨로 최종 목표(분류·인식 등) 수행
- 파인튜닝: 사전학습 가중치를 미세조정해 더 적은 라벨로 적용
## 구성도
```
[Unlabeled Dataset] → Pre-text Task → Knowledge Transfer
[Labeled Dataset]   → Downstream Task (→ Fine-tuning)
```
