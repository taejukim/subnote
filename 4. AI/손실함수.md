## 정의
손실함수(Loss Function)
- 신경망의 실제값과 예측값의 차이(오차)를 수치화하여 최적 가중치를 찾기 위한 함수
## 키워드
* 오차 계산, MSE, RMSE, MAE, BCE, CCE, SCCE
## 암기법
* 회이이 / 분B / 다CS: 회귀(MSE·RMSE·MAE), 이진(BCE), 다중(CCE·SCCE)
## 특징
- 오차 정량화: 예측·실제 차이를 스칼라로 측정
- 과제별 선택: 회귀·이진·다중분류에 따라 상이
- 활성화 연계: BCE↔Sigmoid, CCE/SCCE↔Softmax
- 최적화 입력: 옵티마이저·역전파의 목적함수
## 목적
- 모델 오차를 측정해 가중치 갱신 방향 제공
- 학습 목표(회귀·분류)에 맞는 목적함수 설정
## 구성요소
- 회귀: MSE(제곱오차 평균), RMSE(제곱근으로 왜곡 완화), MAE(절대오차 평균)
- 이진분류: BCE(0/1 출력, 일치→0·불일치→큰 값)
- 다중분류: CCE(원-핫 라벨), SCCE(정수 라벨)
- 학습루프: 예측값 vs 실제값 → Loss → Optimizer(역전파) → 가중치 업데이트
## 구성도
```
[신경망] → 예측값 ⇄ 실제값(레이블)
              ↓ Loss Function
         [Optimizer·역전파] → 가중치 업데이트 → 신경망
```
