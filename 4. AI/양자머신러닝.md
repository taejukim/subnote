#정보관리기술사 #AI #양자머신러닝 #QML
## 정의
양자머신러닝(Quantum Machine Learning, QML)
- 양자컴퓨팅의 중첩·얽힘·간섭 원리를 머신러닝에 접목한 융합 기술
- 큐비트와 양자 회로로 학습·추론 효율을 비약적으로 높이는 차세대 AI 패러다임
## 키워드
* Qubit, 중첩, 얽힘, 간섭, PQC(Parameterized Quantum Circuit), DRU, 하이브리드 신경망
## 암기법
* 중얽간: 중첩·얽힘·간섭
## 특징
- 지수적 병렬성: 큐비트 중첩으로 다중 상태 동시 표현
- 표현력 강화: 고차원 양자 상태로 복잡 패턴 학습
- 하이브리드성: 고전 + 양자 신경망 결합 운영
- 응용 특화성: 양자화학·신약개발·금융 최적화
## 목적
- 고전 머신러닝의 연산·표현 한계 돌파
- 신약·소재·금융 등 고난이도 문제 해결
## 구성요소
- 데이터 단위: Qubit (큐비트)
- 연산구조: 양자회로, 유니터리 변환
- 학습방식: PQC(Parameterized Quantum Circuit) 최적화
- 향상기법: 양자 데이터 재활용(DRU), 항등 블록(IB), 하이브리드 신경망
- 응용: 양성자 친화도 예측, 약물 독성 예측, KRAS 억제제 설계
- 고전 ML 비교: 비트/선형대수 vs 큐비트/양자회로, 제한적 병렬 vs 지수적 확장
## 구성도
```
[고전 데이터] → [양자 인코딩] → [PQC: 회전·얽힘 게이트]
   → [측정] → [고전 후처리] → [최적화 루프 환류]
```
