#정보관리기술사 #AI #RAG #AI/LLM/생성AI
## 정의
- 생성형 AI 서비스를 외부 데이터를 검색하고 검색된 관련 데이터를 컨텍스트에 추가하여 AI모델의 정확성과 신뢰성을 향상시키는 기술
## 키워드
- 인덱싱, 청크, 임베딩, 벡터DB, 유사도, 프롬프트 증각, 할루시네이션

## 암기법
- 처리단계 
	- 저쿼정답출(문서 변환/저장, 입력쿼리/문서 검색, 정보증가, 답변생성, 출력 생성)

## 필요성
- 지식단절 : 모델 학습 이후에 생성된 데이터에 대해서 학습 부족으로 품질 저하
- 환각현상 : 사실에 입각하지 않은 답변을 그럴듯하고 자연스럽게 하는 환각 증상
- 범용성 : 다방면에 일정 수중 이상의 답변을 할 수 있지만, 특정 영역의 전문성
## 처리단계
| **단계**                                  | **기술 요소**                                                                         | **설명**                                                                                                                                          |
| --------------------------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 문서 변환 & 저장**                       | - Sentence Embedding<br>- Vector DB                                               | - 문서를 읽어와서(Load) 분할(Split)하고 파싱(Parsing)<br>- Dense Vector 형태의 Sentence Embedding 변환<br>- Indexing하여 Vector DB에 저장                              |
| **2. 입력 쿼리 & 문서 검색**                    | - Query<br>- 문서 검색 (Document Retrieval)                                           | - 검색 시스템 활성화(Retrieval System Activation)<br>- 입력 쿼리를 검색 시스템이 이해할 수 있도록 쿼리 처리<br>- 쿼리(Query)를 기반으로 말뭉치(corpus)를 검색하고 관련 문서나 정보 스니펫(snippet)을 검색 |
| **3. 정보 증강 (Information Augmentation)** | - 맥락 통합(Context Integration)<br>- 증강된 입력 형성(Context Integration)                  | - 원래 입력과 문서에서 추출된 관련 정보를 결합하는 것을 포함하여 검색된 문서를 입력 쿼리를 강화하는 데 사용<br>- 증강된 입력이 형성되며, 쿼리와 검색된 문서의 추가 맥락을 모두 포함                                      |
| **4. 답변 생성**                            | - Sequence to Sequence<br>- BART (Bidirectional and Auto-Regressive Transformers) | - 강화된(augmentation) 입력을 GPT나 BART와 같은 sequence to sequence 모델에 제공<br>- 언어 모델은 입력된 내용을 처리하고 응답을 생성                                               |
| **5. 출력 생성**                            | - 정제 및 형식화 (Refinement and Formatting)                                            | - 생성 응답을 애플리케이션에 따라 요구 사항에 맞게 정제 혹은 형식화<br>- 최종 응답을 RAG 프로세스의 출력으로 전달                                                                           |
