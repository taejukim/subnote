#정보관리기술사 #AI #AI테스트 #레드팀
## 정의
AI 테스트(AI Red Team Test)
- AI 모델·시스템의 취약점·편향·사회적 해악·보안 위협을 식별하기 위해 의도적으로 다양한 공격을 시도하는 적대적 탐색 테스트
- 비결정성·광범위한 사회 영향을 가진 AI에 특화된 적대적 평가 기법
## 키워드
* Red Team, Blue Team, Prompt Injection, Jailbreak, Adversarial Input, ISO/IEC 42119-7
## 암기법
* 편유보유: 편향·유해성·보안·유출
## 특징
- 적대성: 공격자 관점의 능동 탐색
- 비결정성 대응: AI 출력 변동성을 고려한 반복 시험
- 다학제성: 기술·윤리·법·도메인 전문가 참여
- 표준화 진행: ISO/IEC 42119-7 등 표준 추진
## 목적
- AI 모델의 잠재 위협·편향·취약점 사전 식별
- 가드레일·필터·모니터링 정책 수립 근거 확보
## 구성요소
- 팀구성: 10~100명, 기술·윤리·법·도메인·전문 사용자
- 팀유형: 내부/외부 레드팀, 전문가 유저, 중립 레드팀
- 모델 테스트 기법: Prompt Injection, Jailbreak, 적대적 입력, 편향·유해성 유도, Agent 오동작 유도, 데이터 오염
- 시스템 테스트 기법: 데이터 유출, 권한 탈취, 가드레일 무력화, 보안 경계 테스트
- 절차: 범위 정의 → 레드팀 구성 → 공격 → 블루팀 분석 → 리포팅·대책
- 산출물: 신규 평가지표, 테스트 케이스, 가드레일·필터 규칙
## 구성도
```
[Red Team 공격]              [Blue Team 분석]              [Report]
프롬프트 인젝션·탈옥·   →   리스크 카탈로그·       →   가드레일·필터링·
유출·편향·적대적 입력         취약점 분류                평가지표·테스트 기법
```
