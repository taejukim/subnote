## 정의
머신러닝 옵티마이저(Optimizer)
- 손실함수의 최소값을 찾기 위해 신경망의 가중치를 갱신하여 모델을 최적화하는 알고리즘
## 키워드
* 가중치 갱신, 에포크, 러닝레이트, 경사하강법, SGD, Momentum, NAG, AdaGrad, RMSProp, AdaDelta, Adam
## 암기법
* SMNARΔA: SGD·Momentum·NAG·AdaGrad·RMSProp·AdaDelta·Adam
## 특징
- 가중치 갱신성: 손실 경사를 따라 파라미터 업데이트
- 학습률 의존성: Step 크기로 수렴 속도·안정성 결정
- 문제 대응성: Overshooting·Local Minimum 완화 기법 발전
- 적응성: Ada계열·Adam은 파라미터별 학습률 조절
## 목적
- 손실함수 Global Minimum에 효율적으로 수렴
- 순전파·오차계산·역전파 루프에서 가중치 최적화
## 구성요소
- SGD: 학습률 기준 경사 하강, Overshooting·Local Min 가능
- Momentum: 관성으로 Local Minimum 완화
- NAG: 예견 기울기로 제동·Overshooting 해결
- AdaGrad: 파라미터별 학습률, 많이 변한 쪽은 작게
- RMSProp: 지수이동평균으로 AdaGrad의 학습률 0 수렴 개선
- AdaDelta: 학습률 직접 사용 없이 AdaGrad 개선
- Adam: Momentum + RMSProp 결합(가장 대중적)
## 구성도
```
입력 → [순전파] 가중치 → 예측값 → 손실함수(실제값 비교)
                              ↓
                    [역전파·Optimizer] → 가중치 갱신
```
