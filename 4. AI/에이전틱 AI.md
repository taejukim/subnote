## 정의
에이전틱 AI(Agentic AI)
- 메모리·계획·환경 감지·도구 활용·안전 지침 준수 등 기능과 다양한 AI 기술을 결합해 목표 달성을 위한 작업을 스스로 수행하는 AI
## 키워드
* 자율, 인식, 추론, 행동, 학습, LLM, RAG, 데이터 플라이 휠
## 암기법
* 인추행학: 인식·추론·행동·학습
## 특징
- 자율 계획성: 목표 설정·자율 계획·API 통합 실행
- LLM+RAG 추론: 검색 증강과 LLM 기반 추론
- 데이터 플라이휠: 피드백으로 모델 커스터마이징 지속
- 성숙 관리: SaaS·IoT 통합, 거버넌스·보안
## 목적
- 목표 지향 작업을 인간 개입 최소화로 자율 수행
- 산업·보안·의료·소매 등 도메인 최적화
## 구성요소
- 인식: 데이터 수집, 특징 추출
- 추론: LLM 추론, RAG
- 행동: 목표 설정, 자율 계획, API 통합
- 학습: 피드백 루프, 데이터 플라이휠
- 사례: 공급망·제조, 사이버보안·금융감시, 의료보조, 개인화 CS·재고예측
## 구성도
```
USER → AI Agent(LLM) ↔ DB / Vector DB
              ↓ Action
        Data Flywheel → Model Customization ↺
```
