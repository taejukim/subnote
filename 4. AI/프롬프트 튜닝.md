## 정의
프롬프트 튜닝(Prompt Tuning)
- 초거대 언어모델(LLM) 파라미터는 고정한 채 새로운 작업에 적응하도록 프롬프트(명령·요청 텍스트)를 조정해 원하는 방식으로 응답하게 하는 기법
## 키워드
* 최적화, 프롬프트 조합, Soft Prompt, Learnable Input, PEFT
## 암기법
* 고프모경: 고정파라미터·프롬프트조합·모델유지·경량리소스
## 특징
- 파라미터 고정성: 모델 가중치 불변, Soft Prompt만 학습
- 경량성: 최소한의 하드웨어·시간으로 작업 적응
- 유연성: 다양한 작업에 Task Prompt 단위로 적용 용이
- 오버피팅 회피성: 모델 고정으로 튜닝 자체 오버피팅 불가
## 목적
- 다양한 프롬프트 조합을 반복 최적화해 모델 출력 향상
- Full Fine-Tuning 대비 비용·리소스 최소화
## 구성요소
- Soft Prompt: Mixed-task Batch → Task Prompt(학습 가능 입력) → Pre-trained Model
- 비교(vs 파인튜닝): 목적·방법·구조변경·리소스·정확도·기반기술·오버피팅·확장성
- 기반 기술: One/Zero-Shot Prompting, CoT
- 파인튜닝 대비: 전이학습, LoRA 등 파라미터 재학습
## 구성도
```
Prompt → [프롬프트 조합 변경] → LLM(파라미터 고정) → Response
                ≠
Prompt → LLM → [데이터셋 추가학습] → Response  (Fine Tuning)
```
