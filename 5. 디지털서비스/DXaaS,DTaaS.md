#정보관리기술사 #디지털서비스 #DXaaS #DTaaS
## 정의
DXaaS / DTaaS
- DXaaS(Digital Transformation as a Service): DX 추진을 위한 컨설팅·플랫폼·서비스 일체를 클라우드 기반으로 제공하는 모델
- DTaaS(Digital Twin as a Service): 디지털 트윈 구축·운영 환경을 SaaS 형태로 제공하는 서비스
## 키워드
* DX, Digital Twin, SaaS, Cloud, Plug & Play, Pay-per-use
## 암기법
* 플과종: 플랫폼·과금형·종속최소화
## 특징
- 서비스화: 자체 구축 부담 최소화
- 빠른 도입성: SaaS 기반 즉시 활용
- 확장성: 사용량 기반 유연한 확장
- 통합성: AI·IoT·데이터 분석과 결합
## 목적
- DX·디지털 트윈 도입 진입장벽 완화
- 중견·중소기업의 디지털 혁신 가속
## 구성요소
- DXaaS: DX 컨설팅, 표준 워크플로우, 변화 관리, 도입 KPI
- DTaaS: 모델링 환경, 실시간 데이터 동기화, 시뮬레이션, 시각화 대시보드
- 공통 기술: 클라우드, IoT, AI/ML, API 통합
- 운영 모델: 구독형, 사용량 기반 과금
- 사례: GE Digital, Siemens MindSphere, AWS TwinMaker
## 구성도
```
[기업 고객] → [구독] → [DXaaS / DTaaS 플랫폼 (Cloud)]
                         ↓
              컨설팅·DT 모델·시뮬레이션·KPI 대시보드
                         ↑ IoT 데이터·AI 모델·API ↑
```
