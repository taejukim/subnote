#정보관리기술사 #디지털서비스 #SDV #소프트웨어정의차량
## 정의
소프트웨어 정의 차량(SDV, Software Defined Vehicle)
- 차량의 기능·서비스가 SW에 의해 정의·제어되며 OTA 업데이트로 지속 진화하는 차세대 자동차 아키텍처
- 하드웨어 중심에서 소프트웨어 중심으로 전환된 자동차 패러다임
## 키워드
* OTA, Zonal Architecture, AUTOSAR, Vehicle OS, ADAS, V2X
## 암기법
* OTA존중: OTA·Zonal·중앙 컴퓨팅
## 특징
- SW 중심성: 기능이 SW로 정의·확장
- OTA 진화성: 출시 후에도 기능 추가/개선
- 중앙 컴퓨팅성: Zonal·중앙 ECU 통합
- 데이터 활용성: 차량 데이터 기반 서비스
## 목적
- 차량의 지속적 기능 개선·맞춤형 서비스
- 자율주행·전동화·커넥티비티 통합 구현
## 구성요소
- 차량 OS: QNX, Android Automotive, Linux Auto
- 아키텍처: Zonal Architecture, 중앙 ECU(HPC)
- 미들웨어: AUTOSAR Adaptive, ROS 2
- OTA·DevOps: 차량 SW 배포·관리
- ADAS·자율주행: SLAM, V2X, AI
- 서비스: 사용자 맞춤형 기능, 구독형
## 구성도
```
[차량 (SDV)]
   ├── 중앙 컴퓨팅 + Zonal ECU
   ├── 차량 OS (Linux/QNX/Android)
   ├── AUTOSAR Adaptive 미들웨어
   ├── ADAS·V2X·인포테인먼트
   └── OTA 업데이트 ←─ [Cloud DevOps]
```
