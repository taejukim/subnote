#정보관리기술사 #디지털서비스 #분산클라우드 #DistributedCloud
## 정의
분산 클라우드(Distributed Cloud)
- 단일 클라우드 사업자가 여러 지리적 위치에 클라우드 서비스를 분산 배포·운영하면서 단일 제어 평면으로 관리하는 클라우드 모델
- 데이터 주권·저지연·로컬 컴플라이언스 요구를 충족하는 차세대 클라우드 운영 형태
## 키워드
* AWS Outposts, Azure Arc, GCP Anthos, Local Zones, Edge, Sovereign
## 암기법
* 분주제일: 분산배포·주권·제어평면·일관운영
## 특징
- 분산 배포성: 여러 지역·온프레미스 배포
- 단일 제어성: 통합 제어 평면 운영
- 주권 친화성: 데이터 위치·관할권 확보
- 저지연성: 사용자 근접 처리
## 목적
- 데이터 주권·규제 준수와 저지연 서비스 제공
- 글로벌 운영 일관성과 로컬 적합성 동시 충족
## 구성요소
- 제어 평면: 글로벌 클라우드 사업자 (AWS·Azure·GCP)
- 데이터 평면: Edge·Outpost·Local Zone·Sovereign Cloud
- 운영 도구: 통합 모니터링, 정책, 보안, 컴플라이언스
- 활용: 데이터 주권 요구 산업, 저지연 IoT/AI, 멀티리전
- 사례: AWS Outposts, Azure Arc/Stack, GCP Anthos
## 구성도
```
[글로벌 제어 평면 (퍼블릭 클라우드)]
              ↓ 일관 정책·관리
   [Local Zone] [On-Prem Outpost] [Sovereign Cloud] [Edge Node]
              ↑ 데이터·연산은 로컬 ↑
```
