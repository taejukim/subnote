#정보관리기술사 #디지털서비스 #스테이블코인 #StableCoin
## 정의
스테이블코인(Stablecoin)
- 법정화폐·실물자산과 연동하여 가격 안정성을 보장하도록 설계된 암호화폐
- 민간 주체가 발행하는 법정화폐 연동형 디지털 자산
## 키워드
* 법정 담보, 암호화폐 담보, 알고리즘형, MiCA, 지니어스법, CBDC 비교
## 암기법
* 법암무: 법정화폐담보·암호화폐담보·무담보알고리즘
## 특징
- 안정성: 가치 변동성 최소화
- 담보성: 법정화폐·자산·암호화폐로 가치 보장
- 글로벌성: 국경 간 송금·결제 활용
- 규제 진화성: MiCA·지니어스법 등 법제화 진행
## 목적
- 가격 변동성 해결을 통한 결제·송금 활용
- 디지털 자산 시장의 신뢰성·유동성 제공
## 구성요소
- 유형: 법정화폐 담보형, 암호화폐 담보형, 무담보 알고리즘형
- 외부 연동: 뱅킹 서비스
- 서비스 통합: 백엔드, Operation Events Webhook, Proof of Reserves Service, Cache Service
- 데이터·메시징: PostgreSQL, RabbitMQ
- 블록체인 상호작용: Smart Contract Interface
- API 운영: Backend API Service, Docker 기반 배포
- 발행 절차: 입금확인 → 주문생성 → 입금확인 → 상태업데이트 → 민팅개시 → 작업실행 → 블록체인 전송 → 결과 대기 → 기록저장
- 소각 절차: 소각요청 → 허가서명 → 트랜잭션 실행 → 결과확인 → 스마트컨트랙트 소각 → 법정화폐 송금 → 최종기록
- CBDC 비교: 중앙은행 직접 발행 vs 민간 발행, 국가 보장 vs 담보 기반
## 구성도
```
[사용자] → 법정화폐 입금 → [발행사] → 민팅(Smart Contract)
                                    ↓
                          [블록체인 네트워크 (P2P)]
                                    ↑
[사용자] → 소각 요청 → [발행사] → 법정화폐 송금
```
