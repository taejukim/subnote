#정보관리기술사 #디지털서비스 #AmbientIntelligence #앰비언트인비저블
## 정의
엠비언트 인비저블 인텔리전스(Ambient Invisible Intelligence)
- 사용자가 의식하지 못하는 사이 주변 환경에 자연스럽게 녹아 작동하는 비가시적 지능형 컴퓨팅
- IoT·센서·AI·앰비언트 컴퓨팅이 융합된 차세대 사용자 경험 패러다임
## 키워드
* Ambient Computing, Calm Tech, IoT, Edge AI, Pervasive, Context-aware
## 암기법
* 비자맥: 비가시·자연스러움·맥락 인식
## 특징
- 비가시성: 사용자 인터랙션 없이 동작
- 맥락 인식성: 사용자 상황 자동 파악
- 자연 통합성: 환경에 자연스럽게 녹아듦
- 능동성: 미리 예측·반응
## 목적
- 사용자 인지 부담 최소화와 자연스러운 경험
- 환경·기기·사람의 자연스러운 통합 가능
## 구성요소
- 센서: IoT, 카메라, 음성, 모션
- 분석: AI/ML, Context Awareness, 행동 예측
- 응답 채널: 디스플레이 없는 인터페이스, 음성, 햅틱
- 인프라: 엣지 컴퓨팅, 5G, 클라우드
- 사례: 자동 조명, 음성 비서, 스마트홈, 매장 자동 결제
## 구성도
```
[환경 (집·매장·도시)]
       ↓ IoT 센서·카메라
[Ambient Intelligence Layer (Edge AI·Context)]
       ↓ 자연스러운 응답 (조명·음성·온도)
[사용자: 의식하지 못한 채 혜택 경험]
```
