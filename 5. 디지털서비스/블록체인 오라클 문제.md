#정보관리기술사 #디지털서비스 #블록체인 #오라클문제
## 정의
블록체인 오라클 문제(Oracle Problem)
- 블록체인 외부의 데이터를 신뢰성 있게 블록체인 내부로 가져오는 과정에서 발생하는 신뢰·정확성·보안 문제
- 스마트컨트랙트 실행에 필요한 외부 데이터의 진위·일관성 확보 과제
## 키워드
* Off-chain Data, Smart Contract, Chainlink, DON, TLS Notary, Schelling
## 암기법
* 외신탈: 외부데이터·신뢰·탈중앙
## 특징
- 외부 의존성: 블록체인 외 신뢰 필요
- 단일 장애점 위험: 단일 오라클 조작 위험
- 탈중앙 필요성: 다수 오라클 합의 필요
- 검증 기술성: 암호·합의 기반 검증
## 목적
- 스마트컨트랙트가 안전하게 외부 데이터 활용
- DeFi·보험·예측 시장 등 신뢰성 확보
## 구성요소
- 입력 오라클: 외부 데이터를 블록체인으로 전달
- 출력 오라클: 블록체인 결과를 외부로 전달
- 분산 오라클 네트워크(DON): Chainlink 등
- 검증 기법: 다중 노드 합의, TLS Notary, 영지식 증명, Schelling Point
- 활용: DeFi 가격 피드, 보험 클레임, 예측 시장, 게임
## 구성도
```
[외부 데이터] (가격·날씨·이벤트)
       ↓
[분산 오라클 네트워크 (DON)] ── 합의·검증 ──
       ↓
[Smart Contract] → 자동 실행 → [DeFi·보험·예측]
```
