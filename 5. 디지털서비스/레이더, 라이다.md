#정보관리기술사 #디지털서비스 #레이더 #라이다
## 정의
레이더(RADAR) / 라이다(LiDAR)
- 레이더: 전파를 발사·반사로 거리·속도를 측정하는 전파 기반 감지 기술
- 라이다: 레이저 광선을 이용해 정밀한 거리·3D 형상을 측정하는 광파 기반 감지 기술
## 키워드
* 자율주행, ADAS, 4D 레이더, FMCW, ToF, Point Cloud
## 암기법
* 전광거속: 전파(R)·광파(L)·거리·속도
## 특징
- 측정 원리 차이: 전파(레이더) vs 레이저(라이다)
- 환경 영향: 레이더 강건, 라이다 광학 의존
- 정밀도: 라이다 우수, 레이더 비교적 거침
- 비용: 라이다 고가, 레이더 저렴
## 목적
- 자율주행·로봇·국방 등 주변 환경 감지
- 다중 센서 융합으로 안전성·정밀도 향상
## 구성요소
- 레이더: 송신 안테나, 수신 안테나, FMCW 신호 처리
- 라이다: 레이저 광원, 광 검출기, ToF 측정
- 4D 레이더: 거리+속도+방위각+고도
- 라이다 형식: Mechanical, Solid State, FMCW
- 응용: 자율주행, ADAS, 드론, 산업 측정
- 비교 - 레이더: 전파, 악천후 강건, 거리·속도, 저비용, 정밀도 낮음
- 비교 - 라이다: 레이저, 광학 의존, 3D 형상, 고비용, 정밀도 높음
## 구성도
```
[레이더] 전파 송수신 → 거리·속도 (악천후 강건)
              ↓
       센서 퓨전 → ADAS / 자율주행
              ↑
[라이다] 레이저 송수신 → 3D Point Cloud (정밀)
```
