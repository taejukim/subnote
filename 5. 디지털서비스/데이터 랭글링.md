#정보관리기술사 #디지털서비스 #데이터랭글링 #DataWrangling
## 정의
데이터 랭글링(Data Wrangling)
- Raw Data를 분석·모델링에 적합한 형태로 변환·정제·구조화하는 데이터 준비 작업
- 데이터 사이언스 워크플로우의 80%를 차지하는 핵심 전처리 활동
## 키워드
* Data Cleansing, Munging, ETL/ELT, Pandas, Trifacta, EDA
## 암기법
* 발구정통: 발견·구조화·정제·통합
## 특징
- 반복성: 분석 시도마다 반복 수행
- 다양성: 정형·반정형·비정형 처리
- 자동화 가능성: AI/ML 기반 자동 정제
- 도메인 의존성: 데이터 특성·맥락 이해 필요
## 목적
- 분석·AI 모델링을 위한 신뢰성 있는 데이터 준비
- 데이터 품질·정합성 확보
## 구성요소
- 6단계: 발견(Discover) → 구조화(Structure) → 정제(Clean) → 통합(Enrich) → 검증(Validate) → 게시(Publish)
- 작업 유형: 결측치 처리, 이상치 제거, 형식 변환, 정규화, 매핑
- 도구: Pandas, Trifacta, Alteryx, OpenRefine
- 자동화: AI 기반 패턴 인식·자동 매핑
- EDA(탐색적 데이터 분석)와 결합
## 구성도
```
[Raw Data] → 발견 → 구조화 → 정제 → 통합 → 검증 → 게시
                ↑ 도구 (Pandas/Trifacta) ↑
                ↑ 도메인 지식·EDA·자동화 ↑
```
