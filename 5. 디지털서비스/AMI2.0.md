#정보관리기술사 #디지털서비스 #AMI2 #스마트미터링
## 정의
AMI 2.0(Advanced Metering Infrastructure 2.0)
- 수용가에서 소비되는 전력량을 실시간 측정하고 과거 소비량 기반으로 예측하기 위한 차세대 지능형 검침 인프라
- IoT·통신·보안 기술을 강화한 에너지 데이터 양방향 인프라
## 키워드
* Smart Meter, HES, MDMS, DR, IEC 61850, IoT 보안
## 암기법
* 수통예양: 수집·통신·예측·양방향
## 특징
- 양방향 통신성: 검침 + 제어 동시 가능
- 실시간성: 분 단위 데이터 수집
- 보안 강화성: IoT 보안·암호화 적용
- 분석 활용성: 수요 예측·요금제 다양화
## 목적
- 에너지 효율화와 수요 반응(DR) 활성화
- 그리드 안정성·요금 정확성 제고
## 구성요소
- 스마트 미터(전기·가스·수도)
- 통신망: PLC, NB-IoT, RF Mesh
- HES(Head-End System)
- MDMS(Meter Data Management System)
- 보안: 인증·암호화·키 관리
- 응용: 수요 예측, DR, 시간대별 요금제, 마이크로그리드 연동
## 구성도
```
[수용가 스마트 미터] ─ NB-IoT/PLC ─ [HES] ─ [MDMS]
                                              ↓
                                   요금·DR·예측·시각화
                                              ↑ 보안·인증·암호화 ↑
```
