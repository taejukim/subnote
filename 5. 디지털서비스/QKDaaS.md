#정보관리기술사 #디지털서비스 #QKDaaS #양자키분배
## 정의
QKDaaS(Quantum Key Distribution as a Service)
- QKD(양자 키 분배) 기능을 클라우드 서비스 형태로 제공하여 일반 사용자가 양자 보안 키를 손쉽게 활용할 수 있도록 지원하는 서비스
- 양자암호 인프라 직접 구축 없이 구독·과금 기반으로 양자 키를 활용하는 모델
## 키워드
* QKD, BB84, 양자 키, KMS, PQC 결합, 양자보안 인프라
## 암기법
* 키서구: 키분배·서비스화·구독형
## 특징
- 서비스화: 양자 키 분배를 클라우드 SaaS화
- 진입장벽 완화: HW 직접 구축 불필요
- 표준 결합성: PQC와 하이브리드 결합 가능
- 보안 강화성: 정보 이론적 안전성 제공
## 목적
- 양자컴퓨팅 위협 대응 보안 키 인프라 보급
- 금융·국방·공공 등 고보안 영역 양자 키 활용
## 구성요소
- QKD 인프라: 양자 송·수신기, 광전송망
- KMS(Key Management System): 키 저장·갱신·폐기
- 서비스 인터페이스: API, SDK, 콘솔
- 운영: 구독·과금, SLA, 모니터링
- 보안 결합: PQC 하이브리드(양자키 + PQC 알고리즘)
## 구성도
```
[고객 앱] → API/SDK
              ↓
[QKDaaS 플랫폼: KMS·정책·모니터링]
              ↓ 양자 키 분배
[QKD 인프라: 송신·수신·광전송] ─── 양자 채널 ───
              ↑ PQC 하이브리드 결합 ↑
```
