#정보관리기술사 #디지털서비스 #암호화폐지갑 #CryptoWallet
## 정의
암호화폐 지갑(Crypto Wallet)
- 블록체인 자산을 안전하게 저장·관리·송수신할 수 있도록 개인키와 공개키를 보관하는 디지털 지갑
- Hot/Cold·Custodial/Non-Custodial 형태로 분류되는 블록체인 자산 인터페이스
## 키워드
* Private Key, Public Key, Hot/Cold Wallet, Custodial, Non-Custodial, MPC
## 암기법
* 핫콜커넌: 핫·콜드·커스터디·논커스터디
## 특징
- 키 관리성: 개인키가 자산 통제 핵심
- 분류 다양성: 온/오프라인, 위탁/비위탁
- 보안성: 도난·해킹 방어 핵심 자산
- 사용성 트레이드오프: 보안 ↔ 편의성
## 목적
- 블록체인 자산의 안전한 보관·송수신
- 사용자가 자산을 자기 통제할 수 있도록 지원
## 구성요소
- 핫 월렛: 온라인 연결, 편의성 ↑·보안 ↓ (모바일·웹)
- 콜드 월렛: 오프라인 보관, 보안 ↑·편의성 ↓ (USB·종이)
- Custodial: 거래소 등이 키 관리(편리, 위험)
- Non-Custodial: 사용자가 직접 키 관리(안전, 책임)
- MPC 월렛: 키를 분산 보관 (보안 + 편의)
- 보안: 시드 문구, 다중서명, 하드웨어 키
## 구성도
```
[Crypto Wallet]
   ├── Hot Wallet (온라인): MetaMask, Coinbase
   ├── Cold Wallet (오프라인): Ledger, Trezor
   ├── Custodial: 거래소 보관
   └── Non-Custodial: 사용자 키 보관 (시드)
        ↓ 개인키 → 트랜잭션 서명 → 블록체인
```
