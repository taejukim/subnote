#정보관리기술사 #디지털서비스 #디지털스레드 #DigitalThread
## 정의
디지털 스레드(Digital Thread)
- 제품·서비스의 전 생명주기 데이터를 단일 흐름(Thread)으로 통합 연결하여 부서·시스템 간 데이터 일관성·추적성을 보장하는 통합 데이터 흐름
- 설계·생산·운영·유지보수 단계 데이터를 끊김 없이 연결하는 디지털 트윈 기반 데이터 백본
## 키워드
* PLM, Digital Twin, MES, ERP, Traceability, OT/IT 통합
## 암기법
* 설생운유: 설계·생산·운영·유지보수
## 특징
- 통합성: 설계~폐기 전 단계 데이터 흐름
- 추적성: 부품·공정·이력 단일 추적
- 실시간성: 디지털 트윈과 결합 실시간 동기화
- 부서 통합성: 엔지니어링·생산·서비스 협업 강화
## 목적
- 제품 생명주기 전반의 데이터 단절 해소
- 설계·생산·운영의 의사결정 가속과 품질 개선
## 구성요소
- 시스템 통합: PLM, ERP, MES, CAD/CAE, IoT
- 데이터 흐름: 단일 모델·표준 식별자·메타데이터
- 디지털 트윈 결합: 실물 ↔ 디지털 동기화
- 표준: ISO 23247, OPC UA
- 활용: 추적성, 품질 관리, 예지보전, 지속가능성
## 구성도
```
[설계 (CAD)] → [생산 (MES)] → [운영 (IoT)] → [유지보수 (Field)]
        ↓                                          ↓
        ───── Digital Thread (단일 데이터 흐름) ─────
                          ↑
                  Digital Twin 동기화
```
