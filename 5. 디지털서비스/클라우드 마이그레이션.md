#정보관리기술사 #디지털서비스 #클라우드마이그레이션 #6R
## 정의
클라우드 마이그레이션(Cloud Migration)
- 온프레미스·레거시 시스템을 클라우드 환경으로 이전하는 전략·절차·방법론
- AWS·Gartner가 제시한 6R/7R 전략 기반 단계적 클라우드 전환 활동
## 키워드
* 6R, Lift & Shift, Refactor, Replatform, Repurchase, AWS MAP
## 암기법
* 리홀리리리리: Rehost·Hold·Replatform·Refactor·Repurchase·Retire/Retain
## 특징
- 전략 다양성: 6R/7R 전략 기반 선택
- 단계성: 평가 → 계획 → 실행 → 운영 단계
- 위험 관리성: 비즈니스 연속성·보안 고려
- 가치 지향성: 비용·민첩성·혁신 가치 추구
## 목적
- 인프라 비용·운영 부담 감소와 민첩성 확보
- 클라우드 네이티브 혁신과 비즈니스 가속
## 구성요소
- 6R 전략:
  - Rehost (Lift & Shift): 그대로 이전
  - Replatform: 일부 변경 후 이전
  - Repurchase: SaaS로 교체
  - Refactor: 클라우드 네이티브 재설계
  - Retire: 폐기
  - Retain: 그대로 유지
- 7R 추가: Relocate (VMware 등 동일 환경 이전)
- 절차: Assess → Plan → Migrate → Operate
- 도구: AWS MAP, Azure Migrate, GCP Migrate
- 위험: 데이터 일관성, 보안, 다운타임, 종속성
## 구성도
```
[Assessment] → [Planning] → [Migration] → [Operation]
                  ↓ 6R 전략 선택
   Rehost / Replatform / Repurchase / Refactor / Retire / Retain
```
