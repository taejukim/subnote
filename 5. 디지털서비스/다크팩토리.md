## 정의
- CPS(사이버 물리 시스템)와 AI를 기반으로 공정의 모든 단계가 인간의 개입 없이 자율적으로 수행되는 무인 공장

## 아키텍처
* 서비스 레이어 : ERP, MES, SCM
* 지능화 플랫폼 : 디지털 트윈, AI Agent, 데이터레이크
* 통신, 연결, 제어 : Private 5G/TSN, Edge Computing
* 물리/자율기기 : AMR/AGV, 다관절 로봇, IoT센서
* 지능화 플랫폼 → 통신/연결/제어 → 물리 자율기기 : CPS 루프

AMR(Autonomous Mobile Robot) : 무인운반차
AGV(Automated Guided Vehicle) : 자율 주행 로봇
