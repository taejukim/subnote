#정보관리기술사 #디지털서비스 #SaaS #공공SaaS가이드
## 정의
공공부문 SaaS 이용 가이드라인
- 공공기관이 SaaS(Software as a Service)를 안전하고 효율적으로 도입·운영하기 위한 절차와 기준을 제시한 행정 지침
- 디지털플랫폼정부의 SaaS 우선 정책 시행을 지원하는 표준 가이드
## 키워드
* CSAP SaaS, 디지털플랫폼정부, 공공조달, 데이터 주권, 보안 점검
## 암기법
* 도운보종: 도입·운영·보안·종료
## 특징
- 절차 표준성: 도입~종료 단계 표준화
- 보안 강조성: CSAP·보안 점검 의무
- 데이터 거버넌스: 위치·이전·삭제 명확화
- 종속성 회피: 멀티 SaaS·표준 API 권고
## 목적
- 공공기관의 SaaS 도입 신속성·안전성 확보
- 클라우드 우선 전환 정책의 실행 지원
## 구성요소
- 도입 절차: 요구사항 정의 → 사전 점검 → 도입 결정 → 계약 → 적용
- 보안: CSAP SaaS, 보안 점검 항목, 데이터 암호화
- 운영: SLA 관리, 모니터링, 변경 관리
- 데이터 거버넌스: 위치·이전·반환·삭제 절차
- 종료: 데이터 회수, 폐기 검증
## 구성도
```
[요구사항 정의] → [사전 점검 (CSAP·법적)]
       → [도입 결정·계약]
       → [적용·운영 (SLA·모니터링)]
       → [종료 (데이터 회수·삭제 검증)]
```
