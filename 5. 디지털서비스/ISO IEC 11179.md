#정보관리기술사 #디지털서비스 #ISO11179 #메타데이터
## 정의
ISO/IEC 11179
- 메타데이터 레지스트리(MDR)의 데이터 요소 정의·등록·관리에 관한 국제 표준
- 데이터 요소·표준 용어·개념·관계를 일관되게 정의하기 위한 메타데이터 표준 프레임워크
## 키워드
* MDR(Metadata Registry), Data Element, Concept, Classification, 데이터 표준화
## 암기법
* 정등관: 정의·등록·관리
## 특징
- 표준성: 데이터 요소 정의·표현 국제 표준
- 재사용성: 동일 개념 표준 재사용 가능
- 분류 체계성: 데이터 요소 계층적 분류
- 거버넌스 기반성: 등록·관리 절차 정의
## 목적
- 조직·국가 간 데이터 의미 호환성 확보
- 메타데이터 기반 데이터 거버넌스 강화
## 구성요소
- Part 1~6 구성: 프레임워크, 분류, 레지스트리, 정의, 명명, 등록
- 데이터 요소: Data Element, Value Domain, Concept
- MDR(Metadata Registry): 데이터 요소 등록·관리 시스템
- 분류: 개념적 도메인, 표현, 데이터 타입
- 활용: 공공데이터 표준, 의료 표준, 통계 표준
## 구성도
```
[Concept (개념)]
   ↓ 표현
[Data Element]: 명칭·정의·도메인·표현
   ↓ 등록
[Metadata Registry (MDR)]
   ↓ 활용
[데이터 모델·인터페이스·DB]
```
