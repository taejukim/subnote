## 정의
증권형 토큰(STO, Security Token Offering)
- 해당 암호화폐를 발행한 회사의 자산에 대한 소유권을 가진 토큰 형태로 발행하는 증권
- 분산원장에 기재되는 토큰 증권으로, 법적·제도적으로는 전자증권의 일종
## 키워드
* 토큰 증권, 증권거래법, 자본시장법, 자산의 소유권, 증권성, KYC, AML
## 암기법
* 음식=증권, 그릇=발행형태 (실물·전자·토큰증권)
## 특징
- 혁신성: 다양한 권리·비정형 증권을 디지털로 거래
- 안정성: 투자자 보호를 위한 안정적 토큰 가격·규제 준수
- 유동성: 상장·자산 분할로 거래 용이
- 효율성: 블록체인 조각거래로 시간·비용 절감
## 목적
- 실물·비정형 증권을 토큰화하여 자본시장 접근성·유동성 제고
- 금융위 가이드라인에 따른 토큰 증권 발행·유통 체계 정립
## 구성요소
- 증권(음식): 정형(지분·채무·ELS·DR), 비정형(수익증권·투자계약증권)
- 발행형태(그릇): 실물증권, 전자증권, 토큰증권(분산원장)
- 적용기술: 블록체인, 스마트컨트랙트, KYC, AML
- 발행 주체: 요건 충족 발행인(직접 생성·이전) / 미충족 시 계좌관리기관 경유
- 인프라: 한국예탁결제원(등록심사·관리·결제), 장외중개업자, 증권사, KRX 디지털증권시장
- 금융위: 용어 통일(토큰 증권), 증권성 인정 시 제재, 증권사·은행 외 발행체계 마련
## 구성도
```
[증권] ──발행형태──▶ [실물증권 / 전자증권 / 토큰증권(분산원장)]

[발행]
 요건충족 발행인 ──직접──▶ 토큰 생성·이전
 미충족 발행인 ──경유──▶ 계좌관리기관(증권사·은행) → 토큰 생성·이전
                              ↓
                    [한국예탁결제원] 등록심사·관리·결제
                              ↓
        장외(중개업자) / 장내(증권사 → KRX 디지털증권시장)
```
