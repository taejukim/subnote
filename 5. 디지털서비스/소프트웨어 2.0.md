#정보관리기술사 #디지털서비스 #SW2 #SoftwareTwoPointZero
## 정의
소프트웨어 2.0(Software 2.0)
- Andrej Karpathy가 제안한 개념으로, 사람이 코드 규칙을 작성하던 SW 1.0과 달리 데이터로 모델 가중치를 학습하여 동작을 정의하는 새로운 SW 패러다임
- 전통적 코드가 아닌 신경망 모델 자체가 SW의 본질이 되는 데이터 기반 SW 모델
## 키워드
* Karpathy, Neural Network, Data-Centric, Weights, ML/DL, Inference
## 암기법
* 데가추: 데이터·가중치·추론
## 특징
- 데이터 중심성: 코드 대신 데이터가 동작 정의
- 학습 기반성: 가중치 학습으로 기능 구현
- 추상화성: 고수준 동작을 데이터로 표현
- 새로운 운영성: MLOps·실험·재학습 중심
## 목적
- 복잡한 인지 문제를 학습으로 해결
- 인간 작성 코드 한계를 데이터 기반으로 극복
## 구성요소
- SW 1.0: 사람이 작성한 명시적 코드(if/else)
- SW 2.0: 데이터로 학습된 신경망 가중치
- 도구 체계: PyTorch, TensorFlow, MLOps
- 운영: 데이터·모델·실험·서빙 사이클
- 영역: 컴퓨터 비전, 자연어, 추천, 자율주행
## 구성도
```
[SW 1.0]                       [SW 2.0]
사람 코드 (if/else)       →   데이터 → 학습 → 가중치
명시적 규칙                    추론 결과 = 동작
       ↑ 디버깅·테스트              ↑ MLOps·드리프트
```
