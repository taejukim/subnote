#정보관리기술사 #디지털서비스 #데이터마이닝 #정형비정형
## 정의
정형/비정형 데이터 마이닝
- 정형 데이터 마이닝: 표·DB 형태의 정형 데이터에서 패턴·관계를 발견하는 분석 기법
- 비정형 데이터 마이닝: 텍스트·이미지·영상·음성 등 비정형 데이터에서 의미·패턴을 추출하는 기법
## 키워드
* 분류, 회귀, 군집, 텍스트 마이닝, 이미지 분석, NLP, CNN
## 암기법
* 분군연이: 분류·군집·연관·이상치
## 특징
- 데이터 구조 차이: 정형(스키마) vs 비정형(자유 형식)
- 알고리즘 차이: 통계·ML(정형) vs DL·NLP(비정형)
- 데이터 양 차이: 비정형이 절대 다수(80% 이상)
- 처리 복잡도: 비정형이 더 높은 전처리 필요
## 목적
- 데이터에서 비즈니스 가치 있는 인사이트 도출
- 정형·비정형 통합 분석으로 의사결정 지원
## 구성요소
- 정형 데이터 마이닝 기법: 분류(Decision Tree), 회귀, 군집(K-Means), 연관(Apriori), 이상치 탐지
- 비정형 데이터 마이닝 기법: 텍스트 마이닝(NLP·LDA), 이미지 마이닝(CNN), 영상 마이닝, 음성 마이닝
- 도구: Python·R·SAS·SPSS, scikit-learn, TensorFlow, PyTorch
- 절차: 데이터 수집 → 전처리 → 분석 → 평가 → 적용
- 결합 활용: 정형 + 비정형 통합 분석으로 입체적 인사이트
## 구성도
```
[정형 데이터 (DB)]               [비정형 데이터 (텍스트·이미지·음성)]
       ↓ 통계·ML                          ↓ NLP·CNN·DL
[패턴·예측·군집]                 [의미·감성·객체 인식]
       ↓                                  ↓
       ─────── 통합 인사이트 ──────────
```
