## 정의
트레블 룰(Travel Rule)
- 가상자산을 이전할 때 송신 담당 가상자산사업자(VASP)가 이전 관련 정보를 수취인 측에 제공해야 할 의무
- FATF가 2019년 디지털자산을 적용 범위에 포함, 국내에서는 특정금융정보법(특금법)에 반영
## 키워드
* 국제자금세탁방지기구(FATF), 디지털자산 사업자(VASP), 트레블 룰 이행 방식 4가지, 특금법
## 암기법
* VA→VA·VA→개 이행필요 / 개→VA 정보요청 / 개→개 특금법 미적용
## 특징
- 신원정보 동반 이전: 익명 주소 간 이전이 아닌 송신·수취인 신원정보 공유
- VASP 간 의무: 사업자 간 공통정보 자발적 전송·공유 체계 구축
- 개인지갑 제한: 미확인 개인지갑으로의 이전 금지(사업자→개인)
- 규제 연동: FATF 권고 + 국내 특금법
## 목적
- 가상자산 이전 시 AML·자금세탁 방지를 위한 송수신 정보 투명화
- VASP 간·사업자-개인 이전에서 신원 추적 가능성 확보
## 구성요소
- 제공 정보: 송신 VASP → 수취 VASP로 신원인증정보 전달
- 이행 방식 4가지
  1. VASP→VASP: 이행 필요(사업자 간 정보 제공)
  2. VASP→개인: 이행 필요(수취인 확인, 미확인 지갑 이전 금지)
  3. 개인→VASP: 수취 기술 제한 어려움 → 사업자가 고객에게 송신자 정보 요청
  4. 개인→개인: 특금법 미적용
## 구성도
```
[도입 전] 지갑주소 ABCDE… ──익명──▶ 지갑주소 12345…
[도입 후] 송신자(신원) ──자산이전──▶ 수취자(신원)
              │ 신원인증정보 │
         [VASP A] ────────▶ [VASP B]

이행: VA→VA / VA→개 = 필요
      개→VA = 고객정보요청
      개→개 = 특금법 미적용
```
