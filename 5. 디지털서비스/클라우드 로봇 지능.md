#정보관리기술사 #디지털서비스 #클라우드로봇 #CloudRobotics
## 정의
클라우드 로봇 지능(Cloud Robot Intelligence)
- 로봇이 클라우드 컴퓨팅 자원·데이터·AI 모델을 활용해 인지·학습·협업 능력을 강화하는 분산 로봇 인공지능 패러다임
- 단일 로봇 한계를 클라우드 협업과 데이터 공유로 극복하는 지능 모델
## 키워드
* Cloud Robotics, Fleet, Knowledge Sharing, Edge-Cloud, ROS, RaaS
## 암기법
* 클데공: 클라우드·데이터·공유학습
## 특징
- 자원 확장성: 클라우드 자원 활용
- 지식 공유성: 다중 로봇 학습 결과 공유
- 협업성: Fleet 단위 협업
- 엣지-클라우드 연계성: 실시간 + 학습 분리
## 목적
- 단일 로봇의 자원·지능 한계 극복
- Fleet 단위 협업·공유 학습으로 효율 극대화
## 구성요소
- 클라우드 자원: 학습·시뮬레이션·데이터 저장
- 엣지: 실시간 인지·제어
- 지식 공유: 모델·맵·경험 공유
- Fleet Management: 다수 로봇 협업·할당
- 표준: ROS 2, OPC UA
- RaaS와 결합: 운영 서비스화
## 구성도
```
[Cloud] 학습·데이터·시뮬레이션·Fleet
       ↓ 모델 배포
[Edge/Robot] 실시간 인지·제어
       ↑ 경험·데이터 업로드 ↑
       ↑ 다중 로봇 협업·지식 공유 ↑
```
