## 정의
UCP(Universal Commerce Protocol) / ACP(Agentic Commerce Protocol)
- UCP: AI Agent의 상품 탐색~주문까지 지원하는 개방형 커머스 프로토콜(Google)
- ACP: AI Agent의 안전한 결제·거래 완료를 지원하는 개방형 결제 프로토콜(OpenAI·Stripe)
## 키워드
* Agentic Commerce, Checkout, Payment Token, AP2, SPT, MCP, A2A
## 암기법
* 탐주결완: 탐색·주문·결제·완료
## 특징
- UCP: Discovery·Checkout·Order, 플랫폼 개방·상호운용
- ACP: SPT·Delegated Payment, 결제 보안·무결성
- Agentic Commerce 핵심: AI Agent 자율 탐색·주문·결제
## 목적
- AI Agent 기반 자율형 커머스 표준화
- 쇼핑몰·결제 API 상호연동
## 구성요소
- 절차: Product Discovery → Purchase Decision → Payment(SPT) → Order Complete
- 기술: Discovery(MCP), Checkout API, Payment(AP2·SPT), Agent(MCP·A2A)
## 구성도
```
AI Agent → UCP(탐색·주문) → ACP(SPT·결제) → 배송·상태관리
```
