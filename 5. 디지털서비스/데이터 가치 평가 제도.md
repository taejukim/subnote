#정보관리기술사 #디지털서비스 #데이터가치평가 #DataValuation
## 정의
데이터 가치 평가 제도
- 기업·기관이 보유·생산한 데이터의 경제적 가치를 객관적·정량적으로 평가하는 공식 인증 제도
- 데이터 거래·담보·투자에 활용 가능한 가치 산정 표준
## 키워드
* 데이터 거래, 데이터 자산, 가치 평가 기관, 평가 모델, 데이터 경제
## 암기법
* 비시원: 비용·시장·원가
## 특징
- 객관성: 표준화된 평가 기관·모델
- 활용성: 데이터 거래·담보·투자에 활용
- 표준성: 정부·산업 가이드라인 준수
- 신뢰 보장성: 공식 평가 결과 인증
## 목적
- 데이터의 자산성·시장 가치 가시화
- 데이터 거래·담보·투자 시장 활성화
## 구성요소
- 근거: 데이터 산업 진흥·이용 촉진법
- 평가 기관: 한국데이터산업진흥원(K-Data) 등 지정 기관
- 평가 모델: 비용 접근법, 시장 접근법, 원가/소득 접근법
- 평가 항목: 품질, 활용도, 희소성, 수익성
- 활용: 데이터 거래소 상장, 담보 대출, M&A
## 구성도
```
[데이터 보유자] → 가치 평가 신청
                       ↓
[평가 기관] → [평가 모델 적용 (비용·시장·원가)]
                       ↓
[가치 평가서 발급] → 거래·담보·투자 활용
```
