#정보관리기술사 #디지털서비스 #빅데이터시각화 #Visualization
## 정의
빅데이터 시각화(Big Data Visualization)
- 대용량·다양한 형태의 데이터를 시각적 그래픽으로 표현하여 인사이트를 직관적으로 전달하는 기술
- 데이터 분석·의사결정·커뮤니케이션을 지원하는 시각적 표현 기법
## 키워드
* Tableau, PowerBI, D3.js, Dashboard, Storytelling, Interactive
## 암기법
* 시인의: 시각화·인사이트·의사결정
## 특징
- 직관성: 복잡한 데이터를 한눈에 표현
- 인터랙션성: 드릴다운·필터·줌 가능
- 실시간성: 스트리밍 데이터 가시화
- 다차원성: 시계열·지리·관계 등 다양 표현
## 목적
- 빅데이터의 인사이트 발견과 빠른 의사결정
- 비기술자도 이해 가능한 데이터 커뮤니케이션
## 구성요소
- 차트: Bar·Line·Pie·Heatmap·Tree·Geo
- 도구: Tableau, PowerBI, Looker, Superset, D3.js
- 대시보드: KPI·실시간 모니터링
- 인터랙션: 필터·드릴다운·하이라이트
- 스토리텔링: Narrative + Visualization
- 표준 색상·접근성: Color-blind, WCAG
## 구성도
```
[빅데이터 (DW/Lake)]
       ↓ 분석
[시각화 도구 (Tableau/D3)]
       ↓ 차트·대시보드
[사용자 인터랙션 (필터·드릴다운·스토리)]
       ↓ 인사이트
[의사결정·커뮤니케이션]
```
