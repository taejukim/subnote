#정보관리기술사 #디지털서비스 #웹어셈블리 #WebAssembly
## 정의
웹어셈블리(WebAssembly, Wasm)
- 브라우저에서 네이티브에 가까운 성능으로 실행할 수 있도록 설계된 저수준 바이너리 명령 형식
- C/C++/Rust 등 다양한 언어를 컴파일해 웹·서버·엣지에서 실행 가능한 차세대 휴대 가능 런타임
## 키워드
* Wasm, WASI, Sandbox, Polyglot, Edge Runtime, Module
## 암기법
* 휴안고: 휴대성·안전성·고성능
## 특징
- 휴대성: 브라우저·서버·엣지 동일 실행
- 고성능: JIT/AOT로 네이티브 근접
- 안전성: Sandbox 기반 격리 실행
- 다언어성: C/C++/Rust/Go 등 컴파일 지원
## 목적
- 웹 환경의 네이티브급 성능 확보
- 다언어·다환경 안전 실행 표준 제공
## 구성요소
- Wasm 모듈: 바이너리 명령 + 메타데이터
- 런타임: 브라우저(V8/Spider), 서버(Wasmtime/Wasmer)
- WASI: 시스템 인터페이스 표준
- 응용: 게임, AI 추론, 영상 편집, 엣지 컴퓨팅
- 보안: Sandbox, Capability 기반 권한
## 구성도
```
[C/C++/Rust 소스] → 컴파일 → [Wasm 모듈]
                                 ↓
              [Wasm 런타임 (브라우저·서버·엣지)]
                                 ↓ Sandbox
                       [네이티브급 실행]
```
