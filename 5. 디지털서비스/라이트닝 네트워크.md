#정보관리기술사 #디지털서비스 #라이트닝네트워크 #LightningNetwork
## 정의
라이트닝 네트워크(Lightning Network)
- 비트코인의 속도·확장성 문제 해결을 위해 개별 거래를 별도 채널(Off-Chain)에서 처리하고 결과만 블록체인에 기록하는 결제 프로토콜
- Layer-2 결제 채널 기반의 비트코인 즉시 결제 솔루션
## 키워드
* Off-Chain, HTLC, Payment Channel, Layer-2, BTC, 마이크로페이먼트
## 암기법
* 채오HTLC종: 채널 개설·오프체인 거래·HTLC·종료
## 특징
- 확장성: 초당 수천 건 거래 처리
- 저비용성: 마이크로페이먼트 가능
- 즉시성: 블록 확인 대기 불필요
- 보안성: HTLC로 양방 보안
## 목적
- 비트코인의 결제 활용성·확장성 확보
- 송금·결제·콘텐츠 마이크로페이먼트 활성화
## 구성요소
- 채널: 양자 간 결제 채널
- HTLC(Hashed Time Lock Contract): 조건부 거래
- 라우팅: P2P 네트워크 기반 다중 홉 결제
- 노드: Lightning Node, Watchtower
- 보안 이슈: 중간 노드 의도적 조작 가능성
- 사례: 엘살바도르(국가 결제), Strike, Cash App
## 구성도
```
[채널 개설] (BTC 잠금)
       ↓
[오프체인 거래 다수]
       ↓ (HTLC로 안전 라우팅)
[채널 종료] → 결과만 블록체인 기록
```
