#정보관리기술사 #디지털서비스 #스마트팜 #SmartFarm
## 정의
스마트 팜(Smart Farm)
- ICT·IoT·AI를 활용해 농작물·가축의 생육 환경을 자동 측정·제어하여 생산성·품질을 향상시키는 지능형 농업 시스템
- 정밀 농업·자동화 농업의 차세대 형태로 데이터 기반 농업 운영
## 키워드
* IoT, Precision Agriculture, AgTech, AI 작물 관리, 드론, 자동화
## 암기법
* 측분제최: 측정·분석·제어·최적화
## 특징
- 자동화성: 환경·관수·시비 자동 제어
- 정밀성: 데이터 기반 생육 최적화
- 효율성: 노동력 절감·자원 효율
- 추적성: 생산~유통 이력 추적
## 목적
- 농업 생산성·품질·지속 가능성 향상
- 노동력 부족과 기후 변화에 대응
## 구성요소
- 1세대: 원격 모니터링·자동 제어
- 2세대: 빅데이터·AI 기반 의사결정 지원
- 3세대: 자율주행 농기계, 로봇, 드론, 무인 농장
- 인프라: IoT 센서, 카메라, 드론, 자동 관수·환기
- 데이터: 토양, 기상, 생육, 병해충
- AI 활용: 작물 진단, 수확량 예측, 병해충 방제
## 구성도
```
[IoT 센서·드론·카메라]
       ↓ 데이터 수집
[스마트팜 플랫폼: 빅데이터·AI]
       ↓ 의사결정
[자동 제어 (관수·환기·시비·로봇)]
       ↑ 농민 모니터링·원격 제어 ↑
```
