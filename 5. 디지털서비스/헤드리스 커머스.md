#정보관리기술사 #디지털서비스 #헤드리스커머스 #HeadlessCommerce
## 정의
헤드리스 커머스(Headless Commerce)
- 전자상거래의 프론트엔드(헤드)와 백엔드(커머스 엔진)를 분리하여 API로 통신하는 아키텍처
- 다양한 채널·디바이스에 동일한 백엔드를 활용해 유연한 옴니채널 경험을 제공하는 커머스 모델
## 키워드
* API First, Composable Commerce, Omni-Channel, MACH, Storefront
## 암기법
* 분유옴: 분리·유연·옴니채널
## 특징
- 분리성: 프론트·백엔드 독립 개발
- 유연성: 다양한 채널·디자인 지원
- 빠른 혁신성: 프론트만 빠르게 교체 가능
- 옴니채널성: 웹·앱·키오스크·IoT 통합
## 목적
- 사용자 경험·디자인 혁신을 위한 프론트 자율성 확보
- 다양한 채널을 동일 백엔드로 운영하는 옴니 커머스 구현
## 구성요소
- Headless Frontend: 웹·모바일·키오스크·IoT (Next.js·Vue 등)
- API 계층: REST/GraphQL
- Commerce Engine: 상품·주문·결제·재고·고객 관리
- Composable: Search, CMS, Personalization 결합
- MACH 아키텍처: Microservices, API-first, Cloud-native, Headless
- 사례: Shopify Plus, Commercetools, BigCommerce
## 구성도
```
[Web] [App] [Kiosk] [IoT] [메타버스]
        ↓ API/GraphQL
[Headless Commerce Engine]
        ↓
[상품·주문·결제·재고·고객] (백엔드)
        ↑ Composable Modules: CMS·Search·Personalization ↑
```
