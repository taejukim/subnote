#정보관리기술사 #디지털서비스 #DQ인증 #데이터품질
## 정의
DQ 인증(Data Quality Certification)
- 데이터 품질 관리 체계와 데이터 값 자체의 품질 수준에 대한 객관적 평가·인증 제도
- 한국데이터산업진흥원(K-Data)이 부여하는 데이터 품질 공식 인증
## 키워드
* K-Data, 데이터 품질, 정합성, 완전성, 일관성, 정확성, 적시성
## 암기법
* 정완일정적: 정합성·완전성·일관성·정확성·적시성
## 특징
- 객관성: 표준화된 평가 기준 적용
- 등급 부여성: 우수·최우수 등 등급제
- 신뢰 보장성: 데이터 신뢰성·활용성 보증
- 갱신 유효성: 인증 유효기간·재심사
## 목적
- 데이터 품질에 대한 객관적 신뢰 부여
- 공공·민간 데이터 활용 가치 제고
## 구성요소
- 인증 기관: 한국데이터산업진흥원(K-Data)
- 인증 대상: 데이터 관리체계, 데이터 값
- 평가 항목: 정합성, 완전성, 일관성, 정확성, 적시성
- 인증 등급: 우수, 최우수
- 절차: 신청 → 사전 진단 → 본 심사 → 결과 통보 → 인증서 발급
## 구성도
```
[신청] → [사전 진단] → [본 심사: 체계 + 값 평가]
   → [등급 판정: 우수/최우수] → [인증서 발급] → [재심사]
```
