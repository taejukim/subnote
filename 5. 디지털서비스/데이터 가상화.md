#정보관리기술사 #디지털서비스 #데이터가상화 #DataVirtualization
## 정의
데이터 가상화(Data Virtualization)
- 다양한 소스 데이터를 물리적으로 이동·복제하지 않고 가상의 통합 뷰로 제공하는 데이터 통합 기술
- 실시간 데이터 조회·통합을 가능하게 하는 차세대 데이터 액세스 레이어
## 키워드
* Federation, Logical Data Warehouse, Query Pushdown, Real-time, Data Fabric
## 암기법
* 통실숨: 통합·실시간·물리적 이동 없음
## 특징
- 비복제성: 데이터 이동·복제 없이 통합
- 실시간성: 원본 소스 실시간 조회
- 추상화성: 다양한 소스 단일 뷰 제공
- 거버넌스 강화성: 단일 접근 통제 가능
## 목적
- 다양한 데이터 소스를 빠르게 통합 활용
- ETL·복제 부담 감소와 데이터 신선도 향상
## 구성요소
- 가상 뷰: 통합 메타데이터·논리 모델
- 쿼리 엔진: Federation, Query Pushdown
- 커넥터: DB, DW, Lake, SaaS, API
- 캐싱·성능 최적화: 결과 캐시, 마이크로 캐싱
- 보안: 통합 인증·접근 통제·마스킹
- 도구: Denodo, TIBCO Data Virtualization, Starburst
## 구성도
```
[BI/AI/앱]
    ↓ SQL/REST
[데이터 가상화 계층 (논리 뷰·쿼리 엔진)]
    ↓
[DB] [DW] [Lake] [SaaS] [API] (물리 소스, 복제 없이 조회)
```
