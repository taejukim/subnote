#정보관리기술사 #디지털서비스 #엣지컴퓨팅 #포그컴퓨팅
## 정의
엣지컴퓨팅 / 포그컴퓨팅
- 엣지컴퓨팅(Edge Computing): 데이터 발생 지점 근처에서 처리해 저지연·대역폭 절감을 실현하는 분산 컴퓨팅
- 포그컴퓨팅(Fog Computing): 엣지~클라우드 사이 중간 계층에서 데이터를 분산 처리하는 계층형 컴퓨팅
## 키워드
* MEC, IoT, Latency, Bandwidth, Hierarchical, Cloud-Edge Continuum
## 암기법
* 단중클: 단말(엣지)·중간(포그)·클라우드
## 특징
- 분산성: 데이터 처리 위치 분산
- 저지연성: 사용자 근접 처리
- 계층성: Cloud-Fog-Edge 3단계
- 대역폭 효율성: 클라우드 전송 데이터 감소
## 목적
- 실시간 IoT·자율주행·AR/VR 등 저지연 요구 충족
- 클라우드 의존도 감소와 대역폭 비용 절감
## 구성요소
- 엣지: 디바이스, 게이트웨이, MEC
- 포그: 라우터, 분산 노드, 마이크로 데이터센터
- 클라우드: 글로벌 데이터센터
- 응용: 스마트 팩토리, 자율주행, 스마트시티, AR/VR
- 비교 - 엣지: 단말 근접, 즉시성 ↑, 처리량 ↓
- 비교 - 포그: 중간 계층, 분산 처리, 협업 가능
- 비교 - 클라우드: 중앙, 무한 자원, 지연 ↑
## 구성도
```
[Cloud] 글로벌 데이터센터
   ↑↓
[Fog] 중간 계층 (분산 노드·MEC)
   ↑↓
[Edge] 디바이스/게이트웨이
   ↑↓
[Things] IoT 센서·단말
```
## 엣지 vs 클라우드 비교 (시험용)
| 구분 | Edge Computing | Cloud Computing |
|------|----------------|-----------------|
| **위치** | 데이터 발생·수집 근처 | 중앙 데이터센터 |
| **지연** | ms 단위 (저지연) | 수십~수백 ms |
| **규모** | 소규모·분산 | 대규모·집중 |
| **처리** | 로컬·즉시 처리 | 중앙 집중·대규모 처리 |
| **대역폭** | 클라우드 전송량 감소 | 대용량 데이터 전송 |
| **관리** | 분산·현장 운영 부담 | 중앙·표준화 용이 |
| **보안** | 데이터 주권·로컬 보관 | CSP 공유 책임 모델 |
| **용도** | IoT, 자율주행, AR/VR, 실시간 | 글로벌 서비스, 빅데이터 분석 |
| **관계** | **상호보완** — Edge↔Cloud 하이브리드 연동 | Edge와 경쟁이 아닌 협력 |

## 시험 대비 (1교시)
**1분 정의**
- Edge: 데이터 발생 지점 근처에서 처리 → 저지연·대역폭 절감
- Cloud: IT 자원을 중앙 DC에서 온디맨드 제공 → 대규모·글로벌

**추가 키워드**: 데이터 주권, 프라이버시, 오프라인·단절 대응, MEC

**주의**
- Fog는 한 줄 보조만 (문항=Edge vs Cloud 차이)
- "Edge=구축비 저렴" X → 현장 Edge는 설치·운영·보안 부담 존재
- AWS·GCP는 **활용사례**로만, 비교축은 위치·지연·규모·관리
