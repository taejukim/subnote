#정보관리기술사 #디지털서비스 #EdgeMLaaS #엣지ML
## 정의
서비스형 엣지 머신러닝(Edge MLaaS)
- 엣지 디바이스에 머신러닝 모델 배포·운영을 위한 인프라·플랫폼·도구를 서비스 형태로 제공하는 모델
- 엣지·온디바이스 AI 도입의 진입장벽을 낮추는 서비스화 패러다임
## 키워드
* MLOps, Edge AI, On-Device AI, Model Deployment, OTA, NPU
## 암기법
* 배운모: 배포·운영·모니터링
## 특징
- 서비스화: 모델 배포·관리 SaaS 제공
- 자동화: OTA 모델 갱신·롤백
- 확장성: 다양한 디바이스·모델 동시 관리
- 모니터링: 성능·드리프트 실시간 추적
## 목적
- 엣지 ML 운영 부담 완화와 빠른 도입
- 분산 디바이스의 모델 일관 운영·갱신
## 구성요소
- 모델 변환: TFLite, ONNX, Core ML
- 배포: OTA 업데이트, 컨테이너 배포
- 운영: 모니터링, A/B 테스트, 롤백
- 디바이스 관리: 인증, 정책, 소프트웨어 갱신
- 사례: AWS SageMaker Edge Manager, Azure IoT Edge, Edge Impulse
## 구성도
```
[클라우드: 모델 학습·관리]
       ↓ 변환·OTA
[Edge MLaaS 플랫폼]
       ↓ 배포·정책
[엣지 디바이스: 추론·로깅] ─ 메트릭 ─→ 모니터링·드리프트 감지
```
