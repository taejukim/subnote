#정보관리기술사 #디지털서비스 #스마트시티거버넌스 #DataGovernance
## 정의
스마트시티 데이터 거버넌스
- 스마트시티에서 생성·수집·공유되는 다양한 도시 데이터를 안전·투명·효율적으로 관리·활용하기 위한 정책·조직·프로세스 체계
- 도시 데이터 활용 활성화와 시민 보호를 동시에 추구하는 거버넌스 프레임워크
## 키워드
* Data Hub, Open Data, Privacy, 도시 데이터, ISO 37120, 시민참여
## 암기법
* 정조프: 정책·조직·프로세스
## 특징
- 통합 관리성: 부문 간 데이터 통합 관리
- 시민 보호성: 프라이버시·안전 우선
- 개방성: 적절한 수준의 공공 개방
- 표준화성: 국제 표준 기반 운영
## 목적
- 스마트시티 데이터 활용성·신뢰성 확보
- 시민 권리 보호와 도시 혁신 균형
## 구성요소
- 거버넌스 주체: 시청, 데이터 위원회, 시민 참여
- 정책: 데이터 표준, 보안, 개방, 공유
- 인프라: City Data Hub, 통합 관제, API 플랫폼
- 표준: ISO 37120, ITU-T Y.4900, K-Smart City 표준
- 보안·프라이버시: 비식별화, 익명화, 접근 통제
## 구성도
```
[데이터 생성] (IoT·CCTV·교통·시민)
       ↓
[City Data Hub]
   ├── 데이터 표준·품질·보안
   ├── 거버넌스 위원회 (정책·승인)
   └── 개방 API / 마이데이터
       ↓ 시민·기업·연구 활용
       ↑ 시민 참여·감독 ↑
```
