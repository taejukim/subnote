#정보관리기술사 #디지털서비스 #서버리스 #Serverless
## 정의
서버리스 아키텍처(Serverless Architecture)
- 사전에 서버를 프로비저닝하지 않고 코드 실행이 필요할 때 자동으로 자원을 할당해 수행 후 결과를 제공하는 클라우드 아키텍처
- FaaS·BaaS 기반으로 서버 관리 부담을 최소화하는 무서버 추상화 모델
## 키워드
* FaaS, BaaS, Lambda, Cloud Functions, Event-driven, Pay-per-use
## 암기법
* 무자이종: 무관리·자동확장·이벤트기반·종량과금
## 특징
- 무관리성: 서버 프로비저닝·운영 불필요
- 자동 확장성: 요청에 따라 자동 스케일
- 이벤트 기반성: 이벤트로 함수 트리거
- 종량 과금성: 실행 시간·횟수 기반 과금
## 목적
- 운영 부담 감소와 개발 생산성 극대화
- 트래픽 변동에 유연하게 대응
## 구성요소
- FaaS(Function as a Service): AWS Lambda, GCP Cloud Functions, Azure Functions
- BaaS(Backend as a Service): Auth, Storage, DB 관리형
- 이벤트 소스: HTTP, Queue, Storage, Schedule
- 패턴: API + Lambda, ETL, 챗봇 백엔드, 이벤트 처리
- 한계: Cold Start, 실행 시간 제한, 벤더 종속성
## 구성도
```
[이벤트 트리거] (HTTP·Queue·DB·Schedule)
              ↓
    [FaaS 실행 (Lambda/Functions)]
              ↓
    [BaaS 백엔드: DB·Auth·Storage]
              ↑ 자동 스케일·종량 과금 ↑
```
