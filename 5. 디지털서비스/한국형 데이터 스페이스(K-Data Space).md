#정보관리기술사 #디지털서비스 #KDataSpace #데이터스페이스 #NEW
## 정의
한국형 데이터 스페이스(K-Data Space)
- 데이터 주권·상호운용성·신뢰 기반 교환을 보장하는 연합형·분산형 데이터 공유 체계
- Gaia-X·EU Data Space·Ouranos 대응 국내 산업 생태계형 민관 협력 모델
## 키워드
* 데이터 주권, 연합형 구조, 거버넌스·비즈니스·기술 3계층, DID/VC, DCAT, ODRL
## 암기법
* 거비기: 거버넌스·비즈니스·기술
## 특징
- 3계층: Governance(주권·합의), Business(Use Case·계약), Technology(카탈로그·Connector)
- 핵심 기술: DID/VC, ODRL, DCAT, Clearing House, Policy-as-Code, NFT
- 해외 대비: EU(공통 공간), Gaia-X(연합 클라우드), Ouranos(DFFT), K(국내 산업·민관)
## 목적
- AI 학습용 고품질 데이터 확보
- 데이터 사일로 해소·주권 보장
## 구성요소
- Governance: 연합·분산, 신뢰·투명, 참여자 자율
- Business: 도메인 Use Case, 참여·계약, API/Connector 서비스
- Technology: Federated Catalog, Metadata Broker, Clearinghouse, 전자결제·NFT
## 구성도
```
제공자 → [Governance|Business|Technology] → 소비자(AI·서비스)
```
