#정보관리기술사 #디지털서비스 #마이데이터 #MyData
## 정의
마이데이터(MyData)
- 정보 주체가 본인 데이터를 능동적으로 관리·통제하고 원하는 곳으로 전송할 수 있도록 하는 데이터 자기결정권 기반 서비스
- 개인정보 전송 요구권을 활용한 개인 중심 데이터 활용 패러다임
## 키워드
* 개인정보 전송 요구권, API, 동의 관리, 금융·공공·의료, 개인 데이터 주권
## 암기법
* 자제활: 자기결정·제3자 전송·활용
## 특징
- 자기결정권성: 본인이 데이터 활용 결정
- 표준 API성: 표준 인터페이스 기반 전송
- 다도메인 확산성: 금융 → 공공·의료 확장
- 동의 기반성: 명확한 동의·이력 관리
## 목적
- 개인 데이터 활용 권리 보장
- 데이터 기반 맞춤형 서비스 활성화
## 구성요소
- 법적 근거: 개인정보보호법(전송 요구권), 신용정보법
- 도메인: 금융, 공공, 의료, 통신
- 인프라: 마이데이터 플랫폼, 표준 API, 인증, 동의 관리
- 사업자: 마이데이터 사업자, 정보 제공자, 정보 주체
- 보안: 인증·암호화·접근 통제
## 구성도
```
[정보 주체] → 동의·전송 요구
       ↓
[정보 제공자(은행·공공)] ── 표준 API ──→ [마이데이터 사업자]
       ↑ 동의 관리·인증·로깅 ↑
              ↓ 맞춤형 서비스
       [정보 주체에게 가치 제공]
```
