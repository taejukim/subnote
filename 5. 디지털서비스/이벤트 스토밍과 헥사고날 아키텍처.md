#정보관리기술사 #디지털서비스 #이벤트스토밍 #헥사고날
## 정의
이벤트 스토밍 / 헥사고날 아키텍처
- 이벤트 스토밍(Event Storming): 도메인 이벤트를 중심으로 비즈니스 흐름과 도메인 모델을 발견·설계하는 워크숍 기법
- 헥사고날 아키텍처(Hexagonal Architecture): 도메인 코어를 외부 인프라와 분리하여 포트·어댑터로 연결하는 도메인 중심 아키텍처
## 키워드
* DDD, Domain Event, Bounded Context, Port-Adapter, 의존성 역전
## 암기법
* 도이포어: 도메인·이벤트·포트·어댑터
## 특징
- 이벤트 중심성: 도메인 이벤트로 흐름 표현
- 도메인 분리성: 인프라·UI와 도메인 분리
- 테스트 용이성: 도메인 단위 테스트 가능
- DDD 친화성: 전략적·전술적 설계와 결합
## 목적
- 비즈니스 도메인 이해·복잡성 통제
- 변경에 강한 유연한 아키텍처 구현
## 구성요소
- 이벤트 스토밍: Domain Event(주황), Command(파랑), Aggregate(노랑), Policy(보라), Read Model(초록)
- 헥사고날 - 도메인 코어: Entity, Value Object, Aggregate, Domain Service
- 헥사고날 - 포트: Inbound·Outbound 인터페이스
- 헥사고날 - 어댑터: REST/CLI(Inbound), DB/메시징(Outbound)
- 결합 활용: 이벤트 스토밍 → Bounded Context → 헥사고날 모듈로 구현
## 구성도
```
[Inbound Adapter] (REST/CLI)
       ↓ Port
[Domain Core] ── Entity·Aggregate·Service
       ↓ Port
[Outbound Adapter] (DB·MQ·외부 API)
   (헥사고날: 도메인 코어 + 포트·어댑터 분리)
   이벤트 스토밍으로 도메인 이벤트 발견 → Bounded Context 도출
```
