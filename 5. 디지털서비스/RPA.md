#정보관리기술사 #디지털서비스 #RPA #업무자동화
## 정의
RPA(Robotic Process Automation)
- 사람이 PC에서 수행하는 반복적·규칙 기반 업무를 SW 로봇이 대신 수행하도록 자동화하는 기술
- UI 자동화·OCR·AI를 결합하여 백오피스 프로세스를 자동 실행하는 디지털 워커 솔루션
## 키워드
* UI Automation, OCR, IPA, IDP, UiPath, Bot Orchestrator
## 암기법
* 반규대: 반복·규칙기반·대체수행
## 특징
- 반복 처리성: 동일 작업 정확·신속 수행
- 규칙 기반성: 명확한 규칙 업무에 강점
- 비침습성: 기존 시스템 변경 최소화
- 확장성: AI 결합으로 IPA·IDP 진화
## 목적
- 백오피스 단순·반복 업무 자동화로 생산성 향상
- 직원의 고부가가치 업무 집중 지원
## 구성요소
- Bot Designer: 자동화 시나리오 설계
- Bot Runner: 봇 실행 환경
- Orchestrator: 봇 일정·실행·모니터링
- 통합: UI 자동화, API, OCR, AI(IPA)
- 거버넌스: 권한·보안·감사
- 진화: RPA → IPA(Intelligent Process Automation) → Hyper Automation
## 구성도
```
[Designer] → 시나리오 작성
                ↓
[Orchestrator] → 일정·배포·모니터링
                ↓
[Bot Runner] → UI 조작·OCR·API 호출 → 시스템(ERP·메일·웹)
```
