#정보관리기술사 #디지털서비스 #데이터메시 #DataMesh
## 정의
데이터 메시(Data Mesh)
- 데이터를 도메인 단위로 분산 소유·운영하고 데이터를 제품으로 관리하는 분산형 데이터 아키텍처
- 중앙 집중 데이터 호수의 한계를 극복하는 도메인 기반 데이터 패러다임
## 키워드
* Domain Ownership, Data as a Product, Self-Service Platform, Federated Governance
## 암기법
* 도제셀연: 도메인 소유·제품화·셀프서비스·연합 거버넌스
## 특징
- 분산성: 도메인별 데이터 소유·운영
- 제품성: 데이터를 제품처럼 관리
- 셀프서비스: 도메인이 자율적으로 운영
- 연합 거버넌스: 글로벌 정책 + 로컬 자율
## 목적
- 중앙 집중 데이터 팀의 병목 해소
- 도메인 자율성·책임성 강화로 가치 가속
## 구성요소
- 4대 원칙: Domain Ownership, Data as a Product, Self-Service Platform, Federated Computational Governance
- 도메인: 비즈니스 도메인별 데이터 팀
- 데이터 제품: SLA·OKR로 관리되는 단위
- 셀프서비스 플랫폼: 데이터 인프라 표준 제공
- 연합 거버넌스: 표준·정책·정합성 위원회
## 구성도
```
[도메인 A] Data Product (Owner·SLA)
[도메인 B] Data Product (Owner·SLA)   ↔  Consumer
[도메인 C] Data Product (Owner·SLA)
       ↑ Self-Service Platform ↑
       ↑ Federated Governance ↑
```
