#정보관리기술사 #디지털서비스 #개인정보전송요구권 #마이데이터
## 정의
개인정보 전송 요구권
- 정보 주체가 자신의 개인정보를 본인 또는 제3자(전송 받을 자)에게 전송하도록 요구할 수 있는 권리
- 마이데이터 활성화의 법적 기반이 되는 개인정보보호법상 권리
## 키워드
* 마이데이터, 데이터 이동성, GDPR, 개인정보보호법 제35조의2, API 기반 전송
## 암기법
* 본3제: 본인·제3자·제어권
## 특징
- 자기결정권성: 정보 주체가 능동 행사
- 이동성: 처리자 간 데이터 이전 가능
- 표준성: 구조화·기계 판독 가능 형식
- 산업 확장성: 금융·의료·공공 등 마이데이터 확산
## 목적
- 정보 주체의 개인정보 통제권 강화
- 데이터 활용·산업 혁신 촉진
## 구성요소
- 법적 근거: 개인정보보호법 제35조의2 등
- 전송 방식: 본인 직접, 제3자 전송
- 표준 형식: 구조화·기계 판독 가능
- 도메인: 금융, 공공, 의료, 통신
- 인프라: API 기반 마이데이터 플랫폼, 인증, 동의 관리
## 구성도
```
[정보 주체] → 전송 요구
       ↓
[기존 처리자] ── 표준 API ──→ [본인 / 제3자 처리자]
       ↑ 동의·인증·로깅 ↑
```
