#정보관리기술사 #디지털서비스 #데이터아키텍처 #비교
## 정의
데이터 웨어하우스/레이크/패브릭/메시
- 기업의 데이터 통합·분석을 위해 진화해 온 4가지 대표 데이터 아키텍처 패러다임
- 정형 데이터 통합(DW) → 비정형 통합(Lake) → 메타 통합(Fabric) → 분산 도메인 운영(Mesh) 진화
## 키워드
* DW, Data Lake, Data Lakehouse, Data Fabric, Data Mesh, ETL/ELT
## 암기법
* 정비메도: 정형(DW)·비정형(Lake)·메타(Fabric)·도메인(Mesh)
## 특징
- 진화성: 데이터 양·유형 확장에 따른 진화
- 보완성: 새로운 모델이 기존 모델 보완
- 거버넌스 강화성: 후기 모델일수록 거버넌스 강화
- 조직성 차이: 중앙 집중 → 분산 자율 변화
## 목적
- 다양한 데이터 활용 요구에 맞는 아키텍처 선택
- 도메인·조직·기술 특성 기반 최적 통합 전략
## 구성요소
- 데이터 웨어하우스(DW): 정형 통합 분석, OLAP, 스타·스노우플레이크 스키마
- 데이터 레이크(Lake): 비정형·반정형 원시 저장, S3·HDFS
- 데이터 레이크하우스: Lake + DW 결합 (ACID·BI)
- 데이터 패브릭(Fabric): 메타데이터·AI 기반 통합 추상화
- 데이터 메시(Mesh): 도메인 분산 소유·제품화
- 비교 - DW: 정형·중앙·SQL / 비용 높음
- 비교 - Lake: 비정형·중앙·저비용 / 거버넌스 약점
- 비교 - Fabric: 메타·기술 통합 / AI 자동화
- 비교 - Mesh: 도메인 분산 / 조직 변화 필요
## 구성도
```
[Data Warehouse] 정형·OLAP
       ↓
[Data Lake] 비정형·원시
       ↓
[Lakehouse] Lake + DW 결합
       ↓
[Data Fabric] 메타·AI 기반 통합
       ↓
[Data Mesh] 도메인 분산·제품화
```
