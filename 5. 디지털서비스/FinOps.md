#정보관리기술사 #디지털서비스 #FinOps #클라우드비용관리
## 정의
FinOps(Cloud Financial Operations)
- 클라우드 비용에 대한 책임·가시성·최적화를 다부서가 협력하여 운영하는 재무 운영 문화·프레임워크
- Inform → Optimize → Operate 3단계 사이클로 운영되는 클라우드 비용 거버넌스
## 키워드
* Cloud Cost, Cost Allocation, Reserved/Spot, Tagging, Showback/Chargeback
## 암기법
* 가알최: 가시화·할당·최적화
## 특징
- 협업 중심성: 재무·엔지니어링·운영 협력
- 가시성: 비용·사용량 실시간 가시화
- 책임성: 팀별 비용 책임 분담
- 최적화 반복성: 지속적 비용 최적화 사이클
## 목적
- 클라우드 비용 가시화와 책임 있는 의사결정
- 비용 최적화로 ROI·비즈니스 가치 극대화
## 구성요소
- 3단계 사이클: Inform(가시화) → Optimize(최적화) → Operate(운영)
- 핵심 활동: Tagging, Showback/Chargeback, Reserved/Spot, Rightsizing, Anomaly Detection
- 조직 모델: FinOps Team, Cost Owner, 의사결정 위원회
- 도구: AWS Cost Explorer, Azure Cost Management, GCP Billing, Cloudability
- KPI: Unit Economics, 비용 가시성률, 활용률
## 구성도
```
[Inform] 가시화·태깅·예산
   ↓
[Optimize] Rightsizing·RI/Spot·아이들 제거
   ↓
[Operate] 거버넌스·자동화·환류
   ↑________ 지속 반복 ________|
```
