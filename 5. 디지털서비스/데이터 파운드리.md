#정보관리기술사 #디지털서비스 #데이터파운드리 #DataFoundry #NEW
## 정의
데이터 파운드리(Data Foundry)
- 다양한 원천 데이터를 수집·정제·라벨링·검증하여 AI 학습·산업 활용 가능한 고품질 데이터를 제조하는 국가 산업 근간 체계
## 키워드
* 수집, 표준화, 메타데이터, 라벨링, 멀티모달, 데이터 증강, Sovereign Cloud, 가명·익명
## 암기법
* 수전라저거: 수집·전처리·라벨링·저장·거버넌스
## 특징
- 5단계: 수집/통합→전처리/정제→라벨링→저장/관리→품질/거버넌스
- ETL·메타데이터·QA·라벨링 자동화·멀티모달·증강
- Sovereign Cloud·DaaS·접근 제어
## 목적
- 국가 AI 학습 데이터 인프라
- 고품질·윤리적 데이터 제조
## 구성요소
- 처리·품질: ETL, 표준화, QA 엔진
- AI 데이터셋: 라벨링 자동화, 멀티모달, 증강
- 거버넌스: 접근 제어, Sovereign Cloud, 가명·익명
## 구성도
```
원천 → ETL/정제 → 라벨링 → 저장/버전 → QA/거버넌스 → AI 학습
```
