#정보관리기술사 #디지털서비스 #클라우드 #옵션 #정리 #디지털서비스/클라우드_컴퓨팅/인프라

## 정의
2개 이상 클라우드 연결 구축 모델, 멀티클라우드
- 2개 이상의 퍼블릭/프라이빗 클라우드를 조합하여 연결하고, 워크로드를 분산 배치하는 클라우드 구축 모델
- CSB(Cloud Service Brokerage)를 통해 이기종 CSP 간 클라우드 서비스를 통합 관리
## 키워드
* 하이브리드 클라우드, 프래그머틱 하이브리드 클라우드, 멀티 퍼블릭 클라우드, CSB, 벤더 종속성 탈피
## 암기법
* 하프멀 (하이브리드, 프래그머틱 하이브리드, 멀티 퍼블릭)
## 특징
- 벤더 종속성 회피: 단일 CSP 의존도를 낮추어 비즈니스 유연성 확보
- 최적 서비스 선택: 각 CSP의 강점 서비스를 선별적으로 활용 가능
- 가용성 향상: 하나의 클라우드 장애 시 다른 클라우드로 서비스 연속성 보장
- 비용 최적화: 워크로드 특성에 따라 비용 효율적 클라우드 선택
## 구성요소
| 유형 | 구성 | 설명 |
|------|------|------|
| 하이브리드 클라우드 | Private + Public | 사설과 공용 클라우드 결합 |
| 프래그머틱 하이브리드 | On-premise + Public | 기존 인프라와 퍼블릭 클라우드 결합 |
| 멀티 퍼블릭 클라우드 | 2개 이상 Public | 복수 퍼블릭 CSP 조합 활용 |
* 퍼블릭, 프라이빗 동시는 하이브리드 클라우드

## 기술요소

| 계층                                   | 기술 요소                                               | 기술요소 설명                                                                               |
| ------------------------------------ | --------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Security & Policy<br>Layer           | - CSPM, IAM Federation<br>- DDoS/WAF, Encryption    | - 전체 클라우드에 일관된 보안 정책을 배포하고 신원(Identity) 기반의 접근 제어를 수행함.<br>- 통합 대시보드를 통해 보안 가시성을 확보함. |
| Network Control &<br>Orchestration   | - SDN 컨트롤러, IaC(Terraform)<br>- 자동화 워크플로우           | - 네트워크 설정을 소프트웨어로 정의하고 자동화함.<br>- 중앙 컨트롤러가 여러 CSP의 라우팅 테이블을 코드(IaC)로 일괄 관리함.          |
| Connectivity /<br>Interconnect Layer | - Transit Hub, CXP (Cloud Exchange), SD-WAN, 가상 라우터 | - 실제 데이터 트래픽이 전송되는 통로임.<br>- 전용선과 가상 터널링 기술을 사용하여 클라우드간 고속 데이터 전송을 지원함.               |
| Cloud Provider<br>Infrastructure     | VPC/VNet, 로드밸런서, 보안 그룹, Cloud NAT                   | - 각 CSP가 제공하는 네이티브 네트워크 리소스임.<br>- 상위 MCN 계층의 제어를 받아 실제 워크로드를 연결함.                    |
