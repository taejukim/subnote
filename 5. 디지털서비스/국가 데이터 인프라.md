#정보관리기술사 #디지털서비스 #국가데이터인프라 #DataInfra
## 정의
국가 데이터 인프라
- 국가 차원에서 데이터의 생산·저장·유통·활용을 지원하기 위해 구축·운영하는 표준 데이터 기반 시스템
- 디지털플랫폼정부와 데이터 경제 활성화를 위한 핵심 디지털 공공 기반 시설
## 키워드
* 디지털플랫폼정부, 공공데이터, 데이터 댐, 마이데이터, AI 학습 데이터
## 암기법
* 생저유활: 생산·저장·유통·활용
## 특징
- 공공성: 국가가 구축·운영 주체
- 통합성: 부처·기관 간 데이터 연계
- 개방성: 표준 API·공공데이터 개방
- 활용성: AI·산업·연구 활용 기반
## 목적
- 데이터 경제 활성화와 산업 경쟁력 확보
- 부처 간 데이터 사일로 해소·디지털플랫폼정부 실현
## 구성요소
- 데이터 댐: 빅데이터 수집·저장 인프라
- AI 학습 데이터 플랫폼: NIA AI 허브
- 마이데이터: 개인정보 전송권 기반 플랫폼
- 공공데이터 포털: 표준 API, LOD
- 거버넌스: 데이터 표준, 품질, 보안, 정책
- 보안: 가명정보 처리, 비식별화, 접근 통제
## 구성도
```
[생산] 정부·기업·시민 데이터
   ↓
[저장] 데이터 댐·DW·Lake
   ↓
[유통] 공공데이터 포털·마이데이터·AI 허브
   ↓
[활용] AI·산업·연구·시민 서비스
   ↑ 표준·품질·보안·거버넌스 ↑
```
