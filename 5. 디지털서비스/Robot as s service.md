#정보관리기술사 #디지털서비스 #RaaS #로봇서비스
## 정의
RaaS(Robot as a Service)
- 로봇 하드웨어·소프트웨어·운영 관리를 구독·사용량 기반 서비스로 제공하는 모델
- 직접 구매·운영 부담 없이 로봇 자동화를 활용할 수 있는 서비스형 로봇 비즈니스
## 키워드
* Subscription, AMR, Cloud Robotics, Fleet Management, OPEX 전환
## 암기법
* 구운유: 구독·운영위탁·유연확장
## 특징
- 구독·과금성: 사용량·기간 기반 과금
- OPEX 전환성: 자본 지출(CAPEX) → 운영 비용(OPEX)
- 빠른 도입성: 즉시 배치·운영 가능
- 클라우드 연계성: Fleet 관리·AI 업데이트 통합
## 목적
- 로봇 도입 진입장벽 완화와 ROI 가속
- 중소 사업장·서비스업의 자동화 보급
## 구성요소
- 로봇 HW: AMR, AGV, 협동 로봇, 청소·배달 로봇
- 클라우드 로보틱스: Fleet 관리, AI 업데이트
- 운영 서비스: 설치·유지보수·교체
- 과금 모델: 구독, 시간당, 작업당
- 보안·안전: 인증, 데이터 보호, 안전 표준
## 구성도
```
[고객 사업장]
   ↓ 구독
[RaaS 플랫폼]
   ├── 로봇 HW (AMR·코봇)
   ├── Fleet Management (Cloud)
   ├── AI/소프트웨어 업데이트
   └── 유지보수·운영 서비스
```
