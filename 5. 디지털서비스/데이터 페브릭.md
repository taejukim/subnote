#정보관리기술사 #디지털서비스 #데이터패브릭 #DataFabric
## 정의
데이터 패브릭(Data Fabric)
- 분산된 데이터 소스를 메타데이터·AI·자동화 기술로 통합 연결·관리하는 차세대 데이터 통합 아키텍처
- 데이터 가상화·통합·거버넌스를 지능형 메타데이터 레이어로 제공
## 키워드
* Active Metadata, Data Virtualization, Data Integration, AI/ML, Augmented Data Mgmt
## 암기법
* 메통자: 메타데이터·통합·자동화
## 특징
- 메타데이터 중심성: Active Metadata 활용 자동화
- 통합성: 다양한 소스 단일 패브릭
- AI 기반성: 자동 카탈로깅·연결·추천
- 거버넌스 통합성: 보안·품질·접근 통제 일원화
## 목적
- 분산 데이터의 통합 관리·셀프서비스 제공
- AI·MLOps·BI 기반 의사결정 가속
## 구성요소
- Active Metadata: 사용·계보·품질 능동 수집
- 데이터 가상화: 물리 이동 없이 통합 뷰
- 데이터 카탈로그: 검색·태깅·계보
- 데이터 거버넌스: 정책·보안·품질
- AI/ML 기반 자동화: 분류·연결·추천
- 데이터 메시 비교: Fabric(기술 중심 통합) vs Mesh(조직·도메인 중심 분산)
## 구성도
```
[Source] DB·DW·Lake·SaaS·API
       ↓ 자동 연결·메타 수집
[Data Fabric Layer]
   ├── Active Metadata
   ├── Data Virtualization
   ├── Catalog·Lineage
   └── Governance·Security
       ↓
[BI / AI / Apps] 통합 셀프서비스
```
