#운영체제 #페이지교체 #필수 #운영체제/메모리관리 #NEW
## 정의
페이지 교체 알고리즘(Paging Replacement Algorithm)
- Page Fault 발생 시 주기억의 어떤 페이지 프레임을 교체할지 결정하는 기법
## 키워드
* Page Fault, OPT, FIFO, LRU, LFU, NUR, SCR, Clock, Reference/Modify bit
## 암기법
* OPT=미래미사용최장(이론), FIFO=최초진입, LRU=최장미참조
## 구성요소/특징/유형
| 알고리즘 | 교체 대상 | 비고 |
| ---- | ---- | ---- |
| FIFO | 최초 진입 | Belady Anomaly |
| LRU | 최장 미참조 | 오버헤드 大 |
| LFU | 최소 참조 횟수 | |
| NUR | Reference·Modify bit | LRU 근사, 4그룹 |
| SCR/Clock | FIFO+2nd chance | 순환 큐 |
