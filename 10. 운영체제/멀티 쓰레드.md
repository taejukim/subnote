#운영체제 #MultiThread #필수 #운영체제/CPU스케줄링 #NEW
## 정의
멀티 쓰레드(Multi-Thread)
- 하나의 Processor 내에서 둘 이상 Thread가 동시에 존재·독립 실행 가능한 구조
## 키워드
* IMT, BMT, SMT(Hyper-Threading), CMP, Code/Data 공유, Stack/Register 독립
## 암기법
* SMT=동일 사이클 다중, CMP=물리 다코어
## 구성요소/특징/유형
| 유형 | 설명 |
| ---- | ---- |
| Single | 1 Thread, CPU 활용↓ |
| IMT | 매 사이클 Thread 교대 |
| BMT | Block 시에만 교체 |
| SMT | 동시 다중 Thread(Hyper-Threading) |
| CMP | 물리 다코어 병렬 |
