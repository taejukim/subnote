#운영체제 #Fragmentation #필수 #운영체제/메모리관리 #NEW
## 정의
단편화(Fragmentation)
- 작업 크기와 주기억 분할 영역 불일치로 사용되지 못하고 낭비되는 메모리 공간 현상
## 키워드
* 내부단편화, 외부단편화, Coalescing(통합), Compaction(집약), Slab, Buddy
## 암기법
* 내부=할당블록 내, 외부=분할 전체 빈 공간
## 구성요소/특징/유형
| 유형 | 설명 | 해결 |
| ---- | ---- | ---- |
| **내부** | 고정 분할(페이지·파티션) **할당 블록 내** 잔여 | 페이지 크기↓, Slab, Buddy |
| **외부** | 총 여유는 충분하나 **비연속** 빈 영역 | **통합·집약** |
| 통합 | 인접 빈 영역 병합 | Coalescing → **외부** |
| 집약 | 분산 빈 공간 결합·재배치 | Compaction → **외부** |

## 시험 대비 (2교시) — 단편화 유형·최소화

**나. 단편화 유형**
| 유형 | 개념 | 발생 맥락 |
|------|------|-----------|
| **내부** | 할당 크기 > 프로세스 → 블록 **안** 낭비 | 페이징(고정 분할) |
| **외부** | 빈 공간 합은 충분, **연속 아님** | 연속·가변 할당, 세그멘테이션 |

**다. 최소화 방안 ※매칭 주의**
| 유형 | 방안 | 설명 |
|------|------|------|
| **외부** | **통합(Coalescing)** | 인접 공백 병합 → 큰 영역 |
| **외부** | **집약(Compaction)** | 사용 중 블록 이동·재배치 → 빈 공간 한곳으로 |
| **내부** | **페이지(프레임) 크기 축소** | 잔여 공간 감소 |
| **내부** | **Slab**, Buddy Allocator | 객체 크기별 효율 할당 |

**금지·주의**
- ⚠️ **집약(Compaction) = 외부 단편화** 해결 (내부 X)
- ⚠️ 소제목 「내부」를 외부 내용에 중복 기입하지 말 것
- 페이징은 내부 단편화 **원인**이지, 내부 **해결책**이 아님

**암기**: **외통집 / 내크Slab** (외부=통합·집약 / 내부=크기↓·Slab)
