## 정의
지역성(Locality)
- CPU가 어느 순간 특정 부분의 정보만 집중적으로 참조하는 특성
## 키워드
* Temporal(시간), Spatial(공간), Sequential(순차), LRU, Prefetch, Working Set
## 암기법
* 시간=반복, 공간=인접, 순차=순서
## 구성요소/특징/유형
| 유형 | 내용 | 사례 |
| ---- | ---- | ---- |
| 시간적 | 일정 기간 동일 페이지 집중 | Loop, LRU |
| 공간적 | 인접 페이지 집중 | Array, Working Set |
| 순차적 | 순서대로 실행 | Prefetch, 코드 |
