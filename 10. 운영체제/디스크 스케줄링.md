## 정의
디스크 스케줄링(Disk Scheduling)
- 디스크 헤드 이동 경로를 최적으로 결정해 데이터 접근하는 기법
## 키워드
* FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK, N-Step SCAN, SLTF
## 암기법
* SCAN=엘리베이터, LOOK=요청범위만
## 구성요소/특징/유형
| 기법 | 특징 | 단점 |
| ---- | ---- | ---- |
| FCFS | 도착순 | Seek time 大 |
| SSTF | 최단 Seek | Starvation |
| SCAN | 한 방향 후 반전 | 끝까지 이동 |
| C-SCAN | 한 방향 순환 | 복귀 시 무시 |
| LOOK/C-LOOK | 요청 범위만 | SCAN 개선 |
| SLTF | 동일 트랙 회전 최소 | |
