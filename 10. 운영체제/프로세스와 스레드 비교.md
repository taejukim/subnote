#운영체제 #Process #Thread #필수 #운영체제/CPU스케줄링 #NEW
## 정의
프로세스와 스레드 비교
- Process: CPU에 의해 실행되는 프로그램 단위(자원 할당) / Thread: 프로세스 내 실행 흐름(경량 프로세스)
## 키워드
* PCB, TCB, Code/Data/Heap/Stack, Context Switch, IPC
## 암기법
* Process=독립메모리, Thread=Code/Data/Heap 공유·Stack 독립
## 구성요소/특징/유형
| 구분 | Process | Thread |
| ---- | ---- | ---- |
| 단위 | 자원 할당 | CPU 이용 |
| 메모리 | 독립 | Stack만 독립 |
| 전환 | 느림(PCB) | 빠름(TCB) |
| 통신 | System Call | Library Call |
