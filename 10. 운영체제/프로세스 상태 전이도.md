#운영체제 #ProcessState #필수 #운영체제/CPU스케줄링 #NEW
## 정의
프로세스 상태 전이도
- 프로세스가 시스템 내 존재하는 동안 거치는 상태와 전이
## 키워드
* New, Ready, Running, Waiting, Finished, Dispatching, Time out, PCB
## 암기법
* 디스패칭=Ready→Run, 타임아웃=Run→Ready
## 구성요소/특징/유형
| 상태 | 전이 | 설명 |
| ---- | ---- | ---- |
| New | →Ready | Job Scheduler, Queue 생성 |
| Ready | →Run | Dispatching, FCFS/SJF 등 |
| Running | →Ready | Time out, 선점 |
| Running | →Waiting | I/O·자원 대기 |
| Waiting | →Ready | I/O 완료 Signal |
| Running | →Finished | 종료, PCB 제거 |
