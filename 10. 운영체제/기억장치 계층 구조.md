## 정의
기억장치 계층 구조(Memory Hierarchy)
- 가격·성능이 다른 여러 수준의 기억장치를 비용 최소·고속·대용량을 위해 효율적으로 구성하는 구조
## 키워드
* CPU→캐시→주기억→보조기억, bit당비용, 접근속도, Time/Spatial Locality
## 암기법
* 상↑하↓: 상위=고속·소용량·고가, 하위=저속·대용량·저가
## 구성요소/특징/유형
| 특성 | 상→하 변화 |
| ---- | ---- |
| 용량 | 증가 |
| 접근시간 | 증가 |
| bit당 비용 | 감소 |
| 성능 | 하위 접근 빈도↓일수록 향상 |
