## 정의
스레싱(Thrashing)
- 다중 프로그래밍 환경에서 Page Fault가 빈번해 CPU가 실행보다 페이지 교체에 더 많은 시간을 쓰는 비정상 현상
## 키워드
* Page Fault Rate, CPU Utilization, Working Set, PFF, Residence Set
## 암기법
* Fault↑ CPU↓ = Thrashing
## 구성요소/특징/유형
| 구분 | Working Set | PFF |
| ---- | ---- | ---- |
| 갱신 | 참조마다 | Fault 시만 |
| Thrashing | 간접 완화 | 직접 방지 |
| Overhead | 높음 | 낮음 |
