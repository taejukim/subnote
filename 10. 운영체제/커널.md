#운영체제 #커널 #Kernel #필수 #운영체제/프로세스관리 #NEW
## 정의
커널(Kernel)
- 컴퓨터 하드웨어와 응용 프로그램 간 연계를 위해 자원·프로세스·네트워크 관리 및 추상화를 수행하는 OS 핵심 프로그램
## 키워드
* Process/CPU Scheduling, Memory, I/O, IPC, Network, File System, User/Kernel Mode, Monolithic/Micro Kernel
## 암기법
* 커널6기: Process·Memory·I/O·IPC·Network·FileSystem
## 구성요소/특징/유형
| 구분 | 설명 | 비고 |
| ---- | ---- | ---- |
| User Mode | 사용자 응용 실행, 권한 제한, 커널 기능은 System Call로 접근 | |
| Kernel Mode | OS 커널 기능 수행, 최고 권한, HW 직접 접근 | |
| Monolithic | VFS·드라이버·IPC·스케줄러·메모리관리를 커널 내부에 통합 | 일반 PC |
| Micro Kernel | IPC·스케줄러·VM만 커널, 나머지는 User Space | 임베디드·고성능 서버 |
