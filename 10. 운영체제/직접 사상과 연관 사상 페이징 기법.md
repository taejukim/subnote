#운영체제 #페이징 #TLB #필수 #운영체제/메모리관리 #NEW
## 정의
직접 사상과 연관 사상 페이징 기법
- 직접 사상: PMT(Page Mapping Table) 참조로 가상주소→실주소 변환 / 연관 사상: CAM(Associative Memory)으로 병렬 탐색
## 키워드
* PMT, b+p, Page Frame, TLB, CAM, Page 존재 bit, 변위(d)
## 암기법
* 직접:b+p→프레임, 연관:p 병렬검색→프레임
## 구성요소/특징/유형
| 기법 | 방식 | 특징 |
| ---- | ---- | ---- |
| 직접 사상 | b(시작)+p(페이지번호)→PMT→p'+d | 표 크기 大, 구현 단순 |
| 연관 사상 | p로 CAM 전체 병렬 검색 | 빠름, HW 비용 高 |
| TLB | PMT 캐시 | 변환 가속 |
