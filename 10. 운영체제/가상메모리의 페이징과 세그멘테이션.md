## 정의
가상메모리의 페이징과 세그멘테이션
- 페이징: 고정 크기 블록 단위 관리 / 세그멘테이션: 가변 크기 논리 블록(세그먼트) 단위 관리
## 키워드
* Page/Segment Map Table, 내부단편화(페이징), 외부단편화(세그멘테이션), Page Fault
## 암기법
* 페이징=내부O외부X, 세그먼트=외부O내부X
## 구성요소/특징/유형
| 구분 | 페이징 | 세그멘테이션 |
| ---- | ---- | ---- |
| 분할 | 동일 크기 | 가변 크기 |
| 단편화 | 내부 | 외부 |
| 매핑 | Direct/Associative/Set/Inverted | Direct |
| 공유 | 읽기전용 공유 가능 | 오버헤드 적음 |
