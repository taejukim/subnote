#운영체제 #Deadline #RTOS #필수 #운영체제/CPU스케줄링 #NEW
## 정의
기한부(Deadline) 스케줄링
- 주어진 마감시간(Deadline) 내 작업 완료를 목표로 하는 실시간 스케줄링
## 키워드
* RM(Rate Monotonic), EDF(Earliest-Deadline First), Hard/Soft RTOS
## 암기법
* RM=짧은주기↑우선, EDF=가까운마감↑우선
## 구성요소/특징/유형
| 기법 | 정책 | 특징 |
| ---- | ---- | ---- |
| RM | 정적, 주기 짧을수록 우선 | 단순·예측 가능, CPU 활용↓ |
| EDF | 동적, 마감 가까울수록 우선 | CPU 활용↑, 구현 복잡 |
| Hard RT | 엄격 시간 제약 | |
| Soft RT | 유연 시간 제약 | |
