#운영체제 #FileSystem #Unix #필수 #운영체제/파일시스템 #NEW
## 정의
파일 시스템(유닉스 파일시스템)
- 파일·디렉터리를 계층 트리 구조로 조직하고 모든 데이터를 저장·관리하는 구조
## 키워드
* Root FS, Regular/Directory/Special File, Boot Block, Super Block, i-node, Data Block
## 암기법
* 부트=Bootstrap, 슈퍼=메타, 아이노드=파일정보, 데이터=실데이터
## 구성요소/특징/유형
| 구성 | 설명 |
| ---- | ---- |
| Boot Block | OS 부트·Bootstrap 코드 |
| Super Block | FS 크기, 블록 수, 빈 블록 목록 |
| i-node | 파일·디렉터리 메타정보 |
| Data Block | 실제 데이터 저장 |
