#운영체제 #Scheduler #필수 #운영체제/CPU스케줄링 #NEW
## 정의
스케줄러(Scheduler)
- 어떤 Process에 시스템 자원을 할당할지 결정하는 OS 커널 모듈
## 키워드
* 장기·중기·단기, 처리량, 응답/반환/대기시간, CPU 활용, Dispatcher
## 암기법
* 장중단: Job→Ready→Run, 스와핑
## 구성요소/특징/유형
| 종류 | 전이 | 역할 |
| ---- | ---- | ---- |
| 장기 | New→Ready | Job Pool→Ready, 멀티프로그래밍 정도 |
| 중기 | Run↔Wait | Swapping |
| 단기 | Ready→Run | CPU 할당 |
| Dispatcher | - | Context Switch, User mode, Jump |
