#운영체제 #메모리관리 #가상메모리 #필수 #운영체제/메모리관리
## 정의
사용자에게 실제보다 큰 메모리 공간을 제공하는 기법, Virtual Memory
- 사용자에게 주기억장치보다 더 큰 용량의 가상 기억 공간을 제공하는 기억장치 관리기법
- 구조: CODE, DATA, BSS, HEAP, STACK
## 키워드
* 가상주소, 물리주소, 페이지 테이블, MMU, TLB, 요구 페이징, 스와핑
## 암기법
* "할배인교" - 할당, 배치, 인출, 교체 (4대 관리정책)
## 구성요소/특징/유형
| 구분 | 설명 | 비고 |
| ---- | ---- | ---- |
| 할당 | 연속(단일/다중), 불연속(페이징/세그먼트) | 메모리 양 결정 |
| 배치 | First/Best/Next/Worst Fit | 어디에 배치 |
| 인출 | 요구호출, 예측호출 | 언제 적재 |
| 교체 | LRU, FIFO, LFU, OPT | 어떤것 교체 |
## 시험 대비 (2교시) — 가상메모리 문항

**1분 정의**
> OS가 물리 주기억보다 큰 **가상 기억공간**을 제공하고, MMU로 가상→물리 주소 변환하는 관리 기법

**가. 관리기법 (본문 전면 배치 순서)**

| 계층       | 기법                           | 설명                           |
| -------- | ---------------------------- | ---------------------------- |
| **핵심**   | **Paging**, **Segmentation** | 고정 분할 / 가변 분할                |
| **운영**   | **Demand Paging**, Swapping  | 필요 시 디스크↔주기억                 |
| **하드웨어** | MMU, **페이지 테이블**, **TLB**    | 주소 변환·캐시                     |
| **정책**   | **할배인교**                     | 할당·배치·인출·교체 ([[가상메모리 관리기법]]) |

**구성도**: CPU → 가상주소 → MMU → Main Memory / Swap Disk

**1분 답안 골격**
```
I. 개념(MMU, Swap)
II. 가. Paging·Segmentation + Demand Paging + 할배인교
III. 나. 단편화 유형 → [[단편화]]
IV. 다. 최소화(내부/외부 구분) → [[단편화]]
```
