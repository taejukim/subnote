#운영체제 #RAG #Deadlock #필수 #운영체제/프로세스관리 #NEW
## 정의
자원할당 그래프(Resource Allocation Graph)
- 프로세스(P)와 자원(R) 간 요청·할당 관계를 방향 그래프로 표현
## 키워드
* Request edge(P→R), Assignment edge(R→P), Cycle, Deadlock
## 암기법
* P=원, R=사각형(인스턴스=점)
## 구성요소/특징/유형
| 간선 | 방향 | 의미 |
| ---- | ---- | ---- |
| Request | P→R | 자원 요청·대기 |
| Assignment | R→P | 자원 할당 |
| Cycle+단일인스턴스 | - | Deadlock 확실 |
| Cycle+다중인스턴스 | - | Deadlock 가능 |
