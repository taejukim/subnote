## 정의
가상메모리 관리기법
- 제한된 물리 메모리를 효율 사용하기 위해 필요 시 보조기억에서 동적 적재하는 OS 기법, 가상 주소 공간 제공
## 키워드
* 할당(단일/다중), 배치(First/Best/Next/Worst), 호출(Demand/Pre), 교체(FIFO/LRU/LFU/OPT/NUR)
## 암기법
* 할배인교: 할당→배치→인출→교체
## 구성요소/특징/유형
| 정책 | 유형 | 설명 |
| ---- | ---- | ---- |
| 할당 | 단일 | Swapping, Overlay |
| 할당 | 다중 | 고정/가변 분할 |
| 배치 | Fit | First/Best/Next/Worst |
| 호출 | Fetch | Demand(요구), Pre(예측·지역성) |
| 교체 | Replace | FIFO, LRU, LFU, OPT, NUR |
## 시험 대비 (2교시)

> 「관리기법」 문항: **Paging·Segmentation**을 먼저, **할배인교**는 운영 정책으로 연결

**가. 관리기법 답안 순서**
1. **Paging**(고정) / **Segmentation**(가변)
2. **Demand Paging**, Swapping
3. MMU, 페이지 테이블, TLB
4. 할배인교(할당·배치·인출·교체)

| 정책 | 시험 키워드 |

| 인출 | Demand(요구) / Pre(예측) |
