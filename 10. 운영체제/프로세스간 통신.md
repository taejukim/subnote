#운영체제 #IPC #필수 #운영체제/프로세스관리 #NEW
## 정의
프로세스간 통신(IPC)
- OS에서 실행 중인 프로세스들이 데이터를 교환하는 메커니즘
## 키워드
* Shared Memory, Message Passing, Pipe, mmap, Socket, Signal
## 암기법
* 공유=빠름·동기화필요, 메시지=커널경유·충돌없음
## 구성요소/특징/유형
| 방식 | 대표 기법 | 특징 |
| ---- | ---- | ---- |
| 공유 메모리 | Shared Memory, mmap | 빠름, 동기화 필요 |
| 메시지 전달 | Pipe, MQ, Socket, Signal | 커널 경유, 안전 |
