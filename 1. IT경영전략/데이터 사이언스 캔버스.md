## 정의
데이터 사이언스 캔버스(Data Science Canvas)
- 데이터 수집부터 모델링·가치 창출까지 분석 워크플로우 전체를 한눈에 파악하는 시각화 프레임워크
## 키워드
* DataOps, 가치제안, 데이터소스, 전처리, 모델학습, 워크플로우, 활용시나리오, 모니터링
## 암기법
* 가소수전학플시모: 가치·소스·수집·전처리·학습·워크플로·시나리오·모니터링
## 특징
- 8블록: 기획·소스→수집·처리→모델·파이프라인→시나리오·운영
- BM Canvas 대비: 데이터/AI 프로젝트·DataOps 중심
## 목적
- 데이터 분석·AI 프로젝트 기획·실행 가이드
- BM Canvas와 역할 분담(비즈니스 vs 기술)
## 구성요소
- 1~2: 가치제안, 데이터 소스
- 3~4: 수집, 전처리·탐색(EDA)
- 5~6: 모델 학습·평가, 워크플로우
- 7~8: 활용 시나리오, 운영·모니터링
## 구성도
```
가치→소스→수집→전처리→학습→워크플로→시나리오→모니터링
```
