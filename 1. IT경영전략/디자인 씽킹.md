## 정의
디자인 씽킹(Design Thinking)
- 공감적 관찰(Empathic Observation)을 기반으로 문제를 해석하고 사고(Thinking)를 디자인(Design)하여 문제를 창의적으로 해결하는 사용자 중심 문제 해결 방법
## 키워드
* 공감, 창의적 문제 해결 사고, 사용자 중심 문제 해결 방법
## 암기법
* [공정아프테] (공감·문제정의·아이디어·프로토타입·테스트)
## 특징
- Inspiration(영감) → Ideation(아이디어) → Implementation(실행) 순환
- 더블 다이아몬드: Discover/Define(무엇·왜) → Develop/Deliver(어떻게), 확산↔수렴 반복
- 3I 모델: Innovation(혁신)·Integration(통합)·Impact(영향)
## 목적
- 사용자 Needs 기반의 창의적 문제 해결
- 프로토타입·테스트로 빠른 검증·개선
## 구성요소
- Empathize: 관찰·인터뷰·Shadowing으로 Needs·이슈 파악
- Define: 페르소나·고객여정지도로 문제·Touch Point 정의
- Ideate: 브레인스토밍·스케치, Divergence/Convergence
- Prototype: 스토리보드·MVP로 핵심 기능 실체화
- Test: 사용성 테스트·Role play, 피드백·회고
## 구성도
```
[무엇/왜]              [어떻게]
확산→수렴              확산→수렴
문제공감 → 문제정의 → 해결개발 → 해결실행
(일반질문) (특정문제)   (솔루션)   (전달)
피드백 ↺
```
