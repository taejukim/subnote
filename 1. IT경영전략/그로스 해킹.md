## 정의
그로스 해킹(Growth Hacking)
- 사업 전반에 데이터 기반하에 검증·추적·확장 가능한 방법으로 사업 성장을 이루는 마케팅 전략
## 키워드
* 성장, 해킹, 기술적 요소 결합, 데이터 기반, AARRR, Cohort 분석, A/B 테스트
## 암기법
* [A코퍼] (A/B Test·Cohort·Funnel) / AARRR
## 특징
- 데이터 분석 → 아이디어 → 우선순위 → 실험의 4단계 순환
- 기술·마케팅·데이터 결합으로 빠른 성장 실험
- AARRR 퍼널로 획득부터 추천까지 단계별 측정
## 목적
- 검증·추적 가능한 방식으로 사업 성장 가속
- 단계별 이탈·전환을 데이터로 개선
## 구성요소
- 프로세스: 데이터 분석 → 아이디어 도출 → 우선순위 결정 → 실험
- A/B Test: A·B 방식 시험 후 우수안 채택
- Cohort analysis: 동일 특성 그룹의 시간별 성과 비교
- Funnel Analysis: 단계별 잔존·전환 측정
- AARRR: Acquisition(획득) → Activation(활성화) → Revenue(매출) → Retention(리텐션) → Referral(추천)
## 구성도
```
[데이터분석] → [아이디어] → [우선순위] → [실험] ↺
AARRR Funnel:
Acquisition → Activation → Revenue → Retention → Referral
```
