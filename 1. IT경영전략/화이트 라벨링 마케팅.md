#IT경영전략 #마케팅 #비즈니스모델 #IT경영전략/디지털_전환/경제_모델

## 정의
타사 제품·서비스를 자사 브랜드로 재포장하여 판매하는 마케팅 전략, 화이트 라벨링
- 제조사(공급자)가 브랜드 미표기 제품을 생산, 판매사(리셀러)가 자사 브랜드 부착 후 유통
- OEM/ODM과 유사하나, 완성된 범용 제품을 다수 브랜드에 공급하는 점이 차별점
## 키워드
* OEM, ODM, PB(Private Brand), BaaS, SaaS, API Economy, 플랫폼 비즈니스
## 암기법
* "제브유마" - 제조(공급자), 브랜딩(판매자), 유통(채널), 마진(수익모델)

## 특징

| 구분 | 설명 | 비고 |
| --- | --- | --- |
| 브랜드 재포장 | 공급자 제품에 판매자 브랜드 부착 | 소비자는 공급자 미인지 |
| 다수 공급 | 동일 제품을 복수 브랜드에 공급 가능 | 규모의 경제 |
| 빠른 시장 진입 | 자체 개발 없이 즉시 제품 라인업 확보 | Time-to-Market 단축 |
| 핵심 역량 집중 | 판매자는 마케팅·고객관리에 집중 | 개발비 절감 |
| 커스터마이징 | UI/UX, 기능 일부 커스터마이징 가능 | 완전 맞춤은 제한적 |

## 개념도 및 장단점
```
[공급자(제조/개발사)]
  │ 범용 제품·서비스 생산
  │ (브랜드 미표기)
  ├──────────────────────┐
  ▼                      ▼
[판매사 A]           [판매사 B]
(A 브랜드 부착)      (B 브랜드 부착)
  │                      │
  ▼                      ▼
[소비자: A 제품 인식]  [소비자: B 제품 인식]
```

| 구분 | 장점 | 단점 |
| --- | --- | --- |
| 판매자 | 개발비 절감, 빠른 출시 | 차별화 어려움, 공급자 의존 |
| 공급자 | 다수 채널 확보, 매출 극대화 | 브랜드 인지도 부재 |
| 소비자 | 다양한 브랜드 선택지 확보 | 실질 제품 동일 가능성 |

## 활용 사례

| 분야 | 사례 | 비고 |
| --- | --- | --- |
| 핀테크/BaaS | 은행 API를 비금융사가 자사 브랜드 금융서비스로 제공 | Banking as a Service |
| 클라우드/SaaS | AWS·Azure 인프라를 MSP가 자사 브랜드로 리셀링 | 클라우드 리셀러 |
| 유통/PB | 대형마트 자체 브랜드 상품(이마트 노브랜드 등) | Private Brand |
| 모바일/MVNO | 이통사 망을 알뜰폰 사업자가 자사 브랜드로 제공 | 가상이동통신 |
| AI/챗봇 | OpenAI API를 활용한 자사 브랜드 AI 서비스 구축 | API Economy |
