## 정의
- 정보시스템 도입 시 기본적인 용량과 성능 요구사항이 제시되었을 떄 그것을 시스템 도임을 위한 요구사항으로 변환하기 위한 산정하는 방법
### 암기법
- 규모산정방법
	- 수원시 : 수식계산법, 원가참조법, 시뮬레이션법

## 키워드
- 수식계산법, 원가참조법, 시뮬레이션법

## 규모 산정 대상
| 대상   | 설명                                                                                            |
| ---- | --------------------------------------------------------------------------------------------- |
| CPU  | 해당업무를 처리하기 위한 CPU의 전체규모를 계산한 후, 적정한 성능을 지닌 서버 기종을 선정                                          |
| 메모리  | CPU 규모산정에 따른 서버 구성방안에 의거하여, 서버별 시스템 S/W, 응용프로그램 등의 메모리 사용량을 산정                                |
| 디스크  | CPU 규모산정에 따른 서버 구성방안에 의거하여, 서버별 OS, 시스템 S/W, DB의 데이터, DB의 아카이브(Archive) 및 백업영역 등의 디스크 사용량을 산정 |
| 스토리지 | CPU를 기준으로 산정된 서버 규모에 따라 필요한 스토리지의 규모를 산정                                                      |

## 규모산정 절차
1. 구축 방향 및 기초 자료 조사 
2. 기초자료 및 업무 분석
3. 참조모델 결정 및 서버 규모 산정
4. 참조 모델별 가중치 적용

| 절차                      | 활동                                                    |
| ----------------------- | ----------------------------------------------------- |
| [1단계] 구축방향 및 기초자료 조사    | 구축 방향 파악<br>기초자료 조사                                   |
| [2단계] 기초자료 및 업무분석       | 기준 부하 산정<br>업무 내용 검증                                  |
| [3단계] 참조모델 결정 및 서버 규모산정 | 참조 모델 선택<br>요소별 규모산정                                  |
| [4단계] 참조모델 별 가중치 적용     | 참조모델1 가중치 적용 방식<br>참조모델2 가중치 적용 방식<br>참조모델3 가중치 적용 방식 |

## 규모산정 방법
| 방법         | 개념                                                              | 개념도                                      |
| ---------- | --------------------------------------------------------------- | ---------------------------------------- |
| **수**식계산법  | 사용자 수 등 규모산정을 위한 요소를 토대로 용량 수치를 계산하고, 보정치를 적용하는 방법              | (총 사용자수 / 동시 접속 사용자수) × 보정치 = CPU 2 Core |
| **참**조법    | 업무량(사용자 수, DB 크기)에 따라, 기본 데이터를 토대로 대략적인 시스템 규모를 비교하여 비슷한 규모를 산정 | 유사 시스템 → 참조 → B 시스템                      |
| **시**뮬레이션법 | 대상 업무에 대한 작업부하를 모델링하고 이를 시뮬레이션하여 규모를 산정                         | 기본 규모산정(보정) → 시뮬레이션(부하, 성능)              |
