## 정의
시빅 해킹(Civic Hacking)
- 시민이 협업을 바탕으로 공공데이터와 정보통신기술(ICT)을 활용해 사회적 이슈나 정부 시스템 등을 개선하는 사회운동
## 키워드
* 시민 협업, Web 2.0, 공공 데이터, 공공 API, 시민 참여
## 암기법
* [공공공] (공공데이터·OpenAPI·오픈소스) / 개발·기획·디자인·시민
## 특징
- 시민의 자발적 참여가 핵심
- 요소기술: 공공데이터, OpenAPI, 오픈소스
- 개방·참여·공유(Web 2.0)와 웹·앱 접근성 원칙 중시
## 목적
- 사회적 이슈·정부 시스템 개선
- 집단지성·피드백으로 삶의 질 향상
## 구성요소
- 참여주체: 개발자(도구 개발), 기획자(문제·소통), 디자이너(UI/UX), 일반시민(참여·확산)
- 프로그래머: Open Source, Web 2.0(CSS·HTML5·AJAX·SNS·Blog)
- 디자이너: UI/UX, 웹·앱 접근성 원칙
- 시민: 공공 데이터, 공공 API(시민정보·국토교통 등)
## 구성도
```
사회적 이슈 ──→ [시빅 해킹] ──→ 삶의 질 향상
                 (시민 자발 참여)
         공공데이터 / OpenAPI / 오픈소스
```
