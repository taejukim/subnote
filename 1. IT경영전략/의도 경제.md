## 정의
의도 경제(Intention Economy)
- 소비자가 자신의 필요나 구매 의도(intention)를 명확히 표현하고, 기업이 그 의도에 맞춰 반응하는 방식의 경제 활동 시스템
## 키워드
* 의도(Intention), 주목경제(Attention Economy), LLM, 의도 인식/분류 모델, 인텐토노미(Intentonomy)
## 암기법
* [대의추] (대화·의도분석·추천) / 의도 vs 주목
## 특징
- 주목경제: 노출로 시선 유도, 수동적 소비자, 자극 콘텐츠·깔때기 분석
- 의도경제: 의도·목적 선파악 후 대응, 능동적 소비자, 개인화·추천·의도 마케팅
- 프롬프트 → LLM/의도모델 → 맞춤 추천으로 실질 행동 유도
## 목적
- 고객 의도의 정확한 파악으로 실질적 구매·행동 유도
- 노출 중심에서 의도 기반 맞춤 대응으로 전환
## 구성요소
- 대화: 프롬프트, LLM(대규모 언어모델)
- 의도 분석: 의도 인식/분류 모델, 인텐토노미(Meta, 2021 인간 의도 데이터세트)
- 추천: 컨텐츠 기반 추천, 협업 필터링
## 구성도
```
User Prompt → App → LLM API + Intention Model(+Shopping Data)
                              ↓ Intentonomy
                     맞춤 추천 (예: A 운동화)
의도경제 vs 주목경제: 의도 선파악 ↔ 시선·노출 유도
```
