#IT경영전략 #IT서비스관리 #필수 #IT경영전략/IT_거버넌스/서비스관리

## 정의
ITIL 4.0 (IT Infrastructure Library)
IT 서비스 관리를 위한 전 세계적인 ==Best Practice== 프레임워크, ITIL 4.0
- [[ITSM]] 구축을 위해 비즈니스 가치 창출 중심으로 설계된 서비스 관리 가이드
- 4차 산업혁명 시대의 신기술(AI, 클라우드 등)과 애자일 방식이 반영된 최신 버전
특징) 가치 공동 창출, 서비스 가치 시스템(SVS), 4차원 모델, De-facto
## 키워드
* 가치 창출(Value), SVC, SVS, 4차 산업혁명 대응, Agile/[[DevOps]] 통합, ISO 20000
## 암기법
- 구성요소
	- 지거서지실 조정파가
		- 지도원칙, 거버넌스, 서비스 가치 사슬, 지속적인 개선, 실행
		- 조직과 사람, 정보 및 기술
		- , 파트너 및 공급업체, 가치 흐름과 프로세스
- 서비스 가치 사슬
	- 계참설획제개
		- 계획, 참여, 설계 및 전환, 획득/구축, 제공 및 지원, 개선
## 구성요소

| **구분**         | **구성요소**                                       | **설명**                                                                     |
| -------------- | ---------------------------------------------- | -------------------------------------------------------------------------- |
| **서비스 가치 시스템** | **지도 원칙**<br>(Guiding Principles)              | - 목표, 전략, 업무 유형 또는 관리 구조의 변화에 관계 없이 모든 상황에서 조직 지도 가능 7가지 원칙                |
|                | **거버넌스**<br>(Governance)                       | - 조직이 감독되고 통제되는 수단                                                         |
|                | **서비스 가치 사슬**<br>(Service Value Chain)         | - 조직이 소비자에게 가치 있는 제품이나 서비스를 제공<br>- 가치 실현을 촉진하기 위해 수행하는 6가지 활동             |
|                | **지속적인 개선**<br>(Continual Improvement)         | - 조직의 성과가 이해 관계자의 기대를 지속적으로 충족하는지 확인하기 위해 모든 수준에서 수행되는 반복 활동               |
|                | **실행**<br>(Practices)                          | - 작업을 수행하거나 목표를 달성하기 위해 설계된 34가지 Practices                                 |
| **4차원 모델**     | **조직과 사람**<br>(Organizations & People)         | - 역할과 책임을 명확하게 정의<br>- 보고 회선 및 통신 채널이 개방적이고 명확한지 확인                        |
|                | **정보 및 기술**<br>(Information & Technology)      | - 데이터의 가치 극대화, 소유로 인한 위험과 의무 관리<br>- 클라우드 서비스를 통해 신속 배포, 확장, 해체 수행         |
|                | **파트너 및 공급업체**<br>(Partners & Suppliers)       | - 파트너와 공동 창작을 통해 가치 상승<br>- SIAM(Service Integration and Management) 프레임워크 |
|                | **가치 흐름과 프로세스**<br>(Value streams & Processes) | - 조직이 제품과 서비스를 만들고 소비자 제공 단계<br>- 작업 순서와 종속성 정의, 목표 달성 위한 수행 작업            |

## 서비스 가치 사슬
- 조직이 가치 있는 제품 또는 서비스를 소비자에게 제공하고 가치 실현을 촉진하기 위해 수행하는 일련의 상호 연결된 활동
![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260330234756.png|500]]

| **구분**                               | **핵심 사항**               | **설명**                                                     |
| ------------------------------------ | ----------------------- | ---------------------------------------------------------- |
| **계획**<br>(Plan)                     | - 포트폴리오<br>- 개선 방향      | - 전략적, 전술적, 운영 계획<br>- 설계 및 전환을 위한 아키텍처 및 정책               |
| **참여**<br>(Engage)                   | - 이해관계자 지속적 참여          | - 고객의 서비스 및 제품에 대한 자세한 요구 사항<br>- 고객을 위한 서비스 성능 보고서        |
| **설계 및 전환**<br>(Design & Transition) | - 제품 요구 사항<br>- 제공 및 지원 | - 서비스 품질, 비용, 시장 출시에 대한 고객 기대치 충족<br>- 새롭고 변경된 제품 및 서비스    |
| **획득/구축**<br>(Obtain/Build)          | - 서비스 구성<br>- 합의사항 충족   | - 제공 및 지원을 위한 서비스 구성 요소<br>- 가치사슬 활동에 대한 새롭고 변경된 서비스 구성 요소 |
| **제공 및 지원**<br>(Deliver & Support)   | - 서비스 제공<br>- 유지보수 지원   | - 고객 및 사용자에게 제공되는 서비스<br>- 사용자 지원 작업 완료 정보                 |
| **개선**<br>(Improve)                  | - 지속적 개선 보장             | - 모든 가치 사슬 활동을 위한 개선 계획<br>- 개선 상태 보고서 및 서비스 성능 정보         |
