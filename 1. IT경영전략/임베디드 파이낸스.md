## 정의
임베디드 파이낸스(Embedded Finance)
- 비금융 기업 서비스·제품에 결제·대출·보험 등 금융 기능을 내장(Embedded)하여 제공하는 기술·비즈니스 모델
## 키워드
* BaaS, OpenAPI, Open Banking, Cloud Native, MSA, AML/FDS, eKYC
## 암기법
* 비금IT금: 비금융+IT+금융융합
## 특징
- BaaS·Open Banking·OAuth2·eKYC·AML/FDS 기반
- Cloud Native·MSA·AI/ML 리스크·맞춤 서비스
- 국내: NAVER·카카오·삼성생명 / 해외: Tesla·Google Map
## 목적
- 구매·이용 시점 금융 서비스 seamless 제공
- 플랫폼·커머스 수익 다각화
## 구성요소
- 연동: Open API, BaaS, OAuth2/OpenID
- 신원·규제: eKYC, 생체인증, AML/FDS
- 인프라: Cloud Native, MSA, AI/ML, 암호화·비식별
## 구성도
```
비금융+금융+핀테크 → [OpenAPI·BaaS·AI/ML] → Cloud Native → 고객서비스
```
