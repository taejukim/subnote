#정보관리기술사 #IT경영전략 #환경분석 #IT경영전략/경영전략/분석_기법
## 정의
- 기업 경영에 영향을 주는 기업환경들로 부터 나타나는 그 어떤 징후나 신호 같은 것들을 가능한 한 포작하여 이들 자료나 정보를 이용하여 장래 기업 경영에 영향을 미칠 수 있는 요인 들을 분석하는 것
## 키워드
- 내부환경분석, 외부환경분석, 강점/약점, 기획/위협, [[SWOT분석]]

## 외부환경분석
| **구분** | **설명**                                                                                                                      |
| ------ | --------------------------------------------------------------------------------------------------------------------------- |
| **개념** | - 기업이 경영전략 수립 시 직·간접적으로 경영에 영향을 미치는 **외부적인 요인을 분석**하여 기존 사업과 신규 사업의 성공 가능성을 판단하는 기준을 세우기 위한 분석방법                            |
| **절차** | **거시 환경분석** → **산업 구조분석** → **경쟁 환경분석** → **산업 진화분석** → **시사점도출**                                                           |
| **기법** | **PEST 분석**<br>- PEST분석을 통해 신기술 적용이라는 조직전략에 영향을 주는 거시적인 기업 외부환경으로 정치, 경제, 사회문화, 기술 등의 외부환경 분석 기법                            |
|        | **5 Force 모델 분석**<br>- 조직의 외부환경인 산업과 시장 내 경쟁자 간의 상호작용 및 영향력을 분석하여 산업의 기회요인과 경쟁 제약 및 위협요인을 도출하기 위한 산업환경 분석도구                 |
|        | **3C 분석**<br>- 경쟁사와 비교 및 차별화 포인트를 분석함으로써 자사가 경쟁력 우위를 차지할 수 있는 전략을 분석하는 기법<br> 고객의 Needs를 파악하거나 경쟁력 여부 판단 및 자사 전략 수립을 목적으로 함 |
|        |                                                                                                                             |

## 내부환경분석
| **구분** | **설명**                                                                                                                                              |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **개념** | - 현시점에 기업이 **보유한 역량을 분석**하여 기업의 미래 역량을 도출하기 위한 분석방법                                                                                                 |
| **절차** | **사업성과 및 재무성과 분석** → **경영 현황 진단** → **내부 역량 분석** → **시사점 도출**                                                                                       |
| **기법** | **Value Chain 분석**<br>- 부가가치 창출에 직·간접적으로 관련된 프로세스<br>- 가치 창출 활동의 강·약점과 비용 우위 확보, 제품/서비스의 차별화 속성 창출, 내부역량 분석을 통한 역량 강화 등 전략적 시사점을 분석                 |
|        | **균형 지표 성과 분석 (BSC)**<br>- 재무적 관점, 고객, 내부 프로세스, 학습 및 성장 관점의 비재무적인 관점을 측정 가능한 성과지표로 전환하여 관리 및 성과관리 방안을 분석 기법                                         |
|        | **7S 모형 분석**<br>- 전사 조직의 현황을 진단하고 대응방안을 수립하는 데 활용이 가능한 분석 기법<br>- ‘Hard Element’와 많은 시간과 노력으로 변경 가능한 ‘Soft Element’ 측면으로 모두 고려하여 조직의 총체적인 조직 역량을 진단 |
|        | **가능역량 자원분석**<br>- 기업이 시장에서 우위를 가질 수 있는 요인을 중심으로 자사의 자원과 핵심역량, 경쟁우위를 분석하는 기법                                                                        |
