#정보관리기술사 #IT경영전략 #OKR
## 정의
OKR(Objectives and Key Results)
- 도전적 목표(Objective)와 측정 가능한 핵심결과(Key Result)로 정렬되는 성과 프레임워크
- 상향식·분기 단위로 목표를 재조정하며 성장과 변화 유도
## 키워드
* Objective, Key Result, Stretch Goal, 분기 점검, 정렬, KPI 보완
## 암기법
* 도측분유: 도전·측정·분기·유연
## 특징
- 도전성: 70% 달성을 가정한 Stretch 목표
- 정렬성: 회사·팀·개인 목표 수직 정렬
- 주기성: 분기 단위 점검과 재설정
- 투명성: 전사 공개로 협업 촉진
## 목적
- 전략 방향성과 실행 단위를 강하게 정렬
- 평가 분리로 도전적·창의적 목표 추구 유도
## 구성요소
- Objective: 정성적 도전 목표
- Key Result: 정량적 측정 지표 3~5개
- CFR(Conversation·Feedback·Recognition) 운영
- OKR 캐스케이딩: 회사 → 팀 → 개인
## 구성도
```
전사 OKR → 부서 OKR → 팀 OKR → 개인 OKR (정렬)
Plan(설정) → Execute(주간 체크인) → Review(분기 평가) → Reflect(회고)
```
