#정보관리기술사 #IT경영전략 #ISO #IT경영전략/IT_거버넌스/서비스관리
ISO 38500:2024
## 정의
- 조직의 IT가 효율적이고, 효과적이고 책임성 있게 활용될 수 있도록 IT 활용을 평가하고 지회 하고 감톡하기 위해 [[IT Governance]] 구현 원식 프레임워크를 제시하는 국제 표준
## 키워드
- 평가, 지휘, 감독, 이해관계자 참여, ISO 37000

## 암기법
- 구성요소
	- 평지모이
		- 평가, 지시, 감독(모니터링), 이해관계자 참여
- 원칙
	- 목가전감책 이리의위사지
		- 목적, 가치모델, 전략, 감독, 책임, 이해관계자 참여, 리더쉽, 데이터와 의사결정, 위험거버넌스, 사회적 책임, 지속가능성과 성과

## 개념도

- 구성요소
	- 평가(Evaluation) : 비즈니스상의 내외부적 환경을 고려하여 평가
	- 지휘(Direct) : 비즈니스 목표를 이루기 위한 계획 및 정책 구현
	- 감독(Monitoring) : 정책 준수 및 계획에 따른 성과 모니터링
	- 이해관계자 참여(Engage Stakeholders) : 상호작용으로 IT거버넌스 효과성 극대화
## 원칙
| **구분**    | **핵심원칙**      | **설명**                               |
| --------- | ------------- | ------------------------------------ |
| **주요 원칙** | **목적**        | 조직의 존재 이유를 정의하고 모든 활동과 의사결정의 방향을 설정  |
| **기초 원칙** | **가치 모델**     | 조직의 핵심 가치를 설정하고 윤리적 행동과 의사결정을 촉진     |
|           | **전략**        | 조직의 목적과 가치 달성하기 위한 명확한 전략 수립 및 실행    |
|           | **감독**        | 조직의 성과와 활동을 모니터링하고 목표 달성을 보장         |
|           | **책임**        | 구성원들이 자신의 역할과 책임을 명확히 이해하고 이행        |
| **지원 원칙** | **이해관계자 참여**  | 이해관계자와 적극적으로 소통하고 신뢰를 구축             |
|           | **리더십**       | 윤리적이고 효과적인 리더십을 통해 조직 문화를 형성         |
|           | **데이터와 의사결정** | 신뢰할 수 있는 데이터를 기반으로 투명하고 일관된 의사결정 수행  |
|           | **위험 거버넌스**   | 조직이 직면한 위험을 식별하고 관리하여 지속 가능한 성장 지원   |
|           | **사회적 책임**    | 조직 활동이 사회와 환경에 미치는 영향을 고려하고 책임 있게 행동 |
|           | **지속가능성과 성과** | 장기적인 관점에서 조직의 지속 가능성과 성과를 보장         |
- ISO 37000(조직 거버넌스)과 ISO 38500 연계
- ISO 37000의 원칙과 정합성을 강화하여 11개 원칙으로 확장
