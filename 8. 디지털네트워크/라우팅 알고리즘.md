#정보관리기술사 #디지털네트워크 #라우팅알고리즘 #디지털네트워크/OSI/프로토콜
Routing Protocol
## 정의
- 라우팅 테이블을 생성, 유지, 업데이트, 전달하는 프로토콜
## 키워드
- 거리벡터 라우팅, 링크상태 라우팅, Metric 정보, 홉수(Hop Count), 심볼길이(Symbol Length), 벨만-포드, [[다익스트라 알고리즘]]

## 거리벡터
| **구분**    | **내용**                                                                                                                                                                          |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **정의**    | - 이웃 라우터의 주기적인 갱신정보로 원격 목적지에 대한 라우팅 경로를 결정하는 알고리즘<br>- **Hop count** 기반이며, **벨만-포드(Bellman-Ford) 알고리즘** 사용                                                                      |
| 매커니즘      | ![[Pasted image 20260325233740.png\|500]]                                                                                                                                       |
| **동작 방식** | 1. 송신 노드(C노드)로부터 테이블 정보를 수신<br>2. 수신 받은 테이블 정보와 수신 노드(A노드) 사이의 비용(거리)을 고려하여 정보 반영<br>3. 정보 변경 전 테이블과 반영 후 테이블 정보를 비교<br>4. 반영 후 Hop Count가 기존보다 작은 경우 최소값으로 변경, 그렇지 않으면 기존 값 유지 |
| **프로토콜**  | - **RIP**: 모든 라우팅 정보를 주고받으며 적은 값으로 라우팅 테이블 갱신<br>- **IGRP**: 전송능력, 지연시간, 사용률, 신뢰성을 바탕으로 경로 설정 및 로드밸런싱 수행                                                                        |
## 링크 상태
| **구분**    | **내용**                                                                                                                                                                      |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **정의**    | - 목적지까지 경로를 OSPF 알고리즘을 통해 모든 라우팅 테이블에 기록<br>- 각 링크 비용 합에 기반하여 최소 경로 비용 계산. **다익스트라(Dijkstra) 알고리즘** 사용                                                                      |
| 메커니즘      | ![[Pasted image 20260325233838.png\|500]]                                                                                                                                   |
| **동작 방식** | 1. 각 라우터는 이웃 라우터의 링크 상태정보를 수집<br>2. 링크 정보를 통해 **토폴로지 데이터베이스** 생성<br>3. SPF(Shortest Path First) 알고리즘을 사용해 경로 계산<br>4. 계산된 경로로 **SPF 트리** 생성<br>5. 트리를 활용해 최종 **라우팅 테이블** 생성 |
| **프로토콜**  | - **OSPF**: 네트워크 링크 상태 정보를 수집하여 최적의 경로를 계산하는 개방형 프로토콜<br>- **EIGRP**: IGRP 기반의 향상된 프로토콜. 대역폭/처리능력 활용 및 토폴로지 변경 시 불안정성 최소화                                                   |
