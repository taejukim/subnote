#디지털네트워크 #5G #NetworkSlicing #필수 #디지털네트워크/5G/6G
## 정의
네트워크 슬라이싱
- 단일 물리 네트워크 인프라 위에 다수의 논리적 가상 네트워크를 생성하는 5G 핵심 기술
- SDN/NFV 기반으로 서비스별 맞춤형 E2E 네트워크를 동적으로 구성하는 기술
## 키워드
* SDN, NFV, VNF, CNF
* NSMF, NSSMF, CSMF
* RAN Slice, Core Slice, Transport Slice
## 암기법
* "슬에스" - Slicing, E2E, SDN/NFV
* "씨엔엔" - CSMF, NSMF, NSSMF (관리 계층)
## 구성요소/특징/유형
| 구분              | 설명                          | 비고               |
| --------------- | --------------------------- | ---------------- |
| CSMF            | Customer Service Management | 고객 요구→슬라이스 매핑    |
| NSMF            | Network Slice Management    | E2E 슬라이스 오케스트레이션 |
| NSSMF           | Network Slice Subnet Mgmt   | 도메인별 슬라이스 관리     |
| RAN Slice       | 무선접속망 슬라이스                  | gNB 자원 분할        |
| Core Slice      | 코어망 슬라이스                    | UPF/AMF 인스턴스     |
| Transport Slice | 전송망 슬라이스                    | 백홀/프론트홀          |

## SDN, NFV 상세 설명

| **구분**  | **요소**            | **설명**                                                                                                                       |
| ------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **SDN** | **개념**            | - 전달 및 제어 기능이 결합된 기존 전송 장치에서 **제어 기능을 분리하여 중앙 집중화**함<br>- OpenFlow와 같은 개방형 API를 통해 네트워크 트래픽 전달 동작을 **S/W 기반 컨트롤러**에서 제어하는 기술 |
|         | **Application**   | - Network OS 상위에서 사용자 서비스를 지원하는 프로그램                                                                                         |
|         | **Control plane** | - 전체 망에 대한 Global View를 갖고 제어<br>- **Openflow Controller**를 통해 Data plane 장비의 Flow Table 제어                                  |
|         | **Data plane**    | - 단순 패킷 포워딩, 스위칭 기능만 수행<br>- 기존 L2/L3 스위치에 OpenFlow 기능을 추가하여 구현                                                              |
| **NFV** | **개념**            | - 가상화 기술을 기반으로 통신망 운용에 필요한 다양한 N/W 장비 내 기능을 분리시켜 **S/W로 제어 및 관리가 가능하도록 가상화**하는 기술                                            |
|         | **NFVI**          | - 컴퓨팅, 저장소, 네트워크 하드웨어 자원 및 가상화 지원 기능, VNF 실행 지원                                                                              |
|         | **VNFs**          | - 여러 응용 프로그램을 지원하기 위한 S/W로 개발된 네트워크 기능들의 집합                                                                                  |
|         | **MANO**          | - 물리적, 소프트웨어적 자원 관리 및 전달, VNF 관리 기능(Management and Orchestration)                                                            |
