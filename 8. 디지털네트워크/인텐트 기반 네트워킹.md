#정보관리기술사 #디지털네트워크 #IBN #자율네트워크 #NEW
## 정의
인텐트 기반 네트워킹(Intent-Based Networking)
- 관리자의 의도(Intent)를 AI로 파악해 유·무선망 설정을 자동 수행하는 네트워크 기술
- Closed-Loop Intent Control로 번역→적용→모니터링→피드백
## 키워드
* 의도, 인공지능, 자율 네트워크, 변환과 검증, 자동 수행, 상황 인식
## 암기법
* 변자동상: 변환검증·자동수행·상황인식·동적최적화
## 특징
- 변환·검증: Intent→Policy 변환 후 실행 여부 확인
- 자동 수행: 관리자 개입 최소화
- 상황 인식: 모니터링 데이터로 목표 상태 유지
- 동적 최적화: 의도 유지 방법 판단·조정·자동 실행
## 목적
- 선언적 의도로 망 운영 자동화
- 의도–실제 상태 정합성 지속 보장
## 구성요소
- 의도 명령: NMS·User의 선언적(Declarative) 목적 전달
- 의도 번역: Translation/Optimization/LLM→High-level Policy
- 의도 적용: Activation/Configuration/VM·Container→Low-level Policy
- 의도 모니터링: Monitoring/Assurance로 데이터 수집·분석
- 의도 검정·재설정: Validation/Feedback으로 정책 보완
## 구성도
```
[User/NMS Intent]
      ↓ Translation/Optimization
[High-level Policy] → Activation → [Infrastructure]
                                      │ Monitoring Data
[Feedback] ← Assurance/Monitoring ←──┘
         (Closed-Loop)
```
