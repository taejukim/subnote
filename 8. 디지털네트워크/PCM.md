#정보관리기술사 #디지털네트워크 #PCM #변조 #NEW
## 정의
PCM(Pulse-Code Modulation)
- 아날로그 신호를 표본화 정리로 정해진 주파수로 표본화·양자화한 뒤 2진 부호화하는 디지털 변조 방식
- 아날로그→디지털(A/D) 변환의 기본 원리
## 키워드
* 표본화, 양자화, 부호화, 나이퀴스트, PAM
## 암기법
* 표양부: 표본화·양자화·부호화
## 특징
- 표본화: fs ≥ 2fm(나이퀴스트)로 PAM 펄스열 생성
- 양자화: 진폭을 2^n 이산 레벨로 변환
- 부호화: 양자화 값을 0/1 비트열로 표현
- 앨리어싱: under sampling 시 원신호 복원 불가
## 목적
- 아날로그 신호를 디지털로 안정 전송
- 재생·복호화·재구성으로 원신호 복원
## 구성요소
- 송신-표본화: 프레임/샘플 주기로 PAM 추출, fs ≥ 2fm
- 송신-양자화: PAM을 이산 디지털 값으로 변환(레벨=2^n)
- 송신-부호화: 양자화 진폭을 2진수(0,1)로 표현
- 수신-재생: 수신 디지털 신호 재생
- 수신-복호화: PCM→PAM 복원
- 수신-재구성: PAM을 필터링하여 아날로그 복원
## 구성도
```
[아날로그] → 표본화 → 양자화 → 부호화 → [PCM 전송]
              (fs≥2fm)                        │
[아날로그] ← 재구성 ← 복호화 ← 재생 ←─────────┘
```
