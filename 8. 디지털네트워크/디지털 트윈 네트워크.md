#정보관리기술사 #디지털네트워크 #디지털트윈 #6G #NEW
## 정의
디지털 트윈 네트워크(Digital Twin Network)
- 6G 무선망의 설계·진단·분석과 AI/ML 기반 실시간 최적화·제어를 위해 물리망을 실시간 복제하는 네트워크
- 물리망↔가상 트윈의 상호작용 매핑이 기존 시뮬레이션과 차별점
## 키워드
* 물리적 네트워크, 가상 네트워크, Application Layer, Digital Twin Layer, Physical Layer
## 암기법
* 데매모인: 데이터·매핑·모델·인터페이스
## 특징
- 데이터: 물리망 수집 데이터를 통합 저장소에 보관·적시 모델 제공
- 매핑: 물리–가상 실시간 양방향 매핑
- 모델: 다양한 모델을 유연 결합해 응용 지원
- 인터페이스: 물리↔트윈, 트윈↔애플리케이션(intent) 연동
## 목적
- 6G NW의 실시간 최적화·제어
- AI/ML로 설계·진단·분석 효율화
## 구성요소
- Physical Layer: 6G 물리 요소·환경, 데이터·제어 메시지 교환
- Twin-데이터 도메인: 수집·저장·서비스·관리
- Twin-모델 도메인: 수집 데이터 기반 물리 객체 모델화
- Twin-관리 도메인: 모델·보안 관리
- Application Layer: Intent로 서비스 에뮬레이션, 필요 시 물리층 제어
- 기능-데이터/모델/인터페이스: 수집시점·저장·AI 에뮬레이션·멀티벤더 상호운용
## 구성도
```
[Network Application] Intent / Capability
        ↕
[Digital Twin Layer]
  Unified Data Repo | Functional/Basic Models
        ↕ Data/Control
[Physical Network] Router·Switch·Satellite·UE
```
