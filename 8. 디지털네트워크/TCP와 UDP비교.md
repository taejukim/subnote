## TCP 제어플래그
1. URG(Urgent) :  송신측 상위 계층이 긴급데이터라고 알려주면, 긴급비트 URG를 1로 설정하고 순서에 상관없이 먼저 송싱
2. ACK(Acknowledgement) : 확인응답 필드에 확인 응답번호 값이 세팅되었음을 알림
3. PSH(Push) : 수신 측은 버퍼가 찰 때까지 기다리지 않고, 수신 즉시 버퍼링 된 데이터를 응용프로그램에 전달
4. RST(RESET) : 연결확립된 회선에 강제 리셋 요청
5. SYN(Synchronize) : TCP 연결설정 초기화를 위한 순서번호와 동기화
6. FIN(Finish) : 송신기가 데이터 보내기를 끝마침
