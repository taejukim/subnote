#정보관리기술사 #디지털네트워크 #QoS #디지털네트워크/QoS
Quality of Service
## 정의
- 한정된 네트워크 망의 대역폭을 효율적으로 사용하게 하고, 네트워크 트래픽을 정책별로 제어하여 인터넷 종단간 서비스 품질을 향상 시키는 기술

## 암기법
- 주요지표
	- 대지터패 : 대역폭, 지연, 지터, 패킷 손실
## 키워드
- 대역폭, 지연, 지터, 패킷손실, 자원예약, RSVP, 우선순위, DSCP

## 주요 지표
| **주요 지표**      | **설명**                            |
| -------------- | --------------------------------- |
| **대역폭**        | - 네트워크 또는 채널이 처리 가능한 최대 데이터 처리 능력 |
| **지연**         | - 신호가 통신망을 지날 때 주파수에 따라 겪는 시간 지연  |
| **지터(Jitter)** | - 디지털 펄스 신호 파형이 시간축 상으로 흐트러지는 현상  |
| **패킷 손실**      | - 송수신 패킷이 목적지까지 왕복하며 발생하는 데이터 유실  |
## 관리기술

| 구분               | 기술 요소                        | 상세 설명                                             |
| ---------------- | ---------------------------- | ------------------------------------------------- |
| 데이터 Path 매커니즘    | 패킷 분류기, 표시기, 미터, 폐기처리기, 쉐이퍼  | - 다양한 서비스로 제공할 수 있도록 라우터가 개별 패킷들을 처리하는 일련의 과정     |
| 트래픽 쉐이핑(Shaping) | Leaky Bucket                 | - 인입 트래픽을 버킷에 저장한 후 버킷 속도 평준화 제어                  |
|                  | Token Bucket                 | - 토큰 형태 Credit 사용하여 Token 유무에 따른 트래픽 제어           |
| 혼잡제어             | RED (Random Early Detection) | - 혼잡 발생 전 미리 랜덤 방식으로 패킷 폐기해서 혼잡 상황 제어             |
|                  | WRED (Weighted RED)          | - 다른 클래스 트래픽에 서로 다른 가중치 부여하여 RED함수 적용, 서비스 차별성 유지 |
| 수락제어             | 전송 정책                        | - 어떤 트래픽을 전송할지 결정 정책                              |
| 큐잉(Queuing)      | FIFO Queuing                 | - 하나의 큐에 모든 클래스 트래픽 저장                            |
|                  | Priority Queuing             | - 여러 개의 FIFO큐 사용. 각각의 큐가 서로 다른 트래픽 클래스에 매핑        |
|                  | WFQ (Weighted Fair Queuing)  | - 가중치가 부여된 RR(Round Robin) 스케줄링 방식, 대역폭 예약 기반     |
