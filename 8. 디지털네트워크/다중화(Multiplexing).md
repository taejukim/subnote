#정보관리기술사 #디지털네트워크 #다중화 #디지털네트워크/OSI/프로토콜
## 정의
- 여러 신호를 동시에 송수신할 수 있또록, 하나의 전송로를 분할시켜, 다수의 채널로 분할하여 전송하는 기술
## 키워드
- FDM, TDM, SDM, CDM, WDM

## 다중화와 다원접속 비교
| **구분**   | **다중화 (Multiplexing)**                   | **다원접속 (Multiple Access)**            |
| -------- | ---------------------------------------- | ------------------------------------- |
| **목적**   | - 전송매체의 효율적 이용<br>- 통신비용 절감              | - 한정된 자원의 공동 이용<br>- 사용자의 구분          |
| **송신측**  | - 데이터 송신 지점이 한 곳<br>- 동일 지점에서 데이터를 모아 송출 | - 데이터 송신 지점이 여러 곳<br>- 독립된 각 터미널에서 송출 |
| **다중화**  | - 단일 송신국에서 신호가 다중화되어 발신                  | - 여러 단말기 신호가 다중화되어 발신                 |
| **기술유형** | - FDM, TDM, CDM, WDM, SDM                | - FDMA, TDMA, CDMA, WDMA              |
| **전파방향** | - 하향 Down-LINK                           | - 상향 UP-LINK                          |
## 다중화 종류
| **종류**        | 개념도                                       | **설명**                                                                 |
| ------------- | ----------------------------------------- | ---------------------------------------------------------------------- |
| **FDM** (주파수) | ![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260325225018.png\|300]] | - 공통 채널을 효율적으로 이용하기 위해, 전송매체를 **주파수 분할**로 전송<br>- 넓은 대역폭을 나눠서 사용       |
| **TDM** (시간)  | ![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260325225041.png\|300]] | - **시간분할 된 타임슬롯**을 전송하는 방식<br>- 하나의 회선을 시간간격으로 분할                      |
| **CDM** (코드)  | ![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260325225057.png\|300]] | - **상호 직교성**이 있는 코드를 이용하여 전송하는 방식<br>- 확산 대역(Spread Spectrum)을 사용하여 전송 |
| **WDM** (파장)  | ![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260325225108.png\|300]] | - 손실이 적은 주파수 대역 이용<br>- **파장이 다른 광 신호**를 한 가닥의 광섬유에 다중화                |
| **SDM** (공간)  | ![[1. ITPE/0. Sub-Note/99.attached_file/Pasted image 20260325225122.png\|300]] | - 공간적으로 분리된 다수의 물리 채널을 마치 하나의 채널인 것처럼 만들어진 **논리적 채널**로 전송              |
