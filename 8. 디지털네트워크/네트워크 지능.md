#정보관리기술사 #디지털네트워크 #네트워크지능 #AI #NEW
## 정의
네트워크 지능(Network Intelligence)
- AI로 NW 제어·운용·관리를 수행하며 자율 의사결정 기반의 완전 자동 운영 네트워크
- Closed-Loop로 수집→분석→결정→피드백을 반복
## 키워드
* SDN/VNF, AI/ML, 클라우드·엣지, OAM, MANO
## 암기법
* 폐순제: 폐쇄형 순환 제어(수집·분석·결정·피드백)
## 특징
- 지능 계층: Open AI/ML 서비스로 예측·자가결정·빅데이터 분석
- 가상화 계층: Network Slice·VNF 인스턴스와 상태/이벤트 DB
- 인프라 계층: 물리 Computing/Network 자원
- 오케스트레이션: MANO/SON·OAM(OSS/BSS/NMS) 연계
## 목적
- NW의 완전 자동화·최적화 운영
- 장애 예측·서비스 요구사항 보장
## 구성요소
- AI/ML: 상태·이벤트·로그 수집, 환경·품질 기반 분석 모델 결정
- 빅데이터 분석: 대용량·다양·고속 데이터 수집·통계
- 클라우드/엣지 가상화: AI 플랫폼용 유연 자원 배치
- SDN/NFV: 실시간 정책·소프트웨어형 NW 기반
- Closed-loop: 자동 수집→AI분석→자율결정→피드백
- OAM/MANO: 결정·정책을 물리·가상 자원에 실시간 반영
## 구성도
```
[AI/ML Engine]  ← Prediction / BigData Analytics
       │ Closed-Loop Control
[Virtualized: Slice + VNF + State DB]
       │
[Physical: Router/Switch/Server]
   ↔ MANO/SON + OAM(OSS/BSS/NMS)
```
