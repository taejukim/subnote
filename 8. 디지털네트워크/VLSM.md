#정보관리기술사 #디지털네트워크 #VLSM #서브넷팅
## 정의
VLSM(Variable Length Subnet Mask)
- 하나의 네트워크를 다양한 길이의 서브넷 마스크로 나누어 IP 주소를 효율적으로 사용하는 가변 길이 서브넷팅 기법
- 필요 호스트 수에 맞춰 서브넷 크기를 가변적으로 할당하는 IP 설계 기법
## 키워드
* CIDR, Subnet Mask, Subnetting, IP 효율화, Class 기반, 호스트 분배
## 암기법
* 필호서브사: 필요 NW·호스트·서브넷마스크·브로드캐스트·사용호스트
## 특징
- 가변성: 서브넷별 다른 마스크 길이
- 효율성: 호스트 수에 맞춘 IP 할당
- 계층성: 라우팅 요약(Summary) 가능
- 호환성: CIDR 기반 라우팅 통합
## 목적
- IPv4 주소 자원 절약과 효율적 분배
- 네트워크 설계 유연성과 라우팅 최적화
## 구성요소
- 서브네팅: 하나의 네트워크 클래스를 여러 NW 세그먼트로 분리
- 절차: 필요 NW 정의 → HostID/NWID 결정 → Subnet Mask 계산 → Broadcast 주소 → Subnet Mask → 사용 가능 Host 계산
- CIDR: /24, /25, /26 등 가변 표기
- 라우팅 통합: Route Summarization
## 구성도
```
[/24 네트워크 256개 IP]
   ├── /26 (64개) → 서브넷 A (50 호스트)
   ├── /27 (32개) → 서브넷 B (20 호스트)
   ├── /28 (16개) → 서브넷 C (10 호스트)
   └── /30 (4개) ×N → P2P 링크
```
