## 정의
알고리즘 성능평가
- 알고리즘 수행에 필요한 시간 및 공간을 지표로 성능을 판단하는 과정
## 키워드
* 시간복잡도, 공간복잡도, 점근적 성능표기법
## 암기법
* 분석측정효율 / OΩΘ: 성능분석·측정·효율평가 / Big-O·Omega·Theta
## 특징
- 성능분석: 구현 없이 연산 횟수(함수 of n)로 복잡도 비교
- 성능측정: 동일 HW에서 실제 수행시간 측정
- 효율: 시간(기본연산 수, 컴파일+실행) / 공간(고정+가변), 시간-공간 trade-off
## 목적
- 알고리즘의 시간·공간 효율을 객관적으로 비교·선택
## 구성요소
- O: 점근 상한(최악) / Ω: 점근 하한(최선) / Θ: 상·하한 동시
- 예: sum=n*n → 2회 / for n회 → 2n / 이중 for → 2n²
## 구성도
```
성능평가
 ├─ 분석(복잡도) ─ 시간·공간
 ├─ 측정(실측 시간)
 └─ 표기 O / Ω / Θ
```
## 연관 토픽

- [[병합 정렬]] - O(n log n)
- [[해시 테이블]] - 평균 O(1) 탐색
