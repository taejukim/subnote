## 정의
빔 탐색(Beam Search)
- 그리디의 최적해 미보장 단점을 보완하기 위해, 매 단계 최선 1개가 아니라 Beam Size(K)개의 유력 후보를 유지하는 최적해 탐색 알고리즘
## 키워드
* 최적해 미보장 단점 보완, 최적해, Beam size
## 암기법
* K유확최: K선택·확장·K재선택·최종
## 특징
- 폭(BFS)과 탐욕의 절충, K로 메모리·품질 조절
- Seq2Seq 디코딩 등에 활용
## 목적
- 단일 경로 그리디보다 높은 확률의 최종 서열/해 탐색
## 구성요소
- ① 문제·제약 정의 ② 최초 K개 해 선택 ③ 부분해 확장·Score ④ 상위 K만 유지·반복 ⑤ 최종 최고 점수 선택
## 구성도
```
START → (상위K) → 확장·가지치기 → … → END
NLP예 Beam=2: 경로별 확률 누적 후 최댓값 선택
```
