## 정의
런랭스 코딩(Run Length Encoding)
- 연속 동일 값을 반복 횟수(Length)와 값(Run)만으로 표현하는 데이터 압축 알고리즘
## 키워드
* 무손실 압축, RUN, LENGTH
## 암기법
* 길런: Length + Run
## 특징
- 연속 반복이 많을수록 유리
- 단일값 변화가 잦으면 압축률 급락
- 비반복 구간은 그대로 두고 반복만 코딩 가능
## 목적
- 연속 동일 데이터의 저장·전송량 축소
## 구성요소
- 예1: AAAABBBBB… → 4A5B8C1D5E (LENGTH,RUN 순)
- 예2: 비반복은 그대로, 반복만 *8D*9E 형태
## 구성도
```
평문 연속구간 → (Length, Run) 쌍 → 압축문
```
