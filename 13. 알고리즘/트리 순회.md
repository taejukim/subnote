## 정의
트리 순회(Tree Traversal)
- 계층 구조 트리의 모든 노드를 한 번씩 체계적으로 방문하는 과정
## 키워드
* 전위 순회, 중위 순회, 후위 순회
## 암기법
* 전중후: Root-L-R / L-Root-R / L-R-Root
## 특징
- 재귀로 구현, 수식 표기(전위·중위·후위)와 대응
## 목적
- 트리 전체 노드의 체계적 방문·처리
## 구성요소
- Pre: Visit → Left → Right (Prefix)
- In: Left → Visit → Right (Infix)
- Post: Left → Right → Visit (Postfix)
## 구성도
```
    Root
   /    \
 Left   Right
전: R→L→R / 중: L→R→R / 후: L→R→R(루트마지막)
```
