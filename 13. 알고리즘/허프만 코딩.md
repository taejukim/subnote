## 정의
허프만 코딩(Huffman Coding)
- 자주 나오는 데이터에 짧은 부호, 드문 데이터에 긴 부호를 할당하는 가변 길이 부호화로 전체 길이를 압축하는 기법
## 키워드
* 무손실 압축, 빈도, 통계적 기법, 엔트로피
## 암기법
* 정연배코: 정렬·연결·0/1배정·코드할당
## 특징
- 무손실, 빈도 기반 최적 접두어 코드
- DEFLATE(PKZIP), JPEG·MP3 등에 활용
## 목적
- 출현 빈도 차이를 이용해 비트 길이 최소화
## 구성요소
- ① 빈도 내림차순 정렬 ② 최소빈도 둘부터 이진 결합 반복 ③ 높은쪽 0 배정 ④ 문자별 코드
- 예: A:0 B:10 C:110 D:111, 18B→35bit
## 구성도
```
빈도표 → Huffman Tree(0/1) → 가변코드 → 압축비트열
```
