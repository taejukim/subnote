## 정의
버블 정렬(Bubble Sort)
- 데이터 집합을 순회하며 이웃 요소끼리 비교·교환하여 정렬하는 방식
## 키워드
* 인접 원소 비교, 거품, 완전 정렬, O(n²), 위치 교환
## 암기법
* 비교교환·뒤에서부터 확정
## 특징
- 한 패스마다 최대(또는 최소)가 끝으로 이동(버블링)
- 구현 단순, O(n²)로 대용량 부적합
## 목적
- 인접 비교로 완전 정렬 수행
## 구성요소
- 인접 A[i]·A[i+1] 비교, 역순이면 Swap
- 패스마다 끝쪽 정렬 확정, 나머지만 반복
- 예 [7,5,3,2]: 1회→…7확정 / 2회→5확정 / 3회→[2,3,5,7]
## 구성도
```
시작 [7,5,8,3,9]
1단계 … |9 확정 → 2단계 …|8,9 → … → [3,5,7,8,9]
진행→ / 정렬완료←
```
