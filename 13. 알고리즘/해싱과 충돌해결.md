## 정의
해싱과 충돌해결
- 키에 해시함수를 적용해 주소를 계산하고 해당 위치에 직접 접근하는 방법과, 동일 주소 충돌을 처리하는 기법
## 키워드
* 나눗셈·폴딩·중간제곱·기수변환·자릿수분석·난수 / 개방·폐쇄 주소
## 암기법
* 나폴리는 중세기다: 나눗셈·폴딩·중간제곱·기수·자릿수·난수
* 선이중무 체코: 선형·이차·이중·재해싱 / 체이닝·병합체이닝
## 특징
- 해싱: 빠른 탐색을 위한 주소 계산
- 개방주소: 테이블 내 빈 슬롯 탐색
- 폐쇄주소: 버킷 밖(리스트 등)으로 연결
## 목적
- 충돌을 제어하며 해시 기반 고속 접근 유지
## 구성요소
- 해싱: Division(%), Folding, Mid-Square, Radix, Digit-Analysis, Pseudo-Random
- 개방: Linear / Quadratic / Double Hashing / Rehashing
- 폐쇄: Hash Chaining, Coalesced Hashing
## 구성도
```
Key → Hash → Home Address
충돌 → 개방(다음슬롯) | 폐쇄(체이닝)
```
